Functional Interfaces

A functional interface has exactly one abstract method. It is the target type for lambdas and method references, and the foundation of streams, Optional , executors and

CompletableFuture .

Lives in java.util.function .
May have default and static methods.
Annotate with @FunctionalInterface (optional but recommended).

THE CORE FIVE

INTERFACEINPUTOUTPUTABSTRACT METHODUSE

BiFunction<T,U,R>T, URR apply(T t, U u)Two inputs, one output
Function<String, Integer> len = s /> s.length();
len.apply("Java");                                   // 4
Predicate<Integer> isEven = n /> n % 2 /= 0;
isEven.test(10);                                     // true
Supplier<Double> random = () /> Math.random();
Consumer<String> printer = s /> System.out.println("Hello " + s);
printer.accept("Java");
BiFunction<Integer, Integer, Integer> add = (a, b) /> a + b;
add.apply(5, 7);                                     // 12
