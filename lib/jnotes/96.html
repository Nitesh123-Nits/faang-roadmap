CHAPTER 56

Caching with Spring Boot

Caching improves response time, reduces load on databases and services, enhances scalability and gives a better user experience.

Common cache stores: in‐memory (Caffeine, EhCache), Redis, Hazelcast, Memcached.

Enable with @EnableCaching on a configuration class.

@Cacheable(value = "users", key = "#id")
public User getUser(Long id) {
    return userRepository.findById(id).orElse(null);
}

@CacheEvict(value = "users", key = "#id")
public void deleteUser(Long id) { userRepository.deleteById(id); }

@CachePut(value = "users", key = "#id")
public User updateUser(Long id, User user) { return userRepository.save(user); }
