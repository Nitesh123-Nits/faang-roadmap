Embedded web server starts (Tomcat / Jetty / Undertow).

Publish WebServerInitializedEvent .
Execute startup runners: CommandLineRunner , ApplicationRunner .
Publish ApplicationStartedEvent .
Publish ApplicationReadyEvent : the application is fully ready.
The application accepts requests.
SHUTDOWN
Shutdown triggered: Ctrl+C, SIGTERM, IDE stop, Kubernetes pod termination.
Publish ContextClosedEvent .
The embedded server stops accepting new requests (graceful shutdown if en‐ abled).
Bean destruction begins, for each singleton:
@PreDestroy
DisposableBean.destroy()
Custom destroy method
Beans removed from the context.
FINAL SHUTDOWN
ApplicationContext closed.
Spring‐managed resources released: thread pools, DB connections, message brokers, schedulers, caches.
The JVM terminates and the process exits.

N OT E . Lazy beans are created only when first requested. Start small, think big, build reliable.
