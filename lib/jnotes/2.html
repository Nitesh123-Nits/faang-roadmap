EQUALITY

/= compares references; equals() compares content.
If two objects are equals() , they must return the same hashCode() . The hash picks the

bucket, equals() confirms the match.

Override both together, or neither.

FINAL, FINALLY, FINALIZE

KEYWORDWHAT IT ISEFFECT
finalModifierVariable cannot be reassigned, method cannot be overridden, class cannot be inherited
finallyBlockAlways runs after try/catch, used for cleanup
finalize()MethodCalled by the GC before reclaiming an object; deprecated, never rely on it
final int MAX_SIZE = 10;

try {
    process();
} finally {
    cleanup();   // runs whether or not process() throws
}

R E M E M B E R . Prefer try-with-resources over finally for closing resources, and

treat finalize() as history.
