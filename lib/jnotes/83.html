STEP BY STEP

The client sends an HTTP request.
The request goes through the Filter Chain ( doFilter ) at the Servlet level.
DispatcherServlet (the front controller) receives the request and finds the hand‐

ler through HandlerMapping , then prepares the execution chain (interceptors + controller).

Interceptors execute preHandle() in order.
The controller handles the request and returns the response.
Interceptors execute postHandle() in reverse order, then afterCompletion() .
The response travels back through the filter chain (the finally portion of each filter).
The response is sent to the client.
