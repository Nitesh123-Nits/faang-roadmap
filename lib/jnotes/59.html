CHAPTER 37

Tomcat Thread Pool: Real-World Notes

Understanding default size, tuning, scaling, and when to go reactive.

THE BLOCKING MODEL (SPRING MVC + TOMCAT)

1 request = 1 thread. While a thread waits on I/O (database, Redis, external API, file), it stays blocked and cannot serve other requests.

DEFAULT SIZE

server.tomcat.threads.max=200     # default

About 200 concurrent blocking requests per instance. After that, requests queue (accept count) and latency rises.

WHY 200?

TOO FEW THREADSTOO MANY THREADS
Low throughput, requests wait in aHigh context switching, high memory, GC pressure,

200 is a safe default balance for general‐purpose apps.
