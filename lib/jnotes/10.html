KEY POINTS

Throwable is the root of the hierarchy. Only its subclasses can be thrown.
Error represents serious JVM problems and is generally not handled.
Exception represents conditions an application can handle.
RuntimeException and its subclasses are unchecked.
All other Exception subclasses are checked.
throw new Throwable();          // valid
throw new Exception();          // valid, checked
throw new RuntimeException();   // valid, unchecked
throw new Error();              // valid, but rarely appropriate

R E M E M B E R . Use checked exceptions when the caller can realistically recover.

Use unchecked exceptions for programmer errors and violated preconditions. Never catch Throwable or Error in application code.
