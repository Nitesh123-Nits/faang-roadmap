Scopes other than singleton behave differently in multi‐threaded environments.
For web scopes (request, session, application, websocket), use a scoped proxy

( proxyMode = ScopedProxyMode.TARGET_CLASS ) when injecting into a singleton.

Prototype beans are not destroyed by the container; handle cleanup yourself.
Choose scope based on the lifecycle you need.

BEST PRACTICES

Use singleton for stateless services and components.
Use prototype for stateful or expensive‐to‐share objects.
Use request/session scope for web‐specific data.
Avoid storing state in singleton beans (not thread‐safe).
Keep scope as small as necessary.
