Garbage Collection

GC automatically reclaims memory that is no longer reachable. Its goals: reclaim memory, reduce leaks, keep applications stable.

Reachability starts from GC roots: local variables in active methods, active threads, static variables, JNI references, system class references, monitor‐locked objects. Any‐ thing reachable from a root is alive; everything else is garbage.

YOUNG GENERATION FLOW

New objects are allocated in Eden.
When Eden is full, a Minor GC runs.
Live objects move to a Survivor space (S0), and survivors alternate between S0 and S1.
Objects that survive enough cycles are promoted to the Old Generation.
