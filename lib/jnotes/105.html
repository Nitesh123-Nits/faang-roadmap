STEPS

The client calls a protected endpoint: GET /api/orders with Authorization: Bearer <token> . The request reaches the JWT filter ( OncePerRequestFilter ) before the controller. Read the Authorization header. If it is missing or does not start with Bearer , continue the filter chain (the request will be rejected later as unauthenticated). Extract the token ( header.substring(7) ). Validate the token: signature, expiry, structure, issuer/audience if used. Extract the username and load the user details. Create an authentication token with the user's authorities. Set it in the SecurityContext . Continue the filter chain; the controller runs and returns a response.
