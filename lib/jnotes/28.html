ArrayList vs LinkedList

Both implement List , allow duplicates, maintain insertion order, and are not thread- safe. Their internals decide everything else.

ArrayList is a resizable array in contiguous memory.
LinkedList is a doubly linked list; each node holds prev , data , next .

When an ArrayList is full it grows its internal array (typically by about 1.5x), which is O(n) but rare, hence "amortised" O(1).

USE ARRAYLIST WHEN

Random access matters, reads dominate, the size is mostly stable, or memory efficiency counts. It is the right default.

USE LINKEDLIST WHEN

You do frequent insertions and deletions at the ends or via an iterator, and implement stacks, queues or deques, an LRU cache (with HashMap ), browser history or playlists.
