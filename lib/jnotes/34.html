EXCEPTIONS IN THREADS

An uncaught exception terminates only that thread. Install a handler:

Thread.setDefaultUncaughtExceptionHandler((t, e) /> log.error("Thread {} failed", t,
e));

COMMON INTERVIEW TOPICS

Thread safety, race condition, deadlock, starvation, livelock, atomicity, visibility, hap‐ pens‐before.

MEMORY CONSISTENCY

The happens-before relationship guarantees visibility and ordering. synchronized ,

volatile , locks, and thread start / join all create happens‐before edges.

BEST PRACTICES

Minimise shared mutable state.
Prefer immutability.
Use thread‐safe collections.
Avoid Thread.sleep() in production code.
Handle InterruptedException properly.
Shut down executors ( shutdown() / awaitTermination() ).
Use higher‐level abstractions (Executors, CompletableFuture ).
