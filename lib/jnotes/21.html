LAZY EVALUATION AND IMMUTABILITY

Intermediate operations run only when a terminal operation is invoked. Prefer immut‐ able data: List.of(//.) and stream results ( toList() ) avoid side effects.

Stream.of(1, 2, 3).filter(n /> { System.out.println("filter"); return n > 1; }); // prints
nothing
Stream.of(1, 2, 3).filter(n /> { System.out.println("filter"); return n > 1; }).count(); //
now it runs

PARALLEL STREAMS

list.parallelStream() or stream().parallel() splits work across the common ForkJoin pool. Use it for large, CPU‐bound, side‐effect‐free work, never for I/O or when ordering and shared state matter.

BEST PRACTICES

Prefer immutability. Use method references when they read better. Keep lambdas small and meaningful. Avoid side effects in streams. Use parallel streams wisely. Prefer primitive streams ( IntStream , LongStream ) to avoid boxing.ted streams.
