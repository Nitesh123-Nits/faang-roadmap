Filter runs before and after DispatcherServlet ; it is part of the Servlet API. Inter- ceptor runs inside Spring MVC, around the controller.

INTERCEPTOR METHODS

METHODWHEN
preHandle(req, res, handler) returns booleanBefore the controller. Return true to continue
postHandle(req, res, handler, mav)After the controller, before view rendering
afterCompletion(req, res, handler, ex)After request completion. Always executed

NOTES

Multiple filters run in order of registration ( web.xml or @Order ).
Multiple interceptors run in order of registration ( InterceptorRegistry ).
If any preHandle() returns false , the request does not go to the controller.
afterCompletion() is always called regardless of success or failure of the hand‐

ler.
