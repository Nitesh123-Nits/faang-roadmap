@Async

Runs a method asynchronously in a separate thread so the caller is not blocked.

Why: improve responsiveness, run time‐consuming work in the background, use resources better, fire‐and‐forget operations.

Caller thread

calls @Async method

runs on TaskExecutor thread pool

ENABLE ASYNC SUPPORT
@SpringBootApplication
@EnableAsync
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}
