HOW A SAVE WORKS

The application calls entityManager.persist(user) .
JPA defines the operation (it is an interface, not an implementation).
Hibernate receives it, checks the persistence context (first‐level cache), and performs dirty checking and entity state management.
Hibernate generates SQL from the mappings: INSERT INTO users (name) VALUES (?) .
Hibernate uses JDBC ( PreparedStatement ) to send the SQL.
The database executes it and stores the row.
The result returns through JDBC to Hibernate, which maps it back to entities.
