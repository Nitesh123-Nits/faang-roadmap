TYPICAL USAGE

package com.example;

@SpringBootApplication
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}

Place this class in the root package so @ComponentScan covers all sub‐packages.

com.example
├── Application.java        (@SpringBootApplication)
├── service/UserService.java       (@Service)
├── controller/UserController.java (@RestController)
└── repository/UserRepository.java (@Repository)

INTERVIEW CHEAT SHEET

@SpringBootApplication = combination of three annotations.
@Configuration → Java configuration class.
@EnableAutoConfiguration → automatic configuration based on dependencies.
@ComponentScan → finds Spring‐managed components.

Usually placed in the root package so all sub‐packages are scanned.

It is the main entry point of every Spring Boot application.
