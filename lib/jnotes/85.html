JSON TO JAVA OBJECT AND BACK

CHAPTER 51

JSON to Java Object and Back

How Spring Boot converts a request body into an object and a return value into a response.

REQUEST FLOW: JSON → JAVA OBJECT

The client sends POST /users with Content-Type: application/json and a JSON body.
The servlet container (Tomcat) receives it and passes it through any filters.
DispatcherServlet , the central front controller, receives it.
HandlerMapping finds the matching controller method.
HandlerAdapter ( RequestMappingHandlerAdapter ) invokes the controller.
RequestResponseBodyMethodProcessor detects @RequestBody .
It delegates to a HttpMessageConverter chosen by the Content-Type .
MappingJackson2HttpMessageConverter uses Jackson's ObjectMapper .
ObjectMapper.readValue(json, User.class) deserialises the JSON.
The Java object is created and passed to your controller method.
@PostMapping("/users")
public User createUser(@RequestBody User user) {
    // business logic; `user` is already a Java object
    return user;
}

RESPONSE FLOW: JAVA OBJECT → JSON

The controller returns an object.
HandlerAdapter hands it to RequestResponseBodyMethodProcessor , because @ResponseBody (implicit with @RestController ) is present.
A suitable HttpMessageConverter is selected based on the Accept header andContent-Type .
MappingJackson2HttpMessageConverter calls ObjectMapper.writeValueAsString() .
A JSON string is created and written to the HTTP response ( 200 OK , application/json ).
