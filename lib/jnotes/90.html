The handler builds the standardised error response.

The response is sent back to the client.

COMMON EXCEPTION MAPPING

EXCEPTIONHTTP STATUSWHEN TO USE
ResourceNotFoundException404 Not FoundResource not found
MethodArgumentNotValidException400 Bad RequestValidation failed
IllegalArgumentException400 Bad RequestInvalid input
AccessDeniedException403 ForbiddenNo permission
DataIntegrityViolationException409 ConflictDB constraint violation
Exception (fallback)500 Internal Server ErrorUnexpected errors

BEST PRACTICES

Return meaningful messages, not stack traces.
Log the exception with the proper level, but do not expose internals to clients.
Use custom exceptions for business errors.
Keep the error response format consistent.
Use @RestControllerAdvice for REST APIs and @ControllerAdvice for MVC views.
Order multiple handlers with @Order if needed.
