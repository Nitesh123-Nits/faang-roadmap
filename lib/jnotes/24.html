Collectors.toMap()

Collectors.toMap() is a terminal collector that turns a stream into a Map using

functions that extract each key and value.

OVERLOADS

OVERLOADWHEN TO USE
toMap(keyMapper, valueMapper)Keys are unique. Duplicate key throws IllegalStateException
toMap(keyMapper, valueMapper, mergeFunction)Duplicate keys need custom handling
toMap(keyMapper, valueMapper, mergeFunction,You also need a specific Map type
mapSupplier)

SIMPLE

Map<Integer, String> map = list.stream()
    .collect(Collectors.toMap(Emp/:getId, Emp/:getName));
// {1=Alice, 2=Bob, 3=Charlie}

HANDLING DUPLICATE KEYS

Map<String, List<String/> byDept = list.stream()
    .collect(Collectors.toMap(
        Emp/:getDept,
        e /> new ArrayList/>(List.of(e.getName())),
        (existing, incoming) /> { existing.addAll(incoming); return existing; }));
// {IT=[Alice, Charlie], HR=[Bob]}

CUSTOM MAP (PRESERVE ORDER)

Map<Integer, String> ordered = list.stream()
    .collect(Collectors.toMap(
        Emp/:getId, Emp/:getName,
        (a, b) /> a,
        LinkedHashMap/:new));

DUPLICATE KEY WITHOUT A MERGE FUNCTION

java.lang.IllegalStateException: Duplicate key IT
(attempted merging values Alice and Charlie)

COMMON MERGE FUNCTIONS

LAMBDAEFFECT
(a, b) /> aKeep existing value
(a, b) /> bKeep new value
(a, b) /> a + bConcatenate strings or add numbers
(a, b) /> Math.max(a, b)Keep the maximum
COLLECTORS.TOMAP()

P R O T I P S . Always handle duplicate keys explicitly in real applications. Use a

merge function that is associative and stateless. Prefer LinkedHashMap/:new to preserve order and TreeMap/:new for sorted keys. toMap also throws a

NullPointerException on null values.
