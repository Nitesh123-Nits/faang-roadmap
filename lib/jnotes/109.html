KEY CONCEPTS

CONCEPTMEANING
ORMMaps Java objects to database tables
Persistence context (1st-Hibernate keeps loaded entities in memory within a session
level cache)
Entity statesTransient (new), Persistent (managed), Detached, Removed
Dirty checkingHibernate detects changes to managed entities and updates the DB on transaction commit
Lazy loadingRelated data is loaded only when accessed
TransactionsEnsure data consistency, usually managed by the container (@Transactional)

TYPICAL LAYERED ARCHITECTURE

LAYERSPRING COMPONENT
Presentation@RestController / Spring MVC
Service (business logic)@Service classes, use JPA (EntityManager)
PersistenceJPA API + Hibernate (ORM provider)
JDBCjava.sql.*
DatabaseMySQL / PostgreSQL / Oracle / SQL Server

I N T E RV I E W Q U I C K P O I N T S . JPA is a specification (API); Hibernate is an imple-

mentation (provider). We code against JPA APIs; Hibernate does the actual work. JDBC is the low-level way to talk to the database. ORM simplifies DB access by using Java objects instead of SQL directly.
