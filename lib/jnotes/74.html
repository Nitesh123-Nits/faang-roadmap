Spring Boot Starters

A starter is a convenient dependency descriptor that brings in all the transitive dependencies you need for a particular feature. One dependency to rule them all.

WHY STARTERS

Simplify dependency management.
Bring in compatible versions.
Reduce the need to specify many dependencies.
Provide sensible defaults.
Keep your build clean and readable.

NAMING CONVENTION

spring-boot-starter/<feature> . Add spring-boot-starter-web and Boot adds Tom‐

cat, Spring MVC, Jackson, the Validation API and more.

<dependency>
    <groupId>org.springframework.boot//groupId>
    <artifactId>spring-boot-starter-web//artifactId>
//dependency>
