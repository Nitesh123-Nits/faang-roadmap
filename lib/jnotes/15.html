STOP-THE-WORLD

During some phases all application threads pause: marking, re‐marking, final mark, cleanup. Modern collectors aim to reduce pause time while keeping throughput high.

G1 PHASES

Young GC (minor): collect Eden and Survivor.
Concurrent mark: mark reachable objects.
Remark (STW): finalise marking.
Cleanup: reclaim memory.
Evacuation / mixed GC: collect from Old Gen regions.

GOOD PRACTICES

Set -Xms equal to -Xmx in production.
Use G1 for most applications.
Monitor GC logs and pause times.
Avoid creating unnecessary objects.
Use object pooling carefully; it is not always helpful.
Fix memory leaks: static collections, listeners.
Keep dependencies and frameworks up to date.

R E M E M B E R . Minor GC = young generation, frequent. Major/Full GC = old gener-

ation, rare but impactful. Always benchmark and test after tuning: there is no one-size-fits-all setting.
