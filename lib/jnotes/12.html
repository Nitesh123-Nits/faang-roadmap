CHAPTER 08

JVM Architecture

The JVM has three major subsystems and a bridge to native code.

Class Loader → Runtime Data Areas→ Execution Engine → Native Interface (JNI)
SUBSYSTEMRESPONSIBILIT Y
Class LoaderLoads, links and initialises classes into memory
Runtime Data AreasHolds all runtime data
Execution EngineExecutes bytecode
JNI and Native LibrariesLets Java call C/C++ code

RUNTIME DATA AREAS

AREASCOPESTORES
Method AreaSharedClass metadata, constant pool, static data
HeapSharedObjects and arrays (GC works here)
Java StackPer threadFrames: method calls and local variables
PC RegisterPer threadAddress of the current instruction
Native Method StackPer threadFrames for native (C/C++) methods

EXECUTION ENGINE

Interpreter executes bytecode line by line.
JIT compiler compiles hot code to native machine code for speed.
Garbage collector reclaims memory from unreachable objects.
