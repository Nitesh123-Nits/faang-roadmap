CHAPTER 66

Database Connection Pooling

Opening a database connection is expensive. A pool reuses connections so each request does not pay that cost.

WHY A CONNECTION IS EXPENSIVE

STEPAPPROXIMATE COST
TCP handshake~1 ms
TLS negotiation~5 ms
DB authentication~3 ms
Session setup~1–2 ms
Total~10 ms+

At 1,000 requests per second, opening a connection per request wastes about 10 seconds of work every second. Each connection also consumes a thread on the DB server.

RECOMMENDED POOL SIZE (POSTGRESQL GUIDANCE)

pool_size = (CPU cores × 2) + effective_spindle_count

Example: a 4‐core machine with SSD gives a pool of about 9 to 10, enough for most cases.

MORE CONNECTIONS = MORE CONTENTION, LESS THROUGHPUT. Abiggerpoolis

not a faster pool.
