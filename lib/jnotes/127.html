HOW IT FLOWS

2. 3. 4. 5. 6.

Synchronous code runs in the call stack until it is empty. Async operations are offloaded to Web APIs. When an async operation completes, its callback is added to the callback queue. If the call stack is empty, all microtasks run first. Then the next callback from the callback queue is moved to the call stack. The loop repeats forever.
