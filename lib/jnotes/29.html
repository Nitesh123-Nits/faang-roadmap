HashSet vs TreeSet

Both implement Set and store unique elements. The difference is how elements are stored, ordered and accessed.

FEATUREHASHSETTREESET
Data structureHash table (backed by HashMap)Red-black tree (backed by TreeMap)
OrderingNone (arbitrary)Sorted, ascending (natural or Comparator)
Null elementOne null allowedNot allowed (NPE)
DuplicatesNot allowedNot allowed
add / remove / containsO(1) averageO(log n)
Worst caseO(n) with many collisionsO(log n)
MemoryLowerHigher (tree nodes)
InterfacesSetNavigableSet, SortedSet, Set

TREESET NAVIGATION OPERATIONS

first() , last() , lower(e) , floor(e) , higher(e) , ceiling(e) , pollFirst() , pollLast() , subSet(a, b) , headSet(b) , tailSet(a) .

Set<Integer> tree = new TreeSet/>();
tree.add(30); tree.add(10); tree.add(20); tree.add(10);   // duplicate ignored
System.out.println(tree);   // [10, 20, 30]

Set<Integer> hash = new HashSet/>();
hash.add(30); hash.add(10); hash.add(20);
System.out.println(hash);   // order not guaranteed
