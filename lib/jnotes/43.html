COUNTDOWNLATCH VS CYCLICBARRIER

CHAPTER 28

CountDownLatch vs CyclicBarrier

Both coordinate threads; they answer different questions.

CountDownLatch: "wait until a set of operations completes." Think of a count‐

down timer.

CyclicBarrier: "everyone wait for each other at a point, then proceed together."

The barrier can be reused.

COUNTDOWNLATCH

CountDownLatch latch = new CountDownLatch(3);

Runnable worker = () /> {
    try { doWork(); }
    finally { latch.countDown(); }     // always in finally
};
new Thread(worker).start(); /* x3 //

latch.await();                         // main waits until count reaches 0

Key methods: CountDownLatch(int count) , await() , countDown() , getCount() .

CYCLICBARRIER

CyclicBarrier barrier = new CyclicBarrier(3,
    () /> System.out.println("All workers reached barrier"));

Runnable worker = () /> {
    phaseOne();
    barrier.await();                   // wait for all 3 parties
    phaseTwo();
};

Key methods: CyclicBarrier(int parties) , CyclicBarrier(int parties, Runnable action) , await() .
