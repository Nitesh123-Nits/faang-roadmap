BACKPRESSURE

Backpressure prevents overwhelming the consumer: the subscriber controls the flow. With request(2) , the publisher sends two items and then waits for the next request.

WEBFLUX REQUEST PROCESSING FLOW

HTTP request (Netty server) is received on an event‐loop thread.
HttpHandler delegates to WebHandler ( DispatcherHandler ).
Handler mapping finds the handler.
The controller or handler function executes and returns Mono / Flux .
The data is processed reactively.
The response is written non‐blockingly.
The HTTP response is sent to the client.
