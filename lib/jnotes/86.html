The response is sent back through DispatcherServlet and the servlet container to the client.

KEY COMPONENTS

COMPONENTROLE
Servlet containerReceives the HTTP request (Tomcat / Jetty / Undertow)
FiltersPre-processing: auth, logging, CORS
DispatcherServletFront controller; coordinates the whole flow
HandlerMappingFinds the controller method
HandlerAdapterInvokes the controller
RequestResponseBodyMethodProcessorHandles @RequestBody / @ResponseBody
HttpMessageConverterConverts between HTTP body and Java objects
MappingJackson2HttpMessageConverterJackson-based JSON converter (default)
ObjectMapperThe actual (de)serialisation engine

ANNOTATIONS

ANNOTATIONEFFECT
@RequestBodyConvert the request body (JSON) to a Java object
@ResponseBodyConvert the return value (Java object) to the response body
@RestController@Controller + @ResponseBody

F LOW S U M M A RY. Request: Client → Container → Filters → DispatcherServlet →

HandlerMapping → HandlerAdapter → RequestResponseBodyMethodProcessor

HttpMessageConverter → Jackson → Java object → Controller. Response: Controller → HandlerAdapter → processor → converter → Jackson → JSON → Client. Note that DispatcherServlet coordinates; it does not do JSON conversion itself.
