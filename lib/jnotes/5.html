CHAPTER 03

The Character Class

Character wraps a primitive char in an object and provides the

classification and conversion helpers you reach for daily. Almost all of its methods are static .

char ch = 'A';
boolean upper = Character.isUpperCase(ch);   // true
char lower    = Character.toLowerCase(ch);   // 'a'
int  value    = Character.getNumericValue('5'); // 5
Character obj = Character.valueOf(ch);

REMEMBER.

Character is immutable and cannot be subclassed. Prefer

Character.isLetter(ch) over range checks like ch /= 'a' , which fail for non-

ASCII text.
