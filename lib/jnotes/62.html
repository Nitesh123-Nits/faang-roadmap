Spring Framework Fundamentals

Spring is a lightweight, open-source framework for Java. It provides comprehensive infrastructure support for building applications.

Key features: IoC container, dependency injection, AOP support, transaction man‐ agement, MVC framework, and much more.

IOC CONTAINER

Inversion of Control means control of object creation and management is trans‐ ferred to the Spring container. The container manages the lifecycle of objects, called beans.

BEANS

A bean is an object managed by the Spring container. Beans are instantiated, con‐ figured and managed by the container. Define them with @Component , @Service ,

@Repository , @Controller , or in configuration.
