KEY POINTS

Netty uses the event loop pattern: a small number of threads handle many con‐

nections concurrently.

Each event loop is single‐threaded and responsible for all I/O and tasks of its

channels.

WebFlux is built on Reactor Netty and runs fully non‐blocking.
Blocking operations must be offloaded to boundedElastic (or a custom sched‐

uler).

High concurrency with low thread counts, high throughput and low context

switching.
