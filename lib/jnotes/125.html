THE REQUEST LIFECYCLE (HAPPY PATH)

The client sends a request (HTTP/HTTPS).
The boss event loop accepts the connection.
The connection is assigned to a worker event loop.
Data is read and decoded through the pipeline.
The request is passed to WebFlux.
The handler returns a Mono / Flux .
The response is written; the pipeline encodes it.
The response is flushed to the client.
