CHAPTER 11

Apache Maven

Maven is a build automation and project management tool for Java, built on the Project Object Model (POM).

WHY MAVEN

Standardised build process: the same lifecycle for every project.
Dependency management: downloads and manages libraries automatically.
Build automation: compile, test, package and deploy with simple commands.
Consistency: same structure and build across environments.
Convention over configuration: less setup, more productivity.

THE DEFAULT LIFECYCLE

#PHASEWHAT IT DOES
1validateChecks the project is correct and complete
2initializeSets up build state
3–6generate-sources, process-sources, generate-resources, process-resourcesCreate and process sources and resources
7compileCompiles main source code
8process-classesPost-processes compiled classes
9–14generate-test-sources … process-test-classesPrepare and compile tests
15testRuns unit tests
16–prepare-package, packageCreates the JAR/WAR
17
18verifyChecks package quality
19installInstalls into the local repository
20deployPublishes to the remote repository

Phases run in order: running mvn package runs everything before it.
