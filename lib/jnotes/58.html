IMPORTANT NOTES

Virtual threads do not make CPU‐bound code faster. The CPU is still the bottleneck.
You still need limits for scarce resources (DB connections, HTTP connections, rate

limits).

Do not pool virtual threads. Create one per task.
They are great for existing Spring MVC apps with blocking I/O.

M E N TA L M O D E L . Platform threads: one request = one heavy thread. Virtual

threads: many light threads scheduled on few carriers. Reactive: event-driven streams with backpressure. Different tool, same goal: handle more with fewer resources. Choose the right model for the problem, not the trend.
