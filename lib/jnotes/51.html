THE EXECUTOR FRAMEWORK

GRACEFUL SHUTDOWN

executor.shutdown();                                  // stop accepting new tasks
try {
    if (!executor.awaitTermination(60, TimeUnit.SECONDS)) {
        executor.shutdownNow();                       // cancel running tasks
        if (!executor.awaitTermination(60, TimeUnit.SECONDS))
            System.err.println("Pool did not terminate");
    }
} catch (InterruptedException e) {
    executor.shutdownNow();
    Thread.currentThread().interrupt();
}

BEST PRACTICES

Choose the right pool type for the use case.
Set pool and queue sizes deliberately; prefer bounded queues.
Handle RejectedExecutionException .
Always shut down executors gracefully.
Avoid blocking operations in small pools.
Monitor pool metrics: active threads, queue size.
Give threads meaningful names.
Prefer CompletableFuture for async workflows, and virtual threads for high‐concur‐ rency I/O.
