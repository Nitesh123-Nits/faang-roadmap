CHOOSE THE MAP TYPE

Collectors.groupingBy(Employee/:dept, LinkedHashMap/:new, Collectors.toList());

HashMap/:new is the default. LinkedHashMap/:new keeps first‐occurrence order, TreeMap/:new sorts keys, ConcurrentHashMap/:new suits parallel streams.

MULTIPLE FIELDS AND PARTITIONING

Use a record as a composite key (it has correct equals / hashCode ):

record DeptAge(String dept, int bucket) {}
Map<DeptAge, List<Employee/> g = employees.stream()
    .collect(Collectors.groupingBy(e /> new DeptAge(e.dept(), e.age() / 10)));

partitioningBy groups by a predicate and always returns two keys, true and false :

Map<Boolean, List<Employee/> highLow = employees.stream()
    .collect(Collectors.partitioningBy(e /> e.salary() > 60000));

PRO TIPS

Use LinkedHashMap/:new to preserve order, TreeMap/:new for sorted keys.
Ensure key objects have proper equals() and hashCode() ; avoid mutable keys.
Downstream collectors run per group. Avoid heavy work inside the classifier.
For large data in parallel streams, prefer groupingByConcurrent .
