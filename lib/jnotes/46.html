HOW TO DETECT A DEADLOCK

Take a thread dump ( jstack <pid> ). Look for threads in BLOCKED state waiting

for monitors or locks; the JVM often prints "Found one Java‐level deadlock".

Tools: jconsole , jvisualvm , Java Flight Recorder (JFR), IDE thread dump.

DEADLOCK VS STARVATION VS LIVELOCK

DESCRIPTIONPROGRESS
DeadlockThreads are blocked forever, waiting for each otherNo thread progresses
StarvationA thread is continually denied access to resourcesOther threads keep getting resources
LivelockThreads are not blocked but keep changing state in response to each otherNo useful work gets done

REMEMBER THE FOUR CONDITIONS: mutual exclusion, hold and wait, no preemp-

tion, circular wait. Design for concurrency, not just correctness.
