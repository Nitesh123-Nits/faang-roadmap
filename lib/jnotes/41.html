ReentrantLock

A mutual-exclusion lock with the same basic semantics as synchronized , plus extended capabilities. It lives in java.util.concurrent.locks .

KEY FEATURES

Reentrant: a thread can lock multiple times; it must unlock the same number of

times.

Fairness option: fair mode grants the lock to the longest‐waiting thread. Default is

non‐fair (barging allowed).

Interruptible lock acquisition.
Timed and non-blocking acquisition with tryLock .
Multiple Condition objects.
ReentrantLock lock = new ReentrantLock();        // non-fair (default)
ReentrantLock fair = new ReentrantLock(true);    // fair

BASIC USAGE: ALWAYS UNLOCK IN FINALLY

lock.lock();
try {
    count/+;
} finally {
    lock.unlock();
}

LOCK METHODS

METHODDESCRIPTION
lock()Acquires the lock, blocking
unlock()Releases the lock
tryLock()Acquires only if free right now; returns true/false
tryLock(time, unit)Waits up to the given time
lockInterruptibly()Acquires unless the thread is interrupted
newCondition()Creates a Condition for waiting and signalling
