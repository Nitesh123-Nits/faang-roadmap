THE STEPS

Login request. The client sends POST /api/auth/login with {"username": "user1", "password": "password123"} . AuthController receives the request and creates an Authentication object ( UsernamePasswordAuthenticationToken ), passing it to AuthenticationManager . AuthenticationManager coordinates the process using the configured AuthenticationProvider (s). UserDetailsService loads the user from the database by username. Password validation. The raw password from the request is matched against the stored hash by PasswordEncoder . JWT generation. On success, create a JWT with claims (subject, roles, issued‐at, expiry) and sign it with the secret key. JWT response. Return the token; the client uses it on all future requests.
