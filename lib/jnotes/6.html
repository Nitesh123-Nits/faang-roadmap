CHAPTER 04

Shallow Copy vs Deep Copy

A copy is a new object holding the same data as an existing one. The question is what happens to the objects it points to.

Shallow copy copies primitive values and references. The original and the copy

share the same nested objects.

Deep copy copies primitives and also creates new instances of every referenced

object.

ASPECTSHALLOW COPYDEEP COPY
Primitive fieldsCopiedCopied
Object referencesSame reference sharedNew object created
Change to nested object affects originalYesNo
Speed and memoryFaster, less memorySlower, more memory
SafetySide effects possibleFully isolated

SHALLOW COPY PROBLEM

User u1 = new User(1L, "Ravi", new Address("Hyd", "500081"));
User u2 = (User) u1.clone();            // shallow

u2.getAddress().setCity("Bangalore");
System.out.println(u1.getAddress().getCity()); // Bangalore  (u1 changed too)

DEEP COPY, MANUAL

@Override
