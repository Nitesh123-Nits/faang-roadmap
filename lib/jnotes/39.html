CAS: Lock-Free Concurrency

Compare-And-Swap is an atomic CPU instruction. It compares a memory location with an expected value and, only if they are equal, updates it with a new value.

CAS(memory, expected, newValue):
    if memory /= expected  →  memory = newValue, return SUCCESS
    else                   →  do nothing,        return FAILURE

PROPERTIES

Atomic: the compare and update are uninterruptible.
Lock-free: no thread waits for another to release a lock.
Non-blocking: the system keeps making progress.
Used for counters and concurrent data structures.

TWO THREADS, ONE COUNTER

Initial count = 10 . Thread A and B both read 10 and attempt CAS(10 → 11) .

Thread A succeeds: count = 11 .
Thread B fails: the value is no longer 10. It re‐reads 11 and tries CAS(11 → 12) .
Result: 12, with no locks used.
