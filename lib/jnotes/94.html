RECOVERY METHOD (@RECOVER)

Called after all retries are exhausted. It must have the same return type, take the ex‐ ception as its first parameter, and be in the same class.

@Retryable(retryFor = RuntimeException.class, maxAttempts = 3)
public String charge() { throw new RuntimeException("Payment Gateway Down"); }

@Recover
public String recover(RuntimeException ex) {
    return "Fallback Response";
}
