What Happens When a Spring Boot Application Starts?

Seventeen steps from java -jar app.jar to "ready for traffic".

#STEPWHAT HAPPENS
1Run the applicationjava -jar app.jar. The JVM starts and looks for the main class
2main() executesSpringApplication.run(App.class, args) bootstraps Spring Boot
3Create SpringApplic ationDetects the web application type, loads application listeners and initialisers
4Prepare environmentBuilds a ConfigurableEnvironment from application.properties/yaml, environment variables, JVM args, command-line args
5Create ApplicationC ontextDecides the context type (Servlet / Reactive) and creates the IoC container; selects the web server context
6Execute initialisersApplicationContextInitializer implementations customise the context before it is refreshed
7Component scanningScans base packages for @Component, @Service, @Repository, @Controller, @Configuration and registers bean definitions
8Auto- configuration@EnableAutoConfiguration triggers auto-config classes from spring.factories / AutoConfiguration.imports, creating beans conditionally based on classpath, properties and other conditions
9Bean definition creationAll bean metadata is stored; the dependency graph is built
10BeanFactoryPostProc essor phaseModify bean definitions before beans are instantiated
11BeanPostProcessor registrationInterceptors for the bean lifecycle (AOP, validation) are registered
12Singleton bean creationInstantiate singletons, resolve dependencies; constructor and field injection
13Bean initialisation lifecycle@PostConstruct, afterPropertiesSet(), custom init method
