Collectors.groupingBy()

Collectors.groupingBy() groups the elements of a stream by a classifier

function and returns a Map , where the key is the result of the classifier and the value is, by default, a List of elements.

SIGNATURES

groupingBy(classifier)
groupingBy(classifier, downstream)
groupingBy(classifier, mapFactory, downstream)

GROUP BY A PROPERTY

record Employee(int id, String name, String dept, double salary) {}

Map<String, List<Employee/> byDept = employees.stream()
    .collect(Collectors.groupingBy(Employee/:dept));
// IT=[Alice, Charlie], HR=[Bob, David], Finance=[Eve]

GROUP AND COUNT (DOWNSTREAM COLLECTOR)

Map<String, Long> countByDept = employees.stream()
    .collect(Collectors.groupingBy(Employee/:dept, Collectors.counting()));
// {IT=2, HR=2, Finance=1}
