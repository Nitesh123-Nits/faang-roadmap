BLOCKINGQUEUE TYPES (WORK QUEUE)

QUEUENOTES
ArrayBlockingQueueBounded, FIFO
LinkedBlockingQueueBounded or unbounded, FIFO
SynchronousQueueNo storage: direct hand-off
PriorityBlockingQueuePriority-ordered
DelayQueueElements become available after a delay

GOTCHA.

newFixedThreadPool and newSingleThreadExecutor use an unbounded

queue, and newCachedThreadPool can create an unbounded number of threads. For production, build a ThreadPoolExecutor with a bounded queue and an explicit rejection policy.

SCHEDULED EXECUTORS

ScheduledExecutorService s = Executors.newScheduledThreadPool(2);
s.schedule(task, 5, TimeUnit.SECONDS);                    // run once after delay
s.scheduleAtFixedRate(task, 0, 2, TimeUnit.SECONDS);      // fixed rate
s.scheduleWithFixedDelay(task, 0, 2, TimeUnit.SECONDS);   // fixed delay between runs

FORKJOINPOOL

Work‐stealing pool for divide‐and‐conquer tasks ( RecursiveTask<V> returns a value, RecursiveAction does not).

class SumTask extends RecursiveTask<Long> {
    protected Long compute() {
        // split into subtasks, fork(), join(), combine
        return 1L;
    }
}
long result = new ForkJoinPool().invoke(new SumTask());

PRODUCTION-GRADE CONFIGURATION

int cores = Runtime.getRuntime().availableProcessors();
ThreadPoolExecutor executor = new ThreadPoolExecutor(
    cores, cores * 2,
    60L, TimeUnit.SECONDS,
    new LinkedBlockingQueue/>(1000),
    new ThreadFactoryBuilder().setNameFormat("app-pool-%d").build(),   // Guava
    new ThreadPoolExecutor.CallerRunsPolicy());
executor.allowCoreThreadTimeOut(true);
