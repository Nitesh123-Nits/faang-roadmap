IMPORTANT POINTS

The network transmits only bytes, not objects.
TCP/UDP split data into packets and reassemble at the receiver.
Serialisation adds overhead, so choose the right format (JSON for readability,

Protobuf/Avro for compactness and speed).

For large files, use streaming / chunked upload.
Always define and follow a clear contract (API / schema).

IN A NUTSHELL. Data → Serialize → Bytes → Network → Deserialize → Data. Differ-

ent representation, same meaning. Bytes are the bridge.
