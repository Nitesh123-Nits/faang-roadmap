The Executor Framework

java.util.concurrent provides a standard way to execute asynchronous tasks,

manage thread pools and control concurrency, instead of creating threads by hand.

KEY INTERFACES

INTERFACEROLE
ExecutorExecutes tasks (fire and forget): execute(Runnable)
ExecutorServiceAdds lifecycle management and returns Futures: submit, invokeAll, shutdown
ScheduledExecutorServicSchedules tasks to run later or periodically

TYPES OF THREAD POOLS (EXECUTORS FACTORY)

FACTORYBEHAVIOUR
newFixedThreadPool(n)Fixed number of threads
newCachedThreadPool()Creates threads as needed, reuses idle ones
newSingleThreadExecutor()One worker thread, tasks run in order
newScheduledThreadPool(n)For scheduled and periodic tasks
newWorkStealingPool()Uses ForkJoinPool; idle threads steal work
newVirtualThreadPerTaskExecutor()One virtual thread per task (Java 21+)
