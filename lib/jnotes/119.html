BEST PRACTICES

Always use connection pooling.
Set the max pool size from the formula (CPU × 2 + disks), then measure.
Avoid opening/closing a connection per request.
Use transaction pooling (pgBouncer) for high concurrency.
Set connection timeouts to fail fast.
Monitor pool metrics: active, idle, wait time.
Do not exceed max_connections on the PostgreSQL server.
