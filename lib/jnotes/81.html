Spring AOP

Aspect-Oriented Programming separates cross-cutting concerns from business logic. Cross-cutting concerns include logging, security, transactions, caching, exception handling and performance monitoring.

"AOP is like a decorator magician who adds behaviour without changing the original code."

TERMINOLOGY

TERMMEANING
AspectModule that encapsulates a cross-cutting concern
Join pointA point during execution (a method call, etc.)
PointcutExpression that matches join points
AdviceAction to be taken at a join point
TargetThe object being advised
WeavingLinking aspects with target objects to create an advised object

TYPES OF ADVICE

ADVICEWHEN IT RUNS
@BeforeBefore the join point
@AfterAfter the join point (always executes)
@AfterReturningAfter successful return
@AfterThrowingAfter an exception
@AroundBefore and after; you control when to proceed
