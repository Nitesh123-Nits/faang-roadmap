EXAMPLE: LOG EXECUTION TIME

@Aspect
@Component
public class LoggingAspect {

    @Around("execution(* com.example.service/.*(/.))")
    public Object logExecutionTime(ProceedingJoinPoint jp) throws Throwable {
        long start = System.currentTimeMillis();
        try {
            Object result = jp.proceed();
            return result;
        } finally {
            System.out.println(jp.getSignature().getName() + " took "
                + (System.currentTimeMillis() - start) + " ms");
        }
    }
}

Enable with @EnableAspectJAutoProxy (Spring Boot auto‐configures it when AOP is on the classpath).

Spring AOP is proxy-based and works at runtime, not bytecode weaving like AspectJ.

BEST PRACTICES

Keep aspects focused and cohesive.
Use specific pointcuts; avoid broad /. in production.
Do not use AOP for simple requirements; it is overkill.
Avoid self-invocation: AOP will not work on internal method calls because they by‐

pass the proxy.

Prefer constructor injection in aspects.

Common uses: logging, transactions, security, caching, performance monitoring, excep‐ tion handling.
