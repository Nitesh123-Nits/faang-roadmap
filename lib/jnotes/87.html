CHAPTER 52

End-to-End Request Flow in Spring Boot

Eight stages from a browser tap to a JSON response.

#STAGEWHAT HAPPENS
1ClientBrowser, mobile or API client sends GET /api/users/1
2NetworkThe request travels across the internet
3Server (OS network stack)NIC → IP layer → TCP layer → server socket listening on 8080
4Spring Security filtersSecurityContextPersistenceFilter, UsernamePasswordAuthenticationFilter, AnonymousAuthenticationFilter, ExceptionTranslationFilter, FilterSecurityInterceptor
5DispatcherServletReceives the request, determines the handler, finds the handler adapter
6Controller@RestController method mapped by @GetMapping("/api/users/{id}")
7Service / business logicUserService.findById(id) queries UserRepository (JPA / database)
8Response200 OK with JSON { "id": 1, "name": "Alice" }
Client → Network→ Server socket → Security filters → DispatcherServlet
→Controller → Service and DB → Response

The response travels back along the same path in reverse.
