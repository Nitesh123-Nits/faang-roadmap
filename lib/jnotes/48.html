Runnable vs Callable

Both represent tasks that a thread can execute. The difference is the result.

// Runnable: no result
Runnable task = () /> System.out.println("Task is running");
new Thread(task).start();

// Callable: returns a result
Callable<Integer> job = () /> { return 42; };
ExecutorService executor = Executors.newFixedThreadPool(1);
Future<Integer> future = executor.submit(job);
try {
    Integer result = future.get();      // blocks until done
} catch (Exception e) {
    e.printStackTrace();
}
executor.shutdown();

REMEMBER.

ExecutorService.submit(Runnable) returns a Future<?> whose get()

is always null . submit(Callable<V>) returns the real result. Runnable does the work (no result). Callable does the work and gives a result.
