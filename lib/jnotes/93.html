@Retryable

Resilient microservices need to retry transient failures smartly: add backoff, use jitter.

SETUP

<dependency>
    <groupId>org.springframework.retry//groupId>
    <artifactId>spring-retry//artifactId>
//dependency>
<dependency>
    <groupId>org.springframework.boot//groupId>
    <artifactId>spring-boot-starter-aop//artifactId>
//dependency>

spring-retry provides @Retryable ; AOP is required for the proxies.

@SpringBootApplication
@EnableRetry                      // enables the retry proxies
public class Application {}

BASIC EXAMPLE

@Service
public class PaymentService {

    @Retryable(retryFor = RuntimeException.class, maxAttempts = 3)
    public String processPayment() {
        System.out.println("Calling payment gateway");
        throw new RuntimeException("Gateway unavailable");
    }
}

If processPayment() throws, it is retried up to 3 times in total (1 initial try + 2 re‐ tries).
