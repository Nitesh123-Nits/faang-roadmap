BEST PRACTICES

Never block the event‐loop thread. Use boundedElastic for blocking tasks.
Prefer non‐blocking libraries (WebClient, R2DBC, reactive Redis).
Use backpressure‐aware operators.
Return Mono / Flux from controller methods.
Handle errors gracefully.
Use proper timeouts and limits.
Monitor and test under load.
