WEBCLIENT (NON-BLOCKING HTTP CLIENT)

WebClient client = WebClient.builder()
    .baseUrl("https://api.example.com")
    .build();

Mono<User> userMono = client.get()
    .uri("/users/{id}", 1)
    .retrieve()
    .bodyToMono(User.class);

Flux<User> users = client.get()
    .uri("/users")
    .retrieve()
    .bodyToFlux(User.class);

THREADING MODEL AND SCHEDULERS

Event‐loop (NIO) threads are few and handle I/O and lightweight tasks. Blocking work must be moved to worker threads using schedulers. Never block an event‐ loop thread.

SCHEDULERUSE
Schedulers.parallel()CPU-intensive tasks
Schedulers.boundedElastic()Blocking / I/O tasks
Schedulers.single()Single reusable thread
Schedulers.immediate()Current thread (no switch)
Schedulers.fromExecutor()Custom executor
