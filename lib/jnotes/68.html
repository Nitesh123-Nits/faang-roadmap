DECLARING A SCOPE

@Component
@Scope("prototype")
public class MyBean {}

@Bean
@Scope(value = "request", proxyMode = ScopedProxyMode.TARGET_CLASS)
public MyBean myBean() { return new MyBean(); }

IMPORTANT POINTS

Singleton is the default scope.
