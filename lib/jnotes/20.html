Functional Programming in Java

Functional programming treats computation as the evaluation of functions and avoids changing state and mutable data. It emphasises immutability, first-class functions, higher-order functions and declarative code.

Why use it: cleaner and more readable code, less boilerplate, better abstraction, easier testing, easy parallelism with streams.

BUILDING BLOCKS
