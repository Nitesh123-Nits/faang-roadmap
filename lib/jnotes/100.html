THE SECURITY CONTEXT

SecurityContextHolder holds the SecurityContext , which holds the Authentication (prin‐ cipal, credentials, authorities, details, authenticated flag). It is stored using a strategy, ThreadLocal by default, and is available throughout the application: controllers, ser‐ vices, repositories, @PreAuthorize methods.

T I P S

Prefer delegating authentication to AuthenticationManager .
Never store raw passwords. Use PasswordEncoder (BCrypt, Argon2).
Authorities drive authorisation.
Keep SecurityContext stateless in REST APIs (use JWT/OAuth2).
