CHAPTER 58

JWT Fundamentals

A JSON Web Token is a compact, URL-safe token used to securely transmit claims between parties. It is digitally signed, so it cannot be tampered with, and it is stateless: no session is stored on the server.

HIGH-LEVEL FLOW

The client sends a login request (username and password).
The server authenticates the credentials via AuthenticationManager .
If valid, the server generates a JWT and returns it.
The client sends the JWT in the Authorization: Bearer <token> header on each re‐ quest.
The JwtFilter validates the token.
If valid, the protected resource is returned. Otherwise 401.
