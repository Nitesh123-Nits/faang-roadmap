DEPENDENCY INJECTION AND IOC
@Component
class UserService {
    private final UserRepository repo;

    @Autowired                                   // optional on a single constructor
    public UserService(UserRepository repo) {
        this.repo = repo;
    }
}

WHICH TO USE WHEN

Constructor injection in almost all cases.
Setter injection only when the dependency is optional or must be reconfigured.
Field injection only for quick prototypes, tests or legacy code, never in production.
Method injection rarely, when you need custom logic during injection.

HOW SPRING DOES IT

Spring scans the classes and creates objects. It sees that UserService needs a UserRepository . It creates the repository and injects it into the service. Your code runs.
