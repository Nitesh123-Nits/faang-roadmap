Iterator vs ListIterator

Both traverse collections; they differ in direction and power.

ITERATOR: REMOVE WHILE ITERATING

List<String> list = new ArrayList/>(List.of("A", "B", "C", "D"));
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    if (s.equals("B")) it.remove();      // safe removal
}
// [A, C, D]

LISTITERATOR: REPLACE, ADD, GO BACKWARDS

ListIterator<String> li = list.listIterator();
while (li.hasNext()) {
    String s = li.next();
    if (s.equals("B")) { li.set("BB"); li.add("X"); }
}
while (li.hasPrevious()) System.out.print(li.previous() + " ");
