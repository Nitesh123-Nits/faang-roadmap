APPLICATIONCONTEXT

The central interface to the Spring IoC container. It provides bean management, re‐ source loading, event publication and internationalisation. Common implementa‐ tions: ClassPathXmlApplicationContext , AnnotationConfigApplicationContext .

CORE MODULES

Spring Core , Spring Beans , Spring Context , Spring Expression Language (SpEL) :

these provide basic IoC and dependency injection.

ADVANTAGES

Loose coupling, easier unit testing, code reusability, clean and modular architec‐ ture, a huge ecosystem and community.

S U M M A RY. Spring is all about managing objects and their dependencies. Un-

derstand IoC, DI and bean lifecycle: these are the heart of the framework.
