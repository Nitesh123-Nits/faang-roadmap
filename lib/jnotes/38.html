MEMORY VISIBILITY

Changes made before monitorexit are visible to the next thread that performs monitorenter on the same monitor. This is a happens-before edge.

WAIT() AND NOTIFY()

wait() releases the monitor and moves the thread to the wait set. When another

thread acquires the lock, changes the condition and calls notify() / notifyAll() , the waiter moves back to the entry queue, reacquires the lock, and continues.
