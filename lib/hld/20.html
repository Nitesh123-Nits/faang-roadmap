Scaling &amp; Failure Handling
Event spikes: Kafka buffers; timeline cache serves reads; non-critical features shed first
Search: time-sliced index shards; recent shard in memory, older shards on disk
Regional failure: multi-region replicated tweet store; timelines rebuilt on demand
Hot tweets: counter sharding and cached hydration
