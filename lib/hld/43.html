Functional Requirements
Upload, download, delete and organise files
Automatic sync across devices
Block-level delta sync (only changed chunks)
File versioning and restore
Share files and folders with permissions
Link sharing with expiry
Offline access and conflict handling
Non-Functional Requirements
Durability: 11 nines (S3 + checksums)
Consistency: strong metadata per user, eventual cross-device (seconds)
Latency: change notification < 2 s
Efficiency: chunk dedupe and delta sync save bandwidth
Scalability: billions of files, 50 PB
Availability: 99.99%
Security: encryption at rest and in transit, ACLs

Key design trade-offs

Block-level (efficient) vs whole-file sync (simple)

Global dedupe (saving, privacy side-channels) vs per-user

Last-writer-wins + conflict copy vs OT merge

Long-poll / WebSocket vs periodic polling

Scaling & Failure Handling R

Conflicts: compare-and-swap on baseVersion; losing writer gets a conflicted copy, never silent overwrite
Missed notifications: devices also poll /changes with a cursor, so push is only an optimisation
Block durability: blocks immutable with checksums; GC only deletes blocks with zero references after a grace period
Large files: resumable chunk upload; each block retried independently
