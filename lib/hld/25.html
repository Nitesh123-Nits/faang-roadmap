Reddit

Communities, votes, threads

Functional Requirements
Create subreddits with rules and moderators
Submit text / link / media posts
Upvote and downvote posts and comments
Threaded (nested) comments
Ranked listings: hot, new, top, controversial
Search posts and communities
Moderation: remove, ban, report
Non-Functional Requirements
Latency: listing p99 < 200 ms
Availability: 99.95%, reads prioritised
Scalability: viral threads (100K+ comments)
Consistency: eventual vote counts, strong post create
Freshness: scores update within seconds
Abuse resistance: vote manipulation detection
Cost: cache-heavy, read-optimised

Key design trade-offs

Precomputed listing ZSETs (fast) vs query-time sort

Batched vote counts (eventual) vs exact

Shard by subreddit (locality) vs post_id (even)

Scaling &amp; Failure Handling
Viral threads: hot posts and comment trees cached; vote writes batched; comment pages lazy-load deep branches
Cache loss: listing ZSETs rebuilt from the posts table by score
Brigading: velocity limits and vote-ring detection before score counts
Shard hot spot: very large subreddits get dedicated shards
