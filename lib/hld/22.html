Chat Application

Slack / Teams style

Functional Requirements
Workspaces, public and private channels, DMs
Send, edit, delete and thread messages
Real-time delivery to channel members
Presence and typing indicators
File uploads and previews
Full-text message search
Mentions, reactions and notifications
Non-Functional Requirements
Latency: message delivered < 200 ms
Availability: 99.99%
Consistency: ordered per channel, eventual for presence
Scalability: millions of sockets, workspace-sharded
Durability: messages persisted before ack
Search: new messages searchable in < 10 s
Isolation: tenant data separation per workspace

Pub/Sub on Redis (fast, lossy) + Kafka (durable)

Presence TTL heartbeat vs strong accuracy

Dedicated search index vs DB scan

Scaling &amp; Failure Handling
Gateway loss: clients reconnect and request events since last_ts from the message log
Pub/Sub loss: Redis fan-out is best-effort; clients detect gaps via message sequence and refetch
Hot channels: large channels batched and rate-limited; typing events sampled
Tenant isolation: workspace-level sharding, quotas and per-tenant search filters
