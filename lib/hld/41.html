Music Streaming Service

Spotify style

Functional Requirements
Search and browse tracks, albums, artists
Stream audio with gapless playback
Create and share playlists, library
Offline downloads (premium)
Personalised recommendations and radio
Track listens for royalties and recommendations
Rights and region licensing
Non-Functional Requirements
Start latency: < 300 ms to first audio
Availability: 99.99%
Scalability: 100M DAU, read-heavy
Durability: playlists never lost
Accuracy: every qualified listen counted (royalties)
Consistency: eventual for recommendations, strong for playlist edits
Offline: encrypted downloads with licence expiry

Pre-fetch next track (gapless) vs bandwidth waste

Client-side cache + CDN vs always origin

Exact listen counts (stream) vs sampling

Collaborative filtering vs content-based recs

Scaling &amp; Failure Handling
CDN failure: multi-CDN with client failover; audio chunks are small and quick to refetch
Event loss: client buffers listen events offline and retries; Kafka durable; dedupe by event id
Playlist conflicts: optimistic version check; fractional positions avoid global reorder writes
Licensing: region rules enforced at signed URL issue, not only in the UI
