Functional Requirements
Upload photos and short videos with caption
Home feed of followed accounts
Follow, like, comment, share
User profile with grid of posts
Stories (24 h expiry)
Search users and hashtags
Notifications for social events
Non-Functional Requirements
Latency: image load < 200 ms via CDN
Availability: 99.99% for reads
Durability: uploaded media never lost
Scalability: 500M DAU, media-heavy
Consistency: eventual for feeds and counts
Cost: tiered storage, multiple image sizes
Upload: resumable, async processing

Scaling & Failure Handling R

Processing backlog: uploads are acknowledged immediately; originals safe in S3 while workers catch up
CDN outage: multi-CDN failover; origin shield protects S3 from stampedes
Hot posts: counters in Redis with batched DB flush; replicated hot keys
Moderation: async ML check; content hidden if flagged
