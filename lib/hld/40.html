Video Streaming Platform

Netflix / YouTube style

Functional Requirements
Upload videos (creators) and ingest titles (studio)
Transcode into multiple resolutions and codecs
Adaptive bitrate playback (HLS / DASH)
Search and browse catalog
Personalised recommendations and home page
Resume playback, watch history
DRM and geo-restrictions

Non-Functional Requirements B

Playback start: < 2 s, rebuffer ratio < 0.5%
Availability: 99.99% for playback
Scalability: egress dominated; CDN offloads > 95%
Durability: masters never lost (multi-AZ S3)
Cost: per-title encoding, tiered storage
Consistency: eventual for catalog and history
Security: DRM, signed URLs, token auth

Key design trade-offs

Own CDN appliances (Open Connect) vs third-party CDN

Short segments (fast adapt) vs long (fewer requests)

Per-title encoding (quality / bit) vs fixed ladder

CDN miss storms: Origin Shield collapses duplicate requests; popular content pre-positioned in off-peak hours
Transcode failure: jobs are idempotent per rendition and retried; title stays PROCESSING until all ready
Region outage: multi-region S3 replication; API stateless and multi-region
Playback degrade: player drops bitrate instead of stalling; fallback CDN hostnames
