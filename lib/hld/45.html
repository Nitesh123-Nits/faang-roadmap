Content Delivery Network

Edge caching platform

Functional Requirements
Cache and serve static / video content from the edge
Route users to the nearest healthy PoP
Cache-key rules, TTLs, headers
Purge by URL / tag / prefix globally
Origin shielding and request collapsing
TLS termination, HTTP/2 / HTTP/3
Usage analytics and billing
Non-Functional Requirements
Latency: TTFB < 50 ms on hit
Hit ratio: > 95% for static, 80% overall
Availability: 99.99% (PoP failure reroutes)
Purge: global invalidation in < 5 s
Scalability: tens of Tbps, 300+ PoPs
Security: DDoS absorption, WAF, TLS, signed URLs
Efficiency: origin offload, compression

Key design trade-offs

Anycast (fast failover) vs GeoDNS (fine control)

Cache hierarchy (offload) vs more edge storage

Consistent hashing across PoP servers vs duplication

Purge push (fast) vs short TTL (simple)

Scaling & Failure Handling

R
PoP failure: anycast / DNS health checks reroute to the next PoP in seconds
Origin down: serve stale (stale-if-error) from cache while the shield retries origin
Thundering herd: request collapsing at edge and shield; soft TTLs refresh in background
DDoS: anycast spreads attack traffic; rate limits and WAF at edge
