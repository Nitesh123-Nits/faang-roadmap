News Feed System

Home timeline design

Functional Requirements
Publish a post (text, media reference)
View a personalised home feed
Follow and unfollow users
Rank feed by relevance and recency
Infinite scroll with pagination
Likes and comments update counters
Celebrity posts visible without fan-out storms
Non-Functional Requirements
Latency: feed load p99 < 200 ms
Availability: 99.99%, stale feed beats no feed
Scalability: 300M DAU, read-heavy (50:1)
Freshness: new post in followers' feeds within seconds
Consistency: eventual for feeds, strong for post create
Efficiency: avoid fan-out for users with millions of followers
Durability: posts never lost

Push (fast reads) vs pull (cheap writes)

Hybrid: push for normal users, pull for celebrities

ML ranking (engagement) vs chronological (predictable)

Cache only IDs (small) vs full posts (fast)

Scaling &amp; Failure Handling
Fan-out lag: Kafka absorbs bursts; consumers scale by partition; feed still serves stale cache
Celebrity posts: pull on read avoids millions of cache writes per post
Cache loss: rebuild a user's feed from followed users' recent posts (cold-start path)
Ranking down: fall back to reverse-chronological order
