03

Resilience

One service goes down. The rest must survive.

Every remote call needs an explicit failure strategy

KEY CHALLENGES
Timeouts on every remote call
Fallback responses
Retry policies (with backoff)
Backpressure
Circuit breakers
Load shedding
Bulkheads (failure isolation)
Graceful degradation
Rate limiting

In a monolith, A → B → C usually fails together as one process. In microservices, B can be down while A keeps running, so every downstream call needs an explicit failure strategy.
