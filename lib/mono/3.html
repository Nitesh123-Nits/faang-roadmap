KEY CHALLENGES
Network latency (1 ms → 5–100+ ms)
Partial failures & packet loss
Network & connection failures
Retries and duplicate requests
DNS failures
Serialization / deserialization cost
Connection pool exhaustion
API compatibility across services
Socket / read / write timeouts

What used to be a 1 ms in-process call can now fail independently of the caller. This is the single biggest mindset shift when moving to microservices.
