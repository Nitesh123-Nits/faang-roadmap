CHAPTER 06

YAML, JSON and API Naming

Golden rule: the tool that reads the file decides the style. Where the format is yours (your config keys, your API), pick one convention and never mix. STD means fixed by a spec or framework; TEAM means our choice, agree once.

YAML files: which key style where
application.yml
K E Y S

kebab-case

EXAMPLE
retry-max-attempts: 3
N OT E S

STD Spring recommends it

Env var override

K E Y S
UPPER_SNAKE
EXAMPLE
ORDERSERVICE_RETRY_MAXATTEMPTS
N OT E S

STD dashes dropped, dots become _

Helm values.yaml
K E Y S

camelCase

EXAMPLE
replicaCount: 2
N OT E S

STD flat over nested; quote strings

Kubernetes manifest

K E Y S

camelCase

EXAMPLE
imagePullPolicy: IfNotPresent
N OT E S

STD API fields; names stay kebab-case

GitHub Actions

K E Y S

fixed keys

EXAMPLE

runs-on, timeout-minutes

N OT E S

STD job ids: kebab-case

Docker Compose

K E Y S

snake_case

EXAMPLE

depends_on, container_name

N OT E S

STD service names: kebab-case
