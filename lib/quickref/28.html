Conventional commit types

feat and fix are defined by the Conventional

Commits spec. The other core types follow the Angular convention used by commitlint. TEAM types are custom and you must configure them yourself.

feat
USE IT FOR

New capability or API

EXAMPLE
feat(order-service): add order cancellation endpoint
RELEASE
MINOR
fix
USE IT FOR

Bug fix

EXAMPLE
fix(device-backup): retry SSH on connection timeout
RELEASE
PATCH
docs
USE IT FOR

Documentation only

EXAMPLE
docs(api): document 409 for duplicate payments
RELEASE

none

style
USE IT FOR

Formatting, no behaviour change

EXAMPLE
style: apply google-java-format
RELEASE

none

refactor
USE IT FOR

Restructure, same behaviour

EXAMPLE
refactor(order): extract PricingCalculator
RELEASE

none

perf
USE IT FOR

Performance improvement

RELEASE
