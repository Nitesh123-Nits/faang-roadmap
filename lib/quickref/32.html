release/
USE FOR

Stabilise a version

F LOW

main → fixes only → main, then tag

EXAMPLE
release/1.5.0

Lowercase, hyphens, ticket first, no spaces (Git also rejects ~ ^ : ? * in ref names). Delete branches after merge. GitFlow teams use develop in place of

main for feature and bugfix work, and merge release

and hotfix branches into both. Prefixes are a TEAM convention.

Branches are temporary; tags are permanent. A hotfix branches from the released tag (v1.4.0), ships as v1.4.1, and merges back to main. A release branch takes version bump and fixes only, then ships as v1.5.0.
