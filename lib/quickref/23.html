Request and response JSON

Pick one case for the whole API. camelCase matches Jackson and Java records out of the box.

For snake_case, set spring.jackson.property-naming- strategy: SNAKE_CASE once, globally. Never mix both

in one API.

{
  "id": "9f1c2e7a-…",

✗ CONCERN

Field names

RULE

Singular nouns; plural for collections

GOOD / BAD

customerId, items vs Customer_ID

✗ CONCERN

Booleans

RULE

Plain adjective; Jackson drops is from isX() getters

GOOD / BAD

active, emailVerified

✗ CONCERN

Timestamps

RULE

ISO 8601 / RFC 3339, UTC, suffix At

TEAM
GOOD / BAD

createdAt vs created: 1731147330

✗ CONCERN

Money

RULE

Decimal string plus ISO 4217 currency; never a float

TEAM
GOOD / BAD
"49.90" + "INR"
✗ CONCERN

Enum values

RULE

UPPER_SNAKE, same as the Java enum

TEAM
GOOD / BAD
PAYMENT_PENDING
