One name, everywhere

The same service should carry the same name through the whole pipeline.

Maven device-backup-service →

Docker image acme/device-backup-service →

Helm chart device-backup-service →

K8s deployment device-backup-service →

Java package com.acme.devicebackup

Remember. Git branches, tags, commit types and GitHub labels are naming-sensitive too. They follow the same kebab-case and lowercase discipline; see Chapter 7.
