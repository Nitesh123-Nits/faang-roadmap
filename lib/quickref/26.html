Kafka event payloads follow the same rules

orders.confirmed, envelope plus payload:

{
  "eventId": "b7e2…",
  "eventType": "order.confirmed",
  "eventVersion": 1,
  "occurredAt": "2026-11-09T10:15:30Z",
  "payload": {
    "orderId": "9f1c2e7a-…",
    "total": { "amount": "49.90",
               "currency": "INR" }
  }
}

Remember. Events are contracts too: add fields freely, never rename or remove them without bumping eventVersion.
