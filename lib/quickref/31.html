Branch naming
feature/
USE FOR

New capability

F LOW

main → PR → main

EXAMPLE
feature/PAY-142-kafka-retry-backoff
bugfix/
USE FOR

Non-urgent bug

F LOW

main → PR → main

EXAMPLE
bugfix/ORD-87-null-device-ip
hotfix/
USE FOR

Urgent prod fix (PATCH)

F LOW

release tag → PR → main, then tag

EXAMPLE
hotfix/1.4.1-expired-token-fix
refactor/
USE FOR

Restructure only

F LOW

main → PR → main

EXAMPLE
refactor/BKP-31-extract-backup-validator
