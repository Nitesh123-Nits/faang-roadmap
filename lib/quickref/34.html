Create and push tags:

# annotated tag: use for releases
git tag -a v1.5.0 -m "Release 1.5.0"
# pre-release
git tag -a v1.5.0-rc.1 -m "Release candidate 1"
# push one tag explicitly
git push origin v1.5.0
# push commits + their annotated tags
git push --follow-tags
# list matching tags
git tag -l "v1.5.*"
# branch from a released tag
git switch -c hotfix/1.5.1-fix-npe v1.5.0
# last resort: never reuse a published tag
git tag -d v1.5.0
git push origin --delete v1.5.0
Automation and enforcement

git commit →

Husky commit-msg hook →

commitlint lints message →

GitHub Actions PR title + tests →

semantic-release tag + release

commitlint validates every commit message.

npm i -D @commitlint/cli \
  @commitlint/config-conventional
// commitlint.config.js
module.exports = {
  extends: ['@commitlint/config-conventional'],
  rules: { 'type-enum': [2, 'always', [
    'feat', 'fix', 'docs', 'style',
    'refactor', 'perf', 'test', 'build',
    'ci', 'chore', 'revert',
    'hotfix', 'security', 'infra'
  ]] }
};

Husky runs Git hooks on every commit (v9 syntax). In a Maven or Gradle repo, add a minimal

package.json for tooling only.

npm i -D husky
npx husky init
echo "npx --no -- commitlint --edit \$1" \
  > .husky/commit-msg

GitHub Actions blocks non-conforming PR titles. Pin to the current major version and check the action's releases.

on:
  pull_request:
    types: [opened, edited, synchronize]
jobs:
  pr-title:
    runs-on: ubuntu-latest
    steps:
      - uses: amannn/action-semantic-pull-request@v5
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

semantic-release derives version, tag and notes

from commits. Defaults: breaking gives major, feat

minor, fix and perf patch. Update the Maven or Gradle version in a build step.

{
  "branches": ["main"],
  "plugins": [
    ["@semantic-release/commit-analyzer", {
      "releaseRules": [
        { "type": "hotfix",
          "release": "patch" },
        { "type": "security",
          "release": "patch" }
      ] }],
    "@semantic-release/release-notes-generator",
    "@semantic-release/github"
  ]
}

Remember. Never reuse a published tag. Fix forward with the next patch version.
