Method prefixes carry a contract

Retrieval verbs, ordered by cost, cheap to expensive:

get in-memory read →

find lookup, may be absent →

load storage to memory →

fetch remote call, latency

get

Cheap, side-effect-free access to existing state

getStatus()
find

Lookup that may return nothing (Optional or empty collection)

findDeviceById(id)
fetch

Remote or expensive retrieval (HTTP, SSH, DB join)

fetchRunningConfig(device)
load

Read from storage into memory, or initialise a resource

loadRetryPolicies()
calculate

Pure derivation of a value

calculateMonthlyInterest(loan)
validate

Check rules; throws or returns a result, never silently mutates

validatePaymentRequest(req)
create / of / from

Factories: create makes new; of and from are static factories

Money.of(100, INR)
build

Assemble a complex object step by step

buildBackupCommand(device)
convert / to / map

Change representation: to returns another type, map maps models

toResponse(), mapToEntity(dto)

is / has / can

Boolean question with no side effects

hasExpired(), canRetry()

handle / on

Event or message entry points (listeners, handlers)

onDeviceOffline(event)
process

Only for a real pipeline with defined stages; else name the work

processBackupQueue()

action verbs Commands: verb + domain noun

scheduleBackup(), cancelJob(id)
