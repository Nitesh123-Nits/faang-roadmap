CHAPTER III

The Neural Architectures

The mechanical shapes into which parameters are arranged — each suited to a different sort of data.

No. 15

Neural Network

A model composed of layers of simple computational units ("neurons") connected by weighted links, loosely inspired by the brain's structure.

No. 16

Activation Function

A small non-linear function (e.g. ReLU, sigmoid) applied at each neuron, without which stacked layers would collapse into one plain linear equation.

No. 17

CNN (Convolutional Neural Network)

An architecture that slides small filters across an input — ideal for images — to detect local patterns like edges and textures.

No. 18

RNN / LSTM

Architectures that process sequences step by step, carrying a hidden memory forward. Largely superseded for language by the Transformer, but still seen in timeseries work.

No. 19

Transformer

The architecture (2017) behind nearly all modern LLMs. It processes an entire sequence at once using attention, rather than step by step, enabling far greater parallelism and scale.

No. 20

Attention Mechanism

A technique letting the model weigh how relevant every other token is to the one it is currently processing — the core innovation that lets Transformers capture longrange context.

ENGINEER’S NOTE

it behaves a little like a dynamic join: for each token, the model computes a relevance score against every other token before combining them.

No. 21

Encoder–Decoder

A two-part design: the encoder compresses an input into a representation, the decoder generates an output from it — used in translation and many sequence-tosequence tasks.
