Primary-Replica vs Multi-Primary

Decide whether one node accepts writes, or several, and who resolves the resulting conflicts.

THE 30-SECOND ANSWER

Primary-replica (leader-follower) sends all writes to one node and copies them to read-only replicas, so there are no write conflicts but write capacity and write-region locality are limited. Multi-primary (multileader) lets several nodes accept writes, improving write availability and locality across regions, but concurrent updates to the same data create conflicts that must be detected and resolved. Prefer primaryreplica unless you truly need multi-region writes.
