Document Database vs Key-Value Store

Pick whether the database understands the structure inside a value or treats the value as an opaque blob fetched by key.

THE 30-SECOND ANSWER

A document database understands the fields inside each record, so it can filter, project, and index them. A key-value store maps a key to a value it generally does not interpret, which keeps operations simple and latency low. Use key-value for lookups by a known key (sessions, caches, counters); use documents when you need to query by attributes.
