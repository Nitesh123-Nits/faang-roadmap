Relational vs Document Database

Normalize across tables and join at read time, or store each aggregate as one document that is read and written together.

THE 30-SECOND ANSWER

A relational database stores each fact once and reassembles it with joins, which keeps data consistent and queries flexible. A document database stores an aggregate, such as an order with its items, as one nested document, so a single read returns everything but copied data can drift. Choose documents when data is naturally read and written as a unit and relationships between aggregates are few.
