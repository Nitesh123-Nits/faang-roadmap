Reverse Proxy vs API Gateway

Decide whether the edge only forwards and balances traffic or also manages APIs as products with identity, quotas, and transformation.

THE 30-SECOND ANSWER

A reverse proxy sits in front of servers to terminate TLS, route by host or path, balance load, cache, and compress. An API gateway is a reverse proxy plus API-management features: authentication, rate limiting, quotas, request transformation, versioned routing, and analytics. Use a plain proxy for generic web traffic; use a gateway when many clients consume your APIs and policy should be enforced once at the edge.
