OLTP vs OLAP

Separate the database that runs the business from the one that analyzes it, and know why.

THE 30-SECOND ANSWER

OLTP systems handle many small, concurrent reads and writes against current state with strong integrity, usually in row-oriented databases. OLAP systems run large scans and aggregations over history, usually in column-oriented stores optimized for analytical queries. Running heavy analytics directly on the OLTP primary can hurt user-facing latency, so teams move data to an analytical store.
