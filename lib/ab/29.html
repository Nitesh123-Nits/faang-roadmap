Sharding vs Replication

One splits data to scale capacity; the other copies data to scale reads and survive failure.

THE 30-SECOND ANSWER

Sharding divides the dataset so each node owns a subset, increasing write throughput and total storage. Replication keeps copies of the same data on multiple nodes, improving availability and read capacity but not write capacity on a single-primary setup. Production systems usually combine them: each shard is replicated.
