Offset Pagination vs Cursor Pagination

Page by position or by the last seen key, and see why deep pages and changing data break the first.

THE 30-SECOND ANSWER

Offset pagination ( LIMIT n OFFSET m ) lets clients jump to any page but makes the database skip m rows, so deep pages get slower, and inserts or deletes between requests cause duplicates or missed items. Cursor (keyset) pagination continues after the last seen key using an index, giving stable cost and consistent traversal, but it supports only next/previous navigation. Use offset for small, mostly static data with page numbers; use cursors for feeds and large datasets.
