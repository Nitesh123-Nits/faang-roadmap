BASICS AND FILTERING

SELECT * FROM users WHERE age > 18 AND city = 'Delhi';

SORTING AND LIMITING
SELECT * FROM products ORDER BY price DESC LIMIT 5;
AGGREGATE FUNCTIONS
FUNCTIONRESULT
COUNT()Number of rows

GROUP BY AND HAVING
SELECT column, COUNT(*)
FROM table
GROUP BY column
HAVING COUNT(*) > 1;

GROUP BY groups rows with the same values. HAVING filters on the aggregated result; WHERE filters rows before grouping.
