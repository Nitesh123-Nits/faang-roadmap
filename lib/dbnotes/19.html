CHAPTER 10

How Database Indexing Works

Indexes are special data structures that help the database find data quickly without scanning the entire table.

A N A LO GY. An index is like the index of a book: it helps you find what you need

without reading the whole book.

WHY INDEX
Speeds up data retrieval and avoids full table scans.
Improves ORDER BY , GROUP BY and DISTINCT performance.
Enforces uniqueness (unique index) and supports efficient joins.
COST
Without an indexO(N), a full table scan reading every row
With an indexO(log N), a fast lookup
THE STRUCTURE: B+ TREE

Most databases (MySQL, PostgreSQL, SQL Server) use a B+ tree for indexes.

A balanced tree, so search is always O(log N).
Internal nodes hold keys that guide the search.
Leaf nodes hold the actual data pointers (row IDs), or the rows themselves in a

clustered index.

Leaves are linked, which makes range scans fast.
