If transfer() calls another @Transactional method with REQUIRES_NEW , that method runs in a separate transaction.

ROLLBACK RULES

By default RuntimeException and Error trigger a rollback. Checked exceptions do not. Cus‐ tomise with rollbackFor and noRollbackFor .

@Transactional(
    rollbackFor = {IOException.class, CustomException.class},
    noRollbackFor = {BusinessException.class}
)
public void process() { --. }

PITFALLS
@Transactional works only on public methods called through the proxy.
Self-invocation (a call within the same class) bypasses the proxy, so the annotation has

no effect. Move the method to another bean.

It works with DataSourceTransactionManager (JDBC) or JpaTransactionManager (JPA).
In reactive apps, use the reactive transaction manager; thread‐bound resources do not

apply.

REMEMBER.

@Transactional is Spring AOP plus a transaction manager. It creates

a transaction boundary around your method and manages resources, with com‐ mit or rollback.
