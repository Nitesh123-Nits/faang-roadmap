CAP and Real-World Architectures

THE CAP THEOREM

A distributed data store can guarantee at most two of three properties at once.

PROPERT YMEANING
ConsistencyEvery read sees the most recent write
AvailabilityEvery request gets a response
Partition toleranceThe system keeps working despite network failures between nodes

Partitions are unavoidable in a distributed system, so the real choice is CP or AP when a partition happens.

DATABASET YPICAL PREFERENCE
PostgreSQL, MySQL CP (consistency and partition tolerance), single-node ACID bydefault
Cassandra,AP (availability and partition tolerance)
