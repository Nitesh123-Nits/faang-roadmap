CHAPTER 05

SQL in an RDBMS

SQL commands fall into five families. Know which family a command belongs to and you can answer most "what does it do" questions.

DDL→ DML → DQL → DCL→ TCL
FAMILYFULL NAMETHINKCOMMANDS
DDLData Definition LanguageStructureCREATE, ALTER, DROP, TRUNCATE, RENAME
DMLData Manipulation LanguageDataINSERT, UPDATE, DELETE
DQLData Query LanguageQuerySELECT
DCLData Control LanguageAccessGRANT, REVOKE
TCLTransaction Control LanguageTransactionsCOMMIT, ROLLBACK, SAVEPOINT

SELECT is sometimes grouped under DML, but strictly it is DQL.

DDL: STRUCTURE
CREATE TABLE employee (
  id INT PRIMARY KEY,
  name VARCHAR(100),
  salary DECIMAL(10,2)
);
ALTER TABLE employee ADD department VARCHAR(50);
TRUNCATE TABLE employee;
DROP TABLE employee;
COMMANDPURPOSE
CREATECreate a new object (database, table, index)
ALTERChange the structure of an existing object
DROPDelete an object entirely
TRUNCATERemove all rows but keep the structure
RENAMERename an object

DDL changes auto-commit in most DBMS.
