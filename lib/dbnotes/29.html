CHAPTER 14

ACID Transactions

A transaction groups statements into one unit of work. ACID is the set of guarantees it gives.

PROPERT YMEANINGMECHANISM (T YPIC‐ AL)
AtomicityAll or nothingUndo log, rollback
ConsistencyThe database moves from one valid state to anotherConstraints, triggers
IsolationConcurrent transactions do not interfere with each otherLocks, MVCC
DurabilityOnce committed, changes are permanentWrite-ahead log, fsync
THE CLASSIC EXAMPLE

A transfer debits one account and credits another. Atomicity means either both happen or neither. Consistency means total money is unchanged and constraints hold. Isolation means no one sees the debit without the credit. Durability means a crash right after commit does not lose the transfer.

START TRANSACTION;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
COMMIT;      -- or ROLLBACK on any failure
