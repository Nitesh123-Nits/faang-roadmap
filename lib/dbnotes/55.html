COMMON INTERVIEW QUESTIONS, WITH THE SHORT ANSWER

What is the difference between DELETE, TRUNCATE and DROP? DELETE removes

selected rows (DML, rollback‐able, slower). TRUNCATE removes all rows and keeps the table (DDL, fast). DROP removes the table itself.

What is the difference between WHERE and HAVING? WHERE filters rows before

grouping; HAVING filters groups after aggregation.

What is an index and how does it work? A sorted auxiliary structure (usually a B+ tree) mapping column values to row locations, turning an O(N) scan into an O(log N) lookup, at the cost of storage and slower writes.

Explain ACID with an example. A bank transfer: both the debit and credit happen or neither (atomic); constraints hold (consistent); no one sees half the transfer (isol‐ ated); a committed transfer survives a crash (durable).

What is normalization? Explain 1NF, 2NF, 3NF. Organising data to reduce redund‐ ancy and anomalies. 1NF atomic values, 2NF no partial dependency on a composite key, 3NF no transitive dependency.

How would you optimise a slow SQL query? Run EXPLAIN , look for full scans, add or fix indexes, select only needed columns, avoid functions on indexed columns, re‐ fresh statistics, add LIMIT , consider caching or denormalisation.
