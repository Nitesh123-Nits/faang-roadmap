Paging and Fragmentation

Data in databases is stored on disk in fixed-size blocks called pages. Over time, pages can become fragmented.

WHAT IS A PAGE
The smallest unit of I/O between disk and memory.
Typical sizes are 4 KB, 8 KB, 16 KB or 32 KB, depending on the DBMS (PostgreSQL

8 KB, InnoDB 16 KB, SQL Server 8 KB).

Each page has a page ID. A table or index is made of many pages.
If a row does not fit in a page, it spills into another page.
WHAT IS FRAGMENTATION

Related data is scattered across many non‐contiguous pages.
