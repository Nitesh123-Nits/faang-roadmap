#TOPICIN ONE BREATH
1What is a databaseOrganised collection of structured data, stored electronically, accessed by applications
2TypesSQL: MySQL, PostgreSQL, Oracle, SQL Server. NoSQL: MongoDB (document), Cassandra (wide column), Redis (key-value), Neo4j (graph)
3RDBMS conceptsTable, row, column, primary key, foreign key, constraints, index
4SQL basicsDDL create/alter/drop/truncate. DML insert/update/delete. DQL select. DCL grant/revoke. TCL commit/rollback/savepoint
5JoinsInner: matches. Left: all left plus matches. Right: all right plus matches. Full: all rows. Cross: Cartesian product
6ConstraintsNOT NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY, CHECK, DEFAULT
7Normalization1NF atomic values. 2NF no partial dependency. 3NF no transitive dependency. BCNF stronger 3NF
8ACIDAtomicity, Consistency, Isolation, Durability
9IndexesFaster reads, slower writes. B-tree, hash, full-text, composite. Index columns in WHERE, JOIN, ORDER BY
10NoSQL conceptsDocument: MongoDB. Key-value: Redis (caching, sessions). Wide column: Cassandra (time series). Graph: Neo4j (relationships)
11Common commandsSHOW DATABASES, USE, DESC, SELECT --. LIMIT, EXPLAIN, DELETE --. WHERE
