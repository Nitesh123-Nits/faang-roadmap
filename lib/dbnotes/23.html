RANGE QUERY PERFORMANCE

For a range like id BETWEEN 1000 AND 2000 , a clustered index seeks to 1000 and scans sequentially to 2000. A non‐clustered index seeks, then does a pointer lookup and table access per row, which is less efficient.

COVERING INDEX

A non‐clustered index that contains every column a query needs, so the table is never touched.

CREATE INDEX idx_user ON Users(email) INCLUDE (name, city);
-- A query on email, name, city is answered from the index alone.

INCLUDE is supported in SQL Server and PostgreSQL 11+; in MySQL, add the

columns to the index key instead.

MEMORY TRICK

A clustered index is the book content: the actual pages in order. A non‐clustered in‐ dex is the book index page: keyword to page number.

R E M E M B E R . Most databases use the primary key as the clustered index by de‐

fault (implementation varies; in MySQL InnoDB it always does). Additional searchable columns are typically indexed with non‐clustered indexes.
