SQL CHEAT SHEET
SUBQUERIES
SELECT name FROM users
WHERE id IN (SELECT user_id FROM orders);
INDEXES AND VIEWS
CREATE INDEX idx_name ON users(name);          -- speeds up queries
CREATE VIEW user_view AS
SELECT name, age FROM users;                    -- virtual table
ADVANCED CONCEPTS

Window function: a calculation across a set of related rows without collapsing them.

SELECT name, RANK() OVER (ORDER BY salary DESC) AS rnk
FROM employees;

CTE (common table expression): makes complex queries easier to read and reuse.

WITH adults AS (
  SELECT * FROM users WHERE age > 18
)
SELECT * FROM adults;

CASE: conditional logic in a query.

SELECT name,
  CASE WHEN age > 18 THEN 'Adult' ELSE 'Minor' END AS category
FROM users;

USEFUL HABITS

Back up data regularly. Follow naming conventions. Test queries on sample data. Validate in production before you trust a query.

REMEMBER.

WHERE filters rows; HAVING filters groups. UNION ALL when you

know there are no duplicates.
