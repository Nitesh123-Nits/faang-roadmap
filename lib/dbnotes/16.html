SQL Query Execution Order

SQL is declarative, but the database processes the query in a specific logical order. You write SELECT first; the engine reaches it sixth.

SELECT   e.name, d.department_name
FROM     employees e
JOIN     departments d ON e.dept_id = d.id
WHERE    e.status = 'Active'
GROUP BY d.department_name
HAVING   COUNT(e.id) > 5
ORDER BY d.department_name
LIMIT    10;

WHY IT MATTERS
You cannot use a SELECT alias in WHERE or HAVING in standard SQL, because SELECT

has not run yet. ORDER BY can use it, because it runs after.

WHERE cannot contain aggregates; the groups do not exist yet. Use HAVING .
DISTINCT is applied after SELECT , before ORDER BY .
