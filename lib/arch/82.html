Data Fabric Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

A metadata-driven integration layer that connects data across distributed sources and automates discovery, governance and delivery.

Use active metadata, knowledge graphs and automation to provide unified access without physically centralizing all data.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Fragmented data across clouds, databases and applications that is hard to find and integrate.

Hybrid and multi-cloud estates made centralization impractical.

A metadata-driven fabric layer virtualizes access across sources

How it works

Connectors catalog all data sources.
Active metadata builds a knowledge graph of data and relationships.
Virtualization exposes unified views without copying data.
Governance and security policies apply uniformly.
Automation recommends pipelines and data products.
Consumers discover and query data through one layer.
