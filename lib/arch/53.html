Component-Based UI Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

UIs built from encapsulated, reusable components that manage their own state and render from props, composed into a tree.

Compose complex interfaces from small selfcontained pieces with explicit inputs and outputs.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Page-sized templates with global scripts and duplicated markup.

React, Vue and Angular popularized composition of components with a virtual DOM or reactive rendering.

Component tree; props flow down, events flow up
Domain core
Service / component

Sync call

Async / event

How it works

The UI is decomposed into a tree of components.
Parents pass data to children as props.
Components hold local state when needed.
User events bubble up through callbacks.
State changes trigger a re-render of affected components.
Shared concerns use context or a global store.
