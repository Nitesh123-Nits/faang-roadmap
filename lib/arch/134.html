MAJOR SERVICES & COMPONENTS
COMMUNICATION MECHANISMS

Ingestion (Kafka Connect, CDC), Stream processors, Batch processing, Orchestrator, Catalog and lineage, Serving stores, Feature store.

Kafka as the central log; stream processors consume and produce topics; batch jobs read and write lakehouse tables; orchestrator schedules and monitors.

DATA STORAGE ARCHITECTURE
EXTERNAL DEPENDENCIES

Object storage with Delta/Iceberg tables in Bronze/Silver/Gold layers; low-latency OLAP store for real-time dashboards; feature store; metadata catalog.

Source databases and SaaS exports, BI tools, ML platforms, identity and secrets management.

CHOSEN ARCHITECTURAL STYLE
WHY THIS ARCHITECTURE WAS SELECTED

Kappa-style streaming with a lakehouse and medallion layering, plus orchestrated batch for heavy backfills.

A replayable log lets both real-time and historical use cases share one pipeline; the lakehouse gives ACID tables and governance on cheap storage; medallion layers make quality explicit.

KEY TRADE-OFFS

Operational complexity of streaming and state; storage and compute cost; schema evolution and backfill coordination; skills requirement.
