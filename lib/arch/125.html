Vertical Slice vs Layered Architecture

Layered code is grouped by technical role and requests cut across all layers. Vertical slices group by feature so each request is handled end-to-end inside one slice.

Layered — horizontal layers shared by all features

Vertical slices — feature-oriented

Complexity trade-offs

Suitable use cases

Layered optimizes reuse across features; slices optimize change within a feature. Slices need a rule for extracting shared domain logic so duplication does not turn into divergence.

Layered: small apps and teams standardized on layers.
Vertical slice: feature-driven APIs with frequent, independent changes.

Practical recommendation. Package by feature (slices) and apply layering or hexagonal structure inside the slices that have real domain logic. Extract shared code only after the third repetition.
