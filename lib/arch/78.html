Data Lake Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

A central repository storing raw data of any format at scale in cheap object storage, structured later on read (schema-on-read).

Ingest everything first, model later, and let many engines analyze the same raw data.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Rigid warehouse schemas that cannot absorb diverse, high-volume or unstructured data.

Hadoop and cloud object storage made storing all data cheap and flexible.

How it works

Data from many sources is ingested as-is into the raw zone.
Files are stored in open formats (Parquet, JSON, ORC).
Processing jobs clean and standardize data into curated zones.
A catalog tracks schemas, lineage and access.
Engines like Spark and Presto query data on demand.
Data scientists and BI tools consume curated datasets.
