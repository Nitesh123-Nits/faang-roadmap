Function-as-a-Service (FaaS) Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

Code is deployed as individual stateless functions that run in response to events and are managed, scaled and billed per execution by the platform.

The unit of deployment is a function; the platform handles runtime, scaling and isolation.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Provisioning and paying for servers for small, sporadic or event-driven units of work.

AWS Lambda (2014) introduced fine-grained, payper-invocation compute.

Triggers invoke ephemeral function instances

How it works

An event source triggers the function.
If no warm instance exists, the platform cold-starts one.
The function executes statelessly within time and memory limits.
It reads and writes state in external services.
The platform scales instances by concurrency.
The instance is frozen or discarded after idle time; billing stops.
