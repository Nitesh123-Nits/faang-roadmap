MVI (Model-View-Intent)

WHAT IS IT?
FUNDAMENTAL IDEA

Unidirectional cycle: the View emits Intents, a reducer produces a new immutable Model (state), and the View renders that state.

A single source of truth and one-way data flow make UI state predictable and reproducible.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Inconsistent UI state and hard-to-trace updates in MVVM with many mutable fields.

Inspired by Redux and Cycle.js and adopted for complex Android and web UIs.

Intent → Model (reducer) → View in a one-way cycle

How it works

The user acts; the view converts it into an Intent.
The intent is passed to the model layer.
A reducer combines the intent and current state into a new immutable state.
Side effects (API calls) run and return results as new intents.
The view renders the full state.
State history can be logged or replayed for debugging.
