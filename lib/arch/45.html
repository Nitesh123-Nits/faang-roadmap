Lambda Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

Combines a batch layer for accurate historical views with a speed layer for real-time views, merged by a serving layer.

Use batch for correctness and stream for freshness, then query both together.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Getting low-latency results while still computing complete and corrected results.

Nathan Marz proposed it when stream systems were less reliable than batch for accuracy.

How it works

All data is appended to an immutable master dataset.
The batch layer recomputes accurate views periodically.
The speed layer computes incremental views for recent data.
The serving layer merges batch and real-time views.
Batch results eventually supersede speed-layer approximations.
Queries see a unified, fresh view.
