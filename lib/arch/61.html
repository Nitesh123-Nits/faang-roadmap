Ambassador Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

A helper proxy deployed next to a client application to handle outbound network concerns — retries, circuit breaking, routing and monitoring.

Offload client-side connectivity logic to an out-ofprocess proxy so the application stays unaware of the network’s complexity.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Legacy or polyglot clients lacking resilience features for talking to remote services.

Often used to modernize legacy apps without modifying their code.

Ambassador proxies outbound calls on behalf of the client

How it works

The client sends requests to the ambassador on localhost.
The ambassador resolves the remote service and sets up TLS.
It applies retries, timeouts and circuit breaking.
It forwards the request and returns the response.
It records metrics and logs for outbound traffic.
The client remains unchanged.
