III.01

Pipe-and-Filter Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

A chain of independent processing steps (filters) connected by channels (pipes), each transforming its input stream into an output stream.

Build complex processing from small, single-purpose filters that share only a data format.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Monolithic processing code that is hard to reuse, reorder, test or parallelize.

Unix pipelines and compilers showed that composable transformations scale from shell scripts to ETL and media processing.

How it works

A source emits raw data into the first pipe.
Each filter reads input, applies one transformation and writes output.
Pipes buffer data and decouple filter speeds.
Filters are stateless and know nothing about neighbors.
The sink persists or exposes the final result.
Filters can be reordered, replaced or run in parallel.
