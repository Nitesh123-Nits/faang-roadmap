How to use this handbook

A visual reference for architecture discussions, design reviews, HLD preparation and interviews. Every architecture carries one diagram, one fixed template, and an explicit “when not to use it”. There is no universally best architecture — each chapter states the conditions under which it earns its cost.

Deduplication

Several names appear in more than one part of the catalog (for example Event-Driven, Saga, Microkernel). Each concept has exactly one full chapter; every other mention is a cross-reference on the relevant part’s opening page.
