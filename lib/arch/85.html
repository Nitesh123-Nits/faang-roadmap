ETL / ELT Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

ETL transforms data before loading into the target; ELT loads raw data first and transforms it inside the target system.

ELT exploits scalable warehouse and lake compute for transformation, while ETL cleanses data in a separate engine before storage.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Moving data from operational sources to analytics stores with the right transformation placement.

Cheap, scalable cloud warehouses shifted heavy transformation into the destination.
