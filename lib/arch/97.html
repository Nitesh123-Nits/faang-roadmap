CDN-Based Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

Static and cacheable content is served from globally distributed edge servers, shielding the origin and reducing latency.

Bring content geographically close to users and absorb traffic at the edge.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Latency for global users and origin overload from repeated requests.

Web traffic is dominated by cacheable assets and media; CDNs made global delivery affordable.

Users served from edge caches; origin only on miss

How it works

DNS directs the user to the nearest edge PoP.
The edge serves cached content on a hit.
On a miss, it asks an origin shield, which may also hold the object.
Only a shield miss reaches the origin.
The response is cached according to Cache-Control headers.
Purge or versioned URLs refresh updated content.
