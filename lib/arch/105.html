VIII.03

Reflection-Based Architecture

WHAT IS IT?
FUNDAMENTAL IDEA

A system with a base level (application logic) and a meta level that inspects and modifies the system’s structure and behavior at runtime.

Expose the system’s own types, configuration and behavior to be examined and changed dynamically.

PROBLEM IT SOLVES
WHY IT WAS INTRODUCED

Rigid applications that cannot adapt to new types, configurations or extensions without recompilation.

Frameworks needed to discover and wire components dynamically (dependency injection, serialization, ORMs).

How it works

The framework scans classes and reads metadata (annotations, types).
Metaobjects describe structure and behavior.
The framework instantiates and wires objects via the reflection API.
It invokes methods or maps fields dynamically.
Changes to the meta level alter base-level behavior.
Proxies and interceptors apply cross-cutting behavior.
