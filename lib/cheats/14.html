THE TWELVE RULES

If you remember nothing else

THE ARCHITECT'S CONCEPT MAP

Before any choice: problem, constraints, alternatives, trade-offs, failure, operations, cost, a simpler way, and reversibility.

A VS B DECISION MAP

Name the problem, check the constraints, pick the simpler option, and write the revisit trigger into an ADR.

THE HLD INTERVIEW FRAMEWORK

Requirements drive numbers, numbers drive components, and every component earns its place with a reason and a stated cost.

SPRING BOOT INTERNALS

If a call bypasses the container or the proxy, the annotation does nothing.

DATABASE ESSENTIALS

Measure before tuning: read the plan, check the index, shorten the transaction, then scale.

CACHING CHEAT SHEET

A cache is a copy, and every copy can be wrong. Decide the staleness you accept, set a TTL, protect the database from stampedes, and measure the hit ratio before and after.

KAFKA CHEAT SHEET

Ordering lives in a partition, parallelism is the partition count, durability comes from replication, and delivery guarantees come from when you commit.

SERVICE COMMUNICATION DECISIONS

Choose the weakest coupling that meets the requirement. Ask whether the caller must wait; if not, publish an event. Always set timeouts and make handlers idempotent.

KUBERNETES ESSENTIALS

You declare desired state and controllers reconcile toward it. Probes and resource settings tell Kubernetes how to treat your process.

OBSERVABILITY CHEAT SHEET

Monitoring tells you something is broken; observability lets you ask why. Alert on SLO burn, correlate by traceId, and keep cardinality and cost under control.

PRODUCTION INCIDENT PLAYBOOK

Stabilise first, communicate early, investigate second, learn afterwards.

GIT PRODUCTION INCIDENT PLAYBOOK

Revert before you reset, copy before you rewrite, and rotate a leaked secret before you clean the history.
