About these notes

Assumes Spring Boot 3.x and Java 17+. Check names and defaults against your versions.

THE KEY IDEA

Most Spring surprises come from two facts: beans are created and wired by the container, and cross-cutting behaviour is added by proxies. If a call bypasses the container or the proxy, the annotation does nothing.

Combines @Configuration , @EnableAutoConfiguration and @ComponentScan .
Component scan covers the main class's package and below. Beans outside it are not found.

Proxies

PROXIES

How proxies work

Spring AOP wraps beans in proxies: JDK interface proxies or CGLIB class proxies (CGLIB is the Boot default).
Calls through the proxy get the advice: transactions, async, caching, security.
A call from inside the same object skips the proxy (self- invocation).
Private and final methods cannot be proxied by CGLIB.
Fix: move the method to another bean, inject the proxied bean, or use AspectJ weaving.
WHY IT BREAKS

this.method() never goes through the proxy. That is why so many annotations “do nothing”.

PROXIES

@Transactional pitfalls

Self-invocation or a non-Spring-managed object: no transaction.
By default rolls back on unchecked exceptions and Errors only; set rollbackFor for checked ones.
Swallowing the exception inside the method prevents rollback.
REQUIRED joins an existing transaction; REQUIRES_NEW suspends it and starts another.
readOnly is a hint to the driver and ORM, not a guarantee.
@Async and new threads do not inherit the transaction.
Lazy loading outside a transaction throws LazyInitializationException .
Keep the boundary at the service layer and keep it short.

CONFIG

Configuration

Precedence, roughly: command-line args, environment variables, profile files, application.yml , defaults.
Prefer @ConfigurationProperties (typed, validated with @Validated ) over scattered @Value .
Relaxed binding maps MY_APP_PORT to my.app.port .
Profiles select environment config; do not commit secrets.
@RefreshScope (Spring Cloud) rebinds on refresh.
ASYNC

Async, scheduling and threads

@Async needs @EnableAsync , and goes through the proxy.
Define your own executor; the defaults may not suit load.
Exceptions in void async methods are lost without a handler.
@Scheduled runs on a single thread by default; use a distributed lock (such as ShedLock) when scaling out.
Boot 3.2+ on Java 21: spring.threads.virtual.enabled=true uses virtual threads. Verify against your versions.

Data and security

D ATA

Data access

HikariCP is the default pool; tune maximum-pool-size by measurement.
spring.jpa.open-in-view defaults to true. Consider disabling it to avoid lazy loading in the view layer.
Use Flyway or Liquibase for migrations.
Watch for N+1 queries; check generated SQL.
@Transactional(readOnly = true) for query services.
SECURITY

Spring Security

Register a SecurityFilterChain bean; WebSecurityConfigurerAdapter is gone in Spring Security 6.
Filter chain order matters; authentication runs before authorization.
Method security needs @EnableMethodSecurity .
Stateless APIs: validate JWTs with the resource server support.
CSRF protection is for browser sessions; know when to disable it.
