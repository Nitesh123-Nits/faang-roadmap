Metrics tell you THAT something is wrong · traces tell you WHERE · logs tell you WHY. Exemplars link a latency spike to an example trace.

Three signals, one pipeline. Apps emit via Micrometer/OTel; the Collector processes and routes; shared trace ids connect everything.

Trace IDs vs correlation IDs: a W3C trace id is generated and propagated automatically by tracing; a separate business correlation id (e.g.X-Request-Idfrom a client or anorderId) is useful across async boundaries or systems without tracing. Log both.

12.12Health Checks, Feature Flags and Graceful Degradation

Health: liveness (process), readiness (can serve), deep checks in dashboards / synthetic probes — not in liveness (Chapter

10).

Feature flags (OpenFeature API with a provider like Unleash, LaunchDarkly, flagd): decouple deploy from release, kill‐

switch expensive features, percentage rollouts. Remove stale flags — they are tech debt with branches.

Degradation ladder per dependency: full →cached/stale →reduced feature →static fallback →fail fast with clear error.
