"Thread dump vs heap dump?" — thread dump: what every thread is doing now (cheap, for hangs/CPU). Heap dump: every live

object (expensive, for leaks/OOM). Analyze heap dumps with Eclipse MAT: dominator tree →retained size.

"What is a TLAB?" — Thread‐Local Allocation Buffer; each thread bumps a pointer in its own Eden chunk, so allocation is

extremely cheap.

"Stop‐the‐world?"
all application threads paused at a safepoint. Even "concurrent" collectors have short STW phases.
