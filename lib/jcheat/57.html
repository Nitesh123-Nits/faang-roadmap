8.7Pagination: OFFSET vs Keyset

OFFSET vs keyset pagination

OFFSET 100000 LIMIT 20
DB reads & discards 100,000 rows, returns 20
Cost grows with page number; rows shift if data changes
(duplicates / skipped items between pages)
WHERE (created_at, id) < (:c, :id) LIMIT 20
Index seek to the cursor, read 20 rows
Constant cost on any page; stable under inserts
No 'jump to page 57' — use opaque next-cursor

Keyset (seek) pagination. Remember the last row's sort key and continue from it.
