8.11

MVCC

Writers create new row versions ; readers see the version visible to their snapshot →readers don't block writers and vice

versa.

PostgreSQL: old versions stay in the table until VACUUM removes them. Long‐running transactions (or idle‐in‐transaction

sessions, abandoned replication slots) prevent cleanup →table/index bloat, and in extreme cases transaction‐ID wraparound protection.

MySQL InnoDB: old versions in undo logs; long transactions grow the history list length and slow reads.
