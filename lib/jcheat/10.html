Java native serialization (ObjectInputStream) is a long‐standing source of remote‐code‐execution vulnerabilities via gadget chains. Never deserialize untrusted bytes; use a JEP 290 deserialization filter if you must.

For data exchange use JSON (Jackson), Avro or Protobuf with explicit schemas. Records deserialize through their canonical
