Network Policies

apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata: { name: orders-ingress, namespace: shop }
spec:
  podSelector: { matchLabels: { app: orders } }
  policyTypes: ["Ingress"]
  ingress:
    - from:
        - namespaceSelector: { matchLabels: { kubernetes.io/metadata.name: ingress-nginx } }
        - podSelector: { matchLabels: { app: checkout } }
      ports: [ { protocol: TCP, port: 8080 } ]

Default: all pods can talk to all pods. Start with default‐deny per namespace, then allow explicitly. Requires a CNI that enforces policies (Calico, Cilium, cloud CNIs with policy enabled).
