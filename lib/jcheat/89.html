12.14Performance Profiling and Load Testing

Profile before optimising: async‐profiler / JFR flame graphs for CPU, allocation, lock contention, wall‐clock (finds I/O

waits).

Load test types: baseline, load (expected peak), stress (find the breaking point), soak (hours: leaks, pool exhaustion), spike.
Tools: Gatling, k6, JMeter, wrk2. Use open workload models (arrival rate) to avoid coordinated omission; test against

production‐like data volumes and dependencies (or realistic stubs with latency).

Record: throughput, p50/p95/p99,

error rate, and resource saturation; compare against SLOs, not gut feel.

Micro‐benchmarks only with JMH (warm‐up, dead‐code elimination, forks).
