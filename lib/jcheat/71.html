Jobs and CronJobs

apiVersion: batch/v1
kind: CronJob
metadata: { name: nightly-reconcile }
spec:
  schedule: "30 1 * * *"
  timeZone: "Asia/Kolkata"
  concurrencyPolicy: Forbid
  startingDeadlineSeconds: 600
  successfulJobsHistoryLimit: 3
  failedJobsHistoryLimit: 5
  jobTemplate:
    spec:
      backoffLimit: 2
      activeDeadlineSeconds: 3600
      template:
        spec:
          restartPolicy: Never
          containers:
            - name: reconcile
              image: registry.example.com/orders:1.14.2
              args: ["--spring.profiles.active=prod,reconcile-job"]
# stable since Kubernetes 1.27
# don't start if previous still running

CronJobs can occasionally run twice or be skipped — make jobs idempotent.
