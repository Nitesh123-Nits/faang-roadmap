A.2 Git

CommandExplanation
git switch -c feature/outboxcreate and switch to a branch
git add -pstage hunks interactively (review what you commit)
git commit --amend --no-editadd staged changes to the last commit (only if not pushed/shared)
git fetch --prune && git rebase origin/mainupdate branch on top of main
git rebase -i HEAD~5squash/reword/reorder local commits
git log --oneline --graph --decorate -20compact history graph
git log -S 'retryTemplate' -pfind commits that added/removed a string ("pickaxe")
git blame -w -C -L 120,160 OrderService.javawho changed these lines (ignore whitespace, follow moves)
git bisect start; git bisect bad; git bisect good v1.13.0binary‐search the commit that introduced a bug
git stash push -m wip · git stash popshelve / restore work in progress
git cherry-pick <sha>apply one commit to the current branch (hotfix backports)
git revert <sha>new commit that undoes a pushed commit (safe on shared branches)
git reflogrecover "lost" commits after a bad reset/rebase
git reset --hard origin/maindestructive discard all local changes and commits on this branch
git push --force-with-leaseforce‐push only if the remote hasn't moved (never plain --force on shared branches)
git clean -fdxdestructive delete untracked and ignored files (run -n first for a dry run)
