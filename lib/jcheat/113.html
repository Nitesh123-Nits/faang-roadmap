R.5 Top 25 Kafka, Redis and Database Questions

How does Kafka achieve high throughput? Sequential append, batching, compression, zero‐copy, partition parallelism.
How does Redis Cluster shard? 16384 hash slots via CRC16; hash tags colocate keys.
What is ISR? Replicas caught up with the leader;acks=allwaits for them.
How to implement rate limiting in Redis? Lua token bucket or sliding window per key, atomic.
How do you choose a partition key? The entity needing order, with high cardinality and even load.
What are ACID properties? Atomicity, consistency, isolation, durability.
What triggers a consumer rebalance? Members joining/leaving, missed heartbeats, exceeding changes.

Blocking vs non‐blocking retries? Preserve order but stall partition vs keep flowing but lose per‐key order.
What is log compaction for? Keeping latest state per key (changelogs, KTables).
How do you measure consumer health? Lag in records and time, rebalance rate, processing errors.
Kafka vs RabbitMQ? Replayable partitioned log vs smart broker with routing and per‐message acks.
Which Redis data structure for a leaderboard? Sorted set (ZADD, ZREVRANGE).
How do you prevent cache stampede? Single‐flight locks, serve stale, early refresh, TTL jitter.
Cache penetration vs avalanche? Missing keys hammering DB vs many keys expiring/cache down at once.
Explain isolation anomalies. Dirty, non‐repeatable, phantom reads; lost updates; write skew.
How do indexes work? B‐trees sorted by key enabling seeks and ordered scans; composite indexes by column order.
What is a covering index? Contains all needed columns →index‐ only scan.
Clustered vs non‐clustered index? Table stored in PK order (InnoDB) vs separate structure pointing to rows (PG heap).

Optimistic vs pessimistic locking? Detect conflicts with versions vs block with row locks.
What is MVCC? Multiple row versions so readers and writers don't block each other.
How do you migrate a schema with zero downtime? Expand → backfill →switch →contract; concurrent index builds.
When would you shard? When a single primary can't handle writes/storage after vertical scaling, replicas, partitioning and caching.
RDB vs AOF? Snapshots (fast restart, more loss) vs write log (less loss, larger/slower).
