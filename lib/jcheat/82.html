11.16LLD: Diagrams Worth Drawing

Class diagram: entities, value objects, interfaces, key relationships (composition ◆, aggregation ◇, inheritance △, dependency ⇢). Keep only what the design discussion needs.
Sequence diagram: the critical flow with sync/async arrows, transaction boundaries and failure branch.
State diagram: for anything with a lifecycle (order, payment, trip, booking) — list states, allowed transitions, who triggers

each.

ER diagram: tables, PK/FK, cardinalities, key indexes and unique constraints that encode invariants.
