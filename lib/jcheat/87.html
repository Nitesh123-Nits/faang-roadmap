12.8Secrets Management and Least Privilege

Store secrets in a manager (Vault, AWS Secrets Manager, GCP Secret Manager, Azure Key Vault); inject at runtime; rotate;

audit access.

Never in Git, images, logs, crash dumps, or Helm values committed in plain text. Scan repos (gitleaks, GitHub secret

scanning).

Least privilege everywhere: DB users per service with only needed grants; IAM roles per workload; K8s RBAC per

ServiceAccount; Kafka ACLs per principal.

Prefer short‐lived, dynamically issued credentials over long‐lived static keys.
