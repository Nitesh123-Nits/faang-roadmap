Configuration and Secret Management

Secrets come from the platform: Kubernetes Secrets (ideally synced from Vault / AWS Secrets Manager / GCP Secret

Manager via External Secrets or CSI driver), or Spring Cloud Vault. Never commit them; never bake them into images.

Import config trees:spring.config.import: optional:configtree:/etc/secrets/maps mounted files to properties.
Rotate credentials without redeploys where possible (short‐lived DB credentials from Vault).
Mask secrets in logs and Actuator (
