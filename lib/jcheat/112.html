R.4 Top 30 Microservices and Distributed Systems Questions

When would you not use microservices? Small team, unclear domain, no independent scaling/release need — start with a modular monolith.
How do you define service boundaries? Bounded contexts, aggregates, team ownership, low synchronous coupling.
How do services communicate? Sync REST/gRPC for queries needing an answer; async events for propagation and workflows.
What does an API gateway do? Edge concerns: routing, TLS, authN, rate limits, aggregation for BFFs.
How do you handle a slow dependency? Timeouts, circuit breaker, bulkhead, fallback, caching, async decoupling.
How do you implement retries safely? Only transient errors on idempotent ops; backoff + jitter; one layer; budgets.
How do you prevent duplicate orders? Idempotency keys, unique constraints, idempotent consumers.
Saga orchestration vs choreography? Central coordinator vs event reactions; visibility vs decoupling.
What is the transactional outbox? Write event to an outbox table in the same TX; relay publishes it.
How do you keep data consistent across services? Sagas, outbox, idempotency, reconciliation; accept eventual consistency where safe.
Strong vs eventual consistency — choose for a shopping cart. Cart: eventual is fine; checkout stock and payment: strong.
How does leader election work? Consensus (Raft) or leases in a coordination service; old leaders fenced.
Why are distributed locks hard? Pauses, clock drift, failover; need leases plus fencing tokens.
What delivery guarantee do you design for? At‐least‐once + idempotency.
What causes cascading failures? Saturated threads/connections propagating upstream, retry storms, restart storms.
What is backpressure? Slowing producers when consumers can't keep up — bounded queues, pull‐based consumption.
How do you handle hot keys/partitions? Better keys, salting, local caches, splitting tenants.
What is consistent hashing? Ring mapping keys to the next node; minimal movement on resize; virtual nodes for balance.
SLI vs SLO vs SLA? Measurement vs internal target vs contractual promise.
What is an error budget? 1 −SLO; spend it on change, slow down when it's exhausted.
Why care about p99? Users and fan‐out requests experience the tail.
Database per service — how do you query across? API composition or local read models fed by events/CDC.
How do you detect node failure? Heartbeats/timeouts (suspicion), adaptive detectors, health checks at multiple levels.
How do you version APIs/events? Additive changes first; breaking →new version run in parallel; schema registry compatibility.
How do you trace a request across services? W3C trace context propagated via headers; OTel/Micrometer; trace id in logs.
What is service discovery? Resolving names to healthy instances (K8s DNS, Consul, Eureka).
Explain CAP with an example. During a partition a replicated store either rejects writes (C) or accepts divergent ones (A).
How do you do zero‐downtime deployments? Rolling/canary with readiness gates, backward‐compatible APIs and schemas, graceful shutdown.
How do you test microservices? Unit + component (Testcontainers) + contract tests; few E2E; chaos/resilience tests.
What is a distributed monolith? Services that must deploy together and call each other synchronously — the costs of both worlds.
