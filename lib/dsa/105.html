DP Space Optimization

Keep only the rows you still need: rolling arrays, in-place updates and Hirschberg.

A. Pattern Overview

Most table DPs read only a small window of previous states. Space optimisation keeps just that window: the previous row, the previous two values, or a single array updated in a careful direction. Time stays the same; memory drops from O(m n) to O(n), or from O(n) to O(1). The price is that you can no longer walk back through the table to rebuild the answer, which is where Hirschberg's algorithm helps.

B. When to Recognize This Pattern

Pattern Recognition Signals

Memory limit or large dimensions (10^4 x 10^4 tables are 400 MB).
A transition that reads only the previous row or column.
An interviewer asks "can you reduce the space?" after the table solution.
You only need the final value, not the path.
You need the path in small memory: Hirschberg or checkpointing.
ONE-LINE TEST

Each cell reads only the previous row: keep two rows, then try one.

One row with a saved diagonal

A single array dp[0..n] can hold row i. The cell dp[j] currently holds the up value (dp[i-1][j]); dp[j-1] already holds the left value (dp[i][j-1]). The diagonal dp[i-1][j-1] was overwritten, so save it in a variable before updating:

Range DP in one row (LPS)

For dp[i][j] over s[i..j] the transitions read dp[i+1][j-1], dp[i+1][j] and dp[i][j-1]. Fill i from n-1 down to 0 and keep one array indexed by j; save dp[i+1][j-1] in a variable before it is overwritten. Space O(n).

Hirschberg: the string in linear space

To reconstruct an LCS without the full table, split a at its middle row. Compute the LCS-length row for the top half against b (forward) and for the bottom half reversed against b reversed. The column k maximising left[k] + right[n - k] is where an optimal path crosses the middle row. Recurse on the two halves: (a_top, b[0..k)) and (a_bottom, b[k..)). Total time doubles (O(m n) still) while space is O(n).

INTERVIEW VALUE

Hirschberg is rarely asked as code, but naming it as the answer to "reduce space and still return the string" is a strong signal. Alternatives: store one bit-direction per cell (m n / 8 bytes) or checkpoint every sqrt(m)-th row.

E. Java Implementation

Two-row and one-row LCS, edit distance, LPS, and Hirschberg

SpaceOpt.java: space-optimised LCS, edit distance, LPS, Hirschberg

import java.util.*;

/** Ch 91: DP space optimisation; rolling rows and Hirschberg's algorithm. */
public class SpaceOpt {

    /** LCS length with two rows. */
    public static int lcsTwoRows(String a, String b) {
        int[] prev = new int[b.length() + 1], cur = new int[b.length() + 1];
        for (int i = 1; i <= a.length(); i++) {
            for (int j = 1; j <= b.length(); j++)
                cur[j] = a.charAt(i - 1) == b.charAt(j - 1)
                        ? prev[j - 1] + 1 : Math.max(prev[j], cur[j - 1]);
            int[] t = prev;
            prev = cur;
            cur = t;
        }
        return prev[b.length()];
    }

    /** LCS length with ONE row plus a variable holding the old diagonal. */
    public static int lcsOneRow(String a, String b) {
        int n = b.length();
        int[] dp = new int[n + 1];
        for (int i = 1; i <= a.length(); i++) {
            int diag = 0;                                  // dp[i-1][j-1]
            for (int j = 1; j <= n; j++) {
                int up = dp[j];                            // dp[i-1][j]
                dp[j] = a.charAt(i - 1) == b.charAt(j - 1)
                        ? diag + 1 : Math.max(up, dp[j - 1]);
                diag = up;
            }
        }
        return dp[n];
    }

    /** Edit distance with one row and a saved diagonal. */
    public static int editDistanceOneRow(String a, String b) {

Java 17+

        int n = b.length();
        int[] dp = new int[n + 1];
        for (int j = 0; j <= n; j++) dp[j] = j;
        for (int i = 1; i <= a.length(); i++) {
            int diag = dp[0];
            dp[0] = i;
            for (int j = 1; j <= n; j++) {
                int up = dp[j];
                dp[j] = a.charAt(i - 1) == b.charAt(j - 1)
                        ? diag : 1 + Math.min(diag, Math.min(up, dp[j - 1]));
                diag = up;
            }
        }
        return dp[n];
    }

    /** Longest palindromic subsequence with one row. */
    public static int lpsOneRow(String s) {
        int n = s.length();
        int[] dp = new int[n];
        for (int i = n - 1; i >= 0; i--) {
            int diag = 0;                                  // dp[i+1][j-1]
            dp[i] = 1;
            for (int j = i + 1; j < n; j++) {
                int up = dp[j];                            // dp[i+1][j]
                dp[j] = s.charAt(i) == s.charAt(j)
                    ? diag + 2
                    : Math.max(up, dp[j - 1]);
                diag = up;
            }
        }
        return n == 0 ? 0 : dp[n - 1];
    }

    /**
     * Hirschberg: an actual LCS in O(n) extra space and O(mn) time. Split a at
     * its middle, find the best split of b with a forward and a backward row,
     * recurse on both halves.
     */
    public static String hirschbergLcs(String a, String b) {
        StringBuilder out = new StringBuilder();
        solve(a, 0, a.length(), b, 0, b.length(), out);
        return out.toString();
    }

    private static void solve(String a, int al, int ah, String b, int bl, int bh,
                              StringBuilder out) {
        if (al == ah || bl == bh) return;
        if (ah - al == 1) {
            char c = a.charAt(al);
            for (int k = bl; k < bh; k++)
                if (b.charAt(k) == c) { out.append(c); return; }
            return;
        }
        int mid = (al + ah) >>> 1;
        int[] left = forward(a, al, mid, b, bl, bh);
        int[] right = backward(a, mid, ah, b, bl, bh);
        int len = bh - bl, best = -1, split = bl;
        for (int j = 0; j <= len; j++) {
            int s = left[j] + right[len - j];
            if (s > best) {
                best = s;
                split = bl + j;
            }
        }
        solve(a, al, mid, b, bl, split, out);
        solve(a, mid, ah, b, split, bh, out);
    }

    /** row[j] = LCS(a[al..ah), b[bl..bl+j)). */
    private static int[] forward(String a, int al, int ah, String b, int bl,
            int bh) {
        int[] prev = new int[bh - bl + 1], cur = new int[bh - bl + 1];
        for (int i = al; i < ah; i++) {
            for (int j = 1; j <= bh - bl; j++)
                cur[j] = a.charAt(i) == b.charAt(bl + j - 1)
                        ? prev[j - 1] + 1 : Math.max(prev[j], cur[j - 1]);
            int[] t = prev;
            prev = cur;
            cur = t;
        }
        return prev;
    }

    /** row[j] = LCS(a[al..ah), the LAST j characters of b[bl..bh)). */
    private static int[] backward(String a, int al, int ah, String b, int bl,
            int bh) {
        int[] prev = new int[bh - bl + 1], cur = new int[bh - bl + 1];
        for (int i = ah - 1; i >= al; i--) {
            for (int j = 1; j <= bh - bl; j++)
                cur[j] = a.charAt(i) == b.charAt(bh - j)
                        ? prev[j - 1] + 1 : Math.max(prev[j], cur[j - 1]);
            int[] t = prev;
            prev = cur;
            cur = t;
        }
        return prev;
    }
}

SPACE O(min(m, n))

F. Detailed Dry Run

lcsTwoRows("abcde", "ace"): row 0 [0,0,0,0]. After a: [0,1,1,1]. After b: [0,1,1,1]. After c: [0,1,2,2]. After d: [0,1,2,2]. After e: [0,1,2,3]. Answer 3, identical to the full-table result.

Edit distance, one row: initialise dp[j] = j. For each i, set diag = dp[0] and dp[0] = i; for each j, up = dp[j]; dp[j] = a[i-1] == b[j-1] ? diag : 1 + min(diag, up, dp[j-1]); then diag = up. This reproduces the same row values as the table in Chapter 85.

G. Variations of the Pattern

Rolling variables for linear DPs

Fibonacci, Climbing Stairs, House Robber, Decode Ways: replace the array with two or three locals.

In-place grid DP

If the input grid may be modified, write the DP values into it (Minimum Path Sum). Ask first; mutating input is not always allowed.

Knapsack as one array

The 0/1 and unbounded knapsack are the classic one-array cases; direction decides the item rule (Chapter 82).

Bitset DP

Boolean subset-sum rows compress further: bits |= bits << x with a BitSet or long[] is 64x smaller and faster.

Checkpointing

Store every sqrt(m)-th row, then recompute blocks when walking back: O(sqrt(m) n) space and about 2x time, without Hirschberg's recursion.

CHAPTER SUMMARY

Space optimisation keeps only the states still needed: rolling variables, two rows, or one row with a saved diagonal.

Loop direction comes from the dependency arrows (downward for 0/1 knapsack, upward for unbounded).

Make the row the shorter string to minimise memory.

Compression loses reconstruction; Hirschberg restores it in O(n) space at about twice the time.

Bitsets shrink boolean DPs by 64x and speed them up.
