75

Line Sweep with Events

Skyline and rectangle area: events plus a live structure.

A. Pattern Overview

Chapter 74 swept with a counter. Harder problems need a richer live structure: a multiset of heights for the skyline, a coverage array over compressed y-coordinates for the area of a union of rectangles. The skeleton is identical: create events, sort them with a careful tie rule, apply each event to the structure, and read the answer at the points where it changes. The data structure is the whole difficulty.

The skyline sweep

KEY IDEA

Process events in a fixed order and read the answer only when it can change. For the skyline that is when the maximum height changes; for area it is the gap between consecutive x-coordinates.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Outline / silhouette / skyline" of overlapping shapes.
"Area or perimeter of the union" of rectangles.
"Do these rectangles tile a region exactly?"
A maximum (or minimum) over the objects currently live, not just a count.
Two-dimensional shapes that reduce to one sweep direction plus a 1D structure.
ONE-LINE TEST

Overlapping shapes and a question about the union: sweep one axis, keep the other axis in a structure.

C. Core Intuition with Illustrations

The skyline problem

Buildings [left, right, height]: [2,9,10] [3,7,15] [5,12,12] [15,20,10] [19,24,8]. The skyline is the list of key points (x, height) where the outline's height changes. Result: (2,10) (3,15) (7,12) (12,0) (15,10) (20,8) (24,0).

Figure 118. Five buildings and their skyline.

Why those events and that order

A left edge is stored as {x, -h} and a right edge as {x, +h}. Sorting by (x, value) then gives, at one x: taller starts first (most negative), then starts of shorter buildings, then shorter ends before taller ends. This avoids emitting a spurious key point when one building ends exactly where another begins, and avoids dips below the true outline.

Why a multiset

Two buildings can share a height. Removing the height of one building must not remove the height of the other, so the structure stores counts. A TreeMap<height, count> gives lastKey() in O(log n). (A max-heap with lazy deletion also works; Chapter 61's lazy removal idea.)

Rectangle area: sweep x, track covered y-length

Each rectangle [x1, y1, x2, y2] produces an add event at x1 and a remove event at x2, both for the y-range [y1, y2). Compress the y-coordinates, keep cover[j] = how many live rectangles cover the gap ys[j]..ys[j+1]. Between consecutive x events the covered length is constant, so area += coveredLength * (x - prevX).

Perfect Rectangle (391) without a sweep

The rectangles tile a rectangle exactly iff (1) the sum of their areas equals the area of the bounding box, and (2) every point that is a corner of some rectangle appears an even number of times except the four outer corners, which appear once. Toggle each corner in a set: only the four outer corners survive. Both conditions are necessary; together they are sufficient.

E. Java Implementation

Skyline, rectangle union area, perfect rectangle

EventSweep.java: LeetCode 218, 850, 391
import java.util.*;

/** Ch 75: line sweep with events; LeetCode 218, 850, 391. */
public class EventSweep {

    /**
     * LeetCode 218: the skyline. Events {x, -h} for a left edge and {x, h} for
     * a right edge; sorted so that, at one x, taller starts come first and
     * shorter ends come first. A multiset of live heights gives the maximum.
     */
    public static List<int[]> getSkyline(int[][] buildings) {
        int[][] events = new int[buildings.length * 2][];
        int k = 0;
        for (int[] b : buildings) {
            events[k++] = new int[]{b[0], -b[2]};
            events[k++] = new int[]{b[1], b[2]};
        }
        Arrays.sort(events, (p, q) -> p[0] != q[0]
                ? Integer.compare(p[0], q[0]) : Integer.compare(p[1], q[1]));
        TreeMap<Integer, Integer> heights = new TreeMap<>();
        heights.put(0, 1);
        List<int[]> out = new ArrayList<>();
        int prev = 0;
        for (int[] ev : events) {
            int h = Math.abs(ev[1]);
            if (ev[1] < 0) heights.merge(h, 1, Integer::sum);
            else if (heights.merge(h, -1, Integer::sum) == 0) heights.remove(h);
            int cur = heights.lastKey();
            if (cur != prev) {
                out.add(new int[]{ev[0], cur});
                prev = cur;
            }
        }
        return out;
    }

    /** Exact area of the union of axis-aligned rectangles {x1, y1, x2, y2}. */
    public static long unionArea(int[][] rects) {
        int n = rects.length;
        if (n == 0) return 0;
        int[] ys = new int[2 * n];
        for (int i = 0; i < n; i++)
            { ys[2 * i] = rects[i][1]; ys[2 * i + 1] = rects[i][3]; }
        Arrays.sort(ys);
        int m = 0;
        for (int y : ys) if (m == 0 || ys[m - 1] != y) ys[m++] = y;

Java 17+

        int[][] events = new int[2 * n][];
        for (int i = 0; i < n; i++) {
            events[2 * i] = new int[]{rects[i][0], 1, rects[i][1], rects[i][3]};
            events[2 * i + 1] = new int[]{rects[i][2], -1, rects[i][1],
                    rects[i][3]};
        }
        Arrays.sort(events, Comparator.comparingInt(e -> e[0]));
        int[] cover = new int[m];                 // cover[j]: gap ys[j]..ys[j+1]
        long area = 0;
        int prevX = events[0][0];
        for (int[] ev : events) {
            long covered = 0;
            for (int j = 0; j + 1 < m; j++)
                if (cover[j] > 0) covered += ys[j + 1] - ys[j];
            area += covered * (ev[0] - prevX);
            prevX = ev[0];
            int lo = Arrays.binarySearch(ys, 0, m, ev[2]);
            int hi = Arrays.binarySearch(ys, 0, m, ev[3]);
            for (int j = lo; j < hi; j++) cover[j] += ev[1];
        }
        return area;
    }

    /** LeetCode 850: union area modulo 1e9 + 7. */
    public static int rectangleArea(int[][] rects) {
        return (int) (unionArea(rects) % 1_000_000_007L);
    }

    /**
     * LeetCode 391: do the rectangles tile a rectangle exactly? Corner
     * parity: every interior corner appears an even number of times, so only
     * the four outer corners survive; and the areas must add up.
     */
    public static boolean isRectangleCover(int[][] rects) {
        Set<Long> corners = new HashSet<>();
        long area = 0;
        int x1 = Integer.MAX_VALUE, y1 = Integer.MAX_VALUE;
        int x2 = Integer.MIN_VALUE, y2 = Integer.MIN_VALUE;
        for (int[] r : rects) {
            x1 = Math.min(x1, r[0]); y1 = Math.min(y1, r[1]);
            x2 = Math.max(x2, r[2]); y2 = Math.max(y2, r[3]);
            area += (long) (r[2] - r[0]) * (r[3] - r[1]);
            for (long c : new long[]{key(r[0], r[1]), key(r[0], r[3]),
                                     key(r[2], r[1]), key(r[2], r[3])})
                if (!corners.add(c)) corners.remove(c);
        }
        if (area != (long) (x2 - x1) * (y2 - y1)) return false;
        return corners.size() == 4 && corners.contains(key(x1, y1))
                && corners.contains(key(x1, y2)) && corners.contains(key(x2, y1))
                && corners.contains(key(x2, y2));
    }

    private static long key(int x, int y) {
        return ((long) x << 32) ^ (y & 0xffffffffL);
    }
}

TIME O(n log n)

SPACE O(n)

The skyline is O(n log n): 2n events, each a TreeMap update.

unionArea is O(n²): for each of 2n events it scans the O(n) y-gaps; a segment tree with lazy cover counts brings it to O(n log n). isRectangleCover is O(n) expected.

F. Detailed Dry Run

Skyline events after sorting begin (2,-10) (3,-15) (5,-12) (7,15) (9,10) (12,12) (15,-10) (19,-8) (20,10) (24,8). At x = 2: heights {0, 10}, max 10 ≠ 0, emit (2,10). At x = 3: add 15, max 15, emit (3,15). At x = 5: add 12, max still 15, nothing. At x = 7: remove 15, max 12, emit (7,12). At x = 9: remove 10, max 12, nothing. At x = 12: remove 12, max 0, emit (12,0). Then (15,10), then at 19 adding 8 changes nothing, at 20 removing 10 gives (20,8), at 24 removing 8 gives (24,0).

Area: ys = [0,1,2,3]. Events at x = 0 add y [0,2): covered 0 so far. At x = 1 (two adds): covered 2 × width 1 = 2, then the adds; at x = 2 (two removes): covered 3 × 1 = 3, total 5; at x = 3 (remove): covered 1 × 1 = 1, total 6.

G. Variations of the Pattern

Rectangle Area (223) and Rectangle Overlap (836)

Two rectangles only: overlapWidth = max(0, min(x2, x2') - max(x1, x1')), similarly for height. No sweep needed.

Perimeter of a union of rectangles

Sweep twice (x then y) counting the change in covered length at every event; the absolute change summed over events is the perimeter in that direction.

Maximum overlap of rectangles

Sweep x and keep a coverage array over compressed y with the maximum instead of the covered length: needs a segment tree with range add and range max.

Skyline with a heap

Replace the TreeMap by a max-heap of (height, right edge); discard heap tops whose right edge is <= x lazily. Same complexity, less memory churn.

Closest pair / bounding-box intersection tests

Plane-sweep algorithms (Shamos-Hoey, Bentley-Ottmann) use exactly this: a sorted event list plus a balanced tree ordered by the current sweep position.

J. Interview Tips

INTERVIEW

For the skyline, say the encoding: negative heights for starts so the sort puts taller starts first; then explain the multiset.

Mention the lazy-heap alternative and its trade-off, and that the multiset needs counts.

For area, explain coordinate compression and why the covered length is constant between consecutive x events.

Follow-ups: perimeter of the union; 3D volume (sweep z, 2D coverage); maximum coverage point; skyline for a stream of buildings.

CHAPTER SUMMARY

Richer sweeps keep a richer structure: a multiset of heights for the skyline, a coverage array over compressed y-gaps for the union area.

Skyline: events {x, -h} / {x, h}, sorted by (x, value); emit (x, max) only when the maximum changes; seed the multiset with the ground.

Area: between consecutive x events the covered length is constant; area += covered * dx; use long and reduce at the end.

Perfect Rectangle: areas must add up and only the four outer corners may appear an odd number of times.

A segment tree upgrades the area sweep to O(n log n); the simple array version is enough for n <= 200.
