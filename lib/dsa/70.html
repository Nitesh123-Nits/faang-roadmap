Bridges and Articulation Points

Edges and vertices whose removal disconnects the graph.

A. Pattern Overview

In an undirected connected graph, a bridge (cut edge) is an edge whose removal disconnects the graph; an articulation point (cut vertex) is a vertex whose removal does. Both fall out of one DFS that records disc[u] (discovery time) and low[u] (the earliest discovery time reachable from u's subtree using at most one back edge). Time O(V + E).

Test

Condition (for tree edge u → v)

Bridge (u, v)

low[v] > disc[u]: the subtree of v cannot reach u or above except through this edge

Articulation point u (non-root)

Some child v has low[v] >= disc[u]

Articulation point u (root)

u has two or more DFS children

Bridge finding in 12 lines
void dfs(int u, int parentEdge) {
    disc[u] = low[u] = ++timer;
    for (int[] e : adj.get(u)) {                // e = {neighbour, edgeId}
        int v = e[0], id = e[1];
        // skip the edge we came by (not the parent vertex!)
        if (id == parentEdge) continue;
        if (disc[v] != 0) low[u] = Math.min(low[u], disc[v]);   // back edge
        else {
            dfs(v, id);
            low[u] = Math.min(low[u], low[v]);
            if (low[v] > disc[u]) bridges.add(new int[] {u, v});
        }
    }
}

Java 17+

KEY IDEA

Skip the parent edge, not the parent vertex. With parallel edges, a second edge to the parent is a genuine back edge and the first edge is then not a bridge.

C. Core Intuition with Illustrations

Two triangles joined by one edge

Figure 103. Triangles {0,1,2} and {3,4,5} share only the edge 1–3. Badges show disc/low; amber = articulation point.

Every edge inside a triangle lies on a cycle, so removing it leaves the graph connected. Only 1-3 lies on no cycle: it is the bridge, and its endpoints 1 and 3 are articulation points.

What low means

low[u] answers: how high up the DFS tree can this subtree climb with one back edge? If the answer for child v is still below u's own discovery time (low[v] > disc[u]), nothing in v's subtree connects to anything above u except the tree edge itself.

Bridge vs articulation: > versus >=

For an articulation point, the child's subtree may reach u itself via a back edge and still be cut off when u disappears: so >= is enough. For a bridge, reaching u by another edge already saves the edge, so we need strict >. The root is special: it separates its subtrees only if it has at least two DFS children.

Bridge-connected components

Delete all bridges: what remains are the 2-edge-connected components. Contract each to a node and the bridge tree results, a tree you can use for LCA or diameter queries on network resilience.

Tarjan 1972

Both algorithms are from Hopcroft and Tarjan's work on biconnectivity, and the same low-link idea powers Tarjan's SCC (Chapter 58), the difference being edge directions and the stack condition.

E. Java Implementation

Bridges, Critical Connections, articulation points

BridgesArticulation.java: LeetCode 1192 and articulation points

import java.util.*;

/** Ch 59: bridges and articulation points; LeetCode 1192. */
public class BridgesArticulation {
    private int timer;
    private int[] disc, low;
    private final List<List<int[]>> g = new ArrayList<>();   // {neighbour, edge id}
    private final List<int[]> bridges = new ArrayList<>();
    private final boolean[] cut;
    private final int n;

    private BridgesArticulation(int n, int[][] edges) {
        this.n = n;
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int i = 0; i < edges.length; i++) {
            g.get(edges[i][0]).add(new int[] {edges[i][1], i});
            g.get(edges[i][1]).add(new int[] {edges[i][0], i});
        }
        disc = new int[n];
        low = new int[n];
        Arrays.fill(disc, -1);
        cut = new boolean[n];
        for (int s = 0; s < n; s++) if (disc[s] < 0) dfs(s, -1, true);
    }

    private void dfs(int u, int parentEdge, boolean isRoot) {
        disc[u] = low[u] = timer++;
        int children = 0;
        for (int[] nb : g.get(u)) {

Java 17+

            int v = nb[0];
            if (nb[1] == parentEdge) continue;         // skip only the arrival edge
            if (disc[v] >= 0) {
                low[u] = Math.min(low[u], disc[v]);    // back edge
                continue;
            }
            children++;
            dfs(v, nb[1], false);
            low[u] = Math.min(low[u], low[v]);
            if (low[v] > disc[u]) bridges.add(new int[] {u, v});
            if (!isRoot && low[v] >= disc[u]) cut[u] = true;
        }
        if (isRoot && children > 1) cut[u] = true;
    }

    /**
     * All bridges (each reported once as {u, v}). Parallel edges are not bridges.
     */
    public static List<int[]> bridges(int n, int[][] edges) {
        return new BridgesArticulation(n, edges).bridges;
    }

    /** LeetCode 1192 name: critical connections = bridges. */
    public static List<List<Integer>> criticalConnections(
            int n, List<List<Integer>> conns) {
        int[][] e = new int[conns.size()][];
        for (int i = 0; i < e.length; i++)
            e[i] = new int[] {conns.get(i).get(0), conns.get(i).get(1)};
        List<List<Integer>> out = new ArrayList<>();
        for (int[] b : bridges(n, e)) out.add(List.of(b[0], b[1]));
        return out;
    }

    /** Articulation points in increasing order. */
    public static List<Integer> articulationPoints(int n, int[][] edges) {
        BridgesArticulation b = new BridgesArticulation(n, edges);
        List<Integer> out = new ArrayList<>();
        for (int v = 0; v < b.n; v++) if (b.cut[v]) out.add(v);
        return out;
    }
}

SPACE O(V + E)

Adjacency stores edge ids, so parallel edges are handled correctly. The DFS is recursive; at 10⁵ vertices on a path graph run it on a thread with a larger stack or convert to an explicit stack. Tests compare against edge and vertex deletion oracles.

F. Detailed Dry Run

DFS from 0: disc[0]=0; go to 1 (disc 1), then 2 (disc 2). Vertex 2 has a back edge to 0, so

low[2]=0 and low[1]=0, low[0]=0: edges 1-2 and 0-2 are on cycles. From 1 continue to 3 (disc

3), 4 (disc 4), 5 (disc 5): 5 closes a back edge to 3, so low[5]=low[4]=low[3]=3. Check the tree edge 1→3: low[3]=3 > disc[1]=1, so 1-3 is a bridge. Articulation: vertex 1 (child 3 has low >= disc[1]) and vertex 3 (child 4 has low[4]=3 >= disc[3]).

G. Variations of the Pattern

Critical Connections

Return all bridges (1192). Build the adjacency list with edge ids, run the DFS, collect [u, v].

Articulation points

Collect vertices satisfying the child condition; count root children separately. A Set avoids duplicates, since a vertex can qualify through several children.

Biconnected components

Push edges on a stack during the DFS; when low[v] >= disc[u], pop edges until (u, v): those edges form one biconnected component.

Grid versions

Minimum Number of Days to Disconnect Island (1568): the answer is 0, 1 or 2. Check 0 (already not one island), then try removing each land cell (or use articulation points); otherwise 2.

Dynamic connectivity

When edges are added and removed over time, offline divide and conquer with rollback DSU, or link-cut trees; beyond interview scope but worth naming.

J. Interview Tips

INTERVIEW

Explain low in one sentence: "the earliest discovery time this subtree can reach with one back edge."

Justify the strict inequality for bridges versus the non-strict one for cut vertices; it is the classic follow-up.

Mention parallel edges and use edge ids; it shows production-level care.

Follow-ups: return bridge-connected components; minimum edges to add so the graph

has no bridges (⌈leaves/2⌉ on the bridge tree); iterative version; handle updates.

Edge cases: tree (every edge is a bridge), cycle (none), single vertex, two vertices with parallel edges, disconnected graph.

CHAPTER SUMMARY

A bridge is an edge on no cycle; an articulation point is a vertex whose removal disconnects the graph. One DFS finds both in O(V + E).

Track disc and low; bridge: low[v] > disc[u]; articulation: low[v] >= disc[u] (root: at least two DFS children).

Skip the parent edge (by id), not the parent vertex; update low through back edges with disc[v].

Deleting bridges leaves 2-edge-connected components; contracting them gives a tree.

Same low-link machinery as Tarjan's SCC; difference is undirectedness and the stack condition.
