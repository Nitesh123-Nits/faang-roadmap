Bitmask DP

Encode a subset in an integer: 2^n states, n <= 20, and a bit trick per transition.

A. Pattern Overview

When the state must remember which items out of a small set have been used, encode that set as a bitmask: bit i is 1 if item i is taken. The mask is an int, so dp[mask] or dp[mask][last] is a plain array of size 2^n (times n). With n <= 20 that is about a million masks, which is fast enough; with n <= 16 you can afford an extra dimension of n.

KEY IDEA

Bitmask DP is DP where the state is a set. Process masks in increasing numeric order: any submask of mask is numerically smaller, so dependencies are ready.

B. When to Recognize This Pattern

Pattern Recognition Signals

n <= 20 (or <= 16) items, and an order or assignment matters.
"Visit every node exactly once" (Travelling Salesman, Hamiltonian paths).
"Partition into k groups of equal sum", "assign n tasks to n workers".
"Shortest path that visits all nodes" in a small graph.
Counting hat assignments or permutations with constraints.
ONE-LINE TEST

Tiny n (<= 20) and a subset must be remembered: dp[mask].

C. Core Intuition with Illustrations

Travelling Salesman (Held-Karp)

dp[mask][last] is the cheapest cost of a path that starts at city 0, visits exactly the cities in mask and ends at last. Extend by an unvisited city next: dp[mask | 1<<next][next] =

min(dp[mask][last] + d[last][next]). For the four-city matrix [[0,10,15,20],[10,0,35,25],[15,35,0,30],[20,25,30,0]] (masks printed with city 3 on the left):

WHY IT WORKS

Brute force tries (n-1)! orders. Held-Karp needs 2^n * n states and n transitions each: O(2^n n^2). For n = 20 that is about 4 * 10^8 basic steps instead of 10^17.

Shortest Path Visiting All Nodes (847)

The path may start anywhere and revisit nodes and edges, so run BFS over states (mask, node). Start from all (1 << i, i) simultaneously at distance 0; the first time the mask is full, the distance is the answer. For the star graph [[1,2,3],[0],[0],[0]] the answer is 4 (1 -> 0 -> 2 -> 0 -> 3).

Partition to K Equal Sum Subsets (698)

dp[mask] is the sum of the chosen elements modulo target (target = total / k), or -1 if the mask is unreachable. Adding element i to mask is allowed if the running partial sum does not exceed target. If dp[full] == 0 the elements split into k buckets. For [4,3,2,3,5,2,1] and k = 4: total 20, target 5 (buckets {5}, {1,4}, {2,3}, {2,3}).

Number of Ways to Wear Different Hats (1434) and assignment

Flip the viewpoint to keep the mask small: iterate over hats (up to 40) and let the mask be the set of people (up to 10) who already have a hat. dp[h][mask] = number of ways using the first h hats. Choosing the side with the smaller count is the main modelling decision. The same idea gives the minimum-cost assignment (n workers, n tasks): dp[mask] over tasks done, the worker index is bitCount(mask).

Submask enumeration

Some transitions split a set into two parts: dp[mask] = best over submasks s of dp[s] + dp[mask ^ s]. Iterating all submasks of all masks costs O(3^n), which is acceptable up to n =

16 or so.

E. Java Implementation

TSP, all-nodes shortest path, k equal subsets, hats, assignment

BitmaskDP.java: LeetCode 847, 698, 1434, 1879 and Held-Karp
import java.util.*;

/** Ch 90: bitmask DP; LeetCode 847, 698, 1434, 1947 and the travelling salesman. */
public class BitmaskDP {
    private static final int MOD = 1_000_000_007;

    /**
     * Travelling salesman: cheapest tour from city 0 visiting every city once
     * and returning. dp[mask][last] = cheapest path from 0 through mask ending
     * at last. O(2^n * n^2).
     */
    public static int tsp(int[][] dist) {
        int n = dist.length;
        if (n == 1) return 0;
        final int INF = Integer.MAX_VALUE / 2;
        int[][] dp = new int[1 << n][n];
        for (int[] row : dp) Arrays.fill(row, INF);
        dp[1][0] = 0;
        for (int mask = 1; mask < (1 << n); mask += 2) {          // contains city 0
            for (int last = 0; last < n; last++) {
                if (dp[mask][last] >= INF || (mask >> last & 1) == 0) continue;
                for (int nxt = 1; nxt < n; nxt++) {
                    if ((mask >> nxt & 1) != 0) continue;
                    int nm = mask | 1 << nxt;
                    dp[nm][nxt] =

Java 17+

                            Math.min(dp[nm][nxt], dp[mask][last] + dist[last][nxt]);
                }
            }
        }
        int best = INF, full = (1 << n) - 1;
        for (int last = 1; last < n; last++)
            best = Math.min(best, dp[full][last] + dist[last][0]);
        return best;
    }

    /**
     * LeetCode 847: shortest walk (in edges) visiting every node of an
     * undirected graph; start and end anywhere. BFS over (mask, node).
     */
    public static int shortestPathAllNodes(int[][] graph) {
        int n = graph.length;
        if (n == 1) return 0;
        int full = (1 << n) - 1;
        boolean[][] seen = new boolean[1 << n][n];
        ArrayDeque<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            seen[1 << i][i] = true;
            q.add(new int[]{1 << i, i, 0});
        }
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            for (int nb : graph[cur[1]]) {
                int nm = cur[0] | 1 << nb;
                if (nm == full) return cur[2] + 1;
                if (!seen[nm][nb]) {
                    seen[nm][nb] = true;
                    q.add(new int[]{nm, nb, cur[2] + 1});
                }
            }
        }
        return -1;
    }

    /**
     * LeetCode 698: split nums into k subsets of equal sum. dp[mask] = the sum
     * of the partly filled bucket after placing mask's numbers, or -1.
     */
    public static boolean canPartitionKSubsets(int[] nums, int k) {
        int total = 0;
        for (int x : nums) total += x;
        if (k <= 0 || total % k != 0) return false;
        int target = total / k, n = nums.length;
        int[] dp = new int[1 << n];
        Arrays.fill(dp, -1);
        dp[0] = 0;
        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] < 0) continue;
            for (int i = 0; i < n; i++) {
                if ((mask >> i & 1) != 0 || dp[mask] + nums[i] > target) continue;
                dp[mask | 1 << i] = (dp[mask] + nums[i]) % target;
            }
        }
        return dp[(1 << n) - 1] == 0;
    }

    /**
     * LeetCode 1434: ways for each person to wear a distinct hat they like.
     * Mask the PEOPLE (at most 10) and iterate over the 40 hats.
     */
    public static int numberWays(List<List<Integer>> hats) {
        int n = hats.size();
        List<List<Integer>> likedBy = new ArrayList<>();
        for (int h = 0; h <= 40; h++) likedBy.add(new ArrayList<>());
        for (int p = 0; p < n; p++) for (int h : hats.get(p)) likedBy.get(h).add(p);
        long[] dp = new long[1 << n];
        dp[0] = 1;
        for (int h = 1; h <= 40; h++)
            for (int mask = (1 << n) - 1; mask >= 0; mask--)
                for (int p : likedBy.get(h))
                    if ((mask >> p & 1) == 0)
                        dp[mask | 1 << p] = (dp[mask | 1 << p] + dp[mask]) % MOD;
        return (int) dp[(1 << n) - 1];
    }

    /** Minimum-cost perfect assignment of n workers to n jobs, O(2^n * n). */
    public static int minAssignmentCost(int[][] cost) {
        int n = cost.length;
        int[] dp = new int[1 << n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;
        for (int mask = 0; mask < (1 << n) - 1; mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;
            // next worker to place
            int worker = Integer.bitCount(mask);
            for (int job = 0; job < n; job++)
                if ((mask >> job & 1) == 0)
                    dp[mask | 1 << job] = Math.min(dp[mask | 1 << job],
                            dp[mask] + cost[worker][job]);
        }
        return dp[(1 << n) - 1];
    }
}

F. Detailed Dry Run

TSP on four cities. Start dp[0001][0] = 0. Extend to city 1: dp[0011][1] = 10; city 2: dp[0101][2] = 15; city 3: dp[1001][3] = 20. From 0011: to city 2 costs 10 + 35 = 45 (mask 0111, last 2), to city 3 costs 10 + 25 = 35 (mask 1011, last 3). From 0101: to city 1 15 + 35 = 50, to city 3 15 + 30 = 45. Continuing to 1111 and closing the loop, the best tour costs 80.

Partition: process masks 0..127; from each reachable mask with partial dp[mask], try every unused element if dp[mask] + nums[i] <= target, storing (dp[mask] + nums[i]) % target. Reaching dp[127] = 0 means all buckets closed exactly.

G. Variations of the Pattern

Hamiltonian path / cycle existence

Replace costs by booleans (or a bitset of reachable last nodes per mask).

Profile DP (broken-profile)

Tiling a grid row by row: the mask describes which cells of the current row are already covered (Domino tiling counts, Maximum students taking an exam 1349).

Counting with forbidden pairs

Count permutations where adjacent elements satisfy a condition (Number of Squareful Arrays, 996): dp[mask][last] counts, with a divisibility or square test between last and next.

Game states

Can I Win (464): mask of numbers already chosen, memoised by mask, with the current total derivable from the mask.

Meet in the middle as an alternative

For n up to 40 split the items in half; enumerate each half in 2^(n/2) and combine with sorting or hashing. Use it when 2^n is too big but 2^(n/2) is fine.

INTERVIEW

Read the constraints: n <= 20 is the interviewer's invitation to use a bitmask.

Write the four bit operations from memory and mind operator precedence.

State the complexity as 2^n x transitions and give the memory figure.

CHAPTER SUMMARY

Bitmask DP stores a subset in an integer; dp[mask] or dp[mask][last] for n <= 20.

Held-Karp solves TSP in O(2^n n^2) instead of O(n!).

BFS over (mask, node) gives the shortest walk visiting all nodes.

Mask DP for partition and assignment: the worker index or running sum comes from the mask itself.

Mind precedence and overflow: parenthesise bit tests, use 1L when needed.
