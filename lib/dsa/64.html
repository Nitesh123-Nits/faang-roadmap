Shortest Path Algorithms

BFS, Dijkstra, Bellman-Ford, Floyd-Warshall: pick by weights and scale.

A. Pattern Overview

The shortest-path problem asks for the minimum total weight of a path between vertices. Four algorithms cover almost every case; the choice depends on edge weights (all equal, non-negative, possibly negative) and on how many sources you need.

KEY IDEA

Dijkstra's invariant: when a vertex is popped from the min-heap, its distance is final, because every other route must pass through a vertex still in the heap with distance ≥ the popped one, and edges cannot make it shorter. One negative edge breaks this, so Dijkstra cannot be used; switch to Bellman-Ford.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Minimum cost / time / distance" between nodes with weights: Dijkstra.
"Minimum number of moves" with equal costs: BFS (Chapter 47).
"At most k stops / edges": Bellman-Ford with k + 1 rounds, or Dijkstra on (node, stops).
"Negative weights", "arbitrage", "detect a negative cycle": Bellman-Ford.
"For every pair", small n (a few hundred): Floyd-Warshall.
"Maximise a product of probabilities" or "minimise the maximum edge": Dijkstra with a

changed combine rule.

ONE-LINE TEST

Read the weights first: equal → BFS; 0/1 → 0-1 BFS; non-negative → Dijkstra; negative → Bellman-Ford; all pairs and tiny n → Floyd-Warshall.

TIP

Lazy deletion. Java's PriorityQueue has no decreaseKey. Push a new entry whenever a distance improves and skip popped entries with d > dist[u]. The heap then holds at most m entries and the cost stays O(m log m) = O(m log n).

Bellman-Ford: relax every edge, n − 1 times

Figure 94. A directed graph with one negative edge.

After r rounds, every shortest path that uses at most r edges is correct. A shortest path has at most n − 1 edges, so if a round n still relaxes something, a negative cycle is reachable. Stop early when a round changes nothing.

Floyd-Warshall: allow one more intermediate vertex at a time

d[i][j] starts as the direct edge weight. For each k in turn, try i → k → j. After processing k

= 0..K, d[i][j] is the shortest path using only intermediates 0..K. k must be the outermost loop.

At most k stops

Cheapest Flights Within K Stops (787): run Bellman-Ford for exactly k + 1 rounds, relaxing from a copy of the previous round's distances (otherwise a round can use more than one new edge). Plain Dijkstra fails here because the cheapest path may use too many stops, and a more expensive path with fewer stops can still be needed.

Changing what "distance" means

Path with Maximum Probability: use a max-heap and multiply (valid because probabilities are in [0, 1], so extending a path never helps). Path With Minimum Effort (1631): the cost of a path is its maximum step; max(cur, step) replaces +. The rule is: the combine operation must be monotone (extending a path never makes it better).

E. Java Implementation

Dijkstra, Bellman-Ford, Floyd-Warshall and five LeetCode problems

ShortestPaths.java: LeetCode 743, 787, 1334, 1631, 1514
import java.util.*;

/**
 * Ch 53: Dijkstra, Bellman-Ford, Floyd-Warshall; LeetCode 743, 787, 1334, 1631,
 * 1514.
 */
public class ShortestPaths {
    public static final long INF = Long.MAX_VALUE / 4;

    /** Dijkstra with a lazy-deletion heap. Non-negative weights only. */
    public static long[] dijkstra(int n, int[][] edges, int src, boolean directed) {
        List<List<int[]>> g =
                GraphRepresentation.weightedAdjList(n, edges, directed);
        long[] dist = new long[n];

Java 17+

        Arrays.fill(dist, INF);
        dist[src] = 0;
        PriorityQueue<long[]> pq =
                new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.add(new long[] {0, src});
        while (!pq.isEmpty()) {
            long[] top = pq.poll();
            int u = (int) top[1];
            if (top[0] > dist[u]) continue;            // stale entry
            for (int[] e : g.get(u)) {
                long nd = dist[u] + e[1];
                if (nd < dist[e[0]]) {
                    dist[e[0]] = nd;
                    pq.add(new long[] {nd, e[0]});
                }
            }
        }
        return dist;
    }

    /** Bellman-Ford (directed). Returns null if a negative cycle is reachable. */
    public static long[] bellmanFord(int n, int[][] edges, int src) {
        long[] dist = new long[n];
        Arrays.fill(dist, INF);
        dist[src] = 0;
        for (int round = 0; round < n; round++) {
            boolean changed = false;
            for (int[] e : edges)
                if (dist[e[0]] < INF && dist[e[0]] + e[2] < dist[e[1]]) {
                    dist[e[1]] = dist[e[0]] + e[2];
                    changed = true;
                }
            if (!changed) return dist;
            if (round == n - 1) return null;           // still relaxing on round n
        }
        return dist;
    }

    /**
     * Floyd-Warshall: all pairs, directed edges, O(n^3). null on a negative cycle.
     */
    public static long[][] floydWarshall(int n, int[][] edges) {
        long[][] d = new long[n][n];
        for (long[] row : d) Arrays.fill(row, INF);
        for (int i = 0; i < n; i++) d[i][i] = 0;
        for (int[] e : edges) d[e[0]][e[1]] = Math.min(d[e[0]][e[1]], e[2]);
        for (int k = 0; k < n; k++)                    // k MUST be the outer loop
            for (int i = 0; i < n; i++) {
                if (d[i][k] >= INF) continue;
                for (int j = 0; j < n; j++)
                    if (d[k][j] < INF && d[i][k] + d[k][j] < d[i][j])
                        d[i][j] = d[i][k] + d[k][j];
            }
        for (int i = 0; i < n; i++) if (d[i][i] < 0) return null;
        return d;
    }

    /**
     * LeetCode 743: nodes 1..n, directed {u, v, w}; time for all to hear, or -1.
     */
    public static int networkDelayTime(int[][] times, int n, int k) {
        int[][] e = new int[times.length][];
        for (int i = 0; i < e.length; i++)
            e[i] = new int[] {times[i][0] - 1, times[i][1] - 1, times[i][2]};
        long[] d = dijkstra(n, e, k - 1, true);
        long max = 0;
        for (long x : d) max = Math.max(max, x);
        return max >= INF ? -1 : (int) max;
    }

    /** LeetCode 787: cheapest price with at most k stops = at most k + 1 edges. */
    public static int cheapestFlights(int n, int[][] flights, int src, int dst,
                                      int k) {
        long[] dist = new long[n];
        Arrays.fill(dist, INF);
        dist[src] = 0;
        for (int round = 0; round <= k; round++) {
            // use only last round's values
            long[] next = dist.clone();
            for (int[] f : flights)
                if (dist[f[0]] < INF)
                    next[f[1]] = Math.min(next[f[1]], dist[f[0]] + f[2]);
            dist = next;
        }
        return dist[dst] >= INF ? -1 : (int) dist[dst];
    }

    /**
     * LeetCode 1334: city with the fewest cities within the threshold (ties:
     * larger).
     */
    public static int findTheCity(int n, int[][] edges, int threshold) {
        int[][] directed = new int[edges.length * 2][];
        for (int i = 0; i < edges.length; i++) {
            directed[2 * i] = edges[i];
            directed[2 * i + 1] = new int[] {edges[i][1], edges[i][0], edges[i][2]};
        }
        long[][] d = floydWarshall(n, directed);
        int best = -1, bestCount = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = 0; j < n; j++) if (i != j && d[i][j] <= threshold) count++;
            if (count <= bestCount) {
                bestCount = count;
                best = i;
            }
        }
        return best;
    }

    /** LeetCode 1631: minimise the largest height difference along a path. */
    public static int minimumEffortPath(int[][] h) {
        int m = h.length, n = h[0].length;
        int[][] best = new int[m][n];
        for (int[] row : best) Arrays.fill(row, Integer.MAX_VALUE);
        best[0][0] = 0;
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.add(new int[] {0, 0, 0});
        int[] dr = {1, -1, 0, 0}, dc = {0, 0, 1, -1};
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            if (cur[0] > best[cur[1]][cur[2]]) continue;
            if (cur[1] == m - 1 && cur[2] == n - 1) return cur[0];
            for (int d = 0; d < 4; d++) {
                int r = cur[1] + dr[d], c = cur[2] + dc[d];
                if (r < 0 || c < 0 || r >= m || c >= n) continue;
                int cost = Math.max(cur[0], Math.abs(h[r][c] - h[cur[1]][cur[2]]));
                if (cost < best[r][c]) {
                    best[r][c] = cost;
                    pq.add(new int[] {cost, r, c});
                }
            }
        }
        return 0;
    }

    /** LeetCode 1514: maximise the product of probabilities (Dijkstra on max). */
    public static double maxProbability(int n, int[][] edges, double[] p,
                                        int start, int end) {
        List<List<int[]>> g = new ArrayList<>();       // {neighbour, edge index}
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int i = 0; i < edges.length; i++) {
            g.get(edges[i][0]).add(new int[] {edges[i][1], i});
            g.get(edges[i][1]).add(new int[] {edges[i][0], i});
        }
        double[] best = new double[n];
        best[start] = 1.0;
        PriorityQueue<double[]> pq =
                new PriorityQueue<>((a, b) -> Double.compare(b[0], a[0]));
        pq.add(new double[] {1.0, start});
        while (!pq.isEmpty()) {
            double[] top = pq.poll();
            int u = (int) top[1];
            if (top[0] < best[u]) continue;
            if (u == end) return top[0];
            for (int[] e : g.get(u)) {
                double np = top[0] * p[e[1]];
                if (np > best[e[0]]) {
                    best[e[0]] = np;
                    pq.add(new double[] {np, e[0]});
                }
            }
        }
        return 0.0;
    }
}

SPACE O(n + m)

F. Detailed Dry Run

Follow the Dijkstra table: pop 0 (d = 0): neighbours 1, 2, 5 get 7, 9, 14. Pop 1 (7): neighbour 2 offers 17 (> 9, no), 3 gets 22. Pop 2 (9): 3 improves to 20, 5 improves from 14 to 11. Pop 5 (11): 4 gets 20. Pop 3 and 4 at 20. The stale entries (14, 5) and (22, 3) are skipped when popped. In

Bellman-Ford round 1 (edge order as listed): 0→1 gives 4, 0→2 gives 5, 1→2 gives 4 − 3 = 1, 2→3

gives 5; round 2 changes nothing, so it stops: [0, 4, 1, 5].

G. Variations of the Pattern

State-augmented Dijkstra

Add dimensions to the vertex: (node, stops left), (node, fuel), (cell, keys), (node, parity). Dijkstra then runs on the product graph (Cheapest Flights, Minimum Cost to Reach Destination in Time).

Counting shortest paths

Keep ways[v]: when dist[u] + w < dist[v], set ways[v] = ways[u]; when equal, add (Number of Ways to Arrive at Destination, 1976). Use modulo as asked.

Grids as weighted graphs

Swim in Rising Water (778) and Path With Minimum Effort (1631): Dijkstra with max; or binary search on the answer + BFS (Chapter 13).

0-1 BFS

Minimum Obstacle Removal (2290), Minimum Cost to Make a Valid Path (1368): addFirst on weight 0, addLast on weight 1 in an ArrayDeque.

All pairs and closure

Find the City (1334) is Floyd-Warshall; the same triple loop with boolean gives the transitive closure (Warshall), and with min / max the minimax path.

CHAPTER SUMMARY

Choose by weights: equal → BFS, 0/1 → 0-1 BFS, non-negative → Dijkstra, negative

Bellman-Ford, all pairs / small n → Floyd-Warshall.

Dijkstra: min-heap, settle the closest, lazy deletion with if (d > dist[u]) continue; O((n + m) log n); never with negative edges.

Bellman-Ford: relax all edges n − 1 times; a relaxation in round n proves a negative cycle; for k stops use k + 1 rounds from a copy.

Floyd-Warshall: triple loop with k outermost; O(n³).

Use long with INF = MAX / 4; any monotone combine rule (product, max) can replace + in Dijkstra.
