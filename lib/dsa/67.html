Multi-Source BFS

Start the queue with every source at once: distance to the nearest one.

A. Pattern Overview

Ordinary BFS starts from one vertex. Multi-source BFS starts from a set of sources, all at distance 0, by putting every one of them in the queue before the loop begins. The first time a vertex is reached, its distance is the distance to the nearest source. It is equivalent to adding a virtual super-source connected to every real source by a 0-cost edge.

KEY IDEA

Reverse the direction of the search. "For every cell, distance to the nearest X" would need one BFS per cell (O(mn · mn)). Run one BFS from all the X cells outwards instead (O(mn)): on an undirected graph the distance is symmetric.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Distance of each cell to the nearest …" (zero, gate, land, building).
Simultaneous spreading: fire, infection, rot, flood, rumour: "every minute", "all at the

same time".

"Minimum time for everything to be affected": the number of BFS rounds.
"Farthest / safest from all hazards": compute the distance map first, then optimise on it.
Several starting points but a single shared goal ("shortest bridge", "nearest exit among many").
ONE-LINE TEST

Many sources, unit edges, "nearest" or "time to spread": put all sources in the queue at distance 0.

C. Core Intuition with Illustrations

Rotting oranges, minute by minute

2 rotten, 1 fresh, 0 empty. Each BFS round (one minute) turns every fresh orange adjacent to a rotten one rotten. Freezing queue.size() at the start of a round keeps the minutes apart.

Why one queue is enough

The queue invariant of BFS holds even with many sources: it contains vertices at distance d followed by vertices at distance d + 1. A vertex is first reached through the closest source, so its stored distance is the minimum over all sources.

Shortest Bridge: a source set that is an island

Find one island with a DFS (collect all its cells), then run BFS from all of them at once, expanding through water. The round in which the BFS first touches a land cell of the other island is the number of 0s to flip. Marking the first island's cells as visited prevents the BFS from walking back into it.

Two-phase problems

Find the Safest Path (2812) first runs multi-source BFS from the thieves to get safe[r][c], then finds the path maximising the minimum safe value (Dijkstra with max-heap, or binary search + BFS). Many "escape the hazard" problems have this shape.

INTUITION

Without obstacles, the nearest-source distance in a grid is a Manhattan distance transform, which also has a two-sweep DP solution (top-left to bottom-right, then back). With walls or hazards in between, BFS is the right tool.

import java.util.*;

/** Ch 56: multi-source BFS; LeetCode 994, 542, 1162, 934, 286. */
public class MultiSourceBFS {
    static final int[] DR = {1, -1, 0, 0}, DC = {0, 0, 1, -1};

    /** LeetCode 994: minutes until no fresh orange remains, or -1. */
    public static int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length, fresh = 0;
        int[][] g = new int[m][];
        Deque<int[]> queue = new ArrayDeque<>();
        for (int r = 0; r < m; r++) {
            g[r] = grid[r].clone();
            for (int c = 0; c < n; c++) {
                if (g[r][c] == 2) queue.add(new int[] {r, c});
                else if (g[r][c] == 1) fresh++;
            }
        }
        int minutes = 0;
        while (!queue.isEmpty() && fresh > 0) {
            minutes++;
            for (int i = queue.size(); i > 0; i--) {   // one level = one minute
                int[] cur = queue.poll();
                for (int d = 0; d < 4; d++) {
                    int r = cur[0] + DR[d], c = cur[1] + DC[d];
                    if (r >= 0 && c >= 0 && r < m && c < n && g[r][c] == 1) {
                        g[r][c] = 2;
                        fresh--;
                        queue.add(new int[] {r, c});
                    }
                }
            }
        }
        return fresh == 0 ? minutes : -1;
    }

    /** LeetCode 542: distance of every cell to the nearest 0. */
    public static int[][] updateMatrix(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int[][] dist = new int[m][n];
        Deque<int[]> queue = new ArrayDeque<>();

            for (int c = 0; c < n; c++) {
                if (mat[r][c] == 0) queue.add(new int[] {r, c});

    /**
     * LeetCode 1162: the water cell farthest from land; -1 if all land or all
     * water.
     */
    public static int maxDistance(int[][] grid) {
        int n = grid.length;
        int[][] dist = new int[n][n];
        Deque<int[]> queue = new ArrayDeque<>();
        for (int r = 0; r < n; r++)
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) queue.add(new int[] {r, c});
                else dist[r][c] = -1;
            }
        if (queue.isEmpty() || queue.size() == n * n) return -1;
        int best = 0;
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            for (int d = 0; d < 4; d++) {
                int r = cur[0] + DR[d], c = cur[1] + DC[d];
                if (r >= 0 && c >= 0 && r < n && c < n && dist[r][c] < 0) {
                    dist[r][c] = dist[cur[0]][cur[1]] + 1;
                    best = Math.max(best, dist[r][c]);
                    queue.add(new int[] {r, c});
                }
            }
        }
        return best;
    }

    /** LeetCode 934: two islands; flip the fewest 0s to join them. */
    public static int shortestBridge(int[][] grid) {
        int n = grid.length;
        boolean[][] seen = new boolean[n][n];
        Deque<int[]> queue = new ArrayDeque<>();
        outer:
        for (int r = 0; r < n; r++)
            for (int c = 0; c < n; c++)
                if (grid[r][c] == 1) {
                    Deque<int[]> stack = new ArrayDeque<>();
                    seen[r][c] = true;
                    stack.push(new int[] {r, c});
                    while (!stack.isEmpty()) {         // DFS: collect island one
                        int[] cur = stack.pop();
                        queue.add(cur);
                        for (int d = 0; d < 4; d++) {
                            int nr = cur[0] + DR[d], nc = cur[1] + DC[d];
                            if (nr >= 0 && nc >= 0 && nr < n && nc < n
                                    && grid[nr][nc] == 1 && !seen[nr][nc]) {
                                seen[nr][nc] = true;
                                stack.push(new int[] {nr, nc});
                            }
                        }
                    }
                    break outer;
                }
        int flips = 0;
        while (!queue.isEmpty()) {                     // BFS from the whole island
            for (int i = queue.size(); i > 0; i--) {
                int[] cur = queue.poll();
                for (int d = 0; d < 4; d++) {
                    int r = cur[0] + DR[d], c = cur[1] + DC[d];
                    if (r < 0 || c < 0 || r >= n || c >= n || seen[r][c]) continue;
                    if (grid[r][c] == 1) return flips;
                    seen[r][c] = true;
                    queue.add(new int[] {r, c});
                }
            }
            flips++;
        }
        return -1;
    }

    /**
     * LeetCode 286: rooms: -1 wall, 0 gate, INF empty; fill distance to nearest
     * gate.
     */
    public static int[][] wallsAndGates(int[][] rooms) {
        int m = rooms.length, n = rooms[0].length;
        int[][] g = new int[m][];
        Deque<int[]> queue = new ArrayDeque<>();
        for (int r = 0; r < m; r++) {
            g[r] = rooms[r].clone();
            for (int c = 0; c < n; c++)
                if (g[r][c] == 0) queue.add(new int[] {r, c});
        }
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            for (int d = 0; d < 4; d++) {
                int r = cur[0] + DR[d], c = cur[1] + DC[d];
                if (r >= 0 && c >= 0 && r < m && c < n
                        && g[r][c] == Integer.MAX_VALUE) {
                    g[r][c] = g[cur[0]][cur[1]] + 1;
                    queue.add(new int[] {r, c});
                }
            }
        }
        return g;
    }
}

TIME O(m·n)

SPACE O(m·n)

Each cell enters the queue at most once. orangesRotting and shortestBridge freeze queue.size() per round to count minutes and flips; the others store distances in a matrix initialised to −1.

F. Detailed Dry Run

Oranges 211 / 110 / 011: minute 0 the single rotten orange is at (0,0) and the grid has 6 fresh oranges: (0,1) (0,2) (1,0) (1,1) (2,1) (2,2). Minute 1: (0,1) and (1,0) rot. Minute 2: (0,2) and (1,1) rot. Minute 3: (2,1) rots. Minute 4: (2,2) rots. Answer 4, which equals the longest shortest-path from the source to any reachable fresh orange.

Distance matrix: the zero cells of the 4 × 4 example are at (1,1) and (3,2). (0,1) is 1 from (1,1); (0,0) is 2; (3,0) is 2 from (3,2) (and 3 from (1,1)): the minimum 2 is stored.

G. Variations of the Pattern

Distance fields

Map of Highest Peak (1765): water cells are sources of height 0; every other cell's height is its distance to water (neighbouring heights differ by at most 1).

Spreading hazards that race the player

Escape the Spreading Fire (2258): BFS from the fire gives the arrival time per cell; then binary search the waiting time and BFS the player, comparing arrival times (with a tie-break on the last cell).

Sum or best location over several sources

Shortest Distance from All Buildings (317): BFS from each building (not multi-source, because you need the sum over all buildings), accumulating total[r][c] and counting how many buildings reached each cell.

Graph, not grid

The Time When the Network Becomes Idle (2039): BFS from the master server on a general graph gives each server's round-trip; multi-source applies to any unweighted graph.

Bidirectional and layered

Searching from the start and the goal simultaneously (bidirectional BFS) is the same trick with two sides; expand the smaller frontier.

J. Interview Tips

INTERVIEW

Say "reverse the search": instead of a BFS per cell, one BFS from all targets. It is the insight the interviewer is waiting for.

Name the invariant: the queue holds at most two consecutive distances, so the first visit is the minimum.

Separate the minutes by freezing queue.size(); mention the −1 case for unreachable fresh cells.

Follow-ups: reconstruct which source reached each cell (store the source id); weighted

edges (multi-source Dijkstra); sources that start at different times (Dijkstra with initial distances); in-place O(1) memory (encode time in the grid).

Edge cases: no sources, no targets, everything already rotten, isolated fresh cell, 1 × 1 grid, walls separating regions.

CHAPTER SUMMARY

Multi-source BFS = put every source in the queue at distance 0, then run plain BFS: the first visit gives the distance to the nearest source.

It replaces mn separate BFS runs by one (O(mn)): "reverse the direction of the search".

Freeze queue.size() per round to count minutes / layers; check unreachable cells (−1).

Typical shapes: spreading (oranges, fire), distance maps (01 matrix, gates, peaks), island bridging.

If the answer needs a sum over all sources, you need one BFS per source instead.
