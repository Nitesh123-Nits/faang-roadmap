Linked List Reversal

Flip arrows in place: whole lists, sublists, and blocks of k nodes.

A. Pattern Overview

Reversing a linked list means re-pointing each next arrow to the previous node. No values move and no nodes are allocated: the same nodes end up in the opposite order in O(n) time and O(1) space. The pattern has three sizes, and each larger one is built from the smaller one.

KEY IDEA

Three-step rule for any pointer change: (1) save the node you are about to lose (next), (2) re-link the arrow, (3) advance. Forgetting step 1 is the cause of nearly every linked-list bug: after cur.next = prev, the rest of the list is unreachable unless you saved it.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Reverse the list", "reverse between positions", "reverse in groups of k", "swap every two nodes".
"Read the list backwards" or "compare the first half with the second half" with an O(1) space

limit: reverse one half in place.

"Pair the first with the last", "twin" nodes, interleave front and back: reverse the second half, then walk two pointers.
"Add two numbers stored as digit lists" with most significant digit first: reverse both (or

use stacks).

"Rotate by k": not a reversal but a ring cut, and the same n-minus-k index arithmetic as the array version (Chapter 9).
The statement says "do not modify the node values, only the nodes themselves": relinking is

expected.

C. Core Intuition with Illustrations

The three-pointer dance

Keep prev (the already-reversed part, starting as null), cur (the node being processed), and a temporary nxt (the rest). Each step flips one arrow and slides all three one node to the right.

Figure 41. Green arrows are the flipped ones. When cur falls off the end, prev is the head of the reversed list.

Recursion: trust the rest

Assume reverseRecursive(head.next) returns the reversed rest, whose tail is head.next. Then head.next.next = head hangs head after that tail, and head.next = null ends the list. The recursion depth is n, so very long lists risk StackOverflowError: prefer the iterative version in production.

Reverse a sublist by head-insertion

To reverse positions 2..4 of 1 → 2 → 3 → 4 → 5, stand on node before (position 1). Node cur

(position 2) stays put and becomes the tail of the reversed segment. Each step takes the node after cur and inserts it right after before. After right − left moves the segment is reversed, and no reconnection step is needed.

Figure 42. cur never moves in the list; it simply ends up as the segment's tail as nodes are inserted in front of it.

Blocks of k

For each block: (1) walk k nodes from groupPrev to find kth; if it is null, fewer than k nodes remain, so stop and leave them untouched. (2) Reverse the k nodes, making the first node point to groupNext (so the tail already links to the rest). (3) Point groupPrev.next at the new block head (kth) and move groupPrev to the old first node, now the block's tail.

Figure 43. Blocks are reversed independently; only a short final block is left alone.

D. Brute Force to Optimal Solution

Brute force (copy): push all values on a stack or into an array, then rewrite the node values in reverse. O(n) time and O(n) space, and it breaks when the task forbids changing values.
Recursion: elegant, O(n) time, but O(n) call-stack space.
Iterative three-pointer: O(n) time, O(1) space: the standard answer.
Sublist / blocks: the same loop restricted to a window, plus reconnection of the window to its neighbours. Head-insertion folds the reconnection into the loop.

For blocks of k, the naive plan reverses every k nodes without checking that k remain; the correct plan locates the k-th node first, so a short tail is left untouched.

E. Java Implementation

Reverse the whole list

ReverseList.java: LeetCode 206

Java 17+

/** LeetCode 206 - Reverse Linked List, iterative and recursive. */
public class ReverseList {

    public static ListNode reverse(ListNode head) {
        ListNode prev = null, cur = head;
        while (cur != null) {
            ListNode nxt = cur.next;                     // 1. remember the rest
            cur.next = prev;                             // 2. flip the arrow
            prev = cur;                                  // 3. advance both
            cur = nxt;
        }
        return prev;
    }

    public static ListNode reverseRecursive(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode newHead = reverseRecursive(head.next);  // reverse everything after head
        head.next.next = head;                           // the old successor now points back
        head.next = null;
        return newHead;
    }
}

TIME O(n)

SPACE O(1) iterative, O(n) recursive

Save next first; the loop ends when cur is null, and prev is then the new head.

Reverse a sublist

ReverseBetween.java: LeetCode 92

Java 17+

/**
 * LeetCode 92 - Reverse Linked List II. Head-insertion moves one node per step to the front.
 */
public class ReverseBetween {

    /** Reverses positions left..right (1-indexed, left <= right) in one pass. */
    public static ListNode reverseBetween(ListNode head, int left, int right) {
        ListNode dummy = new ListNode(0, head), before = dummy;
        for (int i = 1; i < left; i++) {
            before = before.next;                        // node just before the segment
        }
        // first node of the segment, becomes its tail
        ListNode cur = before.next;
        for (int i = 0; i < right - left; i++) {
            ListNode move = cur.next;                    // node to move to the front
            cur.next = move.next;
            move.next = before.next;
            before.next = move;
        }
        return dummy.next;
    }
}

TIME O(n)

SPACE O(1)

The dummy node lets left = 1 work with no special case.

Reverse in groups of k

ReverseKGroup.java: LeetCode 25

Java 17+

/**
 * LeetCode 25 - Reverse Nodes in k-Group. Reverse each full block, leave a short tail alone.
 */
public class ReverseKGroup {

    public static ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummy = new ListNode(0, head), groupPrev = dummy;
        while (true) {
            ListNode kth = groupPrev;
            for (int i = 0; i < k && kth != null; i++) {
                kth = kth.next;
            }
            if (kth == null) break;                      // fewer than k nodes remain
            ListNode groupNext = kth.next;
            ListNode prev = groupNext, cur = groupPrev.next;
            // reverse the block, tail -> next block
            while (cur != groupNext) {
                ListNode nxt = cur.next;
                cur.next = prev;
                prev = cur;
                cur = nxt;
            }
            // old first node is the new block tail
            ListNode newTail = groupPrev.next;
            groupPrev.next = kth;
            groupPrev = newTail;
        }
        return dummy.next;
    }
}

TIME O(n)

SPACE O(1)

Each node is visited twice (once to find kth, once to reverse): still linear.

G. Variations of the Pattern

Swap Nodes in Pairs (the k = 2 case)

Relink nodes without swapping values: prev → a → b → rest becomes prev → b → a → rest,

then prev = a.

SwapPairs.java: LeetCode 24
/** LeetCode 24 - Swap Nodes in Pairs (relinks nodes; values are never swapped). */
public class SwapPairs {

    public static ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(0, head), prev = dummy;
        while (prev.next != null && prev.next.next != null) {
            ListNode a = prev.next, b = a.next;
            a.next = b.next;                             // a skips over b

Rotate List: a ring cut

Rotating right by k moves the last k nodes to the front. Measure n, reduce k modulo n, link the tail to the head to form a ring, walk n − k − 1 nodes to the new tail, and cut. It is the three-reversal array rotation (Chapter 9) done with one pointer change.

RotateList.java: LeetCode 61

Java 17+

/** LeetCode 61 - Rotate List. Close the list into a ring, then cut it at the new tail. */
public class RotateList {

    public static ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) return head;
        int n = 1;
        ListNode tail = head;
        while (tail.next != null) {
            tail = tail.next;
            n++;
        }
        k %= n;
        if (k == 0) return head;
        tail.next = head;                                // make a ring
        ListNode newTail = head;
        for (int i = 0; i < n - k - 1; i++) {
            newTail = newTail.next;
        }
        ListNode newHead = newTail.next;
        newTail.next = null;                             // break the ring
        return newHead;
    }
}

TIME O(n)

SPACE O(1)

k can be larger than n (up to 2·10⁹): reduce it first, and return

early when k % n == 0.

Reversal as a subroutine
Palindrome List (Chapter 21): reverse the second half, compare, restore.
Reorder List (Chapter 24): reverse the second half, interleave with the first.
Add Two Numbers II (Chapter 23): reverse both inputs, add with carry, reverse the result

(or use two stacks to avoid mutation).

Reverse Nodes in Even-Length Groups (2074): reverse a group only when its actual length is even; the final group may be short.
Doubly linked list: swap the two pointers

In a doubly linked list each node's prev and next are swapped, and the old tail becomes the head. There is no prev variable: the node already knows its predecessor.

J. Interview Tips

INTERVIEW

Draw four boxes and three arrows (prev, cur, nxt) and execute two iterations on the board before coding. Most candidates who fail linked lists never trace.

Say the three-step rule (save, relink, advance) while you write each loop; it prevents the lost-pointer bug.

Mention the dummy head whenever the head can change, and restore the list if you mutate a half for a read-only question.

Follow-ups: reverse iteratively and recursively; reverse in groups of k using O(1) space; reverse only if the remaining length is at least k; reverse alternate groups; reverse a doubly linked list; print a list in reverse without modifying it (recursion or a stack).
Edge cases: empty list, one node, k = 1, k = n, k > n, left = 1, right = n, left = right.

CHAPTER SUMMARY

Reversal flips each next arrow: save next, relink, advance. Return prev, not head.

Sublist reversal is easiest by head-insertion after the node before left: right − left moves, no reconnection step.

k-group: locate the k-th node first; reverse the block with prev starting at groupNext; reconnect and move groupPrev to the old first node. A short tail stays unchanged.

Rotate is a ring cut: close tail to head, walk n − k − 1, cut. Pairs are k = 2.

Reversal is also a subroutine: palindrome, reorder, twin sum and digit-list addition all reverse one half or one input.
