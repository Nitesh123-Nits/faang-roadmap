DP on Trees

General trees: root once, combine children, and re-root for all-nodes answers.

A. Pattern Overview

Chapter 44 solved DP on binary trees. This chapter handles general trees (any number of children, given as an edge list). The state is a node v plus, when needed, a small flag; the value summarises the subtree of v. A post-order pass combines children into the parent in O(n). Two extensions appear in interviews: re-rooting (compute an answer for every node as root in O(n) total) and tree knapsack (allocate a budget among children).

KEY IDEA

Process children before parents. Do it with recursion (watch the depth), or iteratively: compute a BFS/DFS order from the root and walk it in reverse.

B. When to Recognize This Pattern

Pattern Recognition Signals

An undirected edge list with n - 1 edges, no cycles: a tree.
"Maximum weight set with no two adjacent nodes."
"Diameter", "longest path", "time to collect all apples".
"For every node, compute ..." (sum of distances, farthest node): re-rooting.
"Choose at most k nodes / edges" under tree constraints: tree knapsack.
ONE-LINE TEST

Tree + optimise over a connected or independent set: post-order DP. "For every root": re-root.

Re-rooting: sum of distances to all other nodes

One pass up the tree computes size[v] and down[v] (sum of distances to nodes inside the subtree). The root's answer is down[0]. Moving the root from parent p to child c, the size[c] nodes below c get 1 closer and the other n - size[c] nodes get 1 farther:

WHY RE-ROOT

A naive solution runs a BFS from every node: O(n^2). Re-rooting reuses the parent's answer and does O(1) work per edge, so the whole problem is O(n).

Diameter and best path through a node

For each node, the longest path with that node as its highest point is best1 + best2, the two largest child chains (each + 1 for the edge to the child). Track the maximum over all nodes. For unweighted trees this is the diameter; for weighted trees add edge weights.

Time to collect all apples (1443)

The walk must return to the root, so every edge on a path to an apple is traversed twice. cost[v] = sum over children c of (cost[c] + 2) if the child subtree contains an apple (it has one itself or cost[c] > 0). One post-order pass.

Tree knapsack

dp[v][k] is the best value choosing k nodes in the subtree of v (connected to v if required). Merging a child is a knapsack convolution; with the sizes bounded by the subtree sizes, the total work is O(n^2) rather than O(n^3): every pair of nodes is combined at most once, at their lowest common ancestor.

E. Java Implementation

Sum of distances, independent set, diameter, collect apples, tree knapsack

TreeGraphDP.java: LeetCode 834, 337 (generalised), 1245, 1443

import java.util.*;

/** Ch 87: DP on general trees; LeetCode 834, 1245, 1443 and tree knapsack. */
public class TreeGraphDP {

    /** BFS order from root 0 and parent array (parent[0] = -1). Iterative. */
    private static int[] order(List<List<Integer>> g, int[] parent) {
        int n = g.size();
        int[] order = new int[n];
        Arrays.fill(parent, -1);
        boolean[] seen = new boolean[n];
        int head = 0, tail = 0;
        order[tail++] = 0;
        seen[0] = true;
        while (head < tail) {
            int u = order[head++];
            for (int v : g.get(u))
                if (!seen[v]) {
                    seen[v] = true;
                    parent[v] = u;
                    order[tail++] = v;
                }
        }
        return order;
    }

    private static List<List<Integer>> build(int n, int[][] edges) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {

Java 17+

            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }
        return g;
    }

    /**
     * LeetCode 834 by rerooting. Pass 1 (leaves up): size[v] and down[v], the
     * sum of distances from v to its subtree. Pass 2 (root down):
     * ans[c] = ans[p] - size[c] + (n - size[c]).
     */
    public static int[] sumOfDistancesInTree(int n, int[][] edges) {
        List<List<Integer>> g = build(n, edges);
        int[] parent = new int[n];
        int[] ord = order(g, parent);
        int[] size = new int[n];
        long[] down = new long[n];
        Arrays.fill(size, 1);
        for (int i = n - 1; i > 0; i--) {
            int v = ord[i], p = parent[v];
            size[p] += size[v];
            down[p] += down[v] + size[v];
        }
        long[] ans = new long[n];
        ans[0] = down[0];
        for (int i = 1; i < n; i++) {
            int v = ord[i];
            ans[v] = ans[parent[v]] - size[v] + (n - size[v]);
        }
        int[] out = new int[n];
        for (int i = 0; i < n; i++) out[i] = (int) ans[i];
        return out;
    }

    /** Maximum-weight independent set (no two adjacent nodes) on a tree. */
    public static long maxWeightIndependentSet(int n, int[][] edges, int[] w) {
        List<List<Integer>> g = build(n, edges);
        int[] parent = new int[n];
        int[] ord = order(g, parent);
        long[] take = new long[n], skip = new long[n];
        for (int i = 0; i < n; i++) take[i] = w[i];
        for (int i = n - 1; i > 0; i--) {
            int v = ord[i], p = parent[v];
            take[p] += skip[v];
            skip[p] += Math.max(take[v], skip[v]);
        }
        return Math.max(take[0], skip[0]);
    }

    /** LeetCode 1245: diameter (in edges) from the two deepest child arms. */
    public static int treeDiameter(int n, int[][] edges) {
        List<List<Integer>> g = build(n, edges);
        int[] parent = new int[n];
        int[] ord = order(g, parent);
        int[] best1 = new int[n], best2 = new int[n];     // two deepest arms
        int diameter = 0;
        for (int i = n - 1; i >= 0; i--) {
            int v = ord[i];
            diameter = Math.max(diameter, best1[v] + best2[v]);
            if (i == 0) break;
            int arm = best1[v] + 1, p = parent[v];
            if (arm > best1[p]) {
                best2[p] = best1[p];
                best1[p] = arm;
            } else if (arm > best2[p]) {
                best2[p] = arm;
            }
        }
        return diameter;
    }

    /**
     * LeetCode 1443: minimum time to collect every apple and return to node 0;
     * each edge costs 1. An edge is walked twice iff its lower side has an apple.
     */
    public static int minTimeToCollectApples(int n, int[][] edges,
            boolean[] apple) {
        List<List<Integer>> g = build(n, edges);
        int[] parent = new int[n];
        int[] ord = order(g, parent);
        boolean[] has = apple.clone();
        int time = 0;
        for (int i = n - 1; i > 0; i--) {
            int v = ord[i];
            if (has[v]) {
                time += 2;
                has[parent[v]] = true;
            }
        }
        return time;
    }

    /**
     * Tree knapsack: choose at most k nodes forming a connected subtree that
     * contains the root 0, maximising the total value.
     * dp[v][j] = best value using exactly j nodes of v's subtree (v included).
     */
    public static long treeKnapsack(int n, int[][] edges, int[] val, int k) {
        if (k <= 0) return 0;
        final long NEG = Long.MIN_VALUE / 4;
        List<List<Integer>> g = build(n, edges);
        int[] parent = new int[n];
        int[] ord = order(g, parent);
        long[][] dp = new long[n][k + 1];
        for (long[] row : dp) Arrays.fill(row, NEG);
        for (int v = 0; v < n; v++) dp[v][1] = val[v];
        for (int i = n - 1; i > 0; i--) {
            int c = ord[i], p = parent[c];
            long[] merged = dp[p].clone();
            for (int j = 1; j <= k; j++) {
                if (dp[p][j] == NEG) continue;
                for (int t = 1; j + t <= k; t++)
                    if (dp[c][t] != NEG)
                        merged[j + t] =
                                Math.max(merged[j + t], dp[p][j] + dp[c][t]);
            }
            dp[p] = merged;
        }
        long best = NEG;
        for (int j = 1; j <= k; j++) best = Math.max(best, dp[0][j]);
        return best;
    }
}

TIME O(n)

SPACE O(n)

Each edge is processed a constant number of times (twice for re-rooting). The tree knapsack merges tables in O(n * k) after capping each child table at min(size, k). Iterative orders avoid stack overflow on path-like trees of depth 10^5.

G. Variations of the Pattern

House Robber III (337)

The binary-tree version of take/skip; Chapter 44 shows it with a return pair.

Minimum vertex cover and maximum matching

Vertex cover on a tree is the complement of an independent set: n-weight minus the independent set value. Maximum matching uses a greedy leaf-first rule or (matched, free) states.

Binary Tree Cameras (968) and domination

Three states per node (has camera, covered, not covered) solve minimum dominating set on a tree.

All-roots queries

Re-rooting also solves farthest node from every vertex, minimum height trees (310) and count of nodes within distance d from each root. Maintain prefix and suffix aggregates over children when the combine step is not invertible.

Tree DP with k budget

Cutting k edges, choosing k nodes, or scheduling k workers: a knapsack over children (Section C.6).

Say "root it anywhere" and define what the state means for a subtree.

Name the two-pass trick for all-nodes answers; it separates seniors from the rest.

Mention iterative traversal for depth; interviewers often ask about worst-case stack.

CHAPTER SUMMARY

General-tree DP: root once, process children before parents, combine into the parent in O(1) per edge.

Take/skip gives independent sets; two longest chains give diameters and path sums.

Re-rooting answers "for every node" in O(n): ans[c] = ans[p] - size[c] + (n - size[c]).

Tree knapsack is O(n^2) thanks to size bounds.

Iterate instead of recurse when depth can reach 10^5.
