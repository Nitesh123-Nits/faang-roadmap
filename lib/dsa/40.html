Choose, Explore, Unchoose

The backtracking template: build a path, recurse, undo.

A. Pattern Overview

Backtracking is recursion that builds a solution one decision at a time and undoes each decision after exploring it. The search space is a tree: every node is a partial solution (the path), every edge is a choice. The whole technique is one three-line loop body:

The universal template
void backtrack(State state, List<Choice> choices) {
    if (isComplete(state)) { record(state); return; }      // base case
    for (Choice c : choicesAt(state)) {
        apply(c, state);          // 1. choose
        backtrack(state, ...);    // 2. explore
        undo(c, state);           // 3. unchoose
    }
}

Java 17+

KEY IDEA

State is shared and mutable; correctness depends on the undo. After explore returns, the state must be exactly what it was before choose. That one invariant is what makes siblings independent. Most backtracking bugs are a missing or asymmetric undo.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Generate all …" / "return every …" / "list all valid …": the output is the search tree's leaves.
Small constraints (n ≤ 8, n ≤ 12, n ≤ 20, a string of length ≤ 16): an exponential search is

intended.

A sequence of independent-looking decisions whose combination must satisfy a rule: balanced, no two adjacent equal, sum to target.
"How many ways" with tiny n is also solvable this way; with large n it is DP.
ONE-LINE TEST

Generate all valid X with n ≤ ~12 means backtracking: build X left to right, and prune the moment a prefix cannot be extended to a valid X.

Two-way and one-way choices: Letter Case Permutation

A letter has two choices (keep, flip), a digit has one. The number of leaves is 2^(number of letters).

Figure 64. Digits do not branch, so they just extend every path.

Choose / explore / unchoose on a StringBuilder

cur.append(c) is the choose, the recursive call is the explore, cur.deleteCharAt(cur.length() − 1) is the unchoose. Only copy the path (cur.toString()) when you record a complete solution; copying at every node would add a factor of the path length.

E. Java Implementation

Generate Parentheses

GenerateParentheses.java: LeetCode 22

Java 17+

import java.util.ArrayList;
import java.util.List;

/**
 * LeetCode 22 - Generate Parentheses. Choose '(' while opens remain; choose ')' only if it
 * closes something.
 */
public class GenerateParentheses {
    public static List<String> generate(int n) {
        List<String> out = new ArrayList<>();
        build(new StringBuilder(), 0, 0, n, out);
        return out;
    }

    private static void build(StringBuilder cur, int open, int close, int n,
            List<String> out) {
        if (cur.length() == 2 * n) { out.add(cur.toString()); return; }
        if (open < n) {
            cur.append('(');                       // choose
            build(cur, open + 1, close, n, out);   // explore
            cur.deleteCharAt(cur.length() - 1);    // unchoose
        }
        if (close < open) {
            cur.append(')');
            build(cur, open, close + 1, n, out);
            cur.deleteCharAt(cur.length() - 1);
        }
    }
}

TIME O(Cₙ · n)

SPACE O(n)

Cₙ = C(2n, n)/(n+1) answers. The recursion path and the StringBuilder use O(n) extra space beyond the output.

import java.util.ArrayList;
import java.util.List;

/** LeetCode 17 - Letter Combinations of a Phone Number. One decision per digit. */
public class LetterCombinations {
    private static final String[] KEYS =
            {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};

    public static List<String> letterCombinations(String digits) {
        List<String> out = new ArrayList<>();
        if (digits.isEmpty()) return out;

Java 17+

        build(digits, 0, new StringBuilder(), out);
        return out;
    }

    private static void build(String digits, int pos, StringBuilder cur,
            List<String> out) {
        if (pos == digits.length()) { out.add(cur.toString()); return; }
        for (char c : KEYS[digits.charAt(pos) - '0'].toCharArray()) {
            cur.append(c);
            build(digits, pos + 1, cur, out);
            cur.deleteCharAt(cur.length() - 1);
        }
    }
}

SPACE O(n)

At most 4 letters per digit (digits 7 and 9). Return an empty list for empty input, not a list holding "".

Letter Case Permutation

LetterCasePermutation.java: LeetCode 784

Java 17+

import java.util.ArrayList;
import java.util.List;

/** LeetCode 784 - Letter Case Permutation. Letters branch two ways, digits one way. */
public class LetterCasePermutation {
    public static List<String> letterCasePermutation(String s) {
        List<String> out = new ArrayList<>();
        build(s.toCharArray(), 0, out);
        return out;
    }

    private static void build(char[] a, int i, List<String> out) {
        if (i == a.length) { out.add(new String(a)); return; }
        build(a, i + 1, out);                      // keep as is
        if (Character.isLetter(a[i])) {
            a[i] ^= 32;                            // choose the other case (flip bit 5)
            build(a, i + 1, out);
            a[i] ^= 32;                            // unchoose
        }
    }
}

TIME O(2ᴸ · n)

SPACE O(n)

L letters. a[i] ^= 32 flips the case of an ASCII letter in place, and the second ^= 32 is the unchoose.

K-th Happy String: stop early

HappyStrings.java: LeetCode 1415

Java 17+

/**
 * LeetCode 1415 - The k-th Lexicographical String of All Happy Strings of Length n (letters
 * a, b, c; no equal neighbours).
 */
public class HappyStrings {
    public static String getHappyString(int n, int k) {
        int[] remaining = {k};
        String[] answer = {""};
        build(new StringBuilder(), n, remaining, answer);
        return answer[0];
    }

    /** Returns true once the k-th string has been produced, so the search can stop early. */
    private static boolean build(StringBuilder cur, int n, int[] remaining,
            String[] answer) {
        if (cur.length() == n) {
            if (--remaining[0] == 0) { answer[0] = cur.toString(); return true; }
            return false;
        }
        for (char c = 'a'; c <= 'c'; c++) {
            if (!cur.isEmpty() && cur.charAt(cur.length() - 1) == c) continue;
            cur.append(c);
            if (build(cur, n, remaining, answer)) return true;
            cur.deleteCharAt(cur.length() - 1);
        }
        return false;
    }
}

TIME O(n · k)

SPACE O(n)

Letters are tried in order, so strings appear in lexicographic order. Returning true as soon as the k-th is found stops the whole recursion.

G. Variations of the Pattern

Constraint on the previous choice

K-th Happy String forbids a letter equal to the previous one; Binary strings without consecutive ones forbids 1 after 1. The rule needs only the last element of the path.

Early exit (find one or the k-th)

If the problem asks for one solution, a boolean-returning recursion that stops at the first success avoids exploring the rest. Remember to undo before returning false, and to not undo after returning true only if you rely on the path afterwards (usually copy it first).

Counting instead of listing

If only the number of valid structures is needed, return a count from each call instead of building paths. With overlapping states, memoise (Part XI).

Gray code, binary watch, 24 game

Gray Code (89), Binary Watch (401) and 24 Game (679) are the same template with a different notion of choice and validity.

Iterative versions

Level-by-level expansion (a queue of partial strings) also works for these but stores a whole level in memory; the recursive version stores one path.

J. Interview Tips

INTERVIEW

Say the template first: "complete? record. otherwise for each legal choice: choose, recurse, unchoose." Then fill in the three blanks for the problem.

Draw the tree for the smallest input and mark where pruning removes edges. It also gives you the complexity.

Always state the answer size as the lower bound, so the interviewer knows you are not leaving easy speed on the table.

Follow-ups: generate in lexicographic order (iterate choices in order); only the count

(memo); iterative version; very large n (stream the answers with an iterator instead of building a list).

Edge cases: n = 1, empty input, a single choice per level, all choices pruned (empty result), duplicates in the input.

CHAPTER SUMMARY

Template: if complete, record a copy; otherwise for each legal choice: choose, explore, unchoose.

The state is shared and mutable: every choose has a matching unchoose, so siblings start from the same state.

Prune while choosing, not after: enforce the rule (close < open, no equal neighbour) before recursing so that no dead prefix exists.

The output size is a lower bound; backtracking cost is (number of nodes) × (work per node) and should be close to it.

Stop early (boolean return) when only the first or the k-th solution is needed.
