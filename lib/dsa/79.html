Jump Game

Track the furthest reach; each BFS level is one more jump.

A. Pattern Overview

In a jump game you stand at index 0 of an array and each cell says how far (or in which ways) you may jump. The classic questions are can I reach the end? (55) and what is the fewest number of jumps? (45). Both have an O(n) greedy solution that maintains one number, the furthest index reachable so far, and the second reads it as an implicit BFS whose levels are jumps. Variants with irregular moves (backwards jumps, teleports to equal values, windows) fall back to explicit BFS or sliding-window DP.

The two greedy loops
int far = 0;                                       // Jump Game: can we reach the end?
for (int i = 0; i < nums.length; i++) {
    if (i > far) return false;                     // stranded: index i is unreachable
    far = Math.max(far, i + nums[i]);
}
return true;

int jumps = 0, levelEnd = 0;                       // Jump Game II: fewest jumps
for (int i = 0; i < nums.length - 1; i++) {
    far = Math.max(far, i + nums[i]);
    if (i == levelEnd) { jumps++; levelEnd = far; }   // finished one BFS level
}
return jumps;

KEY IDEA

Reachability is contiguous. If you can reach index far, you can reach every index ≤ far too, because a jump may be shorter than nums[i]. So one number (the furthest reach) describes the entire reachable set.

B. When to Recognize This Pattern

Pattern Recognition Signals

An array of maximum jump lengths and a question about reaching the end or the fewest jumps.
"Reach the last index" with moves that go forward by up to some value.
Layers of reachability: all indices reachable in 1 jump, then 2 jumps, and so on (BFS by levels).
Backward moves or teleports (equal values, ±arr[i]): explicit BFS with a visited array.
A sliding window of allowed jump lengths (minJump..maxJump): sliding window counter or deque DP.
ONE-LINE TEST

Forward jumps up to nums[i]: greedy furthest reach. Arbitrary jump rules: BFS on indices. Score-maximising jumps with a window k: DP + deque.

C. Core Intuition with Illustrations

Furthest reach, scanned once

nums = [2, 3, 1, 1, 4]. At index 0 the reach is 2; index 1 extends it to 4 (the last index); the loop can stop. If the reach ever lags behind the scan (i > far), index i and everything after it is unreachable.

A failing case

[3, 2, 1, 0, 4]: every jump from indices 0 to 2 reaches at most index 3, where nums[3] = 0

traps you. At i = 4, far = 3 < 4: return false. The zero is a barrier only if nothing before it can jump past it.

Fewest jumps: BFS by levels without a queue

Level 0 is {0}. Level 1 is every index reachable by one jump from level 0, i.e. 1..nums[0]. Level 2 is everything reachable from level-1 indices, and so on. Because reachability is contiguous, each level is an interval (levelEnd_prev, levelEnd]. Scan the current level, compute the furthest index any cell in it reaches, and when the scan hits the level's end, count a jump and move the boundary to that furthest index.

Why jumps need to stop one before the last index

The loop runs to n − 2: once the boundary reaches the last index no further jump is needed, and counting at index n − 1 would add a spurious jump when levelEnd == n − 1.

Backward and teleport jumps need a visited array

Jump Game III allows i ± arr[i]; the goal is any index with value 0. A BFS or DFS with a visited array is O(n). Jump Game IV adds teleports to every index with the same value. The classic trap is O(n²): visit a value group once, then delete it from the map so later cells with that value do not re-scan the group.

Window of allowed jump lengths

In Jump Game VII (s[j] == '0', jump length in [minJump, maxJump]) index i is reachable if some reachable j lies in [i − maxJump, i − minJump]. Maintain a counter of reachable indices inside that sliding window: add i − minJump when it becomes eligible, remove i − maxJump − 1 when it leaves. O(n) with no inner loop.

INTUITION

The DP is dp[i] = min over j<i with j + nums[j] ≥ i of dp[j] + 1. Because dp is

non-decreasing in i when reachability is contiguous, each level is an interval, which is why the greedy scan and the BFS-by-levels view agree.

JumpGame.java: LeetCode 55, 45, 1306, 1345, 1871
import java.util.*;

/**
 * Ch 67: jump games; LeetCode 55, 45, 1306, 1345, 1871 (and 1696 in JumpGameVI).
 */
public class JumpGame {

    /**
     * LeetCode 55: can we reach the last index? Track the furthest reachable index.
     */
    public static boolean canJump(int[] nums) {
        int far = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > far) return false;                 // stranded before index i
            far = Math.max(far, i + nums[i]);
            if (far >= nums.length - 1) return true;
        }
        return true;
    }

Java 17+

    /** LeetCode 45: fewest jumps; implicit BFS where each level is one jump. */
    public static int jump(int[] nums) {
        int jumps = 0, levelEnd = 0, far = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            far = Math.max(far, i + nums[i]);
            // finished scanning this level
            if (i == levelEnd) {
                // cannot advance (input may be invalid)
                if (far <= i) return -1;
                jumps++;
                levelEnd = far;
            }
        }
        return jumps;
    }

    /** LeetCode 1306: from start, move +-arr[i]; can we reach any 0? BFS. */
    public static boolean canReach(int[] arr, int start) {
        int n = arr.length;
        boolean[] seen = new boolean[n];
        Deque<Integer> queue = new ArrayDeque<>();
        queue.add(start);
        seen[start] = true;
        while (!queue.isEmpty()) {
            int i = queue.poll();
            if (arr[i] == 0) return true;
            for (int next : new int[] {i + arr[i], i - arr[i]}) {
                if (next >= 0 && next < n && !seen[next])
                    { seen[next] = true; queue.add(next); }
            }
        }
        return false;
    }

    /** LeetCode 1345: jump to i + 1, i - 1 or any index with an equal value. */
    public static int minJumps(int[] arr) {
        int n = arr.length;
        if (n == 1) return 0;
        Map<Integer, List<Integer>> sameValue = new HashMap<>();
        for (int i = 0; i < n; i++)
            sameValue.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);
        boolean[] seen = new boolean[n];
        Deque<Integer> queue = new ArrayDeque<>();
        queue.add(0);
        seen[0] = true;
        int steps = 0;
        while (!queue.isEmpty()) {
            steps++;
            for (int size = queue.size(); size > 0; size--) {
                int i = queue.poll();
                List<Integer> group = sameValue.getOrDefault(arr[i], List.of());
                List<Integer> next = new ArrayList<>(group);
                next.add(i + 1);
                next.add(i - 1);
                // each value group is expanded once
                sameValue.remove(arr[i]);
                for (int j : next) {
                    if (j < 0 || j >= n || seen[j]) continue;
                    if (j == n - 1) return steps;
                    seen[j] = true;
                    queue.add(j);
                }
            }
        }
        return -1;
    }

    /**
     * LeetCode 1871: from i you may jump to [i + minJump, i + maxJump] where s[j]
     * == '0'.
     */
    public static boolean canReachVII(String s, int minJump, int maxJump) {
        int n = s.length();
        if (s.charAt(n - 1) != '0') return false;
        boolean[] reach = new boolean[n];
        reach[0] = true;
        // reachable indices in [i - maxJump, i - minJump]
        int window = 0;
        for (int i = 1; i < n; i++) {
            if (i - minJump >= 0 && reach[i - minJump]) window++;
            if (i - maxJump - 1 >= 0 && reach[i - maxJump - 1]) window--;
            reach[i] = s.charAt(i) == '0' && window > 0;
        }
        return reach[n - 1];
    }
}

F. Detailed Dry Run

Jump Game II on [2, 3, 1, 1, 4]: at i = 0 the furthest is 2 and levelEnd = 0, so we count jump 1 and set levelEnd = 2. Indices 1 and 2 extend the furthest reach to 4 (i = 1: 1 + 3 = 4). At i = 2 = levelEnd we count jump 2 and set levelEnd = 4. Index 3 is the last scanned (i

< n − 1); the boundary has reached the end. Two jumps.

The implicit BFS levels are {0}, {1, 2}, {3, 4}: each jump covers a contiguous block, and the answer is the number of the block that contains the last index.

G. Variations of the Pattern

Jump Game III (1306) and IV (1345)

BFS on indices with a seen array. IV: group indices by value in a map; after expanding a value, remove it from the map.

Jump Game V (1340)

Jump left or right up to d cells over strictly smaller values; maximise the number of visited indices: memoised DFS or DP in increasing order of height, O(n · d).

Jump Game VI (1696) and VII (1871)

VI maximises the score with window k: DP with a monotonic deque (Chapter 8). VII asks reachability: sliding window counter.

Minimum taps and video stitching

These are Jump Game II over intervals (Chapter 64): maxReach[left] = right, then the same level scan.

Frog Jump (403), Odd Even Jump (975)

Jump length depends on the previous jump or on parity: the state needs more than the index (dp[index][lastJump], or two boolean arrays). Greedy no longer applies.

J. Interview Tips

INTERVIEW

State the contiguity fact: "if far is reachable, so is everything before it." It justifies tracking a single number.

Present Jump Game II as BFS: levels are intervals, so no queue is needed. That is the "aha" interviewers look for.

Mention the DP first, then optimise to greedy, and note the O(n²) to O(n) improvement.

Follow-ups: print the path (store parent for each level's best cell); minimum jumps with costs (Dijkstra); jumps that can go backwards (BFS); constraint-limited windows (deque).
Edge cases: [0], [0, 1], [1, 0, 1], large first value, all zeros after the first cell, zero in

the middle that can be jumped over.

CHAPTER SUMMARY

Reachability is contiguous: one number, the furthest reachable index, describes everything reachable so far.

Jump Game: scan once, return false when i > far. Jump Game II: each BFS level is an interval; count a jump when i == levelEnd and set levelEnd = far.

Both are O(n) time and O(1) space; the DP is O(n²) and a useful oracle.

Irregular moves (backward, teleports) need an explicit BFS with a visited array; clear value groups once to stay linear.

Windowed jumps use a sliding counter (reachability) or a monotonic deque (best score); interval covers are Jump Game II in disguise.
