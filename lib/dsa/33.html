Stack for Matching and Nesting

Last in, first out: brackets, undo, and cancelling neighbours.

A. Pattern Overview

A stack gives you the most recent unfinished thing in O(1). Whenever a problem has nesting (a closer must match the nearest opener), cancellation (a new element may destroy the previous one), or backtracking context (return to the state before a bracket), a stack is the natural model. This chapter covers the non-monotonic uses; the monotonic stack (next greater element) is Chapter 7.

KEY IDEA

The stack invariant. At every moment the stack holds exactly the unresolved part of the input, ordered from oldest (bottom) to newest (top). A well-formed solution states in one sentence what is on the stack; if you cannot say it, the algorithm is not clear yet.

B. When to Recognize This Pattern

Pattern Recognition Signals

Nested structure: brackets, tags, parentheses in expressions, k[encoded] strings, function call / return logs.
"The most recent unmatched …", "the nearest enclosing …", "undo the last …": LIFO in plain

words.

Adjacent cancellation repeated until nothing changes: process left to right and let the top of the stack absorb the new item.
"Remove the fewest characters to make the string valid": mark unmatched positions

with an index stack.

A path or token stream with a back command (.., back, undo): the stack is the history.
Collisions where only one direction pair interacts (right-moving meets left-moving).
RECURSION VS STACK

A recursion that is only used to remember where you were is a stack in disguise. Write it iteratively with an explicit stack when depth could reach 10⁵ (Java's default call stack overflows near 10⁴–10⁵ frames).

C. Core Intuition with Illustrations

Push the expected closer

For {[()]}: each opener pushes the closer it will need. A closer is valid only if it equals the top. This removes the separate map from opener to closer and makes the check a single comparison.

Figure 50. The stack always holds the closers still owed, newest on top.

Index stack with a wall: Longest Valid Parentheses

Store indices of unmatched (. After popping at a ), the new top is the index just before the current valid run, so the run length is i − top. When the stack becomes empty, the ) itself is unmatched: push it as the new wall. Seeding the stack with −1 makes the first run work with no special case.

Figure 51. Indices on the stack make run lengths a subtraction.

Cancellation: the stack is the answer so far

In Remove All Adjacent Duplicates the stack is the string built so far. A new character equal to the top cancels it; otherwise it is appended. For runs of k, keep (char, count) pairs and pop when the count reaches k.

Context save: Decode String

At [ you must remember two things about the outer level: the repeat count and the text built so far. Push both, start a fresh buffer, and at ] pop them, repeat the inner buffer, and append it to the restored text.

D. Brute Force to Optimal Solution

Brute force (repeated deletion): repeatedly remove (), [], {} (or equal neighbours) until nothing changes: O(n²), because each pass is O(n) and up to n/2 passes are needed.
Stack: one left-to-right pass; each character is pushed and popped at most once: O(n) time, O(n) space.
Constant space for one bracket type: a counter is enough for Valid Parentheses with ( only; for Longest Valid Parentheses two scans (left-to-right, then right-to-left) with open and close counters give O(1) space. With several bracket kinds, the stack is unavoidable.

The O(n²) repeated-deletion method is exactly what the book's test suite uses as an oracle for these solutions.

E. Java Implementation

Valid Parentheses

ValidParentheses.java: LeetCode 20

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;

/**
 * LeetCode 20 - Valid Parentheses. A closer must match the most recent unmatched opener
 * (LIFO).
 */
public class ValidParentheses {

    public static boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            switch (c) {
                case '(' -> stack.push(')');             // push the closer we expect to see
                case '[' -> stack.push(']');
                case '{' -> stack.push('}');
                default -> {
                    if (stack.isEmpty() || stack.pop() != c) return false;
                }
            }
        }
        return stack.isEmpty();                          // leftover openers are unmatched
    }
}

TIME O(n)

SPACE O(n)

Prefer ArrayDeque to java.util.Stack: Stack is a synchronised Vector subclass.

Longest Valid Parentheses

LongestValidParentheses.java: LeetCode 32

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;

/**
 * LeetCode 32 - Longest Valid Parentheses. The stack holds INDICES; the bottom is a "wall".
 */
public class LongestValidParentheses {

    public static int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        // index just before the current valid run
        stack.push(-1);
        int best = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();                             // match the latest '(' (or the wall)
                if (stack.isEmpty()) {
                    // unmatched ')': it becomes the new wall
                    stack.push(i);
                } else {
                    best = Math.max(best, i - stack.peek());
                }
            }
        }
        return best;
    }
}

TIME O(n)

SPACE O(n)

The stack never becomes empty after the initial −1: whenever it would, the current ) is pushed as the new wall.

Minimum Remove to Make Valid

MinRemoveToMakeValid.java: LeetCode 1249

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;

/**
 * LeetCode 1249 - Minimum Remove to Make Valid Parentheses: mark unmatched brackets, then
 * drop them.
 */
public class MinRemoveToMakeValid {

    public static String minRemoveToMakeValid(String s) {
        char[] a = s.toCharArray();
        // indices of '(' still waiting for a ')'
        Deque<Integer> open = new ArrayDeque<>();
        for (int i = 0; i < a.length; i++) {
            if (a[i] == '(') {
                open.push(i);
            } else if (a[i] == ')') {
                // no opener to match: mark for removal
                if (open.isEmpty()) a[i] = '*';
                else open.pop();
            }
        }
        while (!open.isEmpty()) a[open.pop()] = '*';     // openers never matched
        StringBuilder sb = new StringBuilder();
        for (char c : a) {
            if (c != '*') sb.append(c);
        }
        return sb.toString();
    }
}

TIME O(n)

SPACE O(n)

Two kinds of removals: a ) with no opener (found immediately) and a ( never closed (left on the stack at the end).

Remove adjacent duplicates

RemoveAdjacentDuplicates.java: LeetCode 1047, 1209

Java 17+

import java.util.Iterator;
import java.util.ArrayDeque;
import java.util.Deque;

/**
 * LeetCode 1047 / 1209 - Remove All Adjacent Duplicates (pairs, and runs of k) with a stack.
 */
public class RemoveAdjacentDuplicates {

    /** 1047: delete equal adjacent pairs repeatedly. The StringBuilder is the stack. */
    public static String removePairs(String s) {
        StringBuilder st = new StringBuilder();
        for (char c : s.toCharArray()) {
            int n = st.length();
            if (n > 0 && st.charAt(n - 1) == c) st.setLength(n - 1);   // cancels the top
            else st.append(c);
        }
        return st.toString();
    }

    /**
     * 1209: delete k equal adjacent letters repeatedly; the stack keeps (char, run length).
     */
    public static String removeK(String s, int k) {
        Deque<int[]> st = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (!st.isEmpty() && st.peek()[0] == c) {
                if (++st.peek()[1] == k) st.pop();       // a full run of k disappears
            } else {
                st.push(new int[]{c, 1});
            }
        }
        StringBuilder sb = new StringBuilder();
        for (Iterator<int[]> it = st.descendingIterator(); it.hasNext(); ) {
            int[] e = it.next();
            sb.append(String.valueOf((char) e[0]).repeat(e[1]));
        }
        return sb.toString();
    }
}

Decode String

DecodeString.java: LeetCode 394

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;

/** LeetCode 394 - Decode String: k[encoded]. Two stacks save the context at every '['. */
public class DecodeString {

    public static String decodeString(String s) {
        Deque<Integer> counts = new ArrayDeque<>();      // repeat count of each open bracket
        Deque<StringBuilder> prefixes = new ArrayDeque<>();   // text built before each bracket
        StringBuilder cur = new StringBuilder();
        int k = 0;
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                k = k * 10 + (c - '0');                  // counts can have several digits
            } else if (c == '[') {
                counts.push(k);
                prefixes.push(cur);                      // save the context...
                cur = new StringBuilder();               // ...and start a fresh one
                k = 0;
            } else if (c == ']') {
                StringBuilder prev = prefixes.pop();
                prev.append(cur.toString().repeat(counts.pop()));
                cur = prev;                              // restore the context
            } else {
                cur.append(c);
            }
        }
        return cur.toString();
    }
}

TIME O(output length)

SPACE O(depth + output)

Multi-digit counts (100[a]) need k = k * 10 + digit. Reset k after pushing it.

G. Variations of the Pattern

Simplify Path: a stack of directory names

Split on /; ignore empty parts and .; .. pops (if there is anything to pop); anything else is pushed. Join with /, and return / for an empty stack. Iterate the stack from the bottom when building the answer.

SimplifyPath.java: LeetCode 71

Java 17+

import java.util.Iterator;
import java.util.ArrayDeque;
import java.util.Deque;

/**
 * LeetCode 71 - Simplify Path (Unix canonical form). ".." pops, "." and empty parts are
 * ignored.
 */
public class SimplifyPath {

    public static String simplifyPath(String path) {
        Deque<String> stack = new ArrayDeque<>();
        for (String part : path.split("/")) {
            if (part.isEmpty() || part.equals(".")) continue;
            if (part.equals("..")) {
                if (!stack.isEmpty()) stack.pop();       // at the root, ".." does nothing
            } else {
                stack.push(part);
            }
        }
        if (stack.isEmpty()) return "/";
        StringBuilder sb = new StringBuilder();
        for (Iterator<String> it = stack.descendingIterator(); it.hasNext(); ) {
            sb.append('/').append(it.next());
        }
        return sb.toString();
    }
}

Asteroid Collision: a one-sided cancellation

Only a right-moving top (positive) and a left-moving newcomer (negative) collide. The newcomer keeps destroying smaller tops; equal sizes destroy both; a bigger top destroys the newcomer. Everything else is pushed.

AsteroidCollision.java: LeetCode 735

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;

/**
 * LeetCode 735 - Asteroid Collision. Only (right-moving, left-moving) neighbours can collide.
 */
public class AsteroidCollision {

    public static int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> st = new ArrayDeque<>();
        for (int a : asteroids) {
            boolean alive = true;
            while (alive && a < 0 && !st.isEmpty() && st.peek() > 0) {
                int top = st.peek();
                if (top < -a) st.pop();                  // the top explodes, a keeps going
                else if (top == -a) { st.pop(); alive = false; }   // both explode
                else alive = false;                      // a explodes
            }
            if (alive) st.push(a);
        }
        int[] res = new int[st.size()];
        for (int i = res.length - 1; i >= 0; i--) res[i] = st.pop();
        return res;
    }
}

TIME O(n)

SPACE O(n)

A while loop inside the for is still linear: each asteroid is pushed once and popped at most once.

J. Interview Tips

INTERVIEW

State what the stack holds before writing code: "the closers we still owe", "indices of unmatched (", "the output so far". It is the whole design.

Show the cheaper variant: for one bracket type say a counter suffices; for Longest Valid mention the two-pass counter version for O(1) space.

Trace the failing case (([)]) as well as the passing one; it demonstrates that you check the kind of bracket, not only the count.

Follow-ups: return the positions of mismatched brackets; support * as a wildcard (Valid

Parenthesis String, 678: two counters lo and hi); stream the input; validate HTML tags.

Edge cases: empty string, only closers, only openers, deeply nested input, a single character, multi-digit counts, a path that is only /.

CHAPTER SUMMARY

A stack holds the unresolved part of the input, oldest at the bottom. Say in one sentence what it holds before coding.

Brackets: push the expected closer; a closer must equal the top; the stack must be empty at the end. Use ArrayDeque, not Stack.

Index stack + wall (−1) turns run lengths into subtraction (Longest Valid Parentheses) and marks the unmatched positions to delete (Min Remove).

Cancellation (adjacent duplicates, asteroids): compare with the top, so cascades are handled automatically; pop at most once per push gives O(n).

Context save (k[...]): push the outer state at an opener, pop and combine at the closer. Counts can have several digits.
