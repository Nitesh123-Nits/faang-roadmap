For any optimisation, counting or feasibility problem that brute force solves in exponential time, ask the nine questions in order. The first Yes names the chapter; if all nine are No, write the recursion, find the repeated calls, and decide the state (Chapter 78).

STATE CHECK

Before coding any DP, write one sentence for the state (dp[i][j] means ...), the transition, the base cases, and the loop order. If you cannot say the state in a sentence, the state is wrong.
