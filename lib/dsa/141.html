PART III PATTERN SELECTOR
ONE-LINE TEST

Hashing patterns reduce to one question: what is the key? Complement (target − x), canonical form (sorted letters, reduced slope), frequency, remainder, or prefix sum. Once you name the key, the code is a HashMap loop.
