Kadane's Algorithm

Best subarray ending here: extend it or restart. A 1-state DP in one pass.

A. Pattern Overview

Kadane's algorithm finds the maximum-sum contiguous subarray in O(n) time and O(1) space. It is dynamic programming with a single state: best[i] = the largest sum of a subarray that ends at index i. The recurrence has only two choices: extend the best subarray ending at i-1, or start fresh at i.

best[i] = max(nums[i], best[i-1] + nums[i]) and answer = max over i of best[i]

INTUITION

Why "start fresh" is correct. If best[i-1] is negative, attaching it to nums[i] can only lower the sum, so any optimal subarray ending at i should drop that prefix. Equivalent view: a negative-sum prefix of any optimal subarray can always be removed.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Maximum / minimum sum (or product) of a contiguous subarray." Array contains negatives; otherwise the answer is trivially the whole array.
An optimisation over all subarrays where the value of a subarray ending at i depends

only on the best one ending at i-1.

Phrases such as best time to buy and sell once, maximum profit, largest gain over consecutive differences.
Circular array with a contiguous segment that may wrap around.
A constraint of n ≤ 10⁵ and the brute force is O(n²) over all (i, j).
SANITY CHECK

If the problem allows only non-negative numbers for "max subarray", the answer is the entire array: the problem is a trick or a different one. Kadane earns its keep exactly when negatives are present.

C. Core Intuition with Illustrations

Figure 14. Bars are the inputs; the navy line is bestEndingHere. Whenever the line would dip below the next bar it restarts. The highlighted range [4, -1, 2, 1] = 6.

Read the navy line as a running balance: it climbs while the stretch is profitable and resets to the current element when the previous balance is a liability.

D. Brute Force to Optimal Solution

Brute force: enumerate all (i, j) and compute the sum: O(n³); with a running sum O(n²).
Prefix-sum view: sum(i..j) = P[j+1] - P[i]. For each j we want the minimum earlier prefix: answer = max_j (P[j+1] - min_{i≤j} P[i]). This is already O(n).
Kadane's compression: P[j+1] - min P[i] equals best ending at j; maintaining it needs just one variable instead of the prefix array.
Divide and conquer (O(n log n)) also exists but is never the right answer here.

E. Java Implementation

MaxSubarray.java — LeetCode 53

Java 17+

/** LeetCode 53 - Maximum Subarray. Kadane's algorithm, plus the actual subarray bounds. */
public class MaxSubarray {

    /** Returns the maximum subarray sum. Requires a non-empty array. */
    public static int maxSubArray(int[] nums) {
        int bestEndingHere = nums[0];          // best sum of a subarray that ends at i
        int best = nums[0];
        for (int i = 1; i < nums.length; i++) {
            // Either extend the previous subarray or start fresh at i.
            bestEndingHere = Math.max(nums[i], bestEndingHere + nums[i]);
            best = Math.max(best, bestEndingHere);
        }
        return best;
    }

    /** Returns {sum, startIndex, endIndex} of one maximum subarray. */
    public static int[] maxSubArrayWithBounds(int[] nums) {
        int bestEndingHere = nums[0];
        int best = nums[0];
        int start = 0;                // start of the current run
        int bestStart = 0;
        int bestEnd = 0;
        for (int i = 1; i < nums.length; i++) {
            if (bestEndingHere < 0) {          // extending a negative sum never helps: restart
                bestEndingHere = nums[i];
                start = i;
            } else {
                bestEndingHere += nums[i];
            }
            if (bestEndingHere > best) {
                best = bestEndingHere;
                bestStart = start;
                bestEnd = i;
            }
        }
        return new int[]{best, bestStart, bestEnd};
    }
}

TIME O(n)

SPACE O(1)

Initialise from nums[0], not 0, or an all-negative array returns 0 (an empty subarray that is not allowed).

G. Variations of the Pattern

Circular Maximum Subarray

A wrapping segment is the complement of a non-wrapping minimum segment: wrapSum = total − minSubarray. Answer is max(maxKadane, total − minKadane), except when every element is negative: then minKadane equals total, the complement is empty, and the correct answer is maxKadane.

Figure 15. The wrapping segment 5 + 5 = 10 equals total minus the minimum middle segment.

CircularMaxSubarray.java — LeetCode 918

Java 17+

/**
 * LeetCode 918 - Maximum Sum Circular Subarray. max(normal Kadane, total - minimum subarray).
 */
public class CircularMaxSubarray {

    public static int maxSubarraySumCircular(int[] nums) {
        int total = 0;
        int curMax = 0, bestMax = nums[0];
        int curMin = 0, bestMin = nums[0];
        for (int x : nums) {
            curMax = Math.max(x, curMax + x);
            bestMax = Math.max(bestMax, curMax);
            curMin = Math.min(x, curMin + x);
            bestMin = Math.min(bestMin, curMin);
            total += x;
        }
        // If every element is negative, the "wrap" candidate (total - bestMin) would be an empty
        // subarray (0), which is illegal. In that case bestMax is already the answer.
        if (bestMax < 0) return bestMax;
        return Math.max(bestMax, total - bestMin);
    }
}

TIME O(n)

SPACE O(1)
Maximum Product Subarray

Products behave differently: a big negative can become a big positive after one more negative. So track both the maximum and minimum product ending at i, and swap them when the current number is negative.

MaxProductSubarray.java — LeetCode 152

Java 17+

/** LeetCode 152 - Maximum Product Subarray. Track both max and min product ending here. */
public class MaxProductSubarray {

    public static int maxProduct(int[] nums) {
        int maxEnding = nums[0];
        int minEnding = nums[0];      // a very negative product can become the max after x < 0
        int best = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            if (x < 0) {              // multiplying by a negative swaps the roles
                int tmp = maxEnding;
                maxEnding = minEnding;
                minEnding = tmp;
            }
            maxEnding = Math.max(x, maxEnding * x);
            minEnding = Math.min(x, minEnding * x);
            best = Math.max(best, maxEnding);
        }
        return best;
    }
}

TIME O(n)

SPACE O(1)

Zeros reset both trackers automatically because max(x, … * 0) picks x.

Best Time to Buy and Sell Stock: Kadane on differences

Profit from buying on day i and selling on j is Σ (price[k+1] - price[k]) for k in [i, j). Maximising it is exactly maximum subarray of the daily differences. The implementation below keeps the running minimum price, which is the same thing in prefix form.

BestTimeToBuySellStock.java — LeetCode 121

Java 17+

/**
 * LeetCode 121 - Best Time to Buy and Sell Stock. Kadane on daily differences, in disguise.
 */
public class BestTimeToBuySellStock {

    public static int maxProfit(int[] prices) {
        int minPriceSoFar = Integer.MAX_VALUE;
        int best = 0;
        for (int price : prices) {
            minPriceSoFar = Math.min(minPriceSoFar, price);
            best = Math.max(best, price - minPriceSoFar);
        }
        return best;
    }
}

TIME O(n)

SPACE O(1)
Maximum Absolute Sum: run Kadane twice at once
MaxAbsoluteSum.java — LeetCode 1749

Java 17+

/**
 * LeetCode 1749 - Maximum Absolute Sum of Any Subarray. Run Kadane for max AND min together.
 */
public class MaxAbsoluteSum {

    public static int maxAbsoluteSum(int[] nums) {
        int curMax = 0, curMin = 0, best = 0;
        for (int x : nums) {
            curMax = Math.max(0, curMax + x);       // empty subarray allowed (abs sum 0)
            curMin = Math.min(0, curMin + x);
            best = Math.max(best, Math.max(curMax, -curMin));
        }
        return best;
    }
}

TIME O(n)

SPACE O(1)

Largest |sum| is either the max subarray sum or the negation of the min subarray sum.

J. Interview Tips

INTERVIEW

Define the state in words first: "cur is the best sum of a subarray ending at i." Everything else follows.

Connect it to prefix sums to show why restarting is right: you subtract the smallest earlier prefix.

Mention the wrap-around trap before the interviewer asks.

Follow-ups: return the indices, circular array, at most one deletion allowed (LeetCode 1186: two-state DP), 2D maximum rectangle sum (fix two rows, Kadane on column sums), max subarray with length ≥ L.integer extremes.
