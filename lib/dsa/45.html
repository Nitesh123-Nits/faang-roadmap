N-Queens

One queen per row: O(1) attack tests with column and diagonal sets.

A. Pattern Overview

Place n queens on an n × n board so that no two attack each other (same row, column or diagonal). The N-Queens pattern shows how a good state representation turns a hopeless-looking search into a fast one: the number of boards with n queens is C(n², n), but by placing exactly one queen per row and testing conflicts in O(1), the search visits only a few thousand nodes for n = 8.

KEY IDEA

Choose the representation so the constraint check is O(1). The brute-force check (scan all placed queens) costs O(n) per placement; the three boolean arrays (or three bitmasks) cost O(1). The same idea powers Sudoku (Chapter 39): rows, columns and boxes as bitmasks.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Place n items on a board so that none conflict": queens, rooks, kings, non-attacking pieces.
One decision per row (or per item) and a conflict rule between decisions.
Small n (n ≤ 9 for listing boards, n ≤ 15 for counting with bitmasks).
Constraints expressible as "same line / diagonal / group", so each can be a set or a bit.
ONE-LINE TEST

Assign one value per slot so that no two slots clash is a constraint-satisfaction search. First decide the slot order (rows), then make clash tests O(1) with sets or bitmasks.

C. Core Intuition with Illustrations

Diagonals have an index

Two cells (r₁, c₁), (r₂, c₂) are on the same diagonal (↘) when r₁ − c₁ = r₂ − c₂, and on

the same anti-diagonal (↙) when r₁ + c₁ = r₂ + c₂. So a queen at (r, c) marks column c,

diagonal r − c + n − 1 (shifted to be non-negative) and anti-diagonal r + c. The arrays have n, 2n − 1 and 2n − 1 entries.

E. Java Implementation

N-Queens: boards, and the bitmask count

NQueens.java: LeetCode 51 and 52

Java 17+

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

/**
 * LeetCode 51 / 52 - N-Queens. One queen per row; three boolean arrays make the safety test
 * O(1).
 */
public class NQueens {
    public static List<List<String>> solveNQueens(int n) {
        List<List<String>> out = new ArrayList<>();
        // colOf[r] = column of the queen in row r
        int[] colOf = new int[n];
        place(0, n, colOf, new boolean[n], new boolean[2 * n - 1],
                new boolean[2 * n - 1], out);
        return out;
    }

    private static void place(int r, int n, int[] colOf, boolean[] cols,
            boolean[] diag, boolean[] anti, List<List<String>> out) {
        if (r == n) { out.add(render(colOf)); return; }
        for (int c = 0; c < n; c++) {
            // both are constant along a diagonal / anti-diagonal
intd=r-c+n-1,a=r+c;
            if (cols[c] || diag[d] || anti[a]) continue;
            cols[c] = diag[d] = anti[a] = true;            // choose
            colOf[r] = c;
            place(r + 1, n, colOf, cols, diag, anti, out);
            cols[c] = diag[d] = anti[a] = false;           // unchoose
        }
    }

    private static List<String> render(int[] colOf) {
        List<String> board = new ArrayList<>();
        for (int c : colOf) {
            char[] row = new char[colOf.length];
            Arrays.fill(row, '.');
            row[c] = 'Q';
            board.add(new String(row));
        }
        return board;
    }

    /**
     * Count only, with bitmasks: one int each for occupied columns and the two diagonal
     * directions.
     */
    public static int totalNQueens(int n) {
        return count(0, 0, 0, (1 << n) - 1);
    }

    private static int count(int cols, int diag, int anti, int full) {
        if (cols == full) return 1;
        int total = 0;
        // 1-bits are the safe columns in this row
        int free = full & ~(cols | diag | anti);
        while (free != 0) {
            int bit = free & -free;                        // lowest safe column
            free -= bit;
            total += count(cols | bit, ((diag | bit) << 1) & full,
                    (anti | bit) >> 1, full);
        }
        return total;
    }
}

G. Variations of the Pattern

Count only

N-Queens II (52): return the count; the bitmask version never builds a board. Known counts: 1, 0, 0, 2, 10, 4, 40, 92, 352, 724 for n = 1 … 10.

One solution only

Return a boolean and stop at the first board. For n ≥ 4 a closed-form construction places

queens directly in O(n).

Other pieces

Non-attacking rooks are permutations; kings need adjacency checks; knights need two-step checks. The recursion is the same, only the clash rule changes.

Latin squares and Sudoku

Replace one queen per row with one digit per cell, and columns / diagonals with rows / columns / boxes: Sudoku (Chapter 39).

Ordering heuristics

Branch on the most constrained slot first (fewest safe squares). It rarely matters for N-Queens but is decisive for Sudoku and exact cover (Algorithm X).

J. Interview Tips

INTERVIEW

Explain the state in one line: "rows are the depth; columns, diagonals and anti-diagonals are three boolean arrays indexed by c, r − c + n − 1, r + c."

Justify the one-queen-per-row model: two queens in a row attack each other, so this loses no solution.

Offer the bitmask version as the optimisation for the counting follow-up, and say it is the same search with O(1) clash tests.

Follow-ups: count only; first solution only; n = 14 in a second; symmetry reduction;

place k < n queens; non-attacking kings.

Edge cases: n = 1 (one solution), n = 2, 3 (none), n = 4 (two), n = 9 (352 boards).

CHAPTER SUMMARY

N-Queens: one queen per row; the decision is the column. Three flags make clash tests O(1): column c, diagonal r − c + n − 1, anti-diagonal r + c.

Pruning (never place on an attacked square) explores about 2 000 nodes for n = 8 instead of billions.

Bitmasks: free = full & ~(cols | diag | anti); bit = free & −free; shift diag left and anti right each row, masked by full.

Solutions: n = 4 has 2, n = 8 has 92. n = 2 and 3 have none.

Choosing a representation that makes the constraint check constant-time is the transferable lesson (Sudoku, exact cover).
