Rabin-Karp and Rolling Hash

Compare substrings by fingerprints that update in O(1) as the window slides.

A. Pattern Overview

A rolling hash maps a window of m characters to one number that can be updated in O(1) when the window slides by one character. Rabin-Karp compares the pattern's hash with each window's hash and verifies only the windows that match. Hash comparison is O(1), so search is O(n + m) expected. The same idea powers binary search on the answer for longest repeated substring, duplicate detection, and substring equality queries via prefix hashes.

KEY IDEA

A hash can only prove two strings are different. Equal hashes mean "probably equal": verify, or choose a modulus so large that collisions are negligible.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Repeated", "duplicate", "occurs twice" substring of fixed or searched length.
Compare many substrings for equality (palindromes in O(1) with forward and reverse

hashes).

Fixed-length window over a string or array that needs a canonical key (DNA windows, subarray patterns).
Binary search on length is valid because "a repeat of length L exists" is monotone in L.
Multi-pattern or 2D matching where KMP does not extend easily.
ONE-LINE TEST

Many substring comparisons of the same length, or monotone existence in the length: rolling hash.

Prefix hashes: any substring in O(1)

Store P and powers of the base. hash(l, r) = P[r+1] - P[l] * B^(r-l+1). Two substrings are equal (with high probability) iff the hashes agree. Palindrome test: compare the forward hash of s[l..r] with the hash of the reversed string over the mirrored range.

Longest duplicate substring: binary search on length

If a repeat of length L exists, one of length L-1 does too (drop a character). So binary search

L; for each candidate compute all window hashes in O(n), store them in a HashMap<hash,

start>, and detect a repeat (verify to be safe). Total O(n log n).

Repeated DNA sequences: two bits per base

Map A, C, G, T to 2 bits, so a length-10 window fits in 20 bits and is its own perfect hash (no collisions): key = ((key << 2) | code) & mask.

TRAP

Always map characters to 1.. (not 0..) when using a polynomial hash with leading zeros: otherwise a and aa collide because 'a' hashes to 0. The Java code uses charAt + 1.

E. Java Implementation

Rolling hash mod 2^61 - 1: windows, search, longest duplicate, DNA, distinct windows

RabinKarp.java: collision-resistant rolling hash with verification

import java.util.*;

/** Ch 102: rolling hash; LeetCode 28 (hash), 187, 1044, 1062. */
public class RabinKarp {
    private static final long MOD = (1L << 61) - 1;       // Mersenne prime
    private static final long BASE = 911_382_323L;

    /** a * b mod (2^61 - 1) using 128-bit product split. */
    private static long mulMod(long a, long b) {
        long hi = Math.multiplyHigh(a, b);
        long lo = a * b;
        long r = (lo & MOD) + ((lo >>> 61) | (hi << 3));
        r = (r & MOD) + (r >>> 61);
        return r >= MOD ? r - MOD : r;
    }

    /** Hash of every length-m window of s, O(n). */
    public static long[] windowHashes(String s, int m) {
        int n = s.length();
        if (m > n) return new long[0];
        long pow = 1;
        for (int i = 1; i < m; i++) pow = mulMod(pow, BASE);
        long[] out = new long[n - m + 1];
        long h = 0;
        for (int i = 0; i < n; i++) {
            if (i >= m) {                                // drop the outgoing char
                h = h - mulMod(s.charAt(i - m) + 1, pow);
                if (h < 0) h += MOD;
            }
            h = mulMod(h, BASE) + s.charAt(i) + 1;
            if (h >= MOD) h -= MOD;
            if (i >= m - 1) out[i - m + 1] = h;
        }
        return out;
    }

Java 17+

    /** All occurrences of pattern in text, verified on every hash hit. */
    public static List<Integer> search(String text, String pattern) {
        List<Integer> hits = new ArrayList<>();
        int m = pattern.length(), n = text.length();
        if (m == 0 || m > n) {
            if (m == 0) for (int i = 0; i <= n; i++) hits.add(i);
            return hits;
        }
        long target = windowHashes(pattern, m)[0];
        long[] hs = windowHashes(text, m);
        for (int i = 0; i < hs.length; i++)
            if (hs[i] == target && text.startsWith(pattern, i)) hits.add(i);
        return hits;
    }

    /**
     * LeetCode 1044: longest substring occurring at least twice (binary search on
     * length).
     */
    public static String longestDupSubstring(String s) {
        int lo = 1, hi = s.length() - 1, bestStart = -1, bestLen = 0;
        while (lo <= hi) {
            int mid = (lo + hi) >>> 1;
            int start = findDuplicate(s, mid);
            if (start >= 0) {
                bestStart = start;
                bestLen = mid;
                lo = mid + 1;
            } else hi = mid - 1;
        }
        return bestStart < 0 ? "" : s.substring(bestStart, bestStart + bestLen);
    }

    private static int findDuplicate(String s, int len) {
        long[] hs = windowHashes(s, len);
        Map<Long, List<Integer>> seen = new HashMap<>();
        for (int i = 0; i < hs.length; i++) {
            List<Integer> prev =
                    seen.computeIfAbsent(hs[i], k -> new ArrayList<>());
            // verify
            for (int j : prev) if (s.regionMatches(i, s, j, len)) return i;
            prev.add(i);
        }
        return -1;
    }

    /** LeetCode 187: repeated 10-letter DNA sequences using hash windows. */
    public static List<String> repeatedDna(String s) {
        List<String> out = new ArrayList<>();
        if (s.length() < 10) return out;
        long[] hs = windowHashes(s, 10);
        Map<Long, Integer> count = new HashMap<>();
        for (int i = 0; i < hs.length; i++) {
            int c = count.merge(hs[i], 1, Integer::sum);
            if (c == 2) out.add(s.substring(i, i + 10));
        }
        return out;
    }

    /** Number of distinct substrings of length m. */
    public static int distinctWindows(String s, int m) {
        Set<String> set = new HashSet<>();
        long[] hs = windowHashes(s, m);
        Set<Long> seen = new HashSet<>();
        for (int i = 0; i < hs.length; i++)
            if (seen.add(hs[i])) set.add(s.substring(i, i + m));
        return set.size();
    }
}

TIME O(n + m) expected

SPACE O(n)

Every window costs a constant number of mulMod calls. Longest duplicate substring is O(n log n) expected. Storing window hashes is the main memory cost.

F. Detailed Dry Run

repeatedDna("AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"): slide a 10-letter window with the 20-bit key. The window AAAAACCCCC appears at starts 0 and 10, and CCCCCAAAAA at starts 5 and 15; every other window is unique. Output {AAAAACCCCC, CCCCCAAAAA}.

longestDupSubstring("banana"): L = 3: windows ban, ana, nan, ana: ana repeats, so feasible. L = 4: bana, anan, nana all distinct, infeasible. Binary search ends with L = 3 and the answer ana.

G. Variations of the Pattern

Hash of a multiset (anagram windows)

Use a sum or XOR of per-character random 64-bit values: updating is O(1) and order-independent. Alternative is the 26-count array as a key.

2D Rabin-Karp

Hash each row window, then roll over rows. Finds a k x k pattern in a grid in O(n m) expected.

Longest common subpath and common substring of several strings

Binary search on length; for each length intersect the sets of window hashes across all strings (Longest Common Subpath, LeetCode 1923).

Hash-based palindrome checks

Prefix hashes of s and reverse(s) answer "is s[l..r] a palindrome?" in O(1); Manacher (Chapter 104) is the deterministic alternative.

Anti-hash defence

Pick the base at random at start-up (ThreadLocalRandom), use 2^61 - 1, and verify matches when exactness matters.

J. Interview Tips

INTERVIEW

Say the formula for the rolling update and why the leading term uses B^(m-1).

Name the collision risk and the fix (large modulus, random base, verify) before being asked.

For longest repeated substring, state monotonicity as the reason binary search is valid.

Follow-ups: guarantee correctness (verify, or use a suffix automaton); memory (store

only a sample); streaming; 2D grids.

Edge cases: all characters equal, window equals the whole string, empty pattern, a single-character string.

CHAPTER SUMMARY

A rolling hash updates a window's fingerprint in O(1), so searching for a pattern costs O(n + m) expected.

Prefix hashes give any substring's hash in O(1), which supports equality, palindrome and echo checks.

Binary search on length plus a hash set finds the longest repeated substring in O(n log n).

Use 2^61 - 1, a random base and verification to keep the probability of error negligible.

Never hash characters to 0, and always normalise negatives after subtraction.
