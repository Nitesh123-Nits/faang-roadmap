Insert Interval

Add one interval to a sorted disjoint list: before, overlap, after.

A. Pattern Overview

The list is already sorted and disjoint, so there is no reason to sort again. Inserting a new interval splits the list into three contiguous blocks: intervals that end before the new one, intervals that overlap it (absorbed into one), and intervals that start after it. One pass, O(n), no sort. The same three-block idea generalises to a persistent set of ranges (add, remove, query) kept in a TreeMap, which is LeetCode's Range Module.

Insert interval in three phases
int i = 0, n = intervals.length, lo = added[0], hi = added[1];
while (i < n && intervals[i][1] < lo) out.add(intervals[i++]);      // entirely before
while (i < n && intervals[i][0] <= hi) {                            // overlaps: absorb
    lo = Math.min(lo, intervals[i][0]);
    hi = Math.max(hi, intervals[i][1]);
    i++;
}
out.add(new int[]{lo, hi});
while (i < n) out.add(intervals[i++]);                              // entirely after

C. Core Intuition with Illustrations

The three blocks

List [1,2] [3,5] [6,7] [8,10] [12,16], new interval [4,8]. [1,2] ends at 2, before 4: before. [3,5], [6,7], [8,10] all start at or before 8 and (since the list is sorted) each overlaps the growing union: absorbed into [3,10]. [12,16] starts after 10: after.

Why the conditions are exactly those

An interval is before iff end < lo; with closed intervals, end == lo means they touch and must merge, hence strict <. An interval overlaps iff start <= hi. Because the list is sorted, once one interval fails the first test and passes the second, every following interval up to the first that fails the second also overlaps.

Binary-search variant

When the list has a million intervals and the new one is tiny, scanning wastes work. Binary-search the first interval whose end is >= lo and the first interval whose start is > hi. Everything between them is merged with the new interval; copy the prefix, the merged interval, and the suffix. Searching is O(log n); building the output array is still O(n) for an array (a LinkedList or a balanced tree avoids the copy).

A persistent range set (Range Module)

Maintain half-open ranges [l, r) in a TreeMap<l, r> with the invariant that stored ranges are disjoint and never touch. addRange looks at the range starting at or before l, then absorbs every range starting in [l, r]. removeRange trims or splits the ranges it hits (keeping the left remainder [s, l) and the right remainder [r, e)). queryRange(l, r) is a single floorEntry(l) test: its end must be >= r.

Why removeRange needs care

A removal can hit one range in the middle (splitting it in two), clip the end of one range and the start of another, and swallow several in between. Collect the affected entries first, then mutate; changing a TreeMap while iterating its subMap view throws

ConcurrentModificationException.

import java.util.*;

/** Ch 72: insert interval and range sets; LeetCode 57, 715. */
public class InsertInterval {

    /**
     * LeetCode 57: insert into a sorted list of disjoint closed intervals and
     * merge. Three phases: before, overlapping, after. O(n).
     */
    public static int[][] insert(int[][] intervals, int[] added) {
        List<int[]> out = new ArrayList<>();
        int i = 0, n = intervals.length;
        int lo = added[0], hi = added[1];
        while (i < n && intervals[i][1] < lo) out.add(intervals[i++]);
        while (i < n && intervals[i][0] <= hi) {
            lo = Math.min(lo, intervals[i][0]);
            hi = Math.max(hi, intervals[i][1]);
            i++;
        }
        out.add(new int[]{lo, hi});
        while (i < n) out.add(intervals[i++]);
        return out.toArray(new int[0][]);
    }

    /**
     * Same result, but finds the overlapping block with two binary searches
     * (useful when the list is huge and the insert is local), then splices.
     */
    public static int[][] insertBinarySearch(int[][] intervals, int[] added) {
        int n = intervals.length;
        int first = firstEndAtLeast(intervals, added[0]);       // first overlap
        int past = firstStartAfter(intervals, added[1]);        // one past last
        int lo = added[0], hi = added[1];
        if (first < past) {
            lo = Math.min(lo, intervals[first][0]);
            hi = Math.max(hi, intervals[past - 1][1]);
        }
        int[][] out = new int[n - (past - first) + 1][];

Java 17+

        System.arraycopy(intervals, 0, out, 0, first);
        out[first] = new int[]{lo, hi};
        System.arraycopy(intervals, past, out, first + 1, n - past);
        return out;
    }

    private static int firstEndAtLeast(int[][] iv, int x) {
        int lo = 0, hi = iv.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (iv[mid][1] >= x) hi = mid; else lo = mid + 1;
        }
        return lo;
    }

    private static int firstStartAfter(int[][] iv, int x) {
        int lo = 0, hi = iv.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (iv[mid][0] > x) hi = mid; else lo = mid + 1;
        }
        return lo;
    }

    /**
     * LeetCode 715: a set of half-open ranges [l, r) with add, query and
     * remove. Invariant: stored ranges are disjoint and never touch.
     */
    public static class RangeModule {
        private final TreeMap<Integer, Integer> map = new TreeMap<>();

        public void addRange(int l, int r) {
            Map.Entry<Integer, Integer> f = map.floorEntry(l);
            if (f != null && f.getValue() >= l) {
                l = f.getKey();
                r = Math.max(r, f.getValue());
            }
            Map<Integer, Integer> inside = map.subMap(l, true, r, true);
            for (int end : inside.values()) r = Math.max(r, end);
            inside.clear();
            map.put(l, r);
        }

        public boolean queryRange(int l, int r) {
            Map.Entry<Integer, Integer> f = map.floorEntry(l);
            return f != null && f.getValue() >= r;
        }

        public void removeRange(int l, int r) {
            Integer from = map.floorKey(l);
            if (from == null) from = l;
            List<int[]> hit = new ArrayList<>();
            for (Map.Entry<Integer, Integer> e
                    : map.subMap(from, true, r, false).entrySet())
                if (e.getValue() > l) hit.add(new int[]{e.getKey(), e.getValue()});
            for (int[] h : hit) {
                map.remove(h[0]);
                if (h[0] < l) map.put(h[0], l);          // left remainder
                if (h[1] > r) map.put(r, h[1]);          // right remainder
            }
        }
    }
}

TIME O(n)

SPACE O(n)

insert is a single pass. insertBinarySearch finds the block in O(log n) and copies with System.arraycopy. RangeModule

operations are O(log n) amortised: every range is absorbed at most once per range created.

G. Variations of the Pattern

Remove Interval (1272)

Each interval keeps its left remainder [a, x) if a < x and its right remainder [y, b) if b > y; intervals disjoint from [x, y) pass through. Linear, shown in Chapter 73.

Count Integers in Intervals (2276)

Same absorbing map for closed integer intervals; keep a running total. When an add absorbs entries, subtract their lengths, then add the length of the merged interval.

My Calendar I (729)

Insert-if-no-overlap: lowerEntry(start).end > start or ceilingKey(start) < end rejects the booking. Chapter 77 builds on this.

Merge two sorted interval lists

Merge by start with two pointers and fold overlaps (IntervalLists.intervalUnion): O(m + n), no sort needed.

Insert with weights or labels

The three-block structure survives; the absorbed block's weights are combined (summed, unioned) while building [lo, hi].

J. Interview Tips

INTERVIEW

Do not sort. Say why: the list is sorted and disjoint, so the overlapping block is contiguous.

Write the two conditions out loud: end < lo means before; start <= hi means overlap.

For Range Module, state the invariant (disjoint, non-touching) and why it makes queryRange a single lookup.

Follow-ups: binary-search the block; insert many intervals at once (merge instead); thread-safe range sets; return the number of merged intervals.
Edge cases: empty list, new interval before all, after all, covering all, touching on one

side, identical to an existing interval.

CHAPTER SUMMARY

Absorb the overlapping block by widening lo and hi; emit the merged interval between the two copies.
