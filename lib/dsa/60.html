Cycle Detection

Undirected: a seen vertex that is not the arrival edge. Directed: a gray vertex.

A. Pattern Overview

A cycle is a path that returns to its start. Detecting one is the gateway to "is the dependency list valid?", "is this graph a tree?" and "which nodes are safe?". The rule depends on direction:

GraphCycle testWhy
UndirectedDFS / BFS meets a visited vertex through an edge other than the one it arrived by; or m > n − c; or Union-Find sees both ends already connectedAny second route to a visited vertex closes a loop
DirectedDFS meets a vertex that is still on the recursion stack (gray): a back edge; or Kahn's algorithm cannot remove every vertexA visited vertex that has finished only gives a forward or cross edge

KEY IDEA

Undirected and directed are not the same problem. In an undirected graph the edge u – v makes v see u again immediately, so you must ignore the arrival edge. In a directed graph a visited vertex is only a problem if it is on the current path: visited-and-finished vertices are harmless.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Can all courses be finished", "valid build order", "deadlock": directed cycle detection.
"Is this graph a tree": connected, n − 1 edges, no cycle.
"Find the redundant edge": first edge that closes a cycle (Union-Find, Chapter 52).
"Safe states", "nodes that never enter a cycle": three-colour DFS or reversed Kahn.
"Detect a loop in a 2D grid": undirected cycle on an implicit graph; ignore the cell you came from.
ONE-LINE TEST

Ask: directed or undirected? Undirected: remember the parent edge. Directed: three states (unvisited, in progress, done).

C. Core Intuition with Illustrations

Undirected: skip only the arrival edge

Store each stack entry as (vertex, edge id used to arrive). When scanning u's neighbours, skip the edge with that id, and nothing else. If you skipped every edge back to the parent vertex instead, two parallel edges u = v would be missed.

Directed: three colours

White = unvisited, gray = on the current recursion path, black = finished. An edge into a gray vertex is a back edge, so there is a cycle. An edge into a black vertex is harmless.

Safe nodes

A node is eventually safe if every path from it ends in a terminal node (no outgoing edges). Three-colour DFS: a node is safe iff, after exploring all its neighbours without meeting a gray one, it can be coloured black. Cache the answer so each vertex is processed once: O(n + m).

A tree is a graph with three facts

validTree(n, edges): edges.length == n − 1, no cycle, one component. Any two of the three imply the third, so checking m == n − 1 plus either acyclic or connected is enough.

import java.util.*;

/** Ch 49: cycles in undirected and directed graphs; LeetCode 207, 261, 802. */
public class CycleDetection {

    /**
     * Undirected cycle (parallel edges count). The DFS skips only the ONE edge it
     * arrived by (tracked by edge index), not every edge back to the parent.
     */
    public static boolean hasUndirectedCycle(int n, int[][] edges) {
        List<List<int[]>> g = new ArrayList<>();       // {neighbour, edgeId}
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int i = 0; i < edges.length; i++) {
            g.get(edges[i][0]).add(new int[] {edges[i][1], i});
            g.get(edges[i][1]).add(new int[] {edges[i][0], i});
        }
        boolean[] seen = new boolean[n];
        for (int s = 0; s < n; s++) {
            if (seen[s]) continue;
            // {node, edge used to arrive}
            Deque<int[]> stack = new ArrayDeque<>();
            stack.push(new int[] {s, -1});
            seen[s] = true;
            while (!stack.isEmpty()) {
                int[] cur = stack.pop();
                for (int[] nb : g.get(cur[0])) {
                    if (nb[1] == cur[1]) continue;     // the edge we came through
                    if (seen[nb[0]]) return true;
                    seen[nb[0]] = true;
                    stack.push(new int[] {nb[0], nb[1]});
                }
            }
        }
        return false;
    }

    /** LeetCode 261: a tree is connected and has exactly n - 1 edges. */
    public static boolean validTree(int n, int[][] edges) {
        return edges.length == n - 1 && !hasUndirectedCycle(n, edges)

Java 17+

                && ConnectedComponents.countComponents(n, edges) == 1;
    }

    private static final int WHITE = 0, GRAY = 1, BLACK = 2;

    /** Directed cycle by three-colour DFS: a GRAY neighbour is a back edge. */
    public static boolean hasDirectedCycle(List<List<Integer>> g) {
        int n = g.size();
        int[] color = new int[n];
        for (int s = 0; s < n; s++)
            if (color[s] == WHITE && cycleFrom(g, s, color)) return true;
        return false;
    }

    private static boolean cycleFrom(List<List<Integer>> g, int u, int[] color) {
        color[u] = GRAY;
        for (int v : g.get(u)) {
            if (color[v] == GRAY) return true;
            if (color[v] == WHITE && cycleFrom(g, v, color)) return true;
        }
        color[u] = BLACK;
        return false;
    }

    /** LeetCode 207 (edge {a, b} means b -> a): can all courses be finished? */
    public static boolean canFinish(int numCourses, int[][] prerequisites) {
        int[][] e = new int[prerequisites.length][];
        for (int i = 0; i < e.length; i++)
            e[i] = new int[] {prerequisites[i][1], prerequisites[i][0]};
        return !hasDirectedCycle(GraphRepresentation.adjList(numCourses, e, true));
    }

    /** LeetCode 802: safe nodes are those that cannot reach a cycle. */
    public static List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;
        int[] color = new int[n];
        List<Integer> safe = new ArrayList<>();
        for (int s = 0; s < n; s++) if (isSafe(graph, s, color)) safe.add(s);
        return safe;
    }

    private static boolean isSafe(int[][] g, int u, int[] color) {
        if (color[u] != WHITE) return color[u] == BLACK;
        color[u] = GRAY;
        for (int v : g[u]) if (!isSafe(g, v, color)) return false;
        color[u] = BLACK;                              // all paths end in terminals
        return true;
    }
}

G. Variations of the Pattern

Cycle length and the cycle itself

Store parent[] (undirected) or the recursion stack (directed). On detection, walk back from u to v to print the cycle. Longest Cycle in a Graph (2360) stamps each vertex with the step of its walk: cycle length = step[u] − step[v] + 1.

Cycles in grids

Detect Cycles in 2D Grid (1559): vertices are cells with equal letters; it is an undirected graph, so skip the cell you came from. A 2×2 block of equal letters is already a cycle of length 4.

Union-Find cycle detection

Edge (u, v) closes a cycle iff find(u) == find(v) (undirected only). Redundant Connection (684) returns the last such edge.

Redundant edge in a directed graph

Redundant Connection II (685): the extra edge either gives some node two parents, or closes a cycle, or both; check candidates by Union-Find while skipping one of the two parent edges.

Functional graphs

Find the Duplicate Number (287) and Circular Array Loop (457): every node has exactly one successor, so Floyd's tortoise and hare (Chapter 21) detects the loop in O(1) memory.

J. Interview Tips

INTERVIEW

Open with the directed / undirected split and the one-line rule for each; it signals you know the classic pitfall.

Justify three colours: "visited" alone cannot tell a back edge from a cross edge in a directed graph.

Offer Kahn's algorithm as the iterative alternative: if fewer than n vertices are removed, there is a cycle.

Follow-ups: print the cycle; shortest cycle (BFS from every vertex, O(n (n + m)), the

girth); detect negative cycles (Bellman-Ford, Chapter 53); maximum cycle in a functional graph.

Edge cases: self-loop (u → u), parallel edges, empty graph, several components, a cycle unreachable from vertex 0.

CHAPTER SUMMARY

Undirected: a visited vertex reached by an edge other than the arrival edge, or m > n − c, or Union-Find on the endpoints.

Directed: an edge into a gray (on-stack) vertex is a back edge. Three colours, O(n + m); or Kahn's algorithm.

A tree = connected + n − 1 edges + acyclic; any two imply the third.

Safe nodes are the vertices that cannot reach a cycle: memoised three-colour DFS.

Loop over all start vertices; use an explicit stack or Kahn for very deep graphs.
