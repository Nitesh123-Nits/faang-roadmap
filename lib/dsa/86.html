Interval List Operations

Intersect, subtract and search sorted interval lists with two pointers.

A. Pattern Overview

Once intervals are sorted and disjoint, whole-list operations run in linear time with two pointers: intersect two lists, subtract an interval from a list, or union two lists. Each step compares the current interval of each list, produces at most one output piece, and advances the pointer whose interval ends first, because that interval cannot overlap anything later in the other list. A related trick answers "which interval starts next after this one ends?" with a sort and a binary search.

Intersection of two sorted interval lists
int i = 0, j = 0;
while (i < a.length && j < b.length) {
    int lo = Math.max(a[i][0], b[j][0]);
    int hi = Math.min(a[i][1], b[j][1]);
    if (lo <= hi) out.add(new int[]{lo, hi});         // overlap = [max start, min end]
    if (a[i][1] < b[j][1]) i++; else j++;             // drop the one that ends first
}

C. Core Intuition with Illustrations

Overlap of two intervals

Intervals [a1, a2] and [b1, b2] overlap iff max(a1, b1) <= min(a2, b2), and the overlap is exactly that range. A zero-length result [5,5] is legitimate for closed intervals: they share one point.

Two-pointer intersection

A = [0,2] [5,10] [13,23] [24,25] and B = [1,5] [8,12] [15,24] [25,26].

Why advancing the earlier end is safe

If a[i] ends before b[j], any later b[j+1] starts after b[j] ends, hence after a[i] ends; so a[i] cannot meet b[j+1]. Advancing i loses nothing. If the ends are equal, either pointer may advance: the other interval will simply produce an empty overlap next.

Removing an interval

With half-open intervals and [x, y) to remove: an interval entirely left (end <= x) or right (start >= y) of it passes through. Otherwise keep the left remainder [start, x) if start < x and the right remainder [y, end) if end > y. One interval can yield both remainders (a split) or neither (fully removed).

Find Right Interval (436)

For each interval you want the smallest start that is >= its end. Sort the indices by start and binary-search end. With [[3,4],[2,3],[1,2]] the sorted starts are [1,2,3].

E. Java Implementation

Intersection, remove interval, find right interval, union

IntervalLists.java: LeetCode 986, 1272, 436
import java.util.*;

/** Ch 73: operations on sorted interval lists; LeetCode 986, 1272, 436. */
public class IntervalLists {

    /**
     * LeetCode 986: intersection of two lists of disjoint, sorted closed
     * intervals. Two pointers; advance the one that ends first. O(m + n).
     */
    public static int[][] intervalIntersection(int[][] a, int[][] b) {
        List<int[]> out = new ArrayList<>();
        int i = 0, j = 0;
        while (i < a.length && j < b.length) {
            int lo = Math.max(a[i][0], b[j][0]);
            int hi = Math.min(a[i][1], b[j][1]);
            if (lo <= hi) out.add(new int[]{lo, hi});
            if (a[i][1] < b[j][1]) i++; else j++;
        }
        return out.toArray(new int[0][]);
    }

    /**
     * LeetCode 1272: remove [x, y) from a sorted list of disjoint half-open
     * intervals. Each interval keeps its left and/or right remainder.
     */
    public static List<int[]> removeInterval(int[][] intervals, int[] removed) {
        int x = removed[0], y = removed[1];
        List<int[]> out = new ArrayList<>();
        for (int[] iv : intervals) {
            if (iv[1] <= x || iv[0] >= y) { out.add(iv); continue; }
            if (iv[0] < x) out.add(new int[]{iv[0], x});
            if (iv[1] > y) out.add(new int[]{y, iv[1]});
        }
        return out;
    }

    /**
     * LeetCode 436: for each interval, the index of the interval with the
     * smallest start that is >= its end, or -1. Starts are distinct.
     */
    public static int[] findRightInterval(int[][] intervals) {
        int n = intervals.length;
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, Comparator.comparingInt(i -> intervals[i][0]));
        int[] res = new int[n];
        for (int i = 0; i < n; i++) {
            int end = intervals[i][1];

Java 17+

            int lo = 0, hi = n;                       // first start >= end
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (intervals[order[mid]][0] >= end) hi = mid; else lo = mid + 1;
            }
            res[i] = lo == n ? -1 : order[lo];
        }
        return res;
    }

    /**
     * Union of two sorted disjoint lists in O(m + n): merge by start, then
     * fold overlapping neighbours (closed intervals).
     */
    public static int[][] intervalUnion(int[][] a, int[][] b) {
        List<int[]> out = new ArrayList<>();
        int i = 0, j = 0;
        while (i < a.length || j < b.length) {
            int[] next = (j == b.length || (i < a.length && a[i][0] <= b[j][0]))
                    ? a[i++] : b[j++];
            if (!out.isEmpty() && next[0] <= out.get(out.size() - 1)[1]) {
                int[] last = out.get(out.size() - 1);
                last[1] = Math.max(last[1], next[1]);
            } else {
                out.add(next.clone());
            }
        }
        return out.toArray(new int[0][]);
    }
}

SPACE O(1)

Intersection and union are linear in the two list lengths (output excluded). removeInterval is O(n). findRightInterval is O(n log n) because of the sort of indices.

G. Variations of the Pattern

Interval List Intersections (986)

Exactly the two-pointer loop. For k lists, fold pairwise (each fold output is again sorted and disjoint).

Union of two lists

Merge by start with two pointers, folding into the last output interval whenever the next start is <= its end (intervalUnion).

Remove Interval (1272)

One pass; each interval contributes up to two remainders. Use half-open intervals to avoid off-by-one decisions.

Find Right Interval (436)

Sorted starts plus lowerBound, or a TreeMap<start, index> with ceilingEntry(end). Starts are distinct in the problem; with duplicates you must decide which index to return.

Minimum Interval to Include Each Query (1851)

Not two pointers but the offline cousin: sort queries and sweep with a heap (Chapter 76).

J. Interview Tips

INTERVIEW

Give the overlap formula first: [max(a1, b1), min(a2, b2)] if valid. The rest is bookkeeping.

Explain why you advance the earlier end, in one sentence: nothing later in the other list can touch it.

Mention the zero-length intersection for closed intervals: it shows you thought about boundaries.

Follow-ups: intersect k lists (fold or sweep); return only the total overlap length;

difference of two lists (A minus B); streaming lists.

Edge cases: one list empty, identical lists, intervals that touch at a single point, one huge interval overlapping many small ones.

CHAPTER SUMMARY

Two sorted, disjoint lists: the overlap is [max(start), min(end)] when lo <= hi; advance the pointer whose interval ends first.

Closed intervals can intersect in a single point, so lo <= hi keeps zero-length pieces.

Remove Interval: each interval keeps a left remainder and/or a right remainder; fully covered ones vanish.

Find Right Interval: sort indices by start and binary-search each end; keep the original indices.

Everything here is O(m + n) (or O(n log n) with a sort) and builds on the invariants from Chapters 71 and 72.
