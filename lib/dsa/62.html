Kahn's Algorithm

Peel off vertices with no prerequisites, level by level, using a queue.

A. Pattern Overview

Kahn's algorithm is the BFS version of topological sorting. Count each vertex's in-degree (unmet prerequisites). Put every vertex with in-degree 0 in a queue. Repeatedly remove one, append it to the answer, and decrement its out-neighbours' in-degrees, enqueueing any that reach 0. If the answer ends with fewer than n vertices, the leftover vertices lie on or behind a cycle.

Kahn's algorithm: the whole template
int[] indeg = new int[n];

for (int v = 0; v < n; v++) if (indeg[v] == 0) queue.add(v);
List<Integer> order = new ArrayList<>();
while (!queue.isEmpty()) {
    int u = queue.poll();
    order.add(u);
    for (int v : g.get(u)) if (--indeg[v] == 0) queue.add(v);
}
return order.size() == n ? order : List.of();   // else: a cycle

KEY IDEA

Kahn needs no recursion and detects cycles for free. It is the production-safe topological sort: no StackOverflowError on a 10⁵-vertex chain, and its level structure answers "how many rounds" directly.

B. When to Recognize This Pattern

Pattern Recognition Signals

A topological-sort problem that also asks "minimum number of semesters / rounds / steps" (levels of the DAG).
"Earliest completion time" with dependencies and durations (critical path).
"Is the order unique" or "smallest lexicographic order".
Very deep dependency chains, where recursion is risky.
"Find the roots of minimum height trees": peel leaves inward, a topological sort of an undirected tree.
ONE-LINE TEST

Dependencies and a count of rounds, times or uniqueness: use Kahn. Only a valid order, and the graph is small: DFS postorder is also fine.

C. Core Intuition with Illustrations

Remove sources until nothing is left

A vertex with in-degree 0 has no unmet prerequisite, so it may go next. Removing it lowers the in-degree of its successors; any that hit 0 become available.

Order: [4, 5, 2, 0, 3, 1]. By rounds: [4, 5] | [0, 2] | [3] | [1] (so the minimum number of semesters is 4).

Rounds = longest chain

The number of rounds equals the number of vertices on the longest path in the DAG, since a vertex cannot be taken before its deepest prerequisite chain. Parallel Courses (1136) is this number, or −1 if a cycle blocks some vertices.

Critical path with durations

Parallel Courses III (2050): each course has a duration; finish[v] = time[v] + max(finish[u] for each prerequisite u). Process in Kahn order: when u is removed, relax its successors. The answer is max(finish).

Uniqueness

A topological order is unique iff at every step exactly one vertex is available, which is iff consecutive vertices are joined by edges. Sequence Reconstruction (444) builds the graph from the given sequences and checks that the queue never holds two vertices and that the order equals nums.

Peeling leaves: Minimum Height Trees

In an undirected tree, repeatedly delete all leaves (degree 1). The last one or two vertices left are the centres, the roots with the smallest height (310). This is Kahn's algorithm on degrees, and the rounds are the layers of an onion.

Kahn order, semesters, sequence reconstruction, critical path

KahnAlgorithm.java: LeetCode 1136, 444, 2050
import java.util.*;

/** Ch 51: Kahn's algorithm (BFS topological sort); LeetCode 1136, 444, 2050. */
public class KahnAlgorithm {

    /**
     * Topological order by repeatedly removing in-degree-0 nodes; [] on a cycle.
     */
    public static List<Integer> order(List<List<Integer>> g) {
        int n = g.size();
        int[] indeg = new int[n];
        for (List<Integer> out : g) for (int v : out) indeg[v]++;
        Deque<Integer> queue = new ArrayDeque<>();
        for (int v = 0; v < n; v++) if (indeg[v] == 0) queue.add(v);
        List<Integer> order = new ArrayList<>();
        while (!queue.isEmpty()) {
            int u = queue.poll();
            order.add(u);
            for (int v : g.get(u)) if (--indeg[v] == 0) queue.add(v);
        }
        return order.size() == n ? order : new ArrayList<>();
    }

    /** LeetCode 1136 (nodes 1..n, {a, b} = a before b): number of semesters. */
    public static int minimumSemesters(int n, int[][] relations) {
        int[][] e = new int[relations.length][];
        for (int i = 0; i < e.length; i++)
            e[i] = new int[] {relations[i][0] - 1, relations[i][1] - 1};
        List<List<Integer>> g = GraphRepresentation.adjList(n, e, true);
        int[] indeg = new int[n];
        for (List<Integer> out : g) for (int v : out) indeg[v]++;
        Deque<Integer> level = new ArrayDeque<>();
        for (int v = 0; v < n; v++) if (indeg[v] == 0) level.add(v);
        int semesters = 0, taken = 0;
        // one BFS level = one semester
        while (!level.isEmpty()) {
            semesters++;
            for (int i = level.size(); i > 0; i--) {
                int u = level.poll();
                taken++;
                for (int v : g.get(u)) if (--indeg[v] == 0) level.add(v);
            }
        }
        return taken == n ? semesters : -1;
    }

    /**

    public static boolean sequenceReconstruction(int[] nums, int[][] seqs) {
        int n = nums.length;
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i <= n; i++) g.add(new ArrayList<>());
        int[] indeg = new int[n + 1];
        for (int[] s : seqs) {
            for (int x : s) if (x < 1 || x > n) return false;
            for (int i = 0; i + 1 < s.length; i++) {
                g.get(s[i]).add(s[i + 1]);
                indeg[s[i + 1]]++;
            }
        }
        Deque<Integer> queue = new ArrayDeque<>();
        for (int v = 1; v <= n; v++) if (indeg[v] == 0) queue.add(v);
        int idx = 0;
        while (!queue.isEmpty()) {
            if (queue.size() > 1) return false;        // two choices: not unique
            int u = queue.poll();
            if (idx == n || nums[idx++] != u) return false;
            for (int v : g.get(u)) if (--indeg[v] == 0) queue.add(v);
        }
        return idx == n;
    }

    /**
     * LeetCode 2050 style: finish[v] = time[v] + max finish of prerequisites.
     * Longest path in a DAG, computed in topological order. Edge {a, b}: a -> b.
     */
    public static int minimumTime(int n, int[][] relations, int[] time) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        int[] indeg = new int[n];
        for (int[] r : relations) {
            g.get(r[0]).add(r[1]);
            indeg[r[1]]++;
        }
        int[] finish = new int[n];
        Deque<Integer> queue = new ArrayDeque<>();
        for (int v = 0; v < n; v++)
            if (indeg[v] == 0) {
                queue.add(v);
                finish[v] = time[v];
            }
        int best = 0;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            best = Math.max(best, finish[u]);
            for (int v : g.get(u)) {
                finish[v] = Math.max(finish[v], finish[u] + time[v]);
                if (--indeg[v] == 0) queue.add(v);
            }
        }
        return best;
    }
}

Kahn table for the sample DAG: initial in-degrees [2, 2, 1, 1, 0, 0] (vertices 0 and 1 each have two prerequisites); the sources 4 and 5 start in the queue. Pop 4: vertices 0 and 1 drop to 1 each, no new source. Pop 5: 2 drops to 0 (enqueued) and 0 drops to 0 (enqueued). Pop 2: 3 drops to 0. Pop 0: nothing. Pop 3: 1 drops to 0. Pop 1. All six vertices are out, so the graph is acyclic. The rounds are [4, 5], [0, 2], [3], [1]: four semesters.

G. Variations of the Pattern

Course scheduling family

Course Schedule I / II (feasibility / order), Parallel Courses I, II, III (rounds, bounded parallelism, durations). Part II adds a limit of k courses per semester and becomes bitmask DP (1494).

Constraint ordering

Find All Possible Recipes (2115): ingredients unlock recipes; supplies are the initial sources.

Safe states via reverse Kahn

Reverse every edge; vertices with out-degree 0 (terminal nodes) become sources; every vertex that eventually gets removed is safe (802).

Tree centres

Leaf peeling for Minimum Height Trees (310) and for finding the diameter's centre.

Online dependencies

When edges are added over time, maintain in-degrees and a ready queue incrementally (build systems, schedulers).

J. Interview Tips

INTERVIEW

Lead with the template (in-degree array, queue of sources, decrement) and the size == n cycle test.

Say why Kahn beats DFS in production: no recursion depth issue and rounds come for free.

For uniqueness or smallest order, change only the container: a size check, or a PriorityQueue.

Follow-ups: limit k tasks per round (NP-hard in general; bitmask DP for small n); detect which vertices are on the cycle (run Kahn, then the remaining subgraph); maintain under edge insertions.(never reaches in-degree 0), n = 1.
Edge cases: isolated vertices (in-degree 0, they go first), parallel prerequisites, a self-loop

CHAPTER SUMMARY

Kahn = queue of in-degree-0 vertices, decrement successors. Output shorter than n means a cycle.

Rounds (queue levels) = longest chain: minimum semesters. Add durations and it becomes a critical-path DP.

Swap the container for variations: PriorityQueue (smallest order), size check (unique order).

Run it on a reversed graph for safe states, or on degrees to peel leaves for tree centres.

No recursion, no stack overflow: the safest topological sort for large inputs.
