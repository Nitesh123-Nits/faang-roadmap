Monotonic Stack

Keep a stack in sorted order so each element is pushed once and popped once.

A. Pattern Overview

A monotonic stack is a stack whose elements are kept in strictly increasing or decreasing order. Before pushing a new element you pop everything that violates the order. The pop is the interesting event: the new element is the answer for every element it pops. Because each element is pushed once and popped once, a whole scan costs O(n) even though a single step may pop many items.

KEY IDEA

Each element asks one question: "who is the first element to my right (or left) that beats me?" The monotonic stack answers it for all elements in one pass, because elements still on the stack are exactly the ones whose answer is still unknown.

Versus a normal stack: a normal stack stores pending items (brackets, calls) and pops on a match. A monotonic stack pops on a comparison and exists to find nearest greater/smaller neighbours, or to find the span in which an element is the maximum or minimum.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Next greater / next smaller / previous greater element", or how many days until a warmer temperature.
The problem asks for the largest rectangle, area, or span where one element is the

limiting height.

"Sum of subarray minimums / maximums": count the subarrays in which each element is the minimum.
Greedy digit / letter removal to obtain the smallest or largest result (Remove K Digits,

Remove Duplicate Letters).

Online queries such as stock span: each new element needs the distance to the previous larger one.
A brute force that scans left or right from every index until it finds something larger or

smaller: O(n²) hiding a linear algorithm.

ONE-LINE TEST

If the brute force is "for each i, scan right until arr[j] > arr[i]", it is a monotonic stack. If it is "for each window of size k find the max", it is a monotonic deque (Chapter 8).

INTUITION

Amortised O(n). Each index is pushed exactly once and popped at most once, so the total number of pops ≤ n. The while inside the for does not make it quadratic.

Largest Rectangle in Histogram. For bar h, the widest rectangle of height h extends left and right until it meets a strictly shorter bar. A stack of increasing heights finds both borders when a bar is popped: the right border is the bar that caused the pop; the left border is the new stack top.

Figure 18. The dashed rectangle is the maximum (area 10). Bar 1 (height 1) on the left and bar 4 (height 2) on the right are the strictly shorter borders.

D. Brute Force to Optimal Solution

Example: Largest Rectangle in Histogram (LeetCode 84)

Brute force 1: every pair (i, j), track the minimum height in between: O(n²).
Brute force 2: for each bar, expand left and right while neighbours are ≥ it: O(n²) worst case (sorted input).
Bottleneck: the expansion repeats work that neighbouring bars have already done.
Insight: the left border of bar i is the previous smaller bar and the right border is the next smaller bar. Both come from a monotonic stack.
Optimal: one pass, a sentinel 0 at the end flushes the stack. O(n) time, O(n) space.

E. Java Implementation

Next greater / smaller (linear and circular)

NextGreaterElements.java — LeetCode 503 and the basic forms

Java 17+

import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

/** Monotonic-stack toolkit: next greater / next smaller (linear and circular). */
public class NextGreaterElements {

    /** result[i] = next strictly greater VALUE to the right of i, or -1. */
    public static int[] nextGreater(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        Arrays.fill(result, -1);
        Deque<Integer> stack = new ArrayDeque<>();      // indices, values strictly decreasing
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
                // nums[i] is the answer for everything popped
                result[stack.pop()] = nums[i];
            }
            stack.push(i);
        }
        return result;
    }

    /** result[i] = next strictly smaller VALUE to the right of i, or -1. */
    public static int[] nextSmaller(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        Arrays.fill(result, -1);
        Deque<Integer> stack = new ArrayDeque<>();      // values strictly increasing
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && nums[stack.peek()] > nums[i]) {
                result[stack.pop()] = nums[i];
            }
            stack.push(i);
        }
        return result;
    }

    /** LeetCode 503 - Next Greater Element II: the array is circular. */
    public static int[] nextGreaterCircular(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        Arrays.fill(result, -1);
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < 2 * n; i++) {               // visit every element twice
            int value = nums[i % n];
            while (!stack.isEmpty() && nums[stack.peek()] < value) {
                result[stack.pop()] = value;
            }
            if (i < n) stack.push(i);                   // only first lap pushes indices
        }
        return result;
    }
}

TIME O(n)

SPACE O(n)

Store indices on the stack so you can compute distances; compare through nums[stack.peek()]. Circular: iterate 2n times, push only in the first lap.

Daily Temperatures

DailyTemperatures.java — LeetCode 739

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;

/** LeetCode 739 - Daily Temperatures. Stack of indices still waiting for a warmer day. */
public class DailyTemperatures {

    public static int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] wait = new int[n];                        // default 0 = never gets warmer
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && temperatures[stack.peek()] < temperatures[i]) {
                int colderDay = stack.pop();
                wait[colderDay] = i - colderDay;
            }
            stack.push(i);
        }
        return wait;
    }
}

TIME O(n)

SPACE O(n)

Largest Rectangle in Histogram

LargestRectangleHistogram.java — LeetCode 84

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;

/** LeetCode 84 - Largest Rectangle in Histogram. One pass with an increasing stack. */
public class LargestRectangleHistogram {

    public static int largestRectangleArea(int[] heights) {
        int n = heights.length;
        // indices of bars with increasing heights
        Deque<Integer> stack = new ArrayDeque<>();
        int best = 0;
        for (int i = 0; i <= n; i++) {
            int current = (i == n) ? 0 : heights[i];    // sentinel height 0 flushes the stack
            while (!stack.isEmpty() && heights[stack.peek()] >= current) {
                int height = heights[stack.pop()];
                // first shorter bar on the left
                int leftBoundary = stack.isEmpty() ? -1 : stack.peek();
                // i is the first shorter-or-equal bar on the right
                int width = i - leftBoundary - 1;
                best = Math.max(best, height * width);
            }
            stack.push(i);
        }
        return best;
    }
}

TIME O(n)

SPACE O(n)

Pop with >= so equal heights merge; width = i - leftBoundary - 1, where leftBoundary is the new stack top or -1.

G. Variations of the Pattern

Next Greater Element I: stack + HashMap
NextGreaterElementI.java — LeetCode 496

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;

/** LeetCode 496 - Next Greater Element I. nums1 is a subset of nums2 (distinct values). */
public class NextGreaterElementI {

    public static int[] nextGreaterElement(int[] nums1, int[] nums2) {
        Map<Integer, Integer> nextOf = new HashMap<>();
        Deque<Integer> stack = new ArrayDeque<>();         // values, strictly decreasing
        for (int value : nums2) {
            while (!stack.isEmpty() && stack.peek() < value) {
                nextOf.put(stack.pop(), value);
            }
            stack.push(value);
        }
        int[] answer = new int[nums1.length];
        for (int i = 0; i < nums1.length; i++) {
            answer[i] = nextOf.getOrDefault(nums1[i], -1);
        }
        return answer;
    }
}

TIME O(n + m)

SPACE O(m)

Maximal Rectangle: histogram per row

Turn each row of the binary matrix into a histogram of consecutive 1s ending at that row, then reuse the histogram routine. O(rows · cols).

MaximalRectangle.java — LeetCode 85

Java 17+

/** LeetCode 85 - Maximal Rectangle. Row-by-row histogram + largest rectangle in histogram. */
public class MaximalRectangle {

    public static int maximalRectangle(char[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return 0;
        int cols = matrix[0].length;
        // consecutive '1's ending at current row
        int[] heights = new int[cols];
        int best = 0;
        for (char[] row : matrix) {
            for (int c = 0; c < cols; c++) {
                heights[c] = row[c] == '1' ? heights[c] + 1 : 0;
            }
            best = Math.max(best, LargestRectangleHistogram.largestRectangleArea(heights));
        }
        return best;
    }
}
TIME O(R · C)
SPACE O(C)
Online Stock Span: stack of (price, span)
StockSpanner.java — LeetCode 901

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;

/** LeetCode 901 - Online Stock Span. Stack stores {price, span}; amortised O(1) per call. */
public class StockSpanner {
    private final Deque<int[]> stack = new ArrayDeque<>();

    public int next(int price) {
        int span = 1;                                   // today counts itself
        while (!stack.isEmpty() && stack.peek()[0] <= price) {
            // absorb the whole span of a smaller price
            span += stack.pop()[1];
        }
        stack.push(new int[]{price, span});
        return span;
    }
}

TIME O(1) amortised per call

SPACE O(n)

Contribution technique: Sum of Subarray Minimums

Instead of enumerating subarrays, ask "in how many subarrays is arr[i] the minimum?". That equals leftChoices × rightChoices where the left span ends at the previous strictly smaller element and the right span ends at the next smaller-or-equal element (asymmetric tie-breaking counts each subarray exactly once).

SumSubarrayMins.java — LeetCode 907

Java 17+

import java.util.ArrayDeque;
import java.util.Deque;

/**
 * LeetCode 907 - Sum of Subarray Minimums. Count the subarrays where each element is the
 * minimum.
 */
public class SumSubarrayMins {
    private static final long MOD = 1_000_000_007L;

    public static int sumSubarrayMins(int[] arr) {
        int n = arr.length;
        Deque<Integer> stack = new ArrayDeque<>();      // indices, values strictly increasing
        long total = 0;
        for (int i = 0; i <= n; i++) {
            int current = (i == n) ? Integer.MIN_VALUE : arr[i];
            while (!stack.isEmpty() && arr[stack.peek()] >= current) {
                // arr[mid] is the minimum of its subarrays
                int mid = stack.pop();
                // strictly smaller on the left
                int prevLess = stack.isEmpty() ? -1 : stack.peek();
                int leftChoices = mid - prevLess;
                // i = first smaller-or-equal on the right
                int rightChoices = i - mid;
                total = (total + (long) arr[mid] * leftChoices % MOD * rightChoices) % MOD;
            }
            stack.push(i);
        }
        return (int) total;
    }
}

TIME O(n)

SPACE O(n)

Accumulate long and reduce modulo 10⁹ + 7 at each step.

Greedy with a stack: Remove K Digits

To get the smallest number, remove a digit whenever a smaller digit follows it. A stack of non-decreasing digits does this; leftover removals trim from the end; strip leading zeros.

RemoveKDigits.java — LeetCode 402

Java 17+

/** LeetCode 402 - Remove K Digits. Greedy with an increasing stack of digits. */
public class RemoveKDigits {

    public static String removeKdigits(String num, int k) {
        StringBuilder stack = new StringBuilder();      // used as a char stack
        for (char digit : num.toCharArray()) {
            while (k > 0 && stack.length() > 0 && stack.charAt(stack.length() - 1) > digit) {
                // a bigger digit before a smaller one: drop it
                stack.deleteCharAt(stack.length() - 1);
                k--;
            }
            stack.append(digit);
        }
        // digits were non-decreasing: trim the tail
        while (k > 0 && stack.length() > 0) {
            stack.deleteCharAt(stack.length() - 1);
            k--;
        }
        int start = 0;                                  // strip leading zeros
        while (start < stack.length() - 1 && stack.charAt(start) == '0') start++;
        String result = stack.substring(start);
        return result.isEmpty() ? "0" : result;
    }
}

TIME O(n)

SPACE O(n)

CHAPTER SUMMARY

Pop while the top violates the order; the popped items' answer is the current element.

Decreasing stack → next greater; increasing stack → next smaller; the new top after popping is the previous smaller/greater.

Store indices, use a sentinel to flush, break ties asymmetrically, and quote the push-once / pop-once amortisation.

Contribution technique: count the subarrays where each element is the min or max.
