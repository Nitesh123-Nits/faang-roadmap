Subsets

Every element is in or out: 2ⁿ subsets, with or without duplicates.

A. Pattern Overview

KEY IDEA

Order does not matter, so impose one. Always choose indices in increasing order (start parameter): the subset {1, 3} is generated only as 1 then 3, never as 3 then 1. This single rule is what separates subsets and combinations (Chapters 32, 34, 35) from permutations (Chapter 33).

B. When to Recognize This Pattern

Pattern Recognition Signals

"Return all possible subsets" / "power set" / "all subsequences".
Each element is used at most once and order does not matter.
"Return all unique …" with duplicates in the input: sort, then skip repeats at the same depth (Subsets II).
n ≤ 20 and a question about every selection: subset-sum, partition, maximum of a function over subsets: bitmask enumeration.
"Non-decreasing subsequences": subsets with an order constraint and an unsortable

input: dedupe each level with a set (491).

ONE-LINE TEST

If the answer is a set of elements (not an arrangement) and you must list all of them, it is this pattern; the tree has one node per subset when you use pick the next element.

C. Core Intuition with Illustrations

"Every node is an answer"

In pick the next element form, the path from the root to any node is a valid subset, so we record at every node, not only at the leaves. The root is the empty set. For [1, 2, 3] the tree has 2³ = 8 nodes.

Figure 65. The edge label is the element appended; children only use later indices, so no subset appears twice.

Bitmask enumeration

Interpret an integer mask in [0, 2ⁿ) as a subset: bit j set means nums[j] is chosen. Counting

from 0 to 2ⁿ − 1 visits every subset once. Useful identities: mask & (1 << j) tests membership, mask | (1 << j) adds, mask & (mask − 1) removes the lowest bit, Integer.bitCount(mask) is the size.

Duplicates: skip the repeat at the same depth, not the repeat on the same path

For [1, 2, 2], choosing the second 2 right after the first (path [1, 2, 2]) is fine; choosing the second 2 instead of the first at the same position repeats subsets already produced. After sorting, the rule is: if (i > start && a[i] == a[i−1]) continue. The i > start part is crucial; i > 0 would also forbid [2, 2].

E. Java Implementation

Subsets: three formulations

Subsets.java: LeetCode 78

Java 17+

import java.util.ArrayList;
import java.util.List;

/**
 * LeetCode 78 - Subsets. Three equivalent formulations of the 2^n subsets of distinct
 * numbers.
 */
public class Subsets {
    /** 1. Include / exclude: at each index decide whether to take the element. */
    public static List<List<Integer>> includeExclude(int[] nums) {
        List<List<Integer>> out = new ArrayList<>();
        walk(nums, 0, new ArrayList<>(), out);
        return out;
    }

    private static void walk(int[] nums, int i, List<Integer> cur,
            List<List<Integer>> out) {
        if (i == nums.length) { out.add(new ArrayList<>(cur)); return; }
        walk(nums, i + 1, cur, out);               // exclude nums[i]
        cur.add(nums[i]);                          // choose
        walk(nums, i + 1, cur, out);               // include nums[i]
        cur.remove(cur.size() - 1);                // unchoose
    }

    /**
     * 2. "Every node is an answer": the path to each node of the choose-next-element tree is
     * a subset.
     */
    public static List<List<Integer>> pickNext(int[] nums) {
        List<List<Integer>> out = new ArrayList<>();
        extend(nums, 0, new ArrayList<>(), out);
        return out;
    }

    private static void extend(int[] nums, int start, List<Integer> cur,
            List<List<Integer>> out) {
        out.add(new ArrayList<>(cur));
        for (int i = start; i < nums.length; i++) {
            cur.add(nums[i]);
            extend(nums, i + 1, cur, out);
            cur.remove(cur.size() - 1);
        }
    }

    /** 3. Bitmask: bit j of mask says whether nums[j] is in the subset. Requires n <= 30. */
    public static List<List<Integer>> bitmask(int[] nums) {
        int n = nums.length;
        List<List<Integer>> out = new ArrayList<>(1 << n);
        for (int mask = 0; mask < (1 << n); mask++) {
            List<Integer> s = new ArrayList<>();
            for (int j = 0; j < n; j++) if ((mask >> j & 1) == 1) s.add(nums[j]);
            out.add(s);
        }
        return out;
    }
}

TIME O(n · 2ⁿ)

SPACE O(n)

Copy the path (new ArrayList<>(cur)) when recording. includeExclude, pickNext and bitmask return the same set of subsets in different orders.

Subsets II: duplicates in the input

SubsetsII.java: LeetCode 90

Java 17+

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

/** LeetCode 90 - Subsets II. Sort, then skip a value that was already tried at this depth. */
public class SubsetsII {
    public static List<List<Integer>> subsetsWithDup(int[] nums) {
        int[] a = nums.clone();
        Arrays.sort(a);
        List<List<Integer>> out = new ArrayList<>();
        extend(a, 0, new ArrayList<>(), out);
        return out;
    }

    private static void extend(int[] a, int start, List<Integer> cur,
            List<List<Integer>> out) {
        out.add(new ArrayList<>(cur));
        for (int i = start; i < a.length; i++) {
            // same value already tried as this position
            if (i > start && a[i] == a[i - 1]) continue;
            cur.add(a[i]);
            extend(a, i + 1, cur, out);
            cur.remove(cur.size() - 1);
        }
    }
}

TIME O(n · 2ⁿ)

SPACE O(n)

nums.clone() before sorting: do not mutate the caller's array. The skip test i > start is the whole trick.

Non-decreasing subsequences: dedupe with a set

NonDecreasingSubsequences.java: LeetCode 491

Java 17+

import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

/**
 * LeetCode 491 - Non-decreasing Subsequences (length >= 2). Input is not sortable, so dedupe
 * per level with a set.
 */
public class NonDecreasingSubsequences {
    public static List<List<Integer>> findSubsequences(int[] nums) {
        List<List<Integer>> out = new ArrayList<>();
        extend(nums, 0, new ArrayList<>(), out);
        return out;
    }
    private static void extend(int[] nums, int start, List<Integer> cur,
            List<List<Integer>> out) {
        if (cur.size() >= 2) out.add(new ArrayList<>(cur));
        Set<Integer> usedHere = new HashSet<>();
        for (int i = start; i < nums.length; i++) {
            if (!cur.isEmpty() && nums[i] < cur.get(cur.size() - 1)) continue;
            // this value was already tried at this depth
            if (!usedHere.add(nums[i])) continue;
            cur.add(nums[i]);
            extend(nums, i + 1, cur, out);
            cur.remove(cur.size() - 1);
        }
    }
}

TIME O(n · 2ⁿ)

SPACE O(n²)

Sorting is not allowed (order matters for subsequences), so a per-level HashSet records which values were already tried at this position.

G. Variations of the Pattern

Subsets of a given size: Combinations

Stop recording unless cur.size() == k: Combinations (Chapter 34). Prune when too few elements remain.

Subset sum and target

Carry remaining and prune when it goes negative: Combination Sum (Chapter 35), Partition Equal Subset Sum and Target Sum (counting: DP, Part XI).

Subsets with an order constraint

Non-decreasing Subsequences (491) keeps only subsets whose last element is not greater than the next candidate; sorting would destroy the subsequence order, so use the per-level set.

Subset DP over bitmasks

When n ≤ 20, store a value per mask (dp[mask]): Partition to K Equal Sum Subsets, travelling salesman, Shortest Path Visiting All Nodes. The subset is the DP state.

Subsets of a string and power sets of a set

Subsequences of a string, Maximum Length of a Concatenated String with Unique Characters (1239), and Find Unique Binary String (1980) all enumerate selections.

CHAPTER SUMMARY

There are 2ⁿ subsets; order does not matter, so choose indices in increasing order (start, i + 1).

In pick-the-next form every node is a subset: record on entry. In include/exclude form record at the leaves.

Duplicates: sort, then if (i > start && a[i] == a[i−1]) continue: skip a repeat at the same depth, never on the same path.

Bitmask: bit j = element j chosen; use it for n ≤ 20. It is also the state of subset DP.

Copy the path when recording; sort a clone; the empty subset is always an answer.
