Longest Common Subsequence

Two prefixes, one table: match and extend, or drop a character from either side.

A. Pattern Overview

A subsequence keeps order but may skip characters. The Longest Common Subsequence (LCS) of two sequences is the longest sequence that is a subsequence of both. The state dp[i][j] is the LCS length of the prefixes a[0..i) and b[0..j). LCS is the template for a whole family: edit-like distances, shortest common supersequence, minimum deletions to make strings equal, and longest common substring (with a reset).

KEY IDEA

On a mismatch, at least one of the two last characters is not in the LCS, so the answer is the better of dropping a[i-1] or dropping b[j-1]. On a match, taking it is never worse (exchange argument).

C. Core Intuition with Illustrations

Figure 133. LCS table. Bold green cells are matched characters.

Walking back from dp[7][6] = 4: if the characters match, record the character and go diagonally; otherwise move toward the larger neighbour. One answer is BCBA; other subsequences of length 4 (such as BDAB) are equally valid.

Why a match can be taken greedily

If a[i-1] == b[j-1], any LCS can be rearranged to use this pair: if the optimum does not match the last characters, replacing its last matched pair with them leaves the length unchanged. So dp[i][j] = dp[i-1][j-1] + 1, no need to consider the two drops.

Deletion distance and supersequences

Keep the LCS; delete everything else: m + n - 2 LCS. Merge instead: every LCS character is written once, the rest of both strings once each, giving m + n - LCS. For abac and cab the LCS is ab (length 2), so the shortest supersequence has length 4 + 3 - 2 = 5, e.g. "cabac".

Longest common substring: reset on mismatch

Substrings must be contiguous, so dp[i][j] becomes 0 on a mismatch and dp[i-1][j-1] + 1 on a match. The answer is the maximum cell, not the corner.

SUBSEQUENCE vs SUBSTRING

The subsequence and substring versions differ in exactly one line. Read the problem for the word contiguous.

Three strings

Adding a third string adds a dimension: dp[i][j][k], O(l m n) time and space. Rolling over i saves one dimension of space.

import java.util.*;

/** Ch 83: longest common subsequence; LeetCode 1143, 1092, 583, 1035. */
public class LCS {

    /** dp[i][j] = LCS length of a[0..i) and b[0..j). */
    private static int[][] table(String a, String b) {
        int[][] dp = new int[a.length() + 1][b.length() + 1];
        for (int i = 1; i <= a.length(); i++)
            for (int j = 1; j <= b.length(); j++)
                dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                        ? dp[i - 1][j - 1] + 1
                        : Math.max(dp[i - 1][j], dp[i][j - 1]);
        return dp;
    }

    /** LeetCode 1143. */
    public static int lcsLength(String a, String b) {
        return table(a, b)[a.length()][b.length()];
    }

    /** One actual LCS, recovered by walking the table backwards. */
    public static String lcsString(String a, String b) {
        int[][] dp = table(a, b);
        StringBuilder sb = new StringBuilder();
        int i = a.length(), j = b.length();
        while (i > 0 && j > 0) {
            if (a.charAt(i - 1) == b.charAt(j - 1)) {
                sb.append(a.charAt(i - 1));
                i--;
                j--;
            } else if (dp[i - 1][j] >= dp[i][j - 1]) {
                i--;
            } else {
                j--;
            }
        }
        return sb.reverse().toString();
    }

    /** LeetCode 1035 and any integer version: LCS of two int arrays. */
    public static int lcsLength(int[] a, int[] b) {
        int[][] dp = new int[a.length + 1][b.length + 1];
        for (int i = 1; i <= a.length; i++)
            for (int j = 1; j <= b.length; j++)
                dp[i][j] = a[i - 1] == b[j - 1] ? dp[i - 1][j - 1] + 1
                        : Math.max(dp[i - 1][j], dp[i][j - 1]);
        return dp[a.length][b.length];

    /** Longest common SUBSTRING: contiguous, so a mismatch resets to 0. */
    public static int longestCommonSubstring(String a, String b) {
        int best = 0;
        int[] prev = new int[b.length() + 1];
        for (int i = 1; i <= a.length(); i++) {
            int[] cur = new int[b.length() + 1];
            for (int j = 1; j <= b.length(); j++)
                if (a.charAt(i - 1) == b.charAt(j - 1)) {
                    cur[j] = prev[j - 1] + 1;
                    best = Math.max(best, cur[j]);
                }
            prev = cur;
        }
        return best;
    }

    /** LeetCode 583: deletions (from both strings) to make them equal. */
    public static int minDeleteDistance(String a, String b) {
        return a.length() + b.length() - 2 * lcsLength(a, b);
    }

    /** LeetCode 1092: a shortest string having both a and b as subsequences. */
    public static String shortestCommonSupersequence(String a, String b) {
        int[][] dp = table(a, b);
        StringBuilder sb = new StringBuilder();
        int i = a.length(), j = b.length();
        while (i > 0 && j > 0) {
            if (a.charAt(i - 1) == b.charAt(j - 1)) {
                sb.append(a.charAt(i - 1));
                i--;
                j--;
            } else if (dp[i - 1][j] >= dp[i][j - 1]) {
                // keep a's char, skip it in a
                sb.append(a.charAt(i - 1));
                i--;
            } else {
                sb.append(b.charAt(j - 1));
                j--;
            }
        }
        while (i > 0) sb.append(a.charAt(--i));
        while (j > 0) sb.append(b.charAt(--j));
        return sb.reverse().toString();
    }

    /** Three strings: one more dimension, same recurrence. */
    public static int lcsLength3(String a, String b, String c) {
        int[][][] dp = new int[a.length() + 1][b.length() + 1][c.length() + 1];
        for (int i = 1; i <= a.length(); i++)
            for (int j = 1; j <= b.length(); j++)
                for (int k = 1; k <= c.length(); k++)
                    dp[i][j][k] = a.charAt(i - 1) == b.charAt(j - 1)
                            && b.charAt(j - 1) == c.charAt(k - 1)
                            ? dp[i - 1][j - 1][k - 1] + 1
                            : Math.max(dp[i - 1][j][k],
                                Math.max(dp[i][j - 1][k], dp[i][j][k - 1]));
        return dp[a.length()][b.length()][c.length()];
    }
}

F. Detailed Dry Run

lcsLength("abcde", "ace"): row a: [0,1,1,1]. Row b: [0,1,1,1]. Row c: [0,1,2,2]. Row d: [0,1,2,2]. Row e: [0,1,2,3]. The answer is 3 (ace).

Reconstruction on the table above, preferring "up" on ties: (7,6): B vs A mismatch, dp[6][6] = 4 >= dp[7][5] = 4, go up. (6,6): A = A, record A, go diagonal. (5,5): D vs B, mismatch, go up. (4,5): B = B, record B. (3,4): C vs A, mismatch; dp[3][3] = 2 is larger, go left. (3,3): C = C, record C. (2,2): B vs D, go left. (2,1): B = B, record B. Reading the recorded characters backwards gives BCBA.

G. Variations of the Pattern

Minimum ASCII Delete Sum (712)

Weight each deletion by the character's code: same table, minimise the sum instead of maximising the matched length.

Longest Palindromic Subsequence (516)

LCS of s and its reverse. Chapter 85 gives the interval version that avoids the copy.

Shortest Common Supersequence (1092)

Reconstruct by walking the table: a match emits one character, a mismatch emits the character from the side you move away from; leftovers are appended.

Uncrossed Lines (1035) and integer sequences

Lines may not cross, which means the matched pairs keep order in both arrays: exactly LCS on integers.

Number of Matching Subsequences and Distinct Subsequences

Counting variants (115) add instead of maximising; Chapter 85 treats them.

CHAPTER SUMMARY

LCS: dp[i][j] = match then dp[i-1][j-1] + 1, else max(up, left).

Derived formulas: deletions m + n - 2 LCS; supersequence m + n - LCS; palindrome insertions n - LCS(s, reverse s).

Substring variant resets to zero and returns the table maximum.

Traceback from the corner recovers a string; two rows suffice for the length.

Cost is O(m n) time; use Hirschberg when memory is the limit and the string is required.
