Trie (Prefix Tree)

Share common prefixes in a tree so insert, lookup and prefix queries cost O(length).

A. Pattern Overview

A trie stores a set of strings as a tree whose edges are characters. Every node represents the prefix spelled by the path from the root, and a flag marks nodes where a stored word ends. Lookup cost depends only on the length of the query, not on how many words are stored, and every prefix question becomes "walk down and look at the node".

KEY IDEA

A trie trades memory for prefix awareness. If no query is about prefixes, a HashSet is simpler and smaller.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Starts with", "prefix", "autocomplete", "dictionary of words" in the statement.
Many queries against a fixed word list (precompute once, answer each in O(length)).
Grid or board search for many words at once (prune the DFS with the trie; Chapter 37).
Wildcards such as . in the query: DFS over the trie branches.
Streaming text with suffix matching (reverse the words, walk the reversed stream).
ONE-LINE TEST

Many strings sharing prefixes, queried by prefix: build a trie.

Counters make deletion and prefix counts cheap

Store pass (words through the node) and end (words ending here). countPrefix reads pass; erase decrements pass along the path and can detach a node when it reaches zero, keeping the trie small.

Wildcards

For . try every child. Worst case visits the whole trie, but a literal-letter query stays O(L). This is Design Add and Search Words (LeetCode 211).

CROSS-REFERENCE

For Word Search II (Chapter 37) the trie is walked together with the DFS: each grid step moves one node down, a missing child prunes the branch, and a found word's node is cleared to avoid duplicates.

E. Java Implementation

Trie with counters, erase, wildcard search, prefix listing and MapSum

Trie.java: array-based trie, counters, erase, wildcard search, MapSum

import java.util.*;

/** Ch 94: prefix tree with counts; LeetCode 208, 211, 677. */
public class Trie {
    private static final class Node {
        final Node[] next = new Node[26];
        int pass;       // words passing through this node
        int end;        // words ending exactly here
    }

    private final Node root = new Node();

    /** Inserts a lowercase word. */
    public void insert(String word) {
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int c = word.charAt(i) - 'a';
            if (cur.next[c] == null) cur.next[c] = new Node();
            cur = cur.next[c];
            cur.pass++;
        }
        cur.end++;
    }

    private Node find(String s) {
        Node cur = root;
        for (int i = 0; i < s.length() && cur != null; i++)
            cur = cur.next[s.charAt(i) - 'a'];
        return cur;
    }

    public boolean search(String word) {
        Node n = find(word);
        return n != null && n.end > 0;
    }

    public boolean startsWith(String prefix) {
        return find(prefix) != null;
    }

    /** Number of inserted words that start with prefix. */
    public int countPrefix(String prefix) {
        Node n = find(prefix);
        return n == null ? 0 : n.pass;
    }

Java 17+

    /** Removes one copy of word if present; returns whether it was. */
    public boolean erase(String word) {
        if (!search(word)) return false;
        Node cur = root;
        for (int i = 0; i < word.length(); i++) {
            int c = word.charAt(i) - 'a';
            Node child = cur.next[c];
            if (--child.pass == 0) {       // subtree is now empty: detach
                cur.next[c] = null;
                return true;
            }
            cur = child;
        }
        cur.end--;
        return true;
    }

    /** LeetCode 211: '.' matches any single letter. */
    public boolean searchWithDots(String pattern) {
        return dfs(root, pattern, 0);
    }

    private boolean dfs(Node node, String p, int i) {
        if (node == null) return false;
        if (i == p.length()) return node.end > 0;
        char ch = p.charAt(i);
        if (ch != '.') return dfs(node.next[ch - 'a'], p, i + 1);
        for (Node child : node.next)
            if (child != null && dfs(child, p, i + 1)) return true;
        return false;
    }

    /** All stored words with the given prefix in lexicographic order. */
    public List<String> wordsWithPrefix(String prefix, int limit) {
        List<String> out = new ArrayList<>();
        Node n = find(prefix);
        if (n != null) collect(n, new StringBuilder(prefix), out, limit);
        return out;
    }

    private void collect(Node n, StringBuilder sb, List<String> out, int limit) {
        if (out.size() >= limit) return;
        for (int k = 0; k < n.end && out.size() < limit; k++)
            out.add(sb.toString());
        for (int c = 0; c < 26 && out.size() < limit; c++) {
            if (n.next[c] == null) continue;
            sb.append((char) ('a' + c));
            collect(n.next[c], sb, out, limit);
            sb.deleteCharAt(sb.length() - 1);
        }
    }

    /** LeetCode 677: sum of values of keys with a given prefix. */
    public static final class MapSum {
        private final Map<String, Integer> val = new HashMap<>();
        private final Map<String, Integer> sums = new HashMap<>();

        public void insert(String key, int v) {
            int delta = v - val.getOrDefault(key, 0);
            val.put(key, v);
            for (int i = 1; i <= key.length(); i++)
                sums.merge(key.substring(0, i), delta, Integer::sum);
        }
        public int sum(String prefix) {
            return sums.getOrDefault(prefix, 0);
        }
    }
}

TrieApps.java: classic trie applications
import java.util.*;

/** Ch 94: trie applications; LeetCode 648, 720, 1268, 1032. */
public class TrieApps {
    private static final class Node {
        final Node[] next = new Node[26];
        boolean end;
    }

    private static Node build(Collection<String> words) {
        Node root = new Node();
        for (String w : words) {
            Node cur = root;
            for (char ch : w.toCharArray()) {
                int c = ch - 'a';
                if (cur.next[c] == null) cur.next[c] = new Node();
                cur = cur.next[c];
            }
            cur.end = true;
        }
        return root;
    }

    /** LeetCode 648: replace each word by its shortest dictionary root. */
    public static String replaceWords(List<String> dictionary, String sentence) {
        Node root = build(dictionary);
        StringBuilder out = new StringBuilder();
        for (String word : sentence.split(" ")) {
            if (out.length() > 0) out.append(' ');
            Node cur = root;
            int len = 0;
            boolean found = false;
            while (len < word.length() && cur.next[word.charAt(len) - 'a'] != null)
                {
                cur = cur.next[word.charAt(len++) - 'a'];
                if (cur.end) { found = true; break; }
            }
            out.append(found ? word.substring(0, len) : word);
        }
        return out.toString();
    }

    /** LeetCode 720: longest word buildable one letter at a time; ties smallest. */
    public static String longestWord(String[] words) {
        Node root = build(Arrays.asList(words));
        String best = "";
        Deque<Object[]> stack = new ArrayDeque<>();
        stack.push(new Object[]{root, ""});
        while (!stack.isEmpty()) {
            Object[] top = stack.pop();
            Node n = (Node) top[0];
            String s = (String) top[1];

    /** LeetCode 1268: up to three lexicographic suggestions per typed prefix. */
    public static List<List<String>> suggestedProducts(String[] products,
            String search) {
        String[] sorted = products.clone();
        Arrays.sort(sorted);
        List<List<String>> out = new ArrayList<>();
        int lo = 0;
        for (int len = 1; len <= search.length(); len++) {
            String prefix = search.substring(0, len);
            while (lo < sorted.length && sorted[lo].compareTo(prefix) < 0) lo++;
            List<String> row = new ArrayList<>(3);
            for (int i = lo; i < sorted.length && row.size() < 3
                    && sorted[i].startsWith(prefix); i++) row.add(sorted[i]);
            out.add(row);
        }
        return out;
    }

    /** LeetCode 1032: is any word a suffix of the stream so far? Reversed trie. */
    public static final class StreamChecker {
        private final Node root = new Node();
        private final StringBuilder stream = new StringBuilder();
        private int maxLen;

        public StreamChecker(String[] words) {
            for (String w : words) {
                maxLen = Math.max(maxLen, w.length());
                Node cur = root;
                for (int i = w.length() - 1; i >= 0; i--) {
                    int c = w.charAt(i) - 'a';
                    if (cur.next[c] == null) cur.next[c] = new Node();
                    cur = cur.next[c];
                }
                cur.end = true;
            }
        }

        public boolean query(char letter) {
            stream.append(letter);
            Node cur = root;
            for (int i = stream.length() - 1, k = 0; i >= 0 && k < maxLen; i--, k++)
                {
                cur = cur.next[stream.charAt(i) - 'a'];
                if (cur == null) return false;
                if (cur.end) return true;
            }
            return false;
        }
    }
}

TIME O(L) per operation

SPACE O(total chars x 26)

Each insert, search or prefix query walks at most L nodes. The array layout costs 26 references per node (about 100 bytes on a 64-bit JVM with compressed oops).

F. Detailed Dry Run

searchWithDots("a.t") on {app, apple, apt, bat}: root has child a, move there. The pattern char . tries each child of a: only p. From p the next pattern char is t; p has children p and t, so only t matches, and its end flag is set (apt). Result true.

suggestedProducts(["mobile", "mouse", "moneypot", "monitor", "mousepad"], "mouse"):

sorted products are mobile, moneypot, monitor, mouse, mousepad. Typing m gives the first three; mo the same three; mou gives mouse, mousepad; mous and mouse give the same two. Walk one trie node per keystroke and collect up to 3 words in lexicographic DFS order.

G. Variations of the Pattern

Prefix counting and deletion

Counters per node give countPrefix and make erase correct when the same word was inserted more than once (Implement Trie II).

MapSum

Store the sum of values under each prefix. When a key is overwritten, add the difference along the path (LeetCode 677).

Compressed (radix) tries

Merge single-child chains into one edge labelled with a string. Saves memory; used in routers and databases. Rarely coded in interviews, worth naming.

Suffix structures

A trie of all suffixes is a suffix trie; the compressed form is a suffix tree, and the sorted array of suffixes is a suffix array. All answer substring queries but need much more memory than the dictionary trie.

Aho-Corasick

A trie plus failure links (the KMP idea on a tree) matches many patterns in one pass over the text. Mention it when the question is "find any of these 10 000 words in a document".

Write Node with children[26] and a boolean first, then add counters only when asked.

For grid word search say the trie replaces re-scanning the board for every word.

CHAPTER SUMMARY

A trie shares common prefixes, so insert, search and prefix queries cost O(length) regardless of dictionary size.

Two fields do most of the work: a child table and an end flag; add pass counters for prefix counts and deletion.

Wildcards and autocomplete are DFS over the trie below the node reached by the literal prefix.

Pair a trie with another traversal (grid DFS, text stream) to prune work early.

Pay attention to memory: use arrays for a small alphabet, maps for a large one, or compress chains.
