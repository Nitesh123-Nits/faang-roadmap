Glossary

TermMeaning
Activity selectionChoosing the largest set of non-overlapping intervals; solved by sorting by end time.
Adjacency listA graph stored as one list of neighbours per vertex; O(V + E) memory.
Amortised analysisAveraging the cost of operations over a whole sequence. A while inside a for is still O(n) if each element is processed a bounded number of times in total.
Amortised analysisBounding the average cost per operation over any worst-case sequence of operations; a guarantee about the sequence, not about random inputs.
Amortised O(1)Constant cost per operation averaged over a sequence, although a single operation (such as a stack-to-stack transfer) may cost more.
Anti-diagonalA diagonal running down-left; its cells share the value r + c.
ArgsortThe indices that would sort an array, used when original positions must be kept.
Arm and bendIn path problems, the arm is the best downward path returned to the parent; the bend is the best path through the node, recorded in a global.
Articulation pointA vertex whose removal disconnects an undirected graph.
Auxiliary spaceExtra memory used beyond the input (and usually the returned output).
Auxiliary spaceMemory an algorithm allocates beyond its input, including recursion stack frames.
Back edgeIn a DFS of a directed graph, an edge to an ancestor still on the recursion stack; it proves a cycle.
BacktrackingRecursive search that builds a solution step by step, abandoning (undoing) a choice when it cannot lead to a solution.
Balanced treeA tree in which every node's subtree heights differ by at most one.
Base caseAn input answered directly, without recursion; it guarantees termination.
Bellman-FordShortest paths by V − 1 rounds of relaxing every edge; tolerates negative weights and detects negative cycles.
Big O, Omega, ThetaUpper, lower and tight asymptotic bounds on a function; separate from the best, worst and average case they may describe.
Binary (XOR) trieA trie over the bits of integers, most significant first; walking opposite bits finds the maximum XOR partner.
Binary liftingPrecomputing the 2^j-th ancestor of every node so that k-th ancestors and LCAs are answered in O(log n).
Binary search treeA binary tree in which every key in a node's left subtree is smaller, and every key in its
(BST)right subtree larger, than the node's key.
Bipartite graphA graph whose vertices split into two sets with every edge between them; equivalently, no odd cycle.
TermMeaning
BitmaskAn integer whose bits represent membership of elements in a subset.
Bitonic arrayAn array that strictly increases to a single peak and then strictly decreases (a mountain).
Bounded heapA heap capped at k entries by evicting its root when it grows past k; keeps the k best items in O(n log k).
Boyer-Moore votingA one-pass algorithm that keeps a candidate and a count; different elements cancel, so a strict majority always survives.
BracketA range [lo, hi] known to contain the answer; exponential search first builds it by doubling.
BridgeAn edge whose removal disconnects an undirected graph.
Bucket sort byAn array indexed by frequency (1..n) whose cells list the values with that count;
frequencyscanning it from high to low gives values by descending frequency in O(n).
Canonical keyA representation where two items are equivalent exactly when their keys are equal (sorted letters, reduced slope, count signature).
ChainingCollision handling in which each hash bucket holds a linked list (or tree) of entries.
Choose / explore /The three-step body of every backtracking loop: apply a choice, recurse, then restore
unchoosethe state exactly.
Closed intervalAn interval [a, b] that includes both endpoints; [1,2] and [2,3] share the point 2.
CondensationThe DAG obtained by contracting each strongly connected component to a single node.
CooldownA required number of slots between two runs of the same task; the most frequent task determines the minimum schedule length.
CoordinateReplacing sparse coordinates by their ranks so they can index an array.
compression
Cross product (2D)(b - a) x (c - a); its sign tells whether a, b, c turn left, right or are collinear.
Cut propertyThe lightest edge crossing any cut belongs to some MST; it justifies Kruskal and Prim.
DAGDirected acyclic graph; exactly the graphs that have a topological order.
DiameterThe number of edges on the longest path between any two nodes; the path bends at its highest node.
Difference arrayArray of adjacent differences; makes range additions O(1). Inverse of the prefix sum.
Dijkstra's algorithmGreedy single-source shortest paths for non-negative weights using a priority queue.
Disjoint-intervalStored intervals never overlap or touch, so a new interval can only conflict with its two
invariantnearest neighbours.
DominanceElement a is dominated by b if a can never be a better answer than b from now on; dominated elements are discarded (monotonic deque).
Dummy (sentinel) nodeA placeholder node placed before the head so that every real node has a predecessor; removes head-specific special cases.
Error logA short record of each missed problem and the signal that was overlooked, used to drive spaced revision.
TermMeaning
Euler tourA depth-first walk that records a node on every entry and return; with a sparse table it answers LCA queries in O(1).
Event (sweep)A coordinate at which something starts or ends; the sweep line processes events in sorted order.
Exchange argumentProof technique: show that swapping or discarding an element cannot worsen the optimum. Justifies two-pointer moves.
Exchange argumentA proof that swaps an optimal solution's choice for the greedy one without making it worse, showing the greedy choice is safe.
Exchange argumentA greedy proof: swap an optimal solution's first choice for the greedy choice without making it worse.
Expand around centreGrow l--, r++ from each of the 2n − 1 centres while the characters match; finds palindromes in O(n²) time, O(1) space.
Expected-closer stackA stack holding the closing bracket each open bracket requires; the next closer must equal the top.
Factorial numberA mixed-radix system with place values (n−1)!, (n−2)!, …, 1!; it maps a rank k to the
systemk-th permutation.
Feasibility checkThe function feasible(x) evaluated by binary search on the answer, usually a greedy scan.
Feasibility predicateA yes/no test feasible(x) on a candidate answer; binary search on the answer needs it to be monotone.
Fenwick tree (BIT)A binary indexed tree: cell i stores the aggregate of the i & -i elements ending at i; prefix queries and point updates in O(log n).
TermMeaning
Fisher-Yates shuffleThe unbiased in-place shuffle that swaps position i with a uniformly random position in i..n-1.
Floyd's cycle detectionTortoise-and-hare: slow moves 1, fast moves 2; they meet inside a cycle, and restarting one pointer at the head finds the cycle entrance.
Floyd-WarshallAll-pairs shortest paths by dynamic programming over intermediate vertices, O(V³).
Functional graphA graph in which every node has exactly one outgoing edge (i -> nums[i]); it contains cycles, so Floyd applies.
Gray codeA sequence of binary numbers in which consecutive values differ in exactly one bit; g(i) = i ^ (i >> 1).
Greedy choiceA locally best decision that is proved to be part of some optimal solution, so it never needs to be revisited.
Half-open intervalAn interval [a, b) that includes a but not b; [1,2) and [2,3) do not overlap.
Head insertionRepeatedly moving the node after cur to just after a fixed before node; reverses a segment without a reconnection step.
HeapA complete binary tree stored in an array in which every node is ordered against its children; the root is the minimum (min-heap) or maximum (max-heap).
TermMeaning
Held-KarpThe O(2^n n^2) bitmask DP for the travelling salesman problem: dp[mask][last] is the cheapest path over a set of cities.
Hirschberg's algorithmA divide-and-conquer method that recovers an LCS or alignment in linear space by finding where an optimal path crosses the middle row.
Home indexThe array position where a value belongs in cyclic sort (v - 1 for values 1..n).
Huffman codingA greedy algorithm that merges the two lightest trees repeatedly to build an optimal prefix code.
Idempotent operationAn operation with op(x, x) = x (min, max, gcd, AND, OR); overlapping ranges do no harm, which sparse tables exploit.
Inorder successorThe smallest key greater than a given key; the leftmost node of the right subtree, or the last ancestor from which the walk went left.
Interval coverChoosing the fewest intervals whose union covers a target range; solved by always extending the furthest reach.
Interval graphA graph whose vertices are intervals, adjacent when they overlap; its chromatic number equals its largest clique, the peak overlap.
InvariantA statement that holds before and after every loop iteration; the basis of correctness proofs.
InversionA pair of positions i < j with a[i] > a[j]; the count measures how far an array is from sorted.
k-way mergeMerging k sorted sequences by always taking the smallest current head, using a min-heap or pairwise merging in O(N log k).
K-way mergeMerging k sorted sources by keeping one front element per source in a min-heap; O(N log k) for N elements.
Kahn's algorithmTopological sort that repeatedly removes vertices of in-degree 0; a short result signals a cycle.
Kernighan's trickn & (n - 1) clears the lowest set bit, so a loop of that step counts set bits in O(popcount).
Key point (skyline)A pair (x, height) at which the outline's height changes.
Kraft inequalityA prefix code with codeword lengths l1..ln exists if and only if the sum of 2^(-li) is at most 1; equal to 1 for a complete code.
Lazy deletionMarking an element as removed and discarding it only when it reaches the top of the heap; avoids the O(n) cost of removing from the middle.
Lazy deletionLeaving stale entries in a heap and discarding them when they reach the top, instead of an O(n) removal.
Lazy propagationStoring a pending update at a segment-tree node and pushing it to the children only when they are visited.
Lazy tagA pending update stored on one element and applied only when that element is next read or removed (CustomStack increments).
Lexicographic orderDictionary order: compare element by element from the left.
Load factorEntries divided by buckets; java.util.HashMap resizes at 0.75.
TermMeaning
Low-linklow[u]: the smallest discovery time reachable from u's DFS subtree using at most one back edge; the basis of Tarjan's algorithms.
Lower / upper boundFirst index with nums[i] >= t (lower) or nums[i] > t (upper); the occurrences of t are [lower, upper).
Lowest commonThe deepest node that has both given nodes as descendants (a node is its own
ancestor (LCA)descendant).
LRU / LFULeast Recently Used / Least Frequently Used: cache eviction policies by recency and by access count (ties by recency).
Manacher's algorithmA linear-time method that finds the radius of the longest palindrome at every centre by reusing mirrored radii.
Meet in the middleSplitting the input into two halves, enumerating each half and joining the results, to turn 2^n into about 2^(n/2).
MemoisationCaching the result of a call by its arguments so repeated calls return immediately (top-down dynamic programming).
minFreqIn an LFU cache, the lowest frequency that currently has a non-empty bucket; the eviction bucket.
Minimum spanning treeA subset of edges connecting all vertices with the least total weight and no cycle.
Modular inverseA number x with a x = 1 (mod m); replaces division under a modulus. Exists iff gcd(a, m) = 1.
Monotone / monotonicAlways moving in one direction. A window condition is monotone if growing the window can only break (or only help) validity.
Monotone predicateA yes/no test over an ordered range that changes answer at most once; the precondition for binary search on the answer.
Monotonic stack /A stack or deque kept in sorted order by popping elements that violate the order before
dequeeach push.
Morris traversalInorder or preorder walk in O(1) extra space by temporarily threading each predecessor's right pointer to its ancestor and removing the thread afterwards.
Most constrainedThe slot with the fewest remaining candidates; branching on it first makes failures
variableappear early.
Multi-source BFSBFS started with several sources at distance 0, giving distance to the nearest one.
MultisetA set that stores counts, so equal values can be added and removed independently; a TreeMap<value, count>.
Negative cycleA cycle with negative total weight; shortest paths through it are undefined.
Offline algorithmAn algorithm that sees all its queries in advance and may reorder them; contrast with online.
Online algorithmAn algorithm that must answer each request as it arrives, without seeing later ones.
Optimal substructureAn optimal solution contains optimal solutions to its subproblems, so smaller optima can be combined.
OverlappingThe same smaller question is asked many times; the property that makes caching pay
subproblemsoff.

Path compressionRe-pointing nodes on a find path closer to the root; path halving is the one-pass variant.
TermMeaning
Patience sortingDealing cards onto piles with a decreasing-top rule; the number of piles equals the length of the longest increasing subsequence.
Postfix (RPN)Reverse Polish notation: operands before operators, so evaluation needs only one operand stack and no parentheses.
Power setThe set of all subsets of a set; 2ⁿ elements for n items.
Prefix codeA code in which no codeword is a prefix of another, so a bit stream can be decoded without separators.
Prefix function / borderpi[i] is the length of the longest proper prefix of s[0..i] that is also its suffix; such a prefix is called a border.
Prefix sumP[i] = sum of the first i elements; range sums become P[r+1] - P[l].
Preorder / inorder /Tree traversal orders that visit the node before, between or after its two subtrees; the
postorderinorder of a BST is sorted.
Priority queueAn abstract structure that returns the item with the highest priority; usually implemented with a binary heap, O(log n) per offer and poll.
PruningSkipping a branch because it provably cannot lead to a valid answer.
Pseudo-polynomialPolynomial in the numeric value of an input (such as a knapsack capacity) but exponential in its bit length.
Pseudo-polynomialPolynomial in the numeric value of an input (such as a knapsack capacity) but exponential in its bit length.
QuickselectSelection by partitioning around a pivot and recursing into one side; finds the k-th element in expected O(n).
QuickselectPartitioning around a pivot and recursing into one side to find the k-th smallest element in expected O(n) time.
Re-rootingComputing an answer for every node of a tree as root by reusing the parent's answer in O(1) per edge.
Reader / writer pointersSame-direction two pointers: read scans, write marks the next output slot.
Recursion treeA tree with one node per call; its size times the work per node is the cost of the recursion.
Recursive descentParsing by one function per precedence level, each calling the next-tighter level; parentheses recurse back to the top.
RelaxationImproving a tentative distance dist[v] by going through u: dist[u] + w < dist[v].
RelinkingChanging next pointers to reorder nodes without copying or moving values.
Reservoir samplingChoosing k items uniformly from a stream of unknown length in one pass by replacing a random slot with probability k / i.
Ring (circular list)A list whose tail points to the head; used to rotate by cutting at a computed node.
Ring bufferA fixed array used circularly with a head index and a size; indices wrap with modulo.
TermMeaning
Rolling arrayKeeping only the most recent row(s) of a DP table when each row depends only on the previous one.
Rolling hashA polynomial hash of a window that can be updated in O(1) when the window slides by one character.
Segment treeA tree whose nodes store an aggregate (sum, min, max) of an interval; range queries and point updates run in O(log n).
SentinelA dummy value (for example height 0 at the end) that forces a loop to flush pending state without a special case.
Shunting-yardDijkstra's algorithm that converts infix to postfix with an operator stack, popping operators of greater or equal precedence first.
Sieve of EratosthenesListing primes up to n by crossing out multiples of each prime from its square, in O(n log log n).
Sliding windowA contiguous range [left, right] whose summary is updated incrementally as it moves.
Sparse tableA table st[k][i] of answers for windows of length 2^k; answers idempotent range queries in O(1) after O(n log n) preprocessing.
Stabbing queryAsking which intervals contain a given point.
Stable sortA sort that keeps equal keys in their original relative order; counting sort achieves it by filling the output right to left.
Stable sortA sort that keeps equal elements in their original order; List.sort and Arrays.sort(Object[]) are stable.
Staircase searchWalking a row-and-column-sorted matrix from a corner, discarding a row or column per step.
State (DP)The smallest set of facts about the problem so far that determines the best way to finish; the index (or indices) of a DP table.
State machine DPDP whose state is a small mode (holding, cooldown, colour) updated each step along allowed transitions.
Stays aheadA greedy proof showing that after every step the greedy solution is at least as good as any other partial solution.
Strongly connectedA maximal set of vertices in a directed graph that all reach each other.
