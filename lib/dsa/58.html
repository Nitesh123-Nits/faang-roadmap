BFS and DFS

The two traversals: breadth finds shortest paths, depth explores structure.

A. Pattern Overview

Every graph algorithm in this part is a traversal with some extra bookkeeping. A traversal visits every vertex reachable from a source exactly once, and costs O(n + m) with an adjacency list. The only difference between the two is the container that holds the frontier:

BFSDFS
Container Queue (FIFO)Stack (LIFO), or the call stack
Visits in order of Distance from the source (layers)Going as deep as possible, then backtracking
Finds Shortest path in an unweighted graphAny path; structure (cycles, order, components)
Memory O(width): can be O(n)O(depth): can be O(n)
Typical uses Fewest moves, levels, nearest, multi-sourceComponents, cycles, topological order, bridges, backtracking
KEY IDEA

Mark a vertex visited when you add it to the frontier, not when you remove it. Marking on removal lets the same vertex be enqueued many times (still correct for reachability, but a BFS then does O(m) extra queue work and breaks the distance bookkeeping on weighted or multi-source variants).

B. When to Recognize This Pattern

Pattern Recognition Signals

"Minimum number of steps / moves / transformations" on unweighted transitions: BFS.
"Is there a path" / "can we reach": either; DFS is shorter to write, BFS safer for deep graphs.
"Return all paths": DFS with backtracking (Chapter 31).
"Shortest sequence" over words, locks, genes, puzzle boards: BFS on an implicit state graph.
"Distance from a node", "nodes at distance k", "time to infect everyone": BFS depth.
ONE-LINE TEST

Unit-cost edges and the word minimum mean BFS. A weighted minimum means Dijkstra (Chapter 53). All solutions means DFS with backtracking.

Why BFS gives shortest paths

BFS maintains an invariant: the queue holds vertices at distance d followed by vertices at distance d + 1, never more than one level apart. Dequeueing in order therefore discovers vertices in nondecreasing distance. With weights this breaks (a one-edge path of cost 100 beats nothing but loses to two edges of cost 1); use Dijkstra, or 0-1 BFS when weights are only 0 and 1.

E. Java Implementation

BFS order and distances, recursive and iterative DFS, paths

GraphTraversal.java: LeetCode 1971, 797
import java.util.*;

/** Ch 47: BFS and DFS on graphs; LeetCode 1971, 797, plus distance by BFS. */
public class GraphTraversal {

    /** BFS order from s; marks visited when ENQUEUING so a node enters once. */
    public static List<Integer> bfsOrder(List<List<Integer>> g, int s) {
        List<Integer> order = new ArrayList<>();
        boolean[] seen = new boolean[g.size()];
        Deque<Integer> queue = new ArrayDeque<>();
        queue.add(s);
        seen[s] = true;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            order.add(u);
            for (int v : g.get(u))
                if (!seen[v]) {
                    seen[v] = true;
                    queue.add(v);
                }
        }
        return order;
    }

    /** Unweighted shortest distances from s (-1 = unreachable). */
    public static int[] bfsDistances(List<List<Integer>> g, int s) {
        int[] dist = new int[g.size()];
        Arrays.fill(dist, -1);
        Deque<Integer> queue = new ArrayDeque<>();
        dist[s] = 0;
        queue.add(s);
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : g.get(u))
                if (dist[v] < 0) {
                    dist[v] = dist[u] + 1;
                    queue.add(v);

Java 17+

                }
        }
        return dist;
    }

    /** Recursive DFS preorder from s. Depth can reach n: see the iterative one. */
    public static List<Integer> dfsOrder(List<List<Integer>> g, int s) {
        List<Integer> order = new ArrayList<>();
        dfs(g, s, new boolean[g.size()], order);
        return order;
    }

    private static void dfs(List<List<Integer>> g, int u, boolean[] seen,
                            List<Integer> order) {
        seen[u] = true;
        order.add(u);
        for (int v : g.get(u)) if (!seen[v]) dfs(g, v, seen, order);
    }

    /** Iterative DFS with the same visiting order as the recursive version. */
    public static List<Integer> dfsOrderIterative(List<List<Integer>> g, int s) {
        List<Integer> order = new ArrayList<>();
        boolean[] seen = new boolean[g.size()];
        Deque<Integer> stack = new ArrayDeque<>();
        int[] next = new int[g.size()];                // next neighbour to try
        stack.push(s);
        seen[s] = true;
        order.add(s);
        while (!stack.isEmpty()) {
            int u = stack.peek();
            if (next[u] == g.get(u).size()) {
                stack.pop();
                continue;
            }
            int v = g.get(u).get(next[u]++);
            if (!seen[v]) {
                seen[v] = true;
                order.add(v);
                stack.push(v);
            }
        }
        return order;
    }

    /** LeetCode 1971: is there a path from source to destination? */
    public static boolean validPath(int n, int[][] edges, int source, int dest) {
        List<List<Integer>> g = GraphRepresentation.adjList(n, edges, false);
        return bfsDistances(g, source)[dest] >= 0;
    }

    /** LeetCode 797: all paths from 0 to n-1 in a DAG (backtracking on a path). */
    public static List<List<Integer>> allPathsSourceTarget(int[][] graph) {
        List<List<Integer>> out = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        path.add(0);
        walk(graph, 0, path, out);
        return out;
    }

    private static void walk(int[][] g, int u, List<Integer> path,
                             List<List<Integer>> out) {
        if (u == g.length - 1) {
            out.add(new ArrayList<>(path));
            return;
        }
        for (int v : g[u]) {
            path.add(v);
            walk(g, v, path, out);
            path.remove(path.size() - 1);
        }
    }
}

TIME O(n + m)

SPACE O(n)

allPathsSourceTarget is output-bound: a DAG with 2^k paths costs 2^k to list. The iterative DFS keeps a next[] cursor per vertex so it visits neighbours in the same order as recursion.

F. Detailed Dry Run

The BFS and DFS tables in section C use the sample graph from Chapter 46 with source 0. In the BFS table, vertex 3 is enqueued by vertex 1 (the first of its two neighbours dequeued); when vertex 2 is dequeued, 3 is already marked, so it is not enqueued again: that is the

whole point of marking on enqueue. In the DFS table the walk goes 0 → 1 → 3 → 2 and then 2

backtracks, because its only other neighbour 0 is seen; later 4 is reached from 3 after returning to it.

G. Variations of the Pattern

Level-aware BFS

Freeze queue.size() per round (as in tree BFS, Chapter 41) when the answer is the number of rounds (Time Needed to Inform All Employees, Rotting Oranges).

Bidirectional BFS

Search from both ends and stop when the frontiers meet: O(b^{d/2}) instead of O(b^d) on graphs with branching factor b (Word Ladder at scale). Always expand the smaller frontier.

0-1 BFS

Edges of weight 0 or 1: a deque; push 0-edges to the front, 1-edges to the back. O(n + m) shortest paths without a heap.

DFS with timestamps

Record discover and finish times: the basis of topological sort, SCC and bridges (Chapters 50, 58, 59).

Alternating or constrained states

Shortest Path with Alternating Colors (1129): the vertex is (node, colour of last edge): BFS on a product graph. The same trick handles keys, parity and "at most k obstacles".

J. Interview Tips

INTERVIEW

Choose out loud: "unit edges and minimum → BFS; I mark visited on enqueue to keep it O(n + m)."

Name the visited structure (boolean[], HashSet for implicit states) and its memory.

For deep inputs say the JVM default stack depth is limited (typically around 10⁴ frames) and switch to an explicit stack.

Follow-ups: print the path (store parent[] and walk back); bidirectional BFS; weighted

edges; count the shortest paths (add ways[v] += ways[u] when dist[v] == dist[u] + 1); grids with obstacles.

Edge cases: source equals target, disconnected graph, self-loops, parallel edges, start state already invalid (a dead-end lock).

CHAPTER SUMMARY

BFS = queue, shortest unweighted paths; DFS = stack, structure and enumeration. Both are O(n + m).

Mark visited when enqueueing. Initialise distances to −1.

Use an explicit stack (with a per-vertex neighbour cursor) when the graph can be deep.

Implicit graphs (words, locks, boards) are BFS with a computed neighbour function and a visited set of states.

Back edges (to a gray vertex) mean cycles; BFS fails for weights: use Dijkstra, or 0-1 BFS for weights 0 / 1.
