Manacher's Algorithm

Every palindromic substring of a string in linear time, by reusing mirrored radii.

A. Pattern Overview

Palindromes are symmetric around a centre. Manacher's algorithm computes, for every centre, the radius of the largest palindrome around it, in O(n) total. It keeps the palindrome

[l, r] that reaches farthest to the right. For a new centre i inside it, the mirror centre l + r

i already knows a lower bound for the radius, so only characters beyond r need comparing.

KEY IDEA

Two arrays do everything: d1[i] = number of odd palindromes centred at i (the radius including the centre) and d2[i] = number of even palindromes whose right-centre is i.

The mirror trick

Let [l, r] be the rightmost palindrome seen. For a centre i inside it, its mirror is j = l + r

i. The palindrome around j reappears around i, but it is clipped by the right edge: start from min(d1[j], r - i + 1). If d1[j] fits strictly inside, no comparison is needed; otherwise extend character by character past r, which advances r.

Why it is linear

r increases whenever we extend, and each extension step compares a character that lies beyond the old r. Every position is the right edge at most once, so extensions total O(n). All other work per centre is O(1).

O(1) palindrome queries and per-end counts

s[l..r] is a palindrome iff the radius at its centre covers it: odd length uses d1[(l + r) / 2]

>= (len + 1) / 2, even length uses d2[(l + r + 1) / 2] >= len / 2. For the number of palindromes ending at each index, add a range [i, i + d1[i] - 1] for each odd centre (and [i, i + d2[i] - 1] for even) with a difference array and prefix-sum it (Chapter 4).

The transformed-string variant

Many write-ups insert a separator between characters (#a#b#a#) so every palindrome becomes odd, then run one loop. It is shorter to write but harder to map back to indices. This book uses two arrays instead; the logic is identical.

TRAP

Do not forget the even case. Strings like abba have no odd centre that sees the whole palindrome, and cbbd has bb as its answer.

Manacher.java: radii arrays and their applications
import java.util.*;

/** Ch 104: Manacher's algorithm; LeetCode 5, 647, 516 helpers. */
public class Manacher {
    /**
     * d1[i] = number of odd palindromes centred at i (radius counting the centre).
     */
    public static int[] oddRadii(String s) {
        int n = s.length();
        int[] d1 = new int[n];
        for (int i = 0, l = 0, r = -1; i < n; i++) {
            // mirror start
int k = i > r ? 1 : Math.min(d1[l + r - i], r - i + 1);
            while (i - k >= 0 && i + k < n && s.charAt(i - k) == s.charAt(i + k))
                k++;
            d1[i] = k;
            if (i + k - 1 > r) {
l=i-k+1;
r=i+k-1;
            }
        }
        return d1;
    }

    /** d2[i] = number of even palindromes whose right-centre is i. */
    public static int[] evenRadii(String s) {
        int n = s.length();
        int[] d2 = new int[n];
        for (int i = 0, l = 0, r = -1; i < n; i++) {
int k = i > r ? 0 : Math.min(d2[l + r - i + 1], r - i + 1);

            }
        }
        return d2;
    }

        int n = s.length();
        if (n == 0) return "";

    /** LeetCode 647: number of palindromic substrings. */
    public static int countSubstrings(String s) {
        long total = 0;
        for (int v : oddRadii(s)) total += v;
        for (int v : evenRadii(s)) total += v;
        return (int) total;
    }

    /** O(1) query after O(n) setup: is s[l..r] a palindrome? */
    public static final class PalindromeQuery {
        private final int[] d1, d2;

        public PalindromeQuery(String s) {
            d1 = oddRadii(s);
            d2 = evenRadii(s);
        }

        public boolean isPalindrome(int l, int r) {
            int len = r - l + 1;
            if ((len & 1) == 1) return d1[(l + r) / 2] >= (len + 1) / 2;
            return d2[(l + r + 1) / 2] >= len / 2;
        }
    }

    /**
     * Number of palindromic substrings ending at each index, via the radii arrays.
     */
    public static int[] palindromesEndingAt(String s) {
        int n = s.length();
        int[] diff = new int[n + 2];
        int[] d1 = oddRadii(s), d2 = evenRadii(s);
        for (int i = 0; i < n; i++) {
            // odd palindromes with centre i end at i .. i + d1[i] - 1
            diff[i]++;
            diff[i + d1[i]]--;
            // even palindromes with right-centre i end at i .. i + d2[i] - 1
            if (d2[i] > 0) {
                diff[i]++;
                diff[i + d2[i]]--;
            }
        }
        int[] out = new int[n];
        int run = 0;
        for (int i = 0; i < n; i++) {
            run += diff[i];
            out[i] = run;
        }
        return out;
    }
}

SPACE O(n)

Two integer arrays of length n. Every extension step pushes the right edge r forward, and r never decreases.

G. Variations of the Pattern

Palindromic substrings count

sum(d1) + sum(d2); for abaaba it is 11 (6 single letters, aba twice, aa, baab, abaaba).

Palindrome Partitioning feasibility

isPal(l, r) from radii in O(1) replaces the O(n^2) boolean table, but the partition DP is still O(n^2) for min cuts. Use the palindromic tree (eertree) for O(n).

Maximum product of two non-overlapping palindromes

From the odd radii compute left[i] = longest odd palindrome ending at or before i and

right[i] = longest starting at or after i, using the difference-array trick; answer is max

left[i] x right[i+1] (LeetCode 1960).

Palindromic pairs

Combine a trie of reversed words with palindrome checks on the leftover (Palindrome Pairs, LeetCode 336); Manacher or hashing gives the O(1) check.

Shortest palindrome and KMP/Z link

The longest palindromic prefix is d1[c] == c + 1 for the largest such centre c, or via KMP/Z (Chapters 101 and 103). Manacher gives the same answer from the radii.

J. Interview Tips

INTERVIEW

Start with expand-around-centre (O(n^2), 10 lines), then offer Manacher as the linear improvement if n is large.

Explain the mirror idea with a picture: the palindrome around the mirror reappears, clipped by the right edge.

Mention the alternatives: DP table, hashing, palindromic tree.

Follow-ups: return all palindromic substrings; count them; check many substrings; minimum cuts; streaming.
Edge cases: single character, all equal characters, no repeated characters, even-length

palindrome at the string's end.

CHAPTER SUMMARY

Manacher computes the palindrome radius at every centre in O(n) using the rightmost palindrome [l, r] and mirror centres.

Use two arrays, d1 for odd and d2 for even palindromes, or insert separators to unify them.

sum(d1) + sum(d2) counts all palindromic substrings; max(2 d1 - 1, 2 d2) gives the longest.

Palindrome queries become O(1): compare the radius at the centre with half the length.

Expand around centre is the interview baseline; Manacher is the answer to "can you do it in linear time?".
