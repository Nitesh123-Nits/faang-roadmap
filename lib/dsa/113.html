Sparse Table and Range Queries

O(1) range minimum, maximum and gcd on static data using overlapping power-of-two blocks.

A. Pattern Overview

A sparse table precomputes the answer for every interval whose length is a power of two: st[k][i] summarises a[i .. i + 2^k - 1]. It is built in O(n log n) by doubling (st[k][i] = op(st[k-1][i], st[k-1][i + 2^(k-1)])). For an idempotent operation (op(x, x) = x: min, max, gcd, AND, OR), any query [l, r] is answered by two overlapping blocks, so the overlap does no harm and the query is O(1).

KEY IDEA

Sparse tables are for static arrays with many queries. One update means rebuilding, so choose a segment tree when the data changes.

B. When to Recognize This Pattern

Pattern Recognition Signals

Millions of range min/max/gcd queries on an array that never changes.
Lowest common ancestor with many queries (Euler tour + range minimum on depth).
An inner loop that needs the min/max of a[i..j] for every (i, j) (sliding variants, "longest subarray with max - min <= limit").
Binary search on the right endpoint where the feasibility check is a range statistic.
gcd of subarrays: gcd is idempotent and fits the structure.
ONE-LINE TEST

Static array, many range min/max/gcd queries: precompute powers of two and answer in O(1).

C. Core Intuition with Illustrations

The table

For a = [5, 2, 4, 7, 6, 3, 1, 2] the row for k lists the minimum of every window of length 2^k. Row k has n - 2^k + 1 entries; the table has floor(log2 n) + 1 rows.

Figure 147. Row k holds the minimum of each window of length 2^k.

The O(1) query

For [l, r] let k = floor(log2(r - l + 1)). The answer is op(st[k][l], st[k][r - 2^k + 1]). The two blocks cover the whole range and overlap in the middle; for min/max/gcd that duplication is harmless.

Computing floor(log2) in O(1)

31 - Integer.numberOfLeadingZeros(len) is a single instruction on modern CPUs. Avoid Math.log (floating point) in a hot loop.

LCA by Euler tour

Walk the tree depth-first and record every node on entering and after returning from each child; the sequence has 2n - 1 entries. Store each node's first position. lca(u, v) is the node with the minimum depth between the first occurrences of u and v, which is a range-minimum query: O(n log n) build, O(1) per LCA. Compare with binary lifting in Chapter 45 (O(log n) per query, O(n log n) build, easier with parent arrays).

TRAP

Sparse tables do not answer sums: overlapping blocks would count the middle twice. For associative non-idempotent operations use a disjoint sparse table or a segment tree.

E. Java Implementation

Generic sparse table with min, max and gcd factories

SparseTable.java: idempotent range queries in O(1)
import java.util.function.IntBinaryOperator;

/** Ch 98: sparse table for idempotent operations (min, max, gcd), O(1) queries. */
public class SparseTable {
    private final int[][] table;       // table[k][i] covers [i, i + 2^k)
    private final int[] log;
    private final IntBinaryOperator op;

    public SparseTable(int[] a, IntBinaryOperator op) {
        int n = a.length;
        this.op = op;

Java 17+

        log = new int[n + 2];
        for (int i = 2; i <= n + 1; i++) log[i] = log[i >> 1] + 1;
        int levels = log[Math.max(1, n)] + 1;
        table = new int[levels][];
        table[0] = a.clone();
        for (int k = 1; k < levels; k++) {
            int len = n - (1 << k) + 1;
            table[k] = new int[Math.max(0, len)];
            for (int i = 0; i < len; i++)
                table[k][i] =
                        op.applyAsInt(table[k - 1][i],
                                table[k - 1][i + (1 << (k - 1))]);
        }
    }

    public static SparseTable min(int[] a) {
        return new SparseTable(a, Math::min);
    }

    public static SparseTable max(int[] a) {
        return new SparseTable(a, Math::max);
    }

    public static SparseTable gcd(int[] a) {
        return new SparseTable(a, SparseTable::gcdOf);
    }

    static int gcdOf(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return Math.abs(a);
    }

    /** Combines [l, r] inclusive with two overlapping power-of-two blocks. */
    public int query(int l, int r) {
        int k = log[r - l + 1];
        return op.applyAsInt(table[k][l], table[k][r - (1 << k) + 1]);
    }
}

/** Ch 98: sparse table applications: LCA by Euler tour, longest balanced window. */
public class SparseApps {
    /**
     * LCA queries on a rooted tree (parent array, root 0) via Euler tour and RMQ.

        private final SparseTable rmq;        // min over (depth * n + node) keys
        private final int n;

                    if (v == parent[u]) continue;
                    parent[v] = u;

                    first[v] = euler.size();
                    euler.add(v);
                    st.push(v);
                } else {
                    st.pop();
                    if (!st.isEmpty()) euler.add(st.peek());
                }
            }
            int[] keys = new int[euler.size()];
            for (int i = 0; i < keys.length; i++) {
                int v = euler.get(i);
                keys[i] = depth[v] * n + v;
            }
            rmq = SparseTable.min(keys);
        }

        public int lca(int u, int v) {
            int l = Math.min(first[u], first[v]), r = Math.max(first[u], first[v]);
            return rmq.query(l, r) % n;
        }
    }

    /** LeetCode 1438: longest window with max - min <= limit, two sparse tables. */
    public static int longestSubarray(int[] nums, int limit) {
        SparseTable mx = SparseTable.max(nums), mn = SparseTable.min(nums);
        int best = 0, l = 0;
        for (int r = 0; r < nums.length; r++) {
            while (mx.query(l, r) - mn.query(l, r) > limit) l++;
            best = Math.max(best, r - l + 1);
        }
        return best;
    }

    /**
     * Number of subarrays whose gcd equals k (LeetCode 2447) using a range gcd
     * table.
     */
    public static int subarrayGCD(int[] nums, int k) {
        SparseTable g = SparseTable.gcd(nums);
        int count = 0;
        for (int i = 0; i < nums.length; i++)
            for (int j = i; j < nums.length; j++) {
                int v = g.query(i, j);
                if (v == k) count++;
                if (v < k) break;
            }
        return count;
    }
}

TIME O(n log n) build, O(1) query

SPACE O(n log n)

Memory is n (floor(log2 n) + 1) ints: about 17 MB for n = 10^6. Use int arrays, not boxed objects.

F. Detailed Dry Run

SparseTable.min([5, 2, 4, 7, 6, 3, 1, 2]).query(2, 6): len = 5, k = 2. Left block covers indices 2..5 with minimum 3, right block covers 3..6 with minimum 1. The overlap 3..5 is counted twice, which is harmless for min. Answer 1.

longestSubarray([8, 2, 4, 7], limit = 4): for start i, the maximal end j with max(a[i..j]) - min(a[i..j]) <= 4 is found by binary search using two sparse tables (one max, one min). Starts: i = 0 fails at j = 1 (8 - 2 = 6), so length 1; i = 1: [2, 4] has range 2, adding 7 gives 5 > 4, length 2; i = 2: [4, 7] range 3, length 2; i = 3: length 1. Answer 2.

G. Variations of the Pattern

Disjoint sparse table

For any associative operation (sum, product) split each level at block midpoints and store running aggregates away from the midpoint; every query needs exactly one level, no overlap, O(1). Build O(n log n).

Binary search on top of RMQ

A monotone predicate over [i, j] (the range statistic grows with j) allows per-start binary search with O(1) queries: O(n log n) total.

Range mode, majority and frequency

Not idempotent. Use randomised sampling plus position lists (Online Majority Element in Subarray) or sqrt decomposition.

Sliding-window alternative

If all queries are windows of one fixed length, a monotonic deque (Chapter 8) is O(n) and uses less memory.

2D sparse table

Blocks of 2^a x 2^b; O(m n log m log n) memory. Rare in interviews; named for completeness.

J. Interview Tips

INTERVIEW

State the precondition: static array, idempotent operation, many queries.

Draw the two overlapping blocks for a length-5 query; the picture is the proof.

Offer the alternative (segment tree if updates appear, deque if the window length is fixed).

Follow-ups: updates (segment tree), memory limits (sqrt tree, block decomposition), range sums (prefix sums), LCA with updates (link-cut / heavy-light).

CHAPTER SUMMARY

A sparse table stores st[k][i] = op(a[i .. i + 2^k - 1]) and is built by doubling in O(n log n).

Two overlapping blocks answer any query in O(1) when the operation is idempotent (min, max, gcd, AND, OR).

It cannot handle updates or sums; use a segment tree or prefix sums instead.

Euler tour + RMQ gives O(1) lowest common ancestor queries after O(n log n) preprocessing.

Compute floor(log2) with numberOfLeadingZeros, never with floating point.
