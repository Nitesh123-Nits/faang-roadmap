Graph Representation

Pick the right storage first; every graph algorithm follows from it.

A. Pattern Overview

A graph G = (V, E) is a set of vertices and a set of edges between them. Trees, grids, linked lists, state machines, dependency lists, road maps and social networks are all graphs; the first step in a graph problem is to name the vertices and the edges, and the second is to store them so the algorithm you need is cheap.

KEY IDEA

Default to an adjacency list. A matrix costs n² memory: 10⁵ vertices would need 10¹⁰ cells. Use it only when n is small or the graph is dense and you need O(1) edge lookups.

B. When to Recognize This Pattern

Pattern Recognition Signals

Input is a list of pairs (edges[i] = [a, b]), prerequisites, trust relations, equations, accounts, or flights: build an adjacency list.
Input is a matrix isConnected[i][j]: it already is the adjacency matrix.
Input is a grid or a board of states: the graph is implicit; neighbours are computed (Chapter 55).
Statement says "connected", "reachable", "dependency", "network", "friends of

friends", "minimum number of moves".

A degree question ("who is trusted by everyone", "which node is the centre") needs only counters, not a graph at all.
ONE-LINE TEST

Before choosing an algorithm answer four questions: directed? weighted? may it contain cycles? how large are n and m?

An undirected graph gives a symmetric matrix. A directed one does not. Storing int weights in the matrix needs a sentinel for "no edge" (0 is a legal weight in many problems).

CSR (compressed sparse row)

ArrayContents
start[0, 2, 4, 6, 9, 10, 11, 12]

The neighbours of u are to[start[u] .. start[u + 1] − 1]. Two flat int[] arrays hold the whole graph: no Integer boxing, no per-vertex list objects. Competitive programmers and low-latency services use it; interviews rarely require it.

Degrees answer some questions without any traversal

Find the Town Judge (997): the judge has in-degree n − 1 and out-degree 0, so score[v] = in − out equals n − 1 only for the judge. Find Center of Star Graph (1791): the centre appears in every edge, so two edges are enough. Minimum Vertices to Reach All Nodes (1557): the answer is every vertex with in-degree 0 (in a DAG nothing else can reach them).

Cloning a graph

Clone Graph (133) is the canonical lesson in identity: a map original → copy serves as the visited set and lets every neighbour edge point to the right copy, even in a cyclic graph. Create the copy when the node is first discovered, not when it is popped, otherwise two neighbours can create two copies of the same node.

E. Java Implementation

Adjacency list, matrix and CSR builders; judge, centre, clone

GraphRepresentation.java: LeetCode 997, 1791, 133
import java.util.*;

/** Ch 46: adjacency list / matrix / edge list, plus LeetCode 997, 1791, 133. */
public class GraphRepresentation {

    /** Adjacency list for nodes 0..n-1; O(n + m) time and space. */
    public static List<List<Integer>> adjList(int n, int[][] edges,
                                              boolean directed) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            if (!directed) g.get(e[1]).add(e[0]);
        }
        return g;
    }

    /** Weighted adjacency list: entry = {neighbour, weight}. */
    public static List<List<int[]>> weightedAdjList(int n, int[][] edges,
                                                    boolean directed) {
        List<List<int[]>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(new int[] {e[1], e[2]});
            if (!directed) g.get(e[1]).add(new int[] {e[0], e[2]});
        }
        return g;
    }

    /** Adjacency matrix: O(n^2) space, O(1) edge test. Parallel edges collapse. */
    public static boolean[][] adjMatrix(int n, int[][] edges, boolean directed) {
        boolean[][] m = new boolean[n][n];
        for (int[] e : edges) {
            m[e[0]][e[1]] = true;
            if (!directed) m[e[1]][e[0]] = true;
        }
        return m;
    }

    /** Compact static graph (CSR): two int arrays, cache friendly, no objects. */
    public static int[][] csr(int n, int[][] edges, boolean directed) {
        int[] start = new int[n + 1];
        for (int[] e : edges) {
            start[e[0] + 1]++;
            if (!directed) start[e[1] + 1]++;
        }
        for (int i = 0; i < n; i++) start[i + 1] += start[i];
        int[] fill = Arrays.copyOf(start, n);
        int[] to = new int[start[n]];
        for (int[] e : edges) {
            to[fill[e[0]]++] = e[1];
            if (!directed) to[fill[e[1]]++] = e[0];
        }
        return new int[][] {start, to};
    }

    /** LeetCode 997: the judge trusts nobody and is trusted by the other n - 1. */
    public static int findJudge(int n, int[][] trust) {
        int[] score = new int[n + 1];                  // in-degree minus out-degree
        for (int[] t : trust) {

Java 17+

            score[t[0]]--;
            score[t[1]]++;
        }
        for (int v = 1; v <= n; v++) if (score[v] == n - 1) return v;
        return -1;
    }

    /** LeetCode 1791: in a star the centre appears in every edge. */
    public static int findCenter(int[][] edges) {
        int a = edges[0][0], b = edges[0][1];
        return a == edges[1][0] || a == edges[1][1] ? a : b;
    }

    /** LeetCode 133 node. */
    public static class Node {
        public int val;
        public List<Node> neighbors = new ArrayList<>();
        public Node(int val) { this.val = val; }
    }

    /**
     * LeetCode 133: DFS with a map original -> copy (the map doubles as visited).
     */
    public static Node cloneGraph(Node start) {
        if (start == null) return null;
        Map<Node, Node> copy = new HashMap<>();
        Deque<Node> stack = new ArrayDeque<>();
        copy.put(start, new Node(start.val));
        stack.push(start);
        while (!stack.isEmpty()) {
            Node cur = stack.pop();
            for (Node nb : cur.neighbors) {
                if (!copy.containsKey(nb)) {
                    copy.put(nb, new Node(nb.val));
                    stack.push(nb);
                }
                copy.get(cur).neighbors.add(copy.get(nb));
            }
        }
        return copy.get(start);
    }
}

TIME O(n + m)

SPACE O(n + m)

The builders touch each edge once. adjMatrix is O(n²) space. The clone uses an explicit stack so a long chain does not overflow the call stack.

F. Detailed Dry Run

The three tables in section C are generated from the sample graph. Verify one entry by hand: vertex 3 touches edges 1–3, 2–3 and 3–4, so its list is [1, 2, 4], its matrix row has ones in columns 1, 2, 4, and in CSR start[3] = 6, start[4] = 9, so the slice to[6..8] = [1, 2, 4] is its neighbourhood.

For Town Judge with n = 3, trust = [[1,3],[2,3]]: score[1] = −1, score[2] = −1, score[3] = +2 = n − 1, so the judge is 3. With an extra trust [3,1], score[3] = 1 ≠ 2, so the answer becomes −1.

G. Variations of the Pattern

Implicit graphs

Word Ladder, Open the Lock and sliding puzzles define vertices as states and edges as one move. You never build the list: generate neighbours on demand and keep a visited set of states.

Graph from relations

Evaluate Division (399): variables are vertices, each equation a / b = k is an edge with weight k (and 1/k backwards). Accounts Merge: connect emails that share an account.

Bipartite or layered views

Possible Bipartition (Chapter 57), Jump Game variants (vertices = indices, edges = jumps).

Trees as graphs

Reorder Routes (1466): an undirected tree where each stored direction is a cost. Store each edge as (neighbour, needsFlip) and do one traversal from city 0.

Eulerian trails

Reconstruct Itinerary (332) is an Eulerian path: use every edge exactly once. Hierholzer's algorithm builds it with DFS, appending vertices in postorder and reversing.

J. Interview Tips

INTERVIEW

Say the four questions aloud (directed, weighted, cyclic, size) and the representation you choose, with its memory cost.

State the input encoding: nodes 0..n−1 or 1..n, duplicates, self-loops, disconnected graphs.

Reach for degrees first when the question is about a counting property; it avoids building anything.

Follow-ups: memory-tight storage (CSR); a graph that changes (adjacency sets); a graph

too big for memory (edge streaming, external sort); undirected versus directed storage.

Edge cases: n = 1, no edges, duplicate edges, self-loops, disconnected input, vertices numbered from 1.

CHAPTER SUMMARY

A graph is vertices + edges; define both before choosing an algorithm. Ask: directed? weighted? cyclic? how big?

Adjacency list by default (O(n + m)); matrix only for small or dense graphs; edge list for Kruskal and Bellman-Ford; implicit for grids and state spaces.

Undirected edges are stored twice; allocate all n vertices so isolated ones exist.

Degrees solve judge / centre / source-vertex questions without traversal.

Cloning needs a map original → copy; create the copy on first discovery.
