Sorting and comparators

Java sorts primitives and objects with different algorithms (see Chapter M2), but the code you write is the same: Arrays.sort for arrays, List.sort for lists. For objects, supply a Comparator. Build it with Comparator.comparingInt(...).thenComparing(...), which is readable and cannot overflow.

THE OVERFLOW TRAP

Never write (a, b) -> a - b. For a = Integer.MAX_VALUE and b = -1 the subtraction overflows to a negative number, the comparator answers the wrong way, and the sort silently produces a wrong order (or TimSort throws "Comparison method violates its general contract"). Use Integer.compare(a, b). The toolkit includes a function that detects exactly when subtraction breaks.

PriorityQueue: min-heap, max-heap and custom objects

PriorityQueue is a binary min-heap. offer and poll cost O(log n), peek costs O(1). For a max-heap pass Comparator.reverseOrder(). For your own objects, either implement

Comparable (as the record Job does below) or pass a comparator for one field. A heap of int[]

pairs is the usual shape for Dijkstra and top-k problems.

No decrease-key. To change a priority, insert a new entry and ignore the stale one when it surfaces (lazy deletion). remove(Object) is O(n).
Never mutate a field that determines the ordering while the object is inside the heap.

The heap will not notice.

The iterator and toString are not sorted. Poll repeatedly to read in order.
Build from a collection with the constructor for O(n) heapify instead of n offers.

import java.util.*;

/** Toolkit: PriorityQueue as min-heap, max-heap and heap of custom objects. */
public class ToolkitHeaps {

    /** Min-heap is the default. */
    public static PriorityQueue<Integer> minHeap() {
        return new PriorityQueue<>();
    }

    /** Max-heap: reverse the natural order (never write (a, b) -> b - a). */
    public static PriorityQueue<Integer> maxHeap() {
        return new PriorityQueue<>(Comparator.reverseOrder());
    }

    /** Bulk construction from a collection is O(n), not O(n log n). */
    public static PriorityQueue<Integer> heapify(Collection<Integer> values) {
        return new PriorityQueue<>(values);
    }

    /** k-th largest: keep a min-heap of the k largest values seen so far. */
    public static int kthLargest(int[] nums, int k) {
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        for (int x : nums) {
            heap.offer(x);
            if (heap.size() > k) heap.poll();
        }
        return heap.peek();
    }

    /** Custom object: higher priority first, earlier arrival breaks ties. */
    public record Job(int id, int priority, int arrival)
            implements Comparable<Job> {
        @Override
        public int compareTo(Job o) {
            if (priority != o.priority)
                return Integer.compare(o.priority, priority);
            return Integer.compare(arrival, o.arrival);
        }
    }

    /** Ids in the order a worker would run them. */
    public static List<Integer> runOrder(List<Job> jobs) {
        PriorityQueue<Job> heap = new PriorityQueue<>(jobs);
        List<Integer> order = new ArrayList<>();
        while (!heap.isEmpty()) order.add(heap.poll().id());
        return order;
    }

    /** Heap of int[]{node, dist}: compare one field with Integer.compare. */
    public static PriorityQueue<int[]> distanceHeap() {
        return new PriorityQueue<>((a, b) -> Integer.compare(a[1], b[1]));
    }

    public static Map<Integer, Integer> frequency(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();

        return freq;
    }

    /** Lowercase letters only: a plain array is faster and needs no boxing. */
    public static int[] letterCounts(String s) {
        int[] count = new int[26];
        for (int i = 0; i < s.length(); i++) count[s.charAt(i) - 'a']++;
        return count;
    }

    // ------------------------------------------------------- ArrayDeque as stack
    /** Valid brackets, ArrayDeque as a stack: push / pop / peek at the head. */
    public static boolean validBrackets(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            switch (c) {
                case '(' -> stack.push(')');
                case '[' -> stack.push(']');
                case '{' -> stack.push('}');
                default -> {
                    if (stack.isEmpty() || stack.pop() != c) return false;
                }
            }
        }
        return stack.isEmpty();
    }

    // ------------------------------------------------------ ArrayDeque as queue
    /** BFS distances: offer at the tail, poll from the head. */
    public static int[] bfsDistances(List<List<Integer>> graph, int source) {
        int[] dist = new int[graph.size()];
        Arrays.fill(dist, -1);
        Deque<Integer> queue = new ArrayDeque<>();
        dist[source] = 0;
        queue.offer(source);
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph.get(u)) {
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    queue.offer(v);
                }
            }
        }
        return dist;
    }

    /** Array-based "forward star": no object per edge, good for large graphs. */
    public static final class ForwardStar {
        private final int[] head, next, to;
        private int edges = 0;

        public ForwardStar(int vertices, int maxEdges) {
            head = new int[vertices];
            Arrays.fill(head, -1);
            next = new int[maxEdges];
            to = new int[maxEdges];
        }

        public void addEdge(int u, int v) {
            to[edges] = v;
            next[edges] = head[u];
            head[u] = edges++;
        }

        public List<Integer> neighbours(int u) {
            List<Integer> out = new ArrayList<>();
            for (int e = head[u]; e != -1; e = next[e]) out.add(to[e]);
            return out;
        }
    }

    public static List<String> binaryStrings(int n) {
        List<String> out = new ArrayList<>();
        build(n, new StringBuilder(), out);
        return out;
    }

    private static void build(int n, StringBuilder sb, List<String> out) {
        if (sb.length() == n) {
            out.add(sb.toString());
            return;
        }
        for (char c = '0'; c <= '1'; c++) {
            sb.append(c);
            build(n, sb, out);
            sb.setLength(sb.length() - 1);
        }
    }

TWO QUIET BUGS

Arrays.asList(...) and List.of(...) are fixed-size / immutable: add throws. Wrap them in new ArrayList<>(...) when you need to modify the list. Compare boxed values with equals: Integer objects between -128 and 127 are cached, so == appears to work for small numbers and fails for larger ones.

Safe midpoint and integer overflow prevention

(lo + hi) / 2 overflows when lo + hi exceeds Integer.MAX_VALUE. Binary search on a large range is the classic place it bites (a famous bug lived in the JDK's own binary search for years). Use lo + (hi - lo) / 2, which is safe whenever hi - lo fits in an int, or compute in long for the general case.

/** Toolkit: safe midpoint, overflow prevention, modular helpers. */
public class ToolkitMath {

    /** Floor midpoint of lo <= hi when hi - lo fits in an int. */
    public static int mid(int lo, int hi) {
        return lo + (hi - lo) / 2;
    }

    /** Floor midpoint for any pair of ints, even lo < 0 < hi near the limits. */
    public static int midAny(int lo, int hi) {
        return (int) (((long) lo + hi) >> 1);
    }

    /** Floor of (a + b) / 2 using only int operations (no overflow). */
    public static int floorAverage(int a, int b) {
        return (a & b) + ((a ^ b) >> 1);
    }

    /** Throws ArithmeticException instead of silently wrapping around. */
    public static int addExact(int a, int b) {
        return Math.addExact(a, b);
    }

    /** Saturating add: clamps at the int limits instead of wrapping. */
    public static int saturatingAdd(int a, int b) {
        long sum = (long) a + b;
        if (sum > Integer.MAX_VALUE) return Integer.MAX_VALUE;
        if (sum < Integer.MIN_VALUE) return Integer.MIN_VALUE;
        return (int) sum;
    }

    /** Sum of an int array without overflow: accumulate in long. */
    public static long sum(int[] a) {
        long s = 0;
        for (int x : a) s += x;
        return s;
    }

    /** True if a * b does not fit in a long. */

        try {
            Math.multiplyExact(a, b);
            return false;

Fast input and output

For inputs of a few thousand numbers, Scanner is fine. For 10⁵ to 10⁶ numbers it becomes the bottleneck because it parses with regular expressions. Read bytes through a large buffer and parse integers yourself, and write through a PrintWriter wrapped around a BufferedWriter, flushing once at the end. Interview platforms rarely need this, but online judges and timed contests do.

Output: collect lines in a StringBuilder or a buffered PrintWriter; do not call

System.out.println a million times.

Input: one read call fills a 64 KiB buffer; the parser walks it byte by byte.
Always flush the writer before the program ends, or the last output is lost.

    private final byte[] buf = new byte[1 << 16];
    private int len = 0, ptr = 0;

    public FastIO(InputStream in) {
        this.in = in;

    private int read() throws IOException {
        if (ptr == len) {
            len = in.read(buf, 0, buf.length);
            ptr = 0;
            if (len <= 0) {
                len = 0;
                return -1;
            }
        }
        return buf[ptr++];

    public long nextLong() throws IOException {
        int c = read();
        while (c != '-' && (c < '0' || c > '9')) {
            if (c == -1) throw new EOFException("no more numbers");
            c = read();
        }
        boolean negative = false;
        if (c == '-') {
            negative = true;
            c = read();
        }
        long x = 0;
        while (c >= '0' && c <= '9') {
            x = x * 10 + (c - '0');
            c = read();
        }
        return negative ? -x : x;
    }

    public int nextInt() throws IOException {
        return (int) nextLong();
    }

    /** Next whitespace-separated token, or null at end of input. */
    public String next() throws IOException {
        int c = read();
        while (c != -1 && c <= ' ') c = read();
        if (c == -1) return null;
        StringBuilder sb = new StringBuilder();
        while (c > ' ') {
            sb.append((char) c);
            c = read();
        }
        return sb.toString();
    }

    public int[] nextInts(int n) throws IOException {
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = nextInt();
        return a;
    }

Disjoint set union and trie

These two structures are short enough to write from memory. The DSU below uses path halving and union by size, which together give almost constant amortised time (inverse Ackermann, Chapter 52). The trie stores one child array per node; add a count field for prefix counting (Chapter 94) or swap the array for a HashMap when the alphabet is large.

ToolkitDSU.java
/** Toolkit: disjoint set union with path compression and union by size. */
public class ToolkitDSU {
    private final int[] parent, size;
    private int components;

    public ToolkitDSU(int n) {
        parent = new int[n];
        size = new int[n];
        components = n;
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
        }
    }

    /** Root of x; path halving keeps the trees shallow. */
    public int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    /** Merges the sets of a and b; false if they were already together. */
    public boolean union(int a, int b) {
        int ra = find(a), rb = find(b);

/** Toolkit: lowercase-letter trie with insert, search and prefix queries. */
public class ToolkitTrie {
    private static final class Node {
        final Node[] child = new Node[26];
        boolean word;
    }

    private final Node root = new Node();

    public void insert(String s) {
        Node cur = root;
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            if (cur.child[c] == null) cur.child[c] = new Node();
            cur = cur.child[c];
        }
        cur.word = true;
    }

    private Node walk(String s) {
        Node cur = root;
        for (int i = 0; i < s.length() && cur != null; i++)
            cur = cur.child[s.charAt(i) - 'a'];
        return cur;
    }

    public boolean contains(String s) {
        Node n = walk(s);
        return n != null && n.word;
    }

    /** True if some inserted word starts with prefix; "" always matches. */
    public boolean startsWith(String prefix) {
        return walk(prefix) != null;
    }
}

public class TreeNode {

    public TreeNode left, right;

    public TreeNode(int val) { this.val = val; }

    public TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }

    /**
     * Builds a tree from level-order values, e.g. {3, 9, 20, null, null, 15, 7}.
     */
    public static TreeNode fromLevelOrder(Integer... vals) {
        if (vals.length == 0 || vals[0] == null) return null;
        TreeNode root = new TreeNode(vals[0]);
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);
        int i = 1;
        while (!queue.isEmpty() && i < vals.length) {
            TreeNode node = queue.poll();
            if (i < vals.length && vals[i] != null) {
                node.left = new TreeNode(vals[i]);
                queue.add(node.left);
            }
            i++;
            if (i < vals.length && vals[i] != null) {
                node.right = new TreeNode(vals[i]);
                queue.add(node.right);
            }
            i++;
        }
        return root;
    }

    /**
     * Level-order values with trailing nulls removed (the inverse of {@link
     * #fromLevelOrder}).
     */
    public static List<Integer> toLevelOrder(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        // LinkedList, not ArrayDeque: the queue holds null placeholders

            TreeNode node = queue.poll();

            out.add(node.val);

/** Singly linked list node shared by every list chapter. */
public class ListNode {
    public int val;
    public ListNode next;

    public ListNode(int val) {
        this.val = val;
    }

    public ListNode(int val, ListNode next) {
        this.val = val;
        this.next = next;
    }

    /** Builds 1 -> 2 -> 3 from of(1, 2, 3); returns null when no values are given. */
    public static ListNode of(int... vals) {
        ListNode dummy = new ListNode(0), tail = dummy;
        for (int v : vals) {
            tail.next = new ListNode(v);
            tail = tail.next;
        }
        return dummy.next;
    }

    /** Copies the values into an array (the list must be acyclic). */
    public static int[] toArray(ListNode head) {
        int n = 0;
        for (ListNode c = head; c != null; c = c.next) n++;
        int[] a = new int[n];
        int i = 0;
        for (ListNode c = head; c != null; c = c.next) a[i++] = c.val;
        return a;
    }

CHAPTER SUMMARY

Compare with Integer.compare or Comparator.comparingInt, never subtraction.

PriorityQueue is a min-heap; reverse the comparator for a max-heap; there is no decrease-key, so use lazy deletion.

ArrayDeque is both your stack and your queue; merge counts frequencies; records make clean pair keys.

Compute midpoints as lo + (hi - lo) / 2, accumulate sums in long, and use Math.floorMod and Math.addExact where signs or overflow matter.

Buffered input and a flushed PrintWriter are the only fast I/O you need.
