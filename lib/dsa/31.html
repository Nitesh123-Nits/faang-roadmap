In-Place List Manipulation

Dummy heads, pointer surgery, deep copies and design: the toolkit for everything else.

A. Pattern Overview

The previous three chapters taught named techniques. Most remaining list problems are pointer surgery: delete nodes, regroup them, copy a structure with extra pointers, flatten a nested one, or build the list class itself. They share one toolkit: a dummy head, the save / relink / advance rule, and, when a problem looks hard, a composition of the earlier patterns.

KEY IDEA

The sentinel principle. A dummy node in front of the head (or a sentinel at each end of a doubly linked list) means every real node has a predecessor. Deleting or inserting at the head, in an empty list, or at the tail is then identical to the general case.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Remove all nodes with value x", remove duplicates, remove a node: dummy head and a

prev pointer.

"Group the odd-indexed nodes together", segregate, split into parts: independent chains, then concatenate (like Partition in Chapter 23).
"Rearrange as L0 → Ln → L1 → Ln−1 …": it is Fast / Slow + Reverse + Merge: recognise the

composition.

"Deep copy" of a structure whose nodes have extra pointers (random, child): you need an original → copy mapping, in a map or in the structure itself.
"Flatten" a list whose nodes may carry nested lists: splice, do not copy.
"Implement a linked list / LRU / queue": write the node class and the sentinel-based operations.
DECOMPOSE FIRST

If you can name the three earlier patterns hiding in a hard-looking list problem (fast / slow, reverse, merge), the problem usually becomes three short loops.

C. Core Intuition with Illustrations

A dummy head makes deletion uniform

When the head itself may be deleted (for example removing 6 from 6 → 6 → 1 → 6), a bare

head pointer needs a special loop first. With dummy → head, the same prev.next =

prev.next.next handles every position. Do not advance prev after a deletion: the new prev.next has not been examined yet.

Figure 47. Grey nodes are skipped by the arc. The head (a 6) was deleted without any special case.

Compose patterns: Reorder List

1 → 2 → 3 → 4 → 5 becomes 1 → 5 → 2 → 4 → 3. Find the first middle, reverse the second

half, then interleave the two halves. Each step is a pattern you already know.

Figure 48. Two halves, one reversed, then zipped: O(n) time and O(1) space.

Deep copy by weaving

To copy a list whose nodes also have a random pointer, you must know, for any original node, where its copy is. A HashMap<Node, Node> answers that in O(n) space. The O(1)-space trick stores the answer inside the list: place each copy right after its original, so original.next is its copy.

Figure 49. The next pointer doubles as the original-to-copy map. The third pass must restore the original list.

Flatten: splice the child between a node and its next

For each node with a child, find the tail of the child list, connect tail.next to the node's old next, connect the node to the child, and null the child pointer. Nested children are handled automatically because the loop continues into the spliced nodes.

E. Java Implementation

Delete by value, with a dummy head

RemoveDuplicates.java: LeetCode 203, 83, 82
/** LeetCode 203 / 83 / 82 - delete nodes by value with a dummy head. */
public class RemoveDuplicates {

    /** 203: remove every node whose value equals val. */
    public static ListNode removeElements(ListNode head, int val) {
        ListNode dummy = new ListNode(0, head), prev = dummy;
        while (prev.next != null) {
            if (prev.next.val == val) {
                prev.next = prev.next.next;              // unlink; stay on prev
            } else {
                prev = prev.next;
            }
        }
        return dummy.next;
    }

    /** 83: keep one copy of each value in a sorted list. */
    public static ListNode keepOne(ListNode head) {
        for (ListNode cur = head; cur != null && cur.next != null; ) {
            if (cur.val == cur.next.val) {
                cur.next = cur.next.next;
            } else {
                cur = cur.next;
            }
        }
        return head;
    }

    /** 82: drop every value that appears more than once in a sorted list. */
    public static ListNode removeAllDuplicated(ListNode head) {
        ListNode dummy = new ListNode(0, head), prev = dummy, cur = head;
        while (cur != null) {
            if (cur.next != null && cur.next.val == cur.val) {
                int v = cur.val;
                while (cur != null && cur.val == v) {
                    cur = cur.next;                      // skip the whole run
                }
                prev.next = cur;
            } else {
                prev = cur;
                cur = cur.next;
            }
        }
        return dummy.next;
    }
}

Java 17+

TIME O(n)

SPACE O(1)

In 203 stay on prev after unlinking. In 82 skip the whole run, then decide whether to keep cur using the next node.

Odd Even Linked List

OddEvenList.java: LeetCode 328

Java 17+

/** LeetCode 328 - Odd Even Linked List: group by POSITION (not value), keeping order. */
public class OddEvenList {

    public static ListNode oddEvenList(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode odd = head, even = head.next, evenHead = even;
        while (even != null && even.next != null) {
            odd.next = even.next;                        // odd chain skips an even node
            odd = odd.next;
            even.next = odd.next;                        // even chain skips an odd node
            even = even.next;
        }
        odd.next = evenHead;                             // append the even chain
        return head;
    }
}

TIME O(n)

SPACE O(1)

Positions, not values. Remember evenHead before the loop: it is lost otherwise.

Reorder List

ReorderList.java: LeetCode 143

Java 17+

/** LeetCode 143 - Reorder List: L0 -> Ln -> L1 -> Ln-1 ... = middle + reverse + interleave. */
public class ReorderList {

    public static void reorderList(ListNode head) {
        if (head == null || head.next == null) return;
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode second = reverse(slow.next);            // reverse the second half
        slow.next = null;                                // detach it from the first half
        ListNode first = head;
        while (second != null) {                         // the second half is never longer
            ListNode n1 = first.next, n2 = second.next;
            first.next = second;
            second.next = n1;
            first = n1;
            second = n2;
        }
    }

    private static ListNode reverse(ListNode head) {
        ListNode prev = null;
        while (head != null) {
            ListNode nxt = head.next;
            head.next = prev;
            prev = head;
            head = nxt;
        }
        return prev;
    }
}

TIME O(n)

SPACE O(1)

slow.next = null before interleaving: without the cut, the first half still points into the reversed half.

Copy List with Random Pointer

CopyRandomList.java: LeetCode 138

Java 17+

import java.util.HashMap;
import java.util.Map;

/**
 * LeetCode 138 - Copy List with Random Pointer: hash map version and O(1)-space interleaving.
 */
public class CopyRandomList {

    public static class Node {
        public int val;
        public Node next, random;

        public Node(int val) {
            this.val = val;
        }
    }

    /** O(n) time, O(n) space: map every original node to its copy. */
    public static Node copyWithMap(Node head) {
        Map<Node, Node> copyOf = new HashMap<>();
        for (Node c = head; c != null; c = c.next) copyOf.put(c, new Node(c.val));
        for (Node c = head; c != null; c = c.next) {
            copyOf.get(c).next = copyOf.get(c.next);     // get(null) is null: handles the tail
            copyOf.get(c).random = copyOf.get(c.random);
        }
        return copyOf.get(head);
    }

    /**
     * O(n) time, O(1) extra space: weave A -> A' -> B -> B' ..., set randoms, then unweave.
     */
    public static Node copyInterleaved(Node head) {
        if (head == null) return null;
        for (Node c = head; c != null; c = c.next.next) {
            Node twin = new Node(c.val);
            twin.next = c.next;
            c.next = twin;                               // A -> A' -> B
        }
        for (Node c = head; c != null; c = c.next.next) {
            if (c.random != null) c.next.random = c.random.next;   // twin of the random target
        }
        Node copyHead = head.next;
        for (Node c = head; c != null; c = c.next) {
            Node twin = c.next;
            c.next = twin.next;                          // restore the original chain
            twin.next = (c.next != null) ? c.next.next : null;
        }
        return copyHead;
    }
}

TIME O(n)

SPACE O(n) map version, O(1) weave

version

The map version relies on get(null) == null. The weave version restores the original list in the third pass.

Flatten a Multilevel Doubly Linked List

FlattenMultilevel.java: LeetCode 430

Java 17+

/**
 * LeetCode 430 - Flatten a Multilevel Doubly Linked List (children spliced in after their
 * parent).
 */
public class FlattenMultilevel {

    public static class Node {
        public int val;
        public Node prev, next, child;

        public Node(int val) {
            this.val = val;
        }
    }

    public static Node flatten(Node head) {
        for (Node cur = head; cur != null; cur = cur.next) {
            if (cur.child == null) continue;
            Node child = cur.child, tail = child;
            while (tail.next != null) {
                tail = tail.next;                        // last node of the child list
            }
            tail.next = cur.next;                        // child list ... -> parent's old next
            if (cur.next != null) cur.next.prev = tail;
            cur.next = child;                            // parent -> child list
            child.prev = cur;
            cur.child = null;
        }
        return head;
    }
}

TIME O(n)

SPACE O(1)

Repair prev pointers on both splice points, and set child = null: the problem requires it.

G. Variations of the Pattern

Delete Node in a Linked List (given only that node)

You cannot reach the predecessor, so overwrite the node with its successor: copy node.next.val into node, then unlink the successor. It does not work for the tail, which the problem excludes.

Java: LeetCode 237
public static void deleteNode(ListNode node) {
    node.val = node.next.val;        // become the next node
    node.next = node.next.next;      // and drop the original next
}

Java 17+

TIME O(1)
SPACE O(1)

Constant time; works only because the node is not the tail.

Design Linked List

A singly linked list with get, addAtHead, addAtTail, addAtIndex, deleteAtIndex. A sentinel node plus a size counter and one helper, before(index), make every operation a two-line method.

MyLinkedList.java: LeetCode 707

Java 17+

/**
 * LeetCode 707 - Design Linked List: singly linked with a sentinel node and a size counter.
 */
public class MyLinkedList {

    private static class Node {
        int val;
        Node next;

        Node(int val) {
            this.val = val;
        }
    }

    private final Node sentinel = new Node(0);           // its next is the real head
    private int size;
    /** The node BEFORE position index (the sentinel when index == 0). */
    private Node before(int index) {
        Node p = sentinel;
        for (int i = 0; i < index; i++) {
            p = p.next;
        }
        return p;
    }

    public int get(int index) {
        return (index < 0 || index >= size) ? -1 : before(index).next.val;
    }

    public void addAtHead(int val) {
        addAtIndex(0, val);
    }

    public void addAtTail(int val) {
        addAtIndex(size, val);
    }

    public void addAtIndex(int index, int val) {
        if (index > size) return;                        // out of range: ignored
        Node prev = before(Math.max(index, 0));
        Node node = new Node(val);
        node.next = prev.next;
        prev.next = node;
        size++;
    }

    public void deleteAtIndex(int index) {
        if (index < 0 || index >= size) return;
        Node prev = before(index);
        prev.next = prev.next.next;
        size--;
    }
}

TIME O(index) per operation, O(1) for

head operations

SPACE O(n)

before(index) returns the sentinel when index == 0. Keep a tail pointer to make addAtTail O(1) if asked.

Remove Zero Sum Consecutive Nodes

Prefix sums (Chapter 3) on a list: map each prefix sum to the last node having it; a repeated prefix means the nodes between sum to zero and can be skipped. Two passes with a dummy head, O(n) time and space.

Split Linked List in Parts

Count n, give every part n / k nodes and the first n % k parts one extra; cut each part by nulling its tail. It is arithmetic plus the cut-and-advance move.

Doubly linked lists and LRU Cache (preview)

A doubly linked list lets a node unlink itself in O(1): node.prev.next = node.next; node.next.prev = node.prev. Pair it with a HashMap from key to node and you have LRU Cache (Chapter 29), where both ends use sentinels.

Skip lists

Design Skiplist (1206, Hard) layers several sorted linked lists so that search jumps ahead on the upper layers: expected O(log n) search, insert and delete without balancing. It is the natural capstone for list pointer surgery.

J. Interview Tips

INTERVIEW

Draw the list with prev, cur, and the dummy before touching the keyboard. The bug is always a missed assignment order, and the picture shows it.

Name the sub-patterns when you see a composition: "this is middle, reverse, merge". It shows you decompose problems instead of memorising them.

For deep copy, give the map version first (clear, correct), then offer the O(1) weave as the optimisation; explain that you restore the original list.

Follow-ups: delete a node with a doubly linked list; remove duplicates from an unsorted

list (set) and in O(1) space (sort first, or nested loops); copy a graph (BFS / DFS with a map); detect that a flattened list has a cycle; reorder with k-spacing.

Edge cases: empty list, one node, all nodes equal, the head or tail removed, random pointing to itself or to null, a child list of one node, consecutive nodes with children.

CHAPTER SUMMARY

Dummy head + prev makes deletion and insertion uniform; after a deletion stay on prev, after a keep advance.

Pointer surgery always follows save, relink, advance; draw the assignments in order.

Compose patterns: Reorder List = middle + reverse + interleave; Odd Even = two chains + concatenate; k-group = locate + reverse + reconnect.

Deep copy: a map is simplest; weaving copies after originals stores the mapping in the list (O(1) space) and must be unwoven.

Flatten: splice each child list between its parent and the parent's next, repair prev, null child. Design: sentinel + size.
