Constraint-Based Backtracking

Sudoku, bucket filling, operators: prune hard, choose the tightest slot.

A. Pattern Overview

Constraint-based backtracking assigns values to variables (cells, buckets, operator slots)

under rules that couple the variables. The search tree is huge in principle (9⁵¹ for a Sudoku

with 51 blanks), but strong pruning and a good variable ordering make it fast in practice. Four techniques recur:

KEY IDEA

Prune with a necessary condition, not a hope. Every pruning rule here is a proof that no completion exists (sum not divisible by k, candidate set empty, bucket overflows). A rule that sometimes discards a valid branch is a bug, however fast it makes the program.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Fill the grid / assign items so that every constraint holds" (Sudoku, puzzles).
"Can the array be partitioned into k groups with equal sum?" with n ≤ 16: bucket filling

with pruning (or bitmask DP).

"Insert operators between digits to reach a target": a branching of 4 choices per gap.
"Count arrangements where each position satisfies a rule" (n ≤ 15): permutations with

pruning.

Small n with a hard feasibility rule; plain enumeration is hopeless, and DP needs a subset mask.
ONE-LINE TEST

A feasibility puzzle over a small set where each choice removes options from other variables is constraint backtracking. First find the pruning rules, then the branching order.

C. Core Intuition with Illustrations

Sudoku: candidates from three bitmasks

Keep row[9], col[9], box[9] ints; bit d − 1 is set when digit d is used. For an empty cell, candidates = ~(row[r] | col[c] | box[b]) & 0x1FF: one expression gives all legal digits. The box index is (r / 3) * 3 + c / 3.

Branch on the most constrained cell

At every step scan the empty cells and pick the one with the fewest candidates (Integer.bitCount). A cell with 0 candidates is an immediate dead end; a cell with 1 is a forced move (no branching at all). On the classic puzzle below, all 51 moves turn out to be forced, so the solver never has to guess: the whole puzzle falls out by repeated singles.

Bucket filling: Partition to K Equal Sum Subsets

Total S must be divisible by k; each bucket target is S / k. Fill one bucket at a time: choose unused items until the bucket reaches the target, then start the next. Three prunings keep it fast: sort descending (large items fail early), skip equal neighbours (interchangeable items), and if the first item tried in an empty bucket fails, the whole branch fails (any other item would have to go there instead).

Matchsticks to Square: four buckets with symmetry

Same idea with k = 4 and the extra rule that equal-length sides are interchangeable: when trying side s, skip it if an earlier side currently has the same length (it would lead to an identical subtree).

Expression Add Operators: keep the open term

Between each pair of digits choose nothing, +, − or *. To evaluate in one pass, keep value (the total so far) and last (the signed term that a following * would multiply). Choosing * with operand cur replaces that term: value − last + last·cur, and the new last is last·cur. Use long; forbid operands with leading zeros.

E. Java Implementation

Sudoku solver

SudokuSolver.java: LeetCode 37

Java 17+

/**
 * LeetCode 37 - Sudoku Solver. Row / column / box bitmasks; always branch on the empty cell
 * with the fewest candidates.
 */
public class SudokuSolver {
    public static boolean solve(char[][] board) {
        int[] row = new int[9], col = new int[9], box = new int[9];
        for (int r = 0; r < 9; r++)
            for (int c = 0; c < 9; c++)
                if (board[r][c] != '.') {
                    int bit = 1 << (board[r][c] - '1');
                    row[r] |= bit; col[c] |= bit; box[boxOf(r, c)] |= bit;
                }
        return search(board, row, col, box);
    }

    private static int boxOf(int r, int c) { return r / 3 * 3 + c / 3; }

    private static boolean search(char[][] b, int[] row, int[] col, int[] box) {
        int bestR = -1, bestC = -1, bestMask = 0, bestCount = 10;
        for (int r = 0; r < 9; r++)
            for (int c = 0; c < 9; c++) {
                if (b[r][c] != '.') continue;
                int free = ~(row[r] | col[c] | box[boxOf(r, c)]) & 0x1FF;
                int count = Integer.bitCount(free);
                if (count < bestCount) { bestCount = count; bestR = r; bestC = c;
                        bestMask = free; }
            }
        if (bestR == -1) return true;                      // no empty cell left: solved
        // an empty cell with no candidate: dead end
        if (bestCount == 0) return false;
        for (int m = bestMask; m != 0; m &= m - 1) {
            int bit = m & -m;
            b[bestR][bestC] = (char) ('1' + Integer.numberOfTrailingZeros(bit));
            row[bestR] |= bit; col[bestC] |= bit; box[boxOf(bestR, bestC)] |= bit;
            if (search(b, row, col, box)) return true;
            row[bestR] &= ~bit; col[bestC] &= ~bit; box[boxOf(bestR,
                    bestC)] &= ~bit;
            b[bestR][bestC] = '.';
        }
        return false;
    }
}

TIME Exponential worst case

SPACE O(1) board + O(81) depth

Bitmasks give O(1) candidate sets; choosing the minimum-candidate cell costs a scan of 81 cells per node and dramatically reduces nodes.

Partition to K equal sum subsets

PartitionKSubsets.java: LeetCode 698

Java 17+

import java.util.Arrays;

/**
 * LeetCode 698 - Partition to K Equal Sum Subsets. Fill one bucket at a time; sort descending
 * so big items fail fast.
 */
public class PartitionKSubsets {
    public static boolean canPartitionKSubsets(int[] nums, int k) {
        int sum = Arrays.stream(nums).sum();
        if (sum % k != 0) return false;
        int target = sum / k;
        int[] a = Arrays.stream(nums).boxed().sorted((x,
                y) -> y - x).mapToInt(Integer::intValue).toArray();
        if (a[0] > target) return false;
        return fill(a, new boolean[a.length], k, 0, 0, target);
    }

    /**
     * Builds the current bucket from items at positions >= from; when it reaches target,
     * starts the next bucket.
     */
    private static boolean fill(int[] a, boolean[] used, int bucketsLeft, int from,
            int cur, int target) {
        // the remaining items must sum to target automatically
        if (bucketsLeft == 1) return true;
        if (cur == target) return fill(a, used, bucketsLeft - 1, 0, 0, target);
        for (int i = from; i < a.length; i++) {
            if (used[i] || cur + a[i] > target) continue;
            // equal items are interchangeable
            if (i > 0 && a[i] == a[i - 1] && !used[i - 1]) continue;
            used[i] = true;
            if (fill(a, used, bucketsLeft, i + 1, cur + a[i], target)) return true;
            used[i] = false;
            // the first item of an empty bucket failed: no placement works
            if (cur == 0) return false;
        }
        return false;
    }
}

TIME O(k · 2ⁿ) bound

SPACE O(n)

The recursion fills the current bucket from index from upwards (so each set is formed once); bucketsLeft == 1 returns true because the rest must automatically sum to the target.

Matchsticks to square

Matchsticks.java: LeetCode 473

Java 17+

import java.util.Arrays;

/**
 * LeetCode 473 - Matchsticks to Square. Place each stick (longest first) on one of four
 * sides.
 */
public class Matchsticks {
    public static boolean makesquare(int[] matchsticks) {
        int sum = Arrays.stream(matchsticks).sum();
        if (sum % 4 != 0) return false;
        int side = sum / 4;
        int[] a = Arrays.stream(matchsticks).boxed().sorted((x,
                y) -> y - x).mapToInt(Integer::intValue).toArray();
        if (a[0] > side) return false;
        return place(a, 0, new int[4], side);
    }

    private static boolean place(int[] a, int i, int[] sides, int side) {
        // all sticks placed and every side <= target, so all equal target
        if (i == a.length) return true;
        for (int s = 0; s < 4; s++) {
            if (sides[s] + a[i] > side) continue;
            // symmetry: sides with equal length are interchangeable
            boolean seen = false;
            for (int t = 0; t < s; t++) if (sides[t] == sides[s]) { seen = true;
                    break; }
            if (seen) continue;
            sides[s] += a[i];
            if (place(a, i + 1, sides, side)) return true;
            sides[s] -= a[i];
        }
        return false;
    }
}

TIME O(4ⁿ) pruned

SPACE O(n)

Equal-length sides are interchangeable; trying only the first of them removes a factor up to 4! of redundant subtrees.

Expression Add Operators

ExpressionAddOperators.java: LeetCode 282

Java 17+

import java.util.ArrayList;
import java.util.List;

/**
 * LeetCode 282 - Expression Add Operators. Insert +, - or * between digits (or nothing) so
 * the value equals target.
 */
public class ExpressionAddOperators {
    public static List<String> addOperators(String num, int target) {
        List<String> out = new ArrayList<>();
        build(num, target, 0, 0, 0, new StringBuilder(), out);
        return out;
    }

    /** value = sum so far; last = the signed term still open to a following '*'. */
    private static void build(String s, long target, int pos, long value, long last,
            StringBuilder expr, List<String> out) {
        if (pos == s.length()) {
            if (value == target) out.add(expr.toString());
            return;
        }
        int mark = expr.length();
        long cur = 0;
        for (int end = pos; end < s.length(); end++) {
            // no operand with a leading zero
            if (end > pos && s.charAt(pos) == '0') break;
            cur = cur * 10 + (s.charAt(end) - '0');
            String operand = s.substring(pos, end + 1);
            if (pos == 0) {
                expr.append(operand);
                build(s, target, end + 1, cur, cur, expr, out);
                expr.setLength(mark);
            } else {
                expr.append('+').append(operand);
                build(s, target, end + 1, value + cur, cur, expr, out);
                expr.setLength(mark);
                expr.append('-').append(operand);
                build(s, target, end + 1, value - cur, -cur, expr, out);
                expr.setLength(mark);
                // undo the open term, multiply it, add it back
                expr.append('*').append(operand);
                build(s, target, end + 1, value - last + last * cur, last * cur,
                        expr, out);
                expr.setLength(mark);
            }
        }
    }
}

TIME O(4ⁿ · n)

SPACE O(n)

expr.setLength(mark) is the unchoose for the shared StringBuilder. value, last and cur are long to avoid overflow on 10-digit inputs.

Beautiful Arrangement

BeautifulArrangement.java: LeetCode 526

Java 17+

/**
 * LeetCode 526 - Beautiful Arrangement. Fill positions 1..n; number v may sit at position p
 * only if v % p == 0 or p % v == 0.
 */
public class BeautifulArrangement {
    public static int countArrangement(int n) {
        return place(n, n, 0);
    }

    /**
     * Fills positions from n down to 1 (the most constrained positions first); `used` is a
     * bitmask of numbers.
     */
    private static int place(int pos, int n, int used) {
        if (pos == 0) return 1;
        int total = 0;
        for (int v = 1; v <= n; v++) {
            if ((used >> (v - 1) & 1) == 1) continue;
            if (v % pos != 0 && pos % v != 0) continue;
            total += place(pos - 1, n, used | 1 << (v - 1));
        }
        return total;
    }
}

TIME O(k) with pruning

SPACE O(n)

Filling positions from n down to 1 tries the most constrained positions first (position n accepts only divisors of n).

G. Variations of the Pattern

Exact cover and Algorithm X

Sudoku, N-Queens and tiling are exact cover problems. Knuth's Algorithm X (with dancing links) always branches on the constraint with the fewest options: the formal version of most constrained first.

Bitmask DP instead of search

For partition problems with n ≤ 16, dp[mask] = reachable fill state of the current bucket

removes all repeated sub-searches (Part XI).

Meet in the middle

Split into two halves, enumerate 2^(n/2) each, combine with sorting or hashing: Partition Array Into Two Arrays to Minimize Sum Difference (2035).

Constraint propagation

After placing a value, immediately remove it from related candidate sets and apply forced moves (naked singles) before branching: the way human solvers and fast solvers work.

Optimisation: branch and bound

Track the best known answer and prune any branch whose optimistic bound is no better (travelling salesman with a bound, Minimum Number of Work Sessions).

J. Interview Tips

INTERVIEW

List your pruning rules before coding, each with a one-line proof of safety ("if the sum is not divisible by k, no partition exists").

For Sudoku, state the data structure: three int bitmasks and candidates = ~(r|c|b) & 0x1FF; then say you branch on the minimum-candidate cell.

For * in expressions, explain the open term with 1+2*3: you must take back the 2 before multiplying.

Follow-ups: count Sudoku solutions; generate a puzzle with a unique solution; partition into k subsets with n = 16 (bitmask DP); return the partition; handle 10²⁰ targets (BigInteger or reject).
Edge cases: already-solved board, unsolvable board (an empty candidate set), k = 1, one item larger than the target, digits "000" for expressions, a negative target.

CHAPTER SUMMARY

Constraint backtracking = choose a variable, try its candidates, prune with proofs, undo. The ordering of variables matters as much as the pruning.

Sudoku: row/col/box bitmasks; candidates = ~(r|c|b) & 0x1FF; branch on the cell with the fewest candidates; no candidates means backtrack.

Bucket problems: check S mod k, sort descending, skip equal items, and fail when the first item tried in an empty bucket fails.

Expression operators: carry value and the open term last; * becomes value − last + last·cur; use long; no leading zeros.

If the state is a subset and you only need feasibility or a count, bitmask DP replaces the search (Part XI).
