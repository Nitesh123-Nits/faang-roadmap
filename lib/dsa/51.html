Tree BFS

Process a queue one level at a time: depth, views, zigzag, width.

A. Pattern Overview

Breadth-first search (BFS) visits a tree level by level: all nodes at depth 0, then depth 1, and so on. A queue holds the frontier. The decisive trick is to freeze the queue size at the start of each round: exactly that many nodes belong to the current level, so the loop body knows which level it is in without storing depths.

The level-order template
Queue<TreeNode> queue = new ArrayDeque<>();
queue.add(root);
while (!queue.isEmpty()) {
    int size = queue.size();               // nodes of the current level
    for (int i = 0; i < size; i++) {
        TreeNode n = queue.poll();
        // process n (first node of the level: i == 0, last: i == size - 1)
        if (n.left != null)  queue.add(n.left);
        if (n.right != null) queue.add(n.right);
    }
    // the level is complete here
}

KEY IDEA

BFS finds the shallowest answer first. Whenever the question is about depth, levels, the nearest node with a property, or a view of the tree, BFS is the natural tool; DFS can answer too (pass depth down) but cannot stop early.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Level by level", "row by row", "by depth", "each level".
"Minimum depth" / "nearest leaf" / "closest node with …": the first hit in BFS order is the

answer.

"View from the right / left / top / bottom": one node per level (or per column).
"Zigzag", "spiral": level order plus a direction flag.
"Connect each node to its right neighbour", "width of a level": you need to know the node's position within its level.
ONE-LINE TEST

If the word level (or depth, nearest, shortest) appears in the statement, reach for the queue and the size loop.

C. Core Intuition with Illustrations

The queue, round by round

Each round, size equals the length of the next level, which is exactly what was added during the previous round.

Why freeze the size?

queue.size() changes inside the loop (children are appended). Reading it once before the loop fixes the count of nodes of this level; reading it in the loop condition would mix levels. In Java, for (int i = queue.size(); i > 0; i--) does the same.

Minimum depth: stop at the first leaf

BFS visits shallower nodes before deeper ones, so the first leaf it dequeues has the minimum depth, and the rest of the tree is never touched. A DFS must scan everything. On a tree with a leaf at depth 2 and a million nodes elsewhere, BFS does O(1) work.

COMMON TRAP

Leaf, not null. In a chain 1 → 2 → 3 the minimum depth is 3, not 1: a node with one null child is not a leaf. The recursive formula 1 + min(left, right) gets this wrong unless it handles one-child nodes.

Width: count the gaps with heap indices

Number the root 0; the children of index i are 2i and 2i + 1, as in a heap. The width of a level is lastIndex − firstIndex + 1, including null gaps between its end nodes. Indices double each level, so in a deep tree they overflow long: subtract the first index of the level before computing the children.

The widest level has width 4 (nodes 5 and 9, with an empty slot between them).

Zigzag and views

Zigzag is level order where odd levels are reversed (reverse the finished list, or insert at the front). Right side view keeps the last node of each level; a DFS variant visits right before left and records the first node seen at each new depth.

E. Java Implementation

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Deque;
import java.util.List;
import java.util.Queue;

/**
 * Breadth-first tree patterns: level order (102), zigzag (103), right side view
 * (199), minimum depth (111), width (662).
 */
public class LevelOrder {

Java 17+

    /**
     * 102: process the queue one level at a time by freezing its size at the start
     * of each round.
     */
    public static List<List<Integer>> levels(TreeNode root) {
        List<List<Integer>> out = new ArrayList<>();
        if (root == null) return out;
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);
        while (!queue.isEmpty()) {
            // exactly the nodes of the current level
            int size = queue.size();
            List<Integer> level = new ArrayList<>(size);
            for (int i = 0; i < size; i++) {
                TreeNode n = queue.poll();
                level.add(n.val);
                if (n.left != null) queue.add(n.left);
                if (n.right != null) queue.add(n.right);
            }
            out.add(level);
        }
        return out;
    }

    /** Same answer by DFS: the depth of a node is the index of its list. */
    public static List<List<Integer>> levelsDfs(TreeNode root) {
        List<List<Integer>> out = new ArrayList<>();
        fill(root, 0, out);
        return out;
    }

    private static void fill(TreeNode n, int depth, List<List<Integer>> out) {
        if (n == null) return;
        if (depth == out.size()) out.add(new ArrayList<>());
        out.get(depth).add(n.val);
        fill(n.left, depth + 1, out);
        fill(n.right, depth + 1, out);
    }

    /**
     * 103: left-to-right on even levels, right-to-left on odd levels (reverse the
     * finished level).
     */
    public static List<List<Integer>> zigzag(TreeNode root) {
        List<List<Integer>> out = levels(root);
        for (int d = 1; d < out.size(); d += 2) Collections.reverse(out.get(d));
        return out;
    }

    /** 199: the last node of every level. */
    public static List<Integer> rightSideView(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        if (root == null) return out;
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode n = queue.poll();
                if (i == size - 1) out.add(n.val);
                if (n.left != null) queue.add(n.left);
                if (n.right != null) queue.add(n.right);
            }
        }
        return out;
    }

    /**
     * 111: BFS stops at the first leaf, so it never visits deeper levels (DFS must
     * scan the whole tree).
     */
    public static int minDepth(TreeNode root) {
        if (root == null) return 0;
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);
        int depth = 1;
        while (!queue.isEmpty()) {
            for (int i = queue.size(); i > 0; i--) {
                TreeNode n = queue.poll();
                if (n.left == null && n.right == null) return depth;
                if (n.left != null) queue.add(n.left);
                if (n.right != null) queue.add(n.right);
            }
            depth++;
        }
        return depth;
    }

    /**
     * 662: width counts null gaps; number nodes as in a heap (children of i are 2i,
     * 2i+1), rebased per level to avoid overflow.
     */
    public static long maxWidth(TreeNode root) {
        if (root == null) return 0;
        Deque<TreeNode> nodes = new ArrayDeque<>();
        Deque<Long> index = new ArrayDeque<>();
        nodes.add(root);
        index.add(0L);
        long best = 0;
        while (!nodes.isEmpty()) {
            long first = index.peekFirst(), last = index.peekLast();
            best = Math.max(best, last - first + 1);
            for (int i = nodes.size(); i > 0; i--) {
                TreeNode n = nodes.poll();
                // rebase: the leftmost node of the level becomes 0
                long id = index.poll() - first;
                if (n.left != null) { nodes.add(n.left); index.add(2 * id); }
                if (n.right != null) { nodes.add(n.right); index.add(2 * id + 1); }
            }
        }
        return best;
    }
}

TIME O(n)

SPACE O(w)

w = maximum level width. levelsDfs produces the same lists with O(h) extra space by using the depth as the list index. In maxWidth the subtraction index.poll() − first keeps indices small.

G. Variations of the Pattern

Level-wise aggregates

Average of Levels (637), Largest Value in Each Tree Row (515), Deepest Leaves Sum (1302): compute the aggregate inside the for loop.

Connecting neighbours

Populating Next Right Pointers (116, 117): link n.next = queue.peek() for every node except the last of its level; a constant-space version walks the already-built next links level by level.

Vertical order and columns

Vertical Order Traversal (987): BFS with a (row, column) pair; columns go left −1, right +1; sort ties by value. Top View / Bottom View keep the first or last node per column.

BFS from an arbitrary node

All Nodes Distance K in Binary Tree (863): a tree is a graph; add parent links (or a map) and run BFS from the target to depth K. This is the bridge to graph BFS (Part VIII).

Bidirectional / multi-source

Several start nodes in one queue (Rotting Oranges-style) and the BFS depth counts rounds; covered in Part VIII.

J. Interview Tips

INTERVIEW

Draw the queue for the first two rounds; interviewers want to see the size freeze explained.

State the space cost as O(w) and contrast with DFS O(h): the width of a complete tree is half the nodes.

For minimum depth, name the trap (a node with one child is not a leaf) before they ask.

Follow-ups: bottom-up level order (reverse the list); zigzag without reversing (use a Deque per level); right view by DFS; width of a level in O(1) space; BFS on an n-ary tree.
Edge cases: empty tree, single node, skewed tree (width 1 for every level), complete tree (last level has n/2 nodes), duplicate values.

CHAPTER SUMMARY

Level order = a queue and a frozen size per round; everything else (zigzag, views, aggregates) edits the loop body.

BFS finds the shallowest match first, so minimum depth and nearest node stop early; a leaf has no children at all.

Width needs positions: heap indices 2i, 2i + 1, rebased per level to avoid overflow, counting the null gaps.

BFS uses O(w) space (up to n/2), DFS uses O(h): choose by the shape of the tree and the question.

A tree is a graph: with parent links, BFS from any node gives distances (Part VIII).
