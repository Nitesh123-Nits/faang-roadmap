2D Dynamic Programming (Grids)

Cell (r, c) is built from its neighbours above and to the left.

A. Pattern Overview

In grid DP the state is a cell (r, c). The value is the answer for the path or sub-rectangle that ends at that cell, and the transition looks at the cell above and the cell to the left (or the three upper-left neighbours for squares). Filling row by row, left to right, guarantees every dependency is ready. Space drops from O(m n) to O(n) by keeping only the previous row.

KEY IDEA

State direction matters. Most grid DPs describe the path that ends at a cell and run forward. Dungeon Game describes the requirement that starts at a cell and runs backward, because the health needed now depends on what lies ahead.

B. When to Recognize This Pattern

Pattern Recognition Signals

Moves restricted to right/down (or three downward moves) on a grid.
"Number of paths", "minimum cost path", "largest square".
Obstacles, costs or health attached to cells.
Both m and n are moderate (up to a few thousand).
Free movement in four directions is not this pattern (use BFS or Dijkstra), unless values strictly increase (Chapter 88).
ONE-LINE TEST

Restricted moves on a grid with an optimum or a count: fill the grid.

Maximal Square (221)

If a cell is 1, the largest square ending there has side 1 + min(up, left, up-left): the smallest of the three neighbouring squares limits how far it can grow. For the LeetCode example the largest side is 2, so the area is 4.

Figure 130. Side of the largest all-ones square whose bottom-right corner is the cell.

Dungeon Game (174): run it backwards

A forward DP fails because you need to know the health needed to survive the rest. Define need[r][c] as the minimum health on entering the cell. At the princess cell, need = max(1, 1 - g). Elsewhere need = max(1, min(need_down, need_right) - g).

import java.util.*;

/** Ch 81: grid DP; LeetCode 62, 63, 64, 221, 931, 174, 1277. */
public class GridDP {

    /** LeetCode 62: monotone paths in an m x n grid, one row of state. */
    public static int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        for (int r = 1; r < m; r++)
            for (int c = 1; c < n; c++) dp[c] += dp[c - 1];
        return dp[n - 1];
    }

Java 17+

    /** LeetCode 63: a cell holding 1 is blocked and has zero paths through it. */
    public static int uniquePathsObstacles(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] dp = new int[n];
        dp[0] = grid[0][0] == 1 ? 0 : 1;
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) dp[c] = 0;
                else if (c > 0) dp[c] += dp[c - 1];
            }
        return dp[n - 1];
    }

    /** LeetCode 64: cheapest monotone path; in place on a copy. */
    public static int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[m][n];
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++) {
                int best = r == 0 && c == 0 ? 0
                        : Math.min(r > 0 ? dp[r - 1][c] : Integer.MAX_VALUE,
                                   c > 0 ? dp[r][c - 1] : Integer.MAX_VALUE);
                dp[r][c] = grid[r][c] + best;
            }
        return dp[m - 1][n - 1];
    }

    /** LeetCode 221: dp = side of the largest all-'1' square ending here. */
    public static int maximalSquare(char[][] g) {
        int m = g.length, n = g[0].length, best = 0;
        int[][] dp = new int[m + 1][n + 1];
        for (int r = 1; r <= m; r++)
            for (int c = 1; c <= n; c++)
                if (g[r - 1][c - 1] == '1') {
                    dp[r][c] = 1 + Math.min(dp[r - 1][c - 1],
                            Math.min(dp[r - 1][c], dp[r][c - 1]));
                    best = Math.max(best, dp[r][c]);
                }
        return best * best;
    }

    /** LeetCode 1277: count all-ones squares of every size. */
    public static int countSquares(int[][] a) {
        int m = a.length, n = a[0].length, total = 0;
        int[][] dp = new int[m + 1][n + 1];
        for (int r = 1; r <= m; r++)
            for (int c = 1; c <= n; c++)
                if (a[r - 1][c - 1] == 1) {
                    dp[r][c] = 1 + Math.min(dp[r - 1][c - 1],
                            Math.min(dp[r - 1][c], dp[r][c - 1]));
                    total += dp[r][c];
                }
        return total;
    }

    /** LeetCode 931: fall one row at a time to the column left, same or right. */
    public static int minFallingPathSum(int[][] a) {
        int n = a.length;
        int[] dp = a[0].clone();
        for (int r = 1; r < n; r++) {
            int[] next = new int[n];
            for (int c = 0; c < n; c++) {
                int best = dp[c];
                if (c > 0) best = Math.min(best, dp[c - 1]);
                if (c < n - 1) best = Math.min(best, dp[c + 1]);
                next[c] = a[r][c] + best;
            }
            dp = next;
        }
        int ans = Integer.MAX_VALUE;
        for (int v : dp) ans = Math.min(ans, v);
        return ans;
    }

    /**
     * LeetCode 174: minimum starting health to reach the bottom-right with
     * health always >= 1. The state runs backwards: need[r][c] is the health
     * required when entering (r, c).
     */
    public static int calculateMinimumHP(int[][] d) {
        int m = d.length, n = d[0].length;
        int[][] need = new int[m + 1][n + 1];
        for (int[] row : need) Arrays.fill(row, Integer.MAX_VALUE);
        need[m][n - 1] = 1;
        need[m - 1][n] = 1;
        for (int r = m - 1; r >= 0; r--)
            for (int c = n - 1; c >= 0; c--)
                need[r][c] = Math.max(1,
                        Math.min(need[r + 1][c], need[r][c + 1]) - d[r][c]);
        return need[0][0];
    }
}

SPACE O(n)

F. Detailed Dry Run

minPathSum on [[1,3,1],[1,5,1],[4,2,1]], rolling row: after row 0 the array is [1,4,5]. Row 1: dp[0] = 1 + 1 = 2; dp[1] = 5 + min(4, 2) = 7; dp[2] = 1 + min(5, 7) = 6. Row 2: dp[0] = 2 + 4 = 6; dp[1] = 2 + min(7, 6) = 8; dp[2] = 1 + min(6, 8) = 7. Answer 7.

calculateMinimumHP: need[2][2] = max(1, 1 - (-5)) = 6; need[2][1] = max(1, 6 - 30) =

1; need[1][2] = max(1, 6 - 1) = 5; ... need[0][0] = max(1, min(need[1][0], need[0][1]) -

(-2)) = 7.

G. Variations of the Pattern

Counting with obstacles

A blocked cell is simply set to zero. Remember to handle a blocked start (answer 0).

Three-neighbour falling paths

Min Falling Path Sum (931) lets a cell look at (r-1, c-1), (r-1, c), (r-1, c+1); guard the edges.

Square and rectangle DP

Maximal Square uses min of three neighbours; Maximal Rectangle (85) combines row heights with a stack (Chapter 8), and Count Square Submatrices (1277) sums the dp values.

Backward DP

Dungeon Game, Cherry Pickup (two simultaneous walkers) and Paths with minimum health define the state by what is still ahead.

Grid DP with extra dimension

Add a third index for remaining obstacles removed (1293) or number of turns; the table grows to m x n x k.

J. Interview Tips

INTERVIEW

Say the state as a path/shape ending at the cell. Then the transition reads off the picture.

Initialise the border first; most bugs live there.

For Dungeon Game, announce the reversal before coding: "I need the minimum health required from here, so I solve it backwards."

Follow-ups: print one path (walk back by comparing neighbours); allow diagonal moves; add k obstacle removals; large grid with few obstacles (sparse DP or combinatorics).
Edge cases: single row/column, blocked start, all zeros, negative values, 1 x 1 grid.

CHAPTER SUMMARY

Grid DP: the state is a cell; the value describes the best path or shape ending there.

Initialise the first row and column, then fill row by row; every dependency points up or left.

Squares use 1 + min(up, left, up-left); falling paths look at three cells above.

Dungeon Game runs backwards because the requirement depends on the future.

Keep one row to cut space from O(m n) to O(n).
