C. Core Intuition with Illustrations

Single Number II: count each column modulo 3

Every column of the repeated numbers contributes a multiple of 3 ones. Only the loner can make the count 1 (mod 3). For [2, 2, 3, 2]:

BitSet countCount mod 3Result so far
011mod3=1001
144mod3=1011
200mod3=0011

The O(1)-space automaton version keeps two integers ones and twos that encode the count mod 3 for all 32 columns in parallel; the column-count loop above is easier to explain and needs 32 n operations, which is fine.

Single Number III: split by a bit where the two loners differ

XOR of everything equals a ^ b, which is non-zero because a != b. Any set bit of it is a column where a and b disagree. d = x & -x picks the lowest one. Partition all numbers by that bit: the pairs stay together (equal numbers have the same bit), and a, b land in different groups. XOR each group.

Subsets by mask and counting subsets with a given XOR

Iterate mask from 0 to 2^n - 1; bit i of mask says whether nums[i] is in the subset. For the number of subsets with XOR equal to t, run a small DP over XOR values (dp[x] = number of subsets with XOR x), which is O(n * 2^b) for b-bit values, far better than 2^n.

NO-PLUS ADDITION

getSum terminates in 32 steps because the carry shifts left each iteration and falls off the top of the int. In Java no special handling for negatives is needed: two's complement addition is the same operation.

E. Java Implementation

Single Number II/III, subsets, Gray code, range AND, no-plus addition, flips, word masks

BitTricks.java: column counting, partition by bit, Gray code, masks

import java.util.*;

/** Ch 93: XOR and mask patterns; LeetCode 137, 260, 78, 89, 201, 371, 1318, 318. */
public class BitTricks {
    /** LeetCode 137: every value appears three times except one. */
    public static int singleNumberII(int[] nums) {
        int ones = 0, twos = 0;
        for (int v : nums) {
            ones = (ones ^ v) & ~twos;  // bits seen 1 mod 3 times
            twos = (twos ^ v) & ~ones;  // bits seen 2 mod 3 times
        }
        return ones;
    }

    /** LeetCode 260: two values appear once, all others twice. */
    public static int[] singleNumberIII(int[] nums) {
        int xor = 0;
        for (int v : nums) xor ^= v;     // a ^ b
        int low = xor & -xor;            // a bit where a and b differ
        int a = 0;
        for (int v : nums) if ((v & low) != 0) a ^= v;
        int b = xor ^ a;
        return new int[]{Math.min(a, b), Math.max(a, b)};
    }

    /** LeetCode 78: every subset from a bitmask, mask order. */

Java 17+

    public static List<List<Integer>> subsets(int[] nums) {
        int n = nums.length;
        List<List<Integer>> out = new ArrayList<>(1 << n);
        for (int mask = 0; mask < (1 << n); mask++) {
            List<Integer> s = new ArrayList<>();
            for (int i = 0; i < n; i++) if ((mask >> i & 1) == 1) s.add(nums[i]);
            out.add(s);
        }
        return out;
    }

    /** LeetCode 89: Gray code, consecutive values differ in one bit. */
    public static List<Integer> grayCode(int n) {
        List<Integer> out = new ArrayList<>(1 << n);
        for (int i = 0; i < (1 << n); i++) out.add(i ^ (i >> 1));
        return out;
    }

    /** LeetCode 201: AND of [left, right] = common binary prefix. */
    public static int rangeBitwiseAnd(int left, int right) {
        int shift = 0;
        while (left != right) {
            left >>= 1;
            right >>= 1;
            shift++;
        }
        return left << shift;
    }

    /** LeetCode 371: a + b with XOR (sum) and AND (carry). */
    public static int getSum(int a, int b) {
        while (b != 0) {
            int carry = (a & b) << 1;
            a ^= b;
            b = carry;
        }
        return a;
    }

    /** LeetCode 1318: flips so that (a OR b) == c. */
    public static int minFlips(int a, int b, int c) {
        int flips = 0;
        for (int i = 0; i < 31; i++) {
            int x = a >> i & 1, y = b >> i & 1, z = c >> i & 1;
            if (z == 1) flips += (x | y) == 0 ? 1 : 0;
            else flips += x + y;         // every set bit must be cleared
        }
        return flips;
    }

    /** LeetCode 318: max |a| * |b| of two words sharing no letter. */
    public static int maxProduct(String[] words) {
        int n = words.length;
        int[] mask = new int[n];
        for (int i = 0; i < n; i++)
            for (char ch : words[i].toCharArray()) mask[i] |= 1 << (ch - 'a');
        int best = 0;
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                if ((mask[i] & mask[j]) == 0)
                    best = Math.max(best, words[i].length() * words[j].length());
        return best;
    }
    /** Counts subsets whose elements XOR to target, O(2^n) with a mask DP. */
    public static int countSubsetsWithXor(int[] nums, int target) {
        int n = nums.length;
        int[] xor = new int[1 << n];
        int count = target == 0 ? 1 : 0;   // the empty subset
        for (int mask = 1; mask < (1 << n); mask++) {
            int low = Integer.numberOfTrailingZeros(mask);
            xor[mask] = xor[mask & (mask - 1)] ^ nums[low];
            if (xor[mask] == target) count++;
        }
        return count;
    }
}

F. Detailed Dry Run

getSum(5, 3): a = 101, b = 011. Round 1: sum bits a ^ b = 110, carry (a & b) << 1 = 010. Round 2: 110 ^ 010 = 100, carry (110 & 010) << 1 = 100. Round 3: 100 ^ 100 = 000, carry (100 & 100) << 1 = 1000. Round 4: 000 ^ 1000 = 1000, carry 0. Result 1000 = 8.

minFlips(a = 2, b = 6, c = 5): bits (low to high) of a = 010, b = 110, c = 101. Column 0: a|b = 0, need 1, cost 1. Column 1: a|b = 1, need 0, both are 1 so cost 2. Column 2: a|b = 1, need 1, cost 0. Total 3.

G. Variations of the Pattern

Sum of XORs of all subarrays

Prefix XORs p: xor(l..r) = p[r+1] ^ p[l]. Count pairs with equal prefix XOR for triplet problems such as LeetCode 1442 (i < j <= k with equal halves iff p[i] == p[k+1]).

Subset enumeration of a mask

for (int sub = mask; sub > 0; sub = (sub - 1) & mask) visits all non-empty submasks; summing over all masks costs 3^n, the usual bound in bitmask DP.

Bit sets as boolean arrays

A long is a 64-slot set: add s |= 1L << i, remove s &= ~(1L << i), size Long.bitCount(s). This is the memory-light cousin of boolean[64].

Maximum XOR pair with prefix sets

Another route to Chapter 95: decide the answer bit by bit from the top, testing whether some pair of prefixes XORs to the candidate with a HashSet. O(32 n), no trie.

Parity tricks

Bit 0 of a sum is the XOR of the bit 0s; the parity of a popcount is Integer.bitCount(x) & 1. Some games and toggling puzzles reduce to this.

J. Interview Tips

INTERVIEW

Start with the HashMap solution, then say "we can drop the map because...": the bit argument is the follow-up they want.

For Single Number III, say why the two groups are separated (pairs share every bit, the loners differ at d).

Always mention overflow behaviour when writing getSum or shifting.

Follow-ups: k copies instead of 3; several loners; do it in a stream; in O(1) extra bits with

the ones/twos automaton.

Edge cases: negatives, a loner of 0, the loner at Integer.MIN_VALUE, an array of size 1.

CHAPTER SUMMARY

Count each bit column modulo k to isolate an element that appears a different number of times.

XOR of everything gives a ^ b; its lowest set bit splits the array into two groups, each with one loner.

Masks enumerate subsets without recursion; letter masks make set-disjointness an O(1) AND.

Range AND keeps only the common prefix; Gray code is i ^ (i >> 1).

Addition without + is XOR for the sum bits plus a left-shifted AND for the carries.
