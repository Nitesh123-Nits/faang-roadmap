Top 100 Interview Problems

One hundred high-value problems, grouped by pattern and ordered easy to hard, each taught in this boo

Every problem here appears in a chapter's practice table, so you can read the pattern chapter, see the Java solution and dry run, and then solve the problem yourself. The list favours problems that recur in SDE-1 and SDE-2 interviews and that exercise one clear idea. Within each group the order is a recommended solving order: Easy first, then Medium, then Hard.

Problem numbers, slugs and difficulty labels are written from memory of the public LeetCode catalogue: spot-check a link if it ever lands on the wrong page. Pages marked premium need a subscription.

DIFFICULTY MIX

The mix is 14 Easy, 72 Medium and 14 Hard, like a real interview loop: mostly Medium, with a Hard that is usually a Medium idea plus one extra layer.

How to use the list

Pass 1: read the chapter, then solve each problem cold (25 minutes at most). If stuck, reread only the recognition signals.
Pass 2 (three days later): redo every problem you needed help with, from a blank file, in under 15 minutes.
Pass 3 (before interviews): solve five random problems aloud: pattern, brute force, bottleneck, complexity.
