Reservoir Sampling and Random Sampling

Pick uniformly from data you can't count in advance: streams, weights and shuffles.

A. Pattern Overview

Random-sampling questions test whether you can make an exactly uniform choice with limited memory or information. Reservoir sampling picks k items uniformly from a stream of unknown length in one pass and O(k) space. Related patterns: the Fisher-Yates shuffle (uniform permutation), weighted sampling by prefix sums and binary search, and rejection sampling to build one random source from another.

KEY IDEA

"Uniform" is a proof obligation. Every algorithm here is correct because the probability of each outcome multiplies out to exactly 1/n.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Random" or "pick" in the title, especially with "equal probability".
A linked list or stream whose length you can't know or don't want to count first.
Several indices with the same value, pick one uniformly (Random Pick Index).
Weights or areas that make some outcomes more likely.
Shuffle requirements: every permutation equally likely.
Build a fair generator from a differently-sized one.
ONE-LINE TEST

Unknown length plus uniform choice: reservoir. Known weights: prefix sums plus binary search.

C. Core Intuition with Illustrations

Reservoir sampling with k = 1

Keep the first item. For the i-th item (1-based), replace the kept item with probability 1/i. Item i ends up selected if it is chosen at step i and survives every later step j (survival probability 1 - 1/j = (j-1)/j). The product telescopes to 1/n:

Reservoir sampling with k items

Fill the reservoir with the first k items. For item index i >= k (0-based) draw j uniformly from 0..i; if j < k, overwrite slot j. Item i is kept with probability k/(i+1), and an existing item survives each step with probability 1 - 1/(i+1). Trace for k = 2, stream A..E, with the random draws -, -, 1, 0, 3:

Fisher-Yates: the right shuffle

For i from 0 to n-1, swap a[i] with a[i + rand(n - i)]. This produces each of the n! permutations with probability 1/n!. Swapping with rand(n) instead of rand(n - i) gives n^n equally likely paths, which cannot divide evenly among n! permutations: biased.

Weighted pick with prefix sums

Weights [1, 3, 2] give prefix sums [1, 4, 6]. Draw r uniformly in [0, 6) and pick the first index whose prefix sum is greater than r: r = 0 gives 0; r = 1..3 gives 1; r = 4, 5 gives 2. Binary search finds it in O(log n).

Random points in rectangles and rejection sampling

Weight each rectangle by its number of integer points (x2-x1+1)(y2-y1+1), pick a rectangle by weight, then pick coordinates uniformly inside it. For Rand10() using Rand7():

(rand7()-1)*7 + rand7() is uniform on 1..49; reject values above 40 and map the rest with %

10 + 1. Expected calls per output: 2 x 49/40 ~ 2.45.

TRAP

Calling Math.random() once per decision and reusing it, or using % n on a biased source, quietly breaks uniformity. Prove it, or simulate and count.

Reservoir.java: uniform sampling from streams, weights and shuffles

import java.util.*;

/** Ch 100: sampling with uniform probability; LeetCode 382, 398, 384, 528, 497. */
public class Reservoir {
    /** Algorithm R: k uniform items from a stream of unknown length. */
    public static int[] sample(int[] stream, int k, Random rnd) {
        int[] res = Arrays.copyOf(stream, Math.min(k, stream.length));
        for (int i = k; i < stream.length; i++) {
            int j = rnd.nextInt(i + 1);              // 0..i inclusive
            if (j < k) res[j] = stream[i];
        }
        return res;
    }

    /** LeetCode 382: uniform random node value from a linked list. */
    public static int randomNode(ListNode head, Random rnd) {
        int chosen = head.val, seen = 1;
        for (ListNode cur = head.next; cur != null; cur = cur.next) {
            seen++;
            if (rnd.nextInt(seen) == 0) chosen = cur.val;   // probability 1/seen
        }
        return chosen;
    }

    /** LeetCode 398: random index among those equal to target, O(n) per call. */
    public static int pickIndex(int[] nums, int target, Random rnd) {
        int idx = -1, seen = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != target) continue;
            seen++;
            if (rnd.nextInt(seen) == 0) idx = i;
        }
        return idx;
    }

    /** LeetCode 384: Fisher-Yates shuffle, every permutation equally likely. */
    public static int[] shuffle(int[] nums, Random rnd) {
        int[] a = nums.clone();
        for (int i = a.length - 1; i > 0; i--) {
            int j = rnd.nextInt(i + 1);
            int t = a[i];
            a[i] = a[j];
            a[j] = t;
        }
        return a;
    }

    /** LeetCode 528: index i chosen with probability w[i] / sum(w). */
    public static final class WeightedPicker {

Java 17+

        private final long[] prefix;
        private final Random rnd;

        public WeightedPicker(int[] w, Random rnd) {
            prefix = new long[w.length];
            long s = 0;
            for (int i = 0; i < w.length; i++) prefix[i] = s += w[i];
            this.rnd = rnd;
        }

        public int pick() {
            long target = (long) (rnd.nextDouble() * prefix[prefix.length - 1]);
            return upper(target);
        }

        /** First index with prefix > target. */
        int upper(long target) {
            int lo = 0, hi = prefix.length - 1;
            while (lo < hi) {
                int m = (lo + hi) >>> 1;
                if (prefix[m] > target) hi = m; else lo = m + 1;
            }
            return lo;
        }

        long total() {
            return prefix[prefix.length - 1];
        }
    }

    /** LeetCode 497: uniform integer point inside non-overlapping rectangles. */
    public static final class RectPicker {
        private final int[][] rects;
        private final WeightedPicker picker;
        private final Random rnd;

        public RectPicker(int[][] rects, Random rnd) {
            this.rects = rects;
            this.rnd = rnd;
            int[] area = new int[rects.length];
            for (int i = 0; i < rects.length; i++)
                area[i] = (rects[i][2] - rects[i][0] + 1)
                        * (rects[i][3] - rects[i][1] + 1);
            picker = new WeightedPicker(area, rnd);
        }

        public int[] pick() {
            int[] r = rects[picker.pick()];
            return new int[]{r[0] + rnd.nextInt(r[2] - r[0] + 1),
                    r[1] + rnd.nextInt(r[3] - r[1] + 1)};
        }
    }
}

F. Detailed Dry Run

randomNode on 1 -> 2 -> 3: node 1 is kept at step 1. At step 2 it is replaced with probability 1/2. At step 3 the current choice is replaced with probability 1/3. Probability that node 1 is the final pick: 1 x 1/2 x 2/3 = 1/3. For node 2: 1/2 x 2/3 = 1/3. For node 3: 1/3. Uniform.

pickIndex([1, 3, 3, 3, 2, 3], 3): matches at 1, 2, 3, 5. Count them as you go: match #1 (index 1) is kept; match #2 replaces with probability 1/2; match #3 with 1/3; match #4 with 1/4. Each of the four indices ends with probability 1/4; non-matching indices are never chosen.

G. Variations of the Pattern

Weighted reservoir sampling (A-Res)

Assign each item the key u^(1/w) with u uniform in (0, 1) and keep the k largest keys. Samples proportionally to weight in one pass.

Insert Delete GetRandom O(1)

Array of values plus a map from value to index; delete by swapping with the last element. A uniform random index is a uniform random element.

Random Flip Matrix and Random Pick with Blacklist

Virtual Fisher-Yates: store only the swapped positions in a hash map so the cost is proportional to the number of picks, not the matrix size.

Random point in a circle

Radius must be R sqrt(u), not R u; otherwise points cluster at the centre. Or use rejection sampling in the bounding square.

Reproducibility and testing

Inject the Random so tests can seed it, and check frequencies against expected values with a tolerance (this book's tests do exactly that).

J. Interview Tips

INTERVIEW

Give the proof for k = 1 in two lines (telescoping product) and the interviewer will usually stop there.

Mention that you cannot know the length, so counting first would take a second pass.

Name Fisher-Yates and why the naive swap is biased whenever shuffling comes up.

Follow-ups: weighted streams; sample without replacement; distributed sampling (merge reservoirs); thread safety.
Edge cases: list of length 1, all indices match, k = n, empty stream.

CHAPTER SUMMARY

Reservoir sampling keeps item i with probability 1/i and gives each of n items probability 1/n in one pass.

For k items, fill the reservoir, then replace slot j < k when j = rand(0..i).

Fisher-Yates is the unbiased shuffle; swapping with rand(n) each time is not.

Weighted choices use prefix sums and a binary search on a uniform draw.

Rejection sampling builds a fair generator by discarding the part of the range that breaks uniformity.
