1D Dynamic Programming

One index, a handful of earlier cells: take-or-skip, counts and prefix feasibility.

A. Pattern Overview

In one-dimensional DP the state is a single index: dp[i] answers the problem for the first i items (or for the item ending at i). The transition looks back a fixed number of steps (House Robber, Climbing Stairs) or scans back over a set of allowed lengths (Word Break, Integer Break). Four families cover most problems: take-or-skip, counting ways, prefix feasibility, and best split of a number.

KEY IDEA

Ask what the last element did. Either it is part of the answer (take it, then look back past its neighbours) or it is not (inherit the previous answer). Those two cases are the transition.

B. When to Recognize This Pattern

Pattern Recognition Signals

A sequence of items with a constraint between neighbours: no two adjacent, steps of

size 1 or 2, a code of one or two digits.

"Maximum sum with no two adjacent" or its disguises (delete-and-earn).
"Number of ways to decode / reach": counts that add over disjoint last moves.
"Can the string be segmented": boolean over prefixes.
A greedy local choice that a counter-example breaks.
ONE-LINE TEST

A single array, each answer needs only earlier answers: 1D DP.

If the first and last houses are neighbours, at most one of them is robbed. Run the linear solution twice, on nums[0..n-2] and nums[1..n-1], and take the maximum.

E. Java Implementation

Climbing, Robber I and II, Decode Ways, Delete and Earn, Word Break, Integer Break

OneDDP.java: LeetCode 70, 198, 213, 91, 740, 139, 343
import java.util.*;

/** Ch 80: one-dimensional DP; LeetCode 70, 198, 213, 91, 740, 139, 343. */
public class OneDDP {

    /** LeetCode 70: ways to climb n stairs taking 1 or 2 steps. */
    public static int climbStairs(int n) {
        int a = 1, b = 1;                               // ways(0), ways(1)
        for (int i = 2; i <= n; i++) {
            int next = a + b;
            a = b;
            b = next;
        }
        return b;
    }

    /** LeetCode 198: no two adjacent houses. take / skip over the prefix. */
    public static int rob(int[] nums) {
        int take = 0, skip = 0;
        for (int x : nums) {
            int newTake = skip + x;
            skip = Math.max(skip, take);
            take = newTake;
        }
        return Math.max(take, skip);
    }

Java 17+

    /** LeetCode 213: houses in a circle: first and last are adjacent. */
    public static int robCircular(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];
        return Math.max(robRange(nums, 0, n - 2), robRange(nums, 1, n - 1));
    }

    private static int robRange(int[] nums, int lo, int hi) {
        int take = 0, skip = 0;
        for (int i = lo; i <= hi; i++) {
            int newTake = skip + nums[i];
            skip = Math.max(skip, take);
            take = newTake;
        }
        return Math.max(take, skip);
    }

    /**
     * Maximum sum of elements, no two adjacent, any values (possibly negative);
     * choosing nothing is allowed.
     */
    public static long maxSumNonAdjacent(int[] nums) {
        long incl = 0, excl = 0;
        for (int x : nums) {
            long newIncl = excl + x;
            excl = Math.max(excl, incl);
            incl = Math.max(newIncl, 0);               // never worse than nothing
        }
        return Math.max(incl, excl);
    }

    /** LeetCode 91: number of decodings of a digit string ('1'..'26'). */
    public static int numDecodings(String s) {
        int n = s.length();
        if (n == 0 || s.charAt(0) == '0') return 0;
        int prev2 = 1, prev1 = 1;                      // ways for prefixes i-2, i-1
        for (int i = 2; i <= n; i++) {
            int cur = 0;
            if (s.charAt(i - 1) != '0') cur += prev1;
            int two = (s.charAt(i - 2) - '0') * 10 + (s.charAt(i - 1) - '0');
            if (two >= 10 && two <= 26) cur += prev2;
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }

    /**
     * LeetCode 740: taking x earns x per copy but removes x - 1 and x + 1.
     * Collapse to totals per value, then it is House Robber over values.
     */
    public static int deleteAndEarn(int[] nums) {
        if (nums.length == 0) return 0;
        int max = 0;
        for (int x : nums) max = Math.max(max, x);
        int[] total = new int[max + 1];
        for (int x : nums) total[x] += x;
        return rob(total);
    }

    /** LeetCode 139: can s be segmented into dictionary words? dp[i]: prefix. */
    public static boolean wordBreak(String s, List<String> dict) {
        Set<String> words = new HashSet<>(dict);
        int maxLen = 0;
        for (String w : dict) maxLen = Math.max(maxLen, w.length());
        int n = s.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        for (int i = 1; i <= n; i++) {
            for (int len = 1; len <= Math.min(i, maxLen) && !dp[i]; len++)
                dp[i] = dp[i - len] && words.contains(s.substring(i - len, i));
        }
        return dp[n];
    }

    /** LeetCode 343: split n into at least two positive parts, maximise product. */
    public static int integerBreak(int n) {
        int[] dp = new int[n + 1];
        dp[1] = 1;
        for (int i = 2; i <= n; i++)
            for (int j = 1; j < i; j++)
                dp[i] = Math.max(dp[i], Math.max(j * (i - j), j * dp[i - j]));
        return dp[n];
    }
}

TIME O(n)

SPACE O(1)

Climbing Stairs, both robbers, Delete and Earn and Decode Ways are O(n) time with O(1) extra space (Delete and Earn adds an O(max value) bucket array). Word Break is O(n * L) with a set and word-length cap; Integer Break is O(n^2).

F. Detailed Dry Run

rob([2,7,9,3,1]): (take, skip) goes (0,0) -> (2,0) -> (7,2) -> (11,7) -> (10,11) ->

(12,11). Answer max(12, 11) = 12.

robCircular([2,3,2]): slice [2,3] gives 3, slice [3,2] gives 3; the single-element guard makes n = 1 return nums[0]. The answer is 3, not 4, because robbing both 2s would rob adjacent (circular) houses.

integerBreak(10): for n >= 4 the best split uses 3s: 3 * 3 * 4 = 36. The DP computes dp[i] =

max over j of max(j, dp[j]) * max(i-j, dp[i-j]), which reproduces the same value.

G. Variations of the Pattern

Maximum sum with no two adjacent

The core of House Robber. With large values use long; with the cost of skipping, add a penalty to skip.

Counting with exclusions

Decode Ways with * wildcards (639) multiplies the counts by how many digits each symbol can stand for; zeros force the two-digit branch.

Prefix feasibility with a cap

Word Break only needs to try suffix lengths up to the longest word; with a trie the inner loop stops as soon as the prefix leaves the trie.

Bucketing reductions

Delete and Earn, Maximum Number of Points (similar bucket tricks) turn a value-adjacency rule into an index-adjacency rule.

Circular arrays

When the array wraps, split into two linear cases by fixing whether an endpoint is used. The same trick handles Circular Maximum Subarray (Chapter 7).

J. Interview Tips

INTERVIEW

Define dp[i] out loud ("best total using the first i houses") before writing the recurrence.

Show the greedy counter-example that rules out the simple solution; it proves why DP is needed.

Compress space last: present the table solution, then say only two values matter.

Follow-ups: return the chosen houses (walk back through the table); robbers on a tree

(Chapter 87); robbers in a circle; limit on number of houses.

Edge cases: empty array, one house, all zeros, equal adjacent values, strings with zeros, a dictionary word longer than the string.

CHAPTER SUMMARY

1D DP keeps one index. Ask what the last element did: it is used (look back) or not (inherit).

Take-or-skip is two variables; counting adds disjoint last moves; feasibility ORs over allowed last pieces.

Reductions (Delete and Earn) and splits (circular Robber) reuse the linear solution.

Greedy fails here; a one-line counter-example justifies the DP.

Most 1D DPs finish in O(n) time and O(1) space after the table version is verified.
