Grid-Based Graph Problems

A grid is an implicit graph: cells are vertices, neighbours are computed.

A. Pattern Overview

Many "graph" problems arrive as a matrix. Each cell is a vertex; its edges go to the 4 (or 8) adjacent cells that satisfy a rule. Never build the adjacency list: generate neighbours on demand with direction arrays. Everything from Chapters 47 to 53 applies: components (islands), BFS (shortest path), Dijkstra (weighted cells), Union-Find (online land).

The grid neighbour loop
static final int[] DR = {1, -1, 0, 0}, DC = {0, 0, 1, -1};

for (int d = 0; d < 4; d++) {
    int r = cur[0] + DR[d], c = cur[1] + DC[d];
    if (r < 0 || c < 0 || r >= m || c >= n) continue;   // bounds
    if (grid[r][c] != LAND || seen[r][c]) continue;     // rule + visited
    seen[r][c] = true;                                  // mark when enqueued
    queue.add(new int[] {r, c});
}

KEY IDEA

Flip the question when it helps. "Which regions are enclosed?" is hard to test region by region; "which cells can reach the border?" is one flood from the border, and the enclosed ones are what remains.

B. When to Recognize This Pattern

Pattern Recognition Signals

A matrix of 0 / 1, letters or heights and the words island, region, connected, flood, path.
"Number of / largest / perimeter of" groups of adjacent cells.
"Minimum steps from the top-left to the bottom-right" (BFS on a grid).
"Cells that cannot reach / are surrounded by" the border: border-seeded flood.
Adjacent includes diagonals? Use an 8-direction array (Shortest Path in Binary Matrix).
ONE-LINE TEST

Matrix + adjacency + a rule per cell ≈ implicit graph. Decide: connect (flood fill), shortest (BFS), weighted (Dijkstra), or enclosed (border seeds).

C. Core Intuition with Illustrations

Flood fill counts islands

Scan every cell in row-major order. Each time you find an unvisited land cell you have found a new island; flood it so it is not counted again. Total work O(mn): each cell is pushed once and scanned once.

Mark visited in place, or not?

LeetCode's char[][] grids are often sunk ('1' → '0') to double as the visited set: no extra

memory. In a library or when the input must survive, copy the grid or use boolean[][] (the Java in this chapter works on a copy). Whichever you choose, mark when pushing, not when popping, or cells enter the stack many times.

Perimeter without a traversal

Each land cell contributes 4 sides; every pair of adjacent land cells hides 2 sides. Scan once and, for each land cell, subtract 2 for the neighbour above and the neighbour on the left: perimeter = 4 · land − 2 · sharedEdges.

Border seeds: enclaves and surrounded regions

To count land that cannot walk off the grid, flood from every land cell on the border, then count the land that was never reached.

Figure 97. Number of Enclaves: land that cannot reach the border.

The same idea gives Surrounded Regions (130: flip the Os that were not reached) and Number of Closed Islands (1254: islands of 0 whose cells never reach the border).

Shortest path in a grid

BFS with (row, col, dist) in the queue, or a dist[][] array initialised to −1. In Shortest Path in Binary Matrix (1091) the 8 neighbours are the edges and the answer counts cells, so the start cell has length 1. BFS stops at the first time the target is dequeued.

import java.util.*;

/** Ch 55: grids as graphs; LeetCode 200, 695, 463, 733, 130, 1020, 1254, 1091. */
public class GridGraph {
    static final int[] DR = {1, -1, 0, 0}, DC = {0, 0, 1, -1};

    /**
     * Sinks the island containing (r, c) with an explicit stack; returns its area.
     */
    private static int sink(char[][] g, int r, int c) {
        int area = 0;
        Deque<int[]> stack = new ArrayDeque<>();
        g[r][c] = '0';
        stack.push(new int[] {r, c});
        while (!stack.isEmpty()) {
            int[] cur = stack.pop();
            area++;
            for (int d = 0; d < 4; d++) {
                int nr = cur[0] + DR[d], nc = cur[1] + DC[d];
                if (nr >= 0 && nc >= 0 && nr < g.length && nc < g[0].length
                        && g[nr][nc] == '1') {
                    g[nr][nc] = '0';                   // mark when pushed
                    stack.push(new int[] {nr, nc});
                }
            }
        }
        return area;
    }

    private static char[][] copy(char[][] g) {
        char[][] c = new char[g.length][];
        for (int i = 0; i < g.length; i++) c[i] = g[i].clone();
        return c;
    }

    /** LeetCode 200 (works on a copy, so the input is not destroyed). */
    public static int numIslands(char[][] grid) {
        char[][] g = copy(grid);
        int count = 0;
        for (int r = 0; r < g.length; r++)
            for (int c = 0; c < g[0].length; c++)
                if (g[r][c] == '1') {
                    sink(g, r, c);
                    count++;
                }
        return count;
    }

    /** LeetCode 695. */
    public static int maxAreaOfIsland(int[][] grid) {
        char[][] g = new char[grid.length][grid[0].length];
        for (int r = 0; r < g.length; r++)
            for (int c = 0; c < g[0].length; c++)
                g[r][c] = (char) ('0' + grid[r][c]);
        int best = 0;
        for (int r = 0; r < g.length; r++)
            for (int c = 0; c < g[0].length; c++)

        return best;
    }

    /** LeetCode 463: perimeter = 4 per land cell minus 2 per shared edge. */
    public static int islandPerimeter(int[][] grid) {
        int p = 0;
        for (int r = 0; r < grid.length; r++)
            for (int c = 0; c < grid[0].length; c++) {
                if (grid[r][c] == 0) continue;
                p += 4;
                if (r > 0 && grid[r - 1][c] == 1) p -= 2;
                if (c > 0 && grid[r][c - 1] == 1) p -= 2;
            }
        return p;
    }

    /** LeetCode 733: flood fill from (sr, sc). */
    public static int[][] floodFill(int[][] image, int sr, int sc, int color) {
        int old = image[sr][sc];
        int[][] img = new int[image.length][];
        for (int i = 0; i < img.length; i++) img[i] = image[i].clone();
        if (old == color) return img;
        Deque<int[]> stack = new ArrayDeque<>();
        img[sr][sc] = color;
        stack.push(new int[] {sr, sc});
        while (!stack.isEmpty()) {
            int[] cur = stack.pop();
            for (int d = 0; d < 4; d++) {
                int r = cur[0] + DR[d], c = cur[1] + DC[d];
                if (r >= 0 && c >= 0 && r < img.length && c < img[0].length
                        && img[r][c] == old) {
                    img[r][c] = color;
                    stack.push(new int[] {r, c});
                }
            }
        }
        return img;
    }

    /** Marks every '1' cell reachable from the border cells as '#'. */
    private static void markBorderLand(char[][] g) {
        int m = g.length, n = g[0].length;
        Deque<int[]> stack = new ArrayDeque<>();
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++)
                if ((r == 0 || c == 0 || r == m - 1 || c == n - 1)
                        && g[r][c] == '1') {
                    g[r][c] = '#';
                    stack.push(new int[] {r, c});
                }
        while (!stack.isEmpty()) {
            int[] cur = stack.pop();
            for (int d = 0; d < 4; d++) {
                int r = cur[0] + DR[d], c = cur[1] + DC[d];
                if (r >= 0 && c >= 0 && r < m && c < n && g[r][c] == '1') {
                    g[r][c] = '#';
                    stack.push(new int[] {r, c});
                }
            }
        }
    }

    /** LeetCode 1020: land cells that cannot reach the border. */
    public static int numEnclaves(int[][] grid) {
        char[][] g = new char[grid.length][grid[0].length];
        for (int r = 0; r < g.length; r++)
            for (int c = 0; c < g[0].length; c++)
                g[r][c] = (char) ('0' + grid[r][c]);
        markBorderLand(g);
        int count = 0;
        for (char[] row : g) for (char x : row) if (x == '1') count++;
        return count;
    }

    /** LeetCode 130: capture 'O' regions not connected to the border. */
    public static char[][] solve(char[][] board) {
        int m = board.length, n = board[0].length;
        char[][] g = new char[m][n];
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++) g[r][c] = board[r][c] == 'O' ? '1' : '0';
        markBorderLand(g);
        char[][] out = new char[m][n];
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++)
                out[r][c] = g[r][c] == '#' ? 'O' : 'X';
        return out;
    }

    /** LeetCode 1254: islands of 0 completely surrounded by 1 (water). */
    public static int closedIsland(int[][] grid) {
        char[][] g = new char[grid.length][grid[0].length];
        for (int r = 0; r < g.length; r++)
            for (int c = 0; c < g[0].length; c++)
                g[r][c] = grid[r][c] == 0 ? '1' : '0';
        markBorderLand(g);
        int count = 0;
        for (int r = 0; r < g.length; r++)
            for (int c = 0; c < g[0].length; c++)
                if (g[r][c] == '1') {
                    sink(g, r, c);
                    count++;
                }
        return count;
    }

    /** LeetCode 1091: shortest clear path, 8-directional, in cells; -1 if none. */
    public static int shortestPathBinaryMatrix(int[][] grid) {
        int n = grid.length;
        if (grid[0][0] == 1 || grid[n - 1][n - 1] == 1) return -1;
        boolean[][] seen = new boolean[n][n];
        Deque<int[]> queue = new ArrayDeque<>();
        queue.add(new int[] {0, 0, 1});
        seen[0][0] = true;
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            if (cur[0] == n - 1 && cur[1] == n - 1) return cur[2];
            for (int dr = -1; dr <= 1; dr++)
                for (int dc = -1; dc <= 1; dc++) {
                    int r = cur[0] + dr, c = cur[1] + dc;
                    if (r >= 0 && c >= 0 && r < n && c < n
                            && grid[r][c] == 0 && !seen[r][c]) {
                        seen[r][c] = true;
                        queue.add(new int[] {r, c, cur[2] + 1});
                    }
                }
        }
        return -1;
    }
}

G. Variations of the Pattern

Reverse flood from the goals

Pacific Atlantic Water Flow (417): instead of testing each cell, flood uphill from each ocean's border cells; the answer is the intersection of both reached sets.

Island shape and identity

Number of Distinct Islands (694): record the island's cells relative to its first cell (or the DFS move string with backtrack markers), put it in a Set.

Largest island after one flip

Making A Large Island (827): label islands and store sizes; for every water cell, add the sizes of the distinct adjacent labels + 1.

Weighted and obstacle grids

Minimum effort, rising water and obstacle removal are Dijkstra or 0-1 BFS on the grid (Chapter 53).

Online land

Number of Islands II (305): Union-Find over r · n + c; count after each addition (Chapter 52).

J. Interview Tips

INTERVIEW

Write the direction arrays first and a one-line bounds check: it is the most reused scaffold in matrix problems.

Ask whether diagonals count and whether you may modify the input; then choose in-place marking or a copy.

Mention stack depth: recursion up to mn frames is risky, so say you would use an explicit stack for big grids.

Follow-ups: return the island coordinates; handle a grid too large for memory (process in tiles, union boundary cells); diagonal adjacency; wrap-around (toroidal) grids; count distinct shapes.
Edge cases: all land, all water, single row or column, 1 × 1 grid, start equals end, blocked start.

CHAPTER SUMMARY

A grid is an implicit graph: neighbours come from direction arrays; never build an adjacency list.

Flood fill (DFS / BFS) finds and measures regions in O(mn); BFS gives fewest steps; weights need Dijkstra / 0-1 BFS.

Seed from the border to find what can or cannot escape: enclaves, surrounded regions, closed islands, Pacific Atlantic (reverse flood).

Mark visited when pushing; use an explicit stack for big grids; copy the grid if the input must survive.

Check bounds first, rows vs cols, 4 vs 8 directions, and whether the answer counts cells or edges.
