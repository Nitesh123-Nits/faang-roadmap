Interval DP

Solve small ranges first, then combine them by choosing a split point.

A. Pattern Overview

Interval DP has the state dp[l][r]: the best answer for the range l..r. The transition picks a split point or the last operation inside the range and combines two smaller ranges. Because every range depends on strictly shorter ranges, the table is filled by increasing length. The cost is O(n^2) states times O(n) choices: O(n^3).

Interval DP skeleton
for (int len = 2; len <= n; len++)               // shorter ranges first
    for (int l = 0; l + len - 1 < n; l++) {
        int r = l + len - 1;
        dp[l][r] = INF;
        for (int k = l; k < r; k++)                 // split point
            dp[l][r] = Math.min(dp[l][r], dp[l][k] + dp[k + 1][r] + cost(l, k, r));
    }

KEY IDEA

Think about the last action, not the first. In Burst Balloons, bursting k first leaves neighbours that depend on later choices; bursting k last in (l, r) fixes its neighbours at l and r, and the two sides become independent subproblems.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Remove / merge / burst elements one at a time and the cost depends on the neighbours."
"Minimum cost to multiply / merge / triangulate."
Parenthesisation or tree shape of a sequence.
A range [l, r] shrinks or splits and subranges are independent after a choice.
n is up to ~500 (cubic time is fine) or ~100 for four-way states.
ONE-LINE TEST

A sequence, a cost depending on the interval's ends, and a choice of split or last move: interval DP.

C. Core Intuition with Illustrations

Matrix Chain Multiplication: 10x30, 30x5, 5x60

Dimensions d = [10, 30, 5, 60] describe three matrices. Multiplying (AB)C costs 10*30*5 + 10*5*60 = 1500 + 3000 = 4500; A(BC) costs 30*5*60 + 10*30*60 = 9000 + 18000 = 27000. The DP discovers the cheaper order automatically.

Figure 138. Cheapest multiplication cost of each range.

Burst Balloons: choose the last balloon

Pad with 1 on both sides: [1, 3, 1, 5, 8, 1]. dp[l][r] is the best coins from bursting every balloon strictly between l and r. If k is last in (l, r), its neighbours at that moment are exactly l and r, so it earns a[l] a[k] a[r] and the two sides (l, k) and (k, r) are independent.

Figure 139. Burst Balloons table on the padded array.

The optimum 167 bursts 1, 5, 3, 8 in that order: 3*1*5 = 15, 3*5*8 = 120, 1*3*8 = 24, 1*8*1 = 8.

Palindrome Partitioning II (132)

Precompute pal[i][j] in O(n^2): s[i] == s[j] && (j - i < 2 || pal[i+1][j-1]). Then cut[j] is the minimum cuts for s[0..j]: zero if the whole prefix is a palindrome, else the best cut[i-1] + 1 over palindromic suffixes s[i..j]. For "aab":

jPrefixBest splitcut[j]

Minimum Score Triangulation (1039)

For a convex polygon with vertex values v, triangulating the range i..j means choosing the apex k of the triangle on edge (i, j): dp[i][j] = min over k of dp[i][k] + dp[k][j] + v[i] v[k] v[j]. The structure is the same as matrix chain.

Merge Stones (1000)

Merging exactly K consecutive piles at a time adds a third dimension (number of piles left) and a feasibility check (n - 1) % (K - 1) == 0. The cost of the final merge is the sum of the whole range, found from a prefix-sum array.

import java.util.*;

/** Ch 86: interval DP; LeetCode 312, 132, 1039, 1000 and matrix chain. */
public class IntervalDP {

    /**
     * Matrix chain: matrix i has size dims[i] x dims[i + 1]. dp[i][j] = fewest
     * scalar multiplications to multiply matrices i..j.
     */
    public static long matrixChain(int[] dims) {
        int n = dims.length - 1;
        if (n <= 1) return 0;
        long[][] dp = new long[n][n];
        for (int len = 2; len <= n; len++)
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                dp[i][j] = Long.MAX_VALUE;
                for (int k = i; k < j; k++)
                    dp[i][j] = Math.min(dp[i][j], dp[i][k] + dp[k + 1][j]
                            + (long) dims[i] * dims[k + 1] * dims[j + 1]);
            }
        return dp[0][n - 1];
    }

    /**
     * LeetCode 312: bursting balloon k earns a[l] * a[k] * a[r] for its
     * CURRENT neighbours. Think of k as the LAST balloon burst in (l, r).
     */
    public static int maxCoins(int[] nums) {
        int n = nums.length;
        int[] a = new int[n + 2];
        a[0] = a[n + 1] = 1;
        System.arraycopy(nums, 0, a, 1, n);
        int[][] dp = new int[n + 2][n + 2];
        for (int len = 2; len <= n + 1; len++)

Java 17+

            for (int l = 0; l + len <= n + 1; l++) {
                int r = l + len;
                for (int k = l + 1; k < r; k++)
                    dp[l][r] = Math.max(dp[l][r],
                            dp[l][k] + dp[k][r] + a[l] * a[k] * a[r]);
            }
        return dp[0][n + 1];
    }

    /** LeetCode 132: fewest cuts so that every piece is a palindrome. */
    public static int minCut(String s) {
        int n = s.length();
        boolean[][] pal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--)
            for (int j = i; j < n; j++)
                pal[i][j] = s.charAt(i) == s.charAt(j)
                        && (j - i < 2 || pal[i + 1][j - 1]);
        // cut[j]: best for prefix s[0..j]
        int[] cut = new int[n];
        for (int j = 0; j < n; j++) {
            if (pal[0][j]) { cut[j] = 0; continue; }
            cut[j] = j;
            for (int i = 1; i <= j; i++)
                if (pal[i][j]) cut[j] = Math.min(cut[j], cut[i - 1] + 1);
        }
        return n == 0 ? 0 : cut[n - 1];
    }

    /**
     * LeetCode 1039: triangulate a convex polygon with vertex values v; each
     * triangle costs the product of its vertices. dp[i][j] over the chord (i, j).
     */
    public static int minScoreTriangulation(int[] v) {
        int n = v.length;
        int[][] dp = new int[n][n];
        for (int len = 2; len < n; len++)
            for (int i = 0; i + len < n; i++) {
                int j = i + len;
                dp[i][j] = Integer.MAX_VALUE;
                for (int k = i + 1; k < j; k++)
                    dp[i][j] = Math.min(dp[i][j],
                            dp[i][k] + dp[k][j] + v[i] * v[k] * v[j]);
            }
        return dp[0][n - 1];
    }

    /**
     * LeetCode 1000: repeatedly merge exactly k consecutive piles; cost is the
     * total of the merged piles. Returns -1 when impossible.
     */
    public static int mergeStones(int[] stones, int k) {
        int n = stones.length;
        if ((n - 1) % (k - 1) != 0) return -1;
        int[] pre = new int[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + stones[i];
        int[][] dp = new int[n][n];
        for (int len = k; len <= n; len++)
            for (int i = 0; i + len <= n; i++) {
                int j = i + len - 1;
                dp[i][j] = Integer.MAX_VALUE;
                for (int m = i; m < j; m += k - 1)
                    dp[i][j] = Math.min(dp[i][j], dp[i][m] + dp[m + 1][j]);
                if ((len - 1) % (k - 1) == 0) dp[i][j] += pre[j + 1] - pre[i];
            }
        return dp[0][n - 1];
    }
}

TIME O(n^3)

SPACE O(n^2)

Three nested loops (length, left end, split) over an n x n table. minCut is O(n^2) because the palindrome table is O(n^2) and each cut[j] scans j suffixes. mergeStones is O(n^3 / K) time with O(n^2) space after rolling the pile count.

G. Variations of the Pattern

Cost depends on the endpoints

Matrix chain and triangulation: the combine cost uses l, k, r only.

Cost depends on the neighbours at the time

Burst Balloons, Remove Boxes (546), Strange Printer (664): choose the last element or the final merge so that the boundary is known.

Interval DP with a third dimension

Merge Stones adds the number of groups; Remove Boxes adds the count of equal boxes attached to the left end.

Palindromic intervals

pal[i][j] tables answer partitioning, counting palindromic substrings and Longest Palindromic Subsequence (Chapter 85).

Game intervals

Stone Game (877), Predict the Winner (486): dp[l][r] is the best score difference the current player can force on l..r; the opponent plays the rest, so dp[l][r] = max(a[l] -

dp[l+1][r], a[r] - dp[l][r-1]).

CHAPTER SUMMARY

Interval DP: state dp[l][r], filled by increasing length, combining two shorter ranges at a split point.

Choose the last action (balloon, merge, apex) so the two subranges are independent.

Complexity: O(n^2) states x O(n) splits = O(n^3); Knuth optimisation can reach O(n^2) for special costs.

Pad boundaries and set the diagonal base case.

Palindrome tables (pal[i][j]) feed partitioning and counting problems.
