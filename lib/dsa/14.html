String Patterns

Strings are arrays of characters with extra rules: same pointers, plus the cost of immutability.

A. Pattern Overview

String problems reuse array patterns (two pointers, sliding window, hashing) but add three recurring concerns: immutability (every concatenation copies), character sets (case, digits, Unicode, ASCII-only?), and construction (build the answer without quadratic copying). This chapter covers the pointer and simulation patterns that appear in nearly every screening round. Windows over substrings are in Chapter 2, frequency maps in Part III, and string-matching algorithms (KMP, Rabin-Karp, Z, Manacher) in Part XII.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Is s a subsequence of t?": one pass over t with a pointer into s.
"Palindrome" in the statement: compare from both ends, or expand from a centre.

Longest or count of palindromic substrings suggests expansion (O(n²)) before Manacher (O(n)).

"Ignore case / non-alphanumeric" means two pointers that skip characters rather than building a cleaned copy.
"In place" on a char[]: reader / writer pointers, as in Chapter 1.
A conversion that follows a geometric rule (zigzag, spiral of characters): simulate with a cursor and direction.
"Reverse the words": scan from the end or reverse twice; never split in a space-limited

setting.

C. Core Intuition with Illustrations

Expand around the centre. A palindrome is symmetric, so it is determined by its centre. A string of length n has 2n − 1 centres: n letters (odd-length palindromes) and n − 1 gaps between letters (even length). For each centre, grow l--, r++ while s[l] == s[r].

Figure 22. Each centre costs up to O(n); all 2n − 1 centres cost O(n²) with O(1) space.

Zigzag by cursor. Instead of computing indices with formulas, keep a row and a step (+1 going down, −1 going up); append each character to rows[row], flipping step at the top and bottom rows.

Figure 23. Concatenating the rows gives PAHNAPLSIIGYIR.

INTUITION

Immutability tax. In Java s += c inside a loop is O(n²) because each concatenation copies. Use StringBuilder (or a char[]) for any loop that builds output, and substring carefully: since JDK 7u6 it copies, so repeated slicing is also O(n) each.

D. Brute Force to Optimal Solution

Example: Longest Palindromic Substring (LeetCode 5)

Brute force: check every substring (i, j) for palindromicity: O(n³).
DP: dp[i][j] = s[i] == s[j] && dp[i+1][j-1]: O(n²) time and O(n²) space (or reversed-string LCS).
Expand around centre: same O(n²) time, O(1) space, and short to write: the interview default.
Manacher's algorithm: O(n) time. Rarely expected in interviews; covered in Part XII.

For Valid Palindrome II the brute force deletes each character and re-checks (O(n²)). The key observation is that only the first mismatch matters: the deleted character must be one of the two mismatching characters, so try both once, O(n) total.

E. Java Implementation

Subsequence, palindromes and common prefix

StringBasics.java — LeetCode 392, 125, 680, 14

Java 17+

/** String two-pointer family: LeetCode 392, 125, 680, 14. */
public class StringBasics {

    /** LeetCode 392 - Is Subsequence: greedy single pass over t. */
    public static boolean isSubsequence(String s, String t) {
        int i = 0;
        for (int j = 0; j < t.length() && i < s.length(); j++) {
            if (s.charAt(i) == t.charAt(j)) i++;     // match as early as possible
        }
        return i == s.length();
    }

    /** LeetCode 125 - Valid Palindrome: alphanumeric only, case-insensitive. */
    public static boolean isPalindrome(String s) {
        int left = 0;
        int right = s.length() - 1;
        while (left < right) {
            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) left++;
            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) right--;
            char a = Character.toLowerCase(s.charAt(left));
            char b = Character.toLowerCase(s.charAt(right));
            if (a != b) return false;
            left++;
            right--;
        }
        return true;
    }

    /** LeetCode 680 - Valid Palindrome II: may delete at most one character. */
    public static boolean validPalindromeII(String s) {
        int left = 0;
        int right = s.length() - 1;
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                // Mismatch: the deleted character is either the left or the right one.
                return isPalin(s, left + 1, right) || isPalin(s, left, right - 1);
            }
            left++;
            right--;
        }
        return true;
    }

    private static boolean isPalin(String s, int lo, int hi) {
        while (lo < hi) {
            if (s.charAt(lo++) != s.charAt(hi--)) return false;
        }
        return true;
    }

    /** LeetCode 14 - Longest Common Prefix: vertical scan, stops at the first mismatch. */
    public static String longestCommonPrefix(String[] strs) {
        if (strs.length == 0) return "";
        for (int col = 0; col < strs[0].length(); col++) {
            char c = strs[0].charAt(col);
            for (int row = 1; row < strs.length; row++) {
                if (col == strs[row].length() || strs[row].charAt(col) != c) {
                    return strs[0].substring(0, col);
                }
            }
        }
        return strs[0];
    }
}

TIME O(n)

SPACE O(1)

Character.isLetterOrDigit is Unicode-aware; use an ASCII check if the statement limits the alphabet. Inner while loops must keep left < right as a guard.

Zigzag, reverse words and in-place compression

StringSimulation.java — LeetCode 6, 151, 443

Java 17+

/** String construction and in-place compression: LeetCode 6, 151, 443. */
public class StringSimulation {

    /** LeetCode 6 - Zigzag Conversion: append each character to the row the cursor is on. */
    public static String zigzag(String s, int numRows) {
        if (numRows == 1 || numRows >= s.length()) return s;
        StringBuilder[] rows = new StringBuilder[numRows];
        for (int i = 0; i < numRows; i++) rows[i] = new StringBuilder();
        int row = 0;
        int step = 1;
        for (char c : s.toCharArray()) {
            rows[row].append(c);
            if (row == 0) step = 1;                  // bounce at the top
            else if (row == numRows - 1) step = -1;  // bounce at the bottom
            row += step;
        }
        StringBuilder out = new StringBuilder();
        for (StringBuilder r : rows) out.append(r);
        return out.toString();
    }
    /** LeetCode 151 - Reverse Words in a String: trims and collapses multiple spaces. */
    public static String reverseWords(String s) {
        StringBuilder out = new StringBuilder();
        int end = s.length();
        for (int i = s.length() - 1; i >= 0; i--) {
            if (s.charAt(i) == ' ') {
                // the next word (to the left) ends before i
                end = i;
            } else if (i == 0 || s.charAt(i - 1) == ' ') {
                if (out.length() > 0) out.append(' ');
                out.append(s, i, end);                // i is the first letter of a word
            }
        }
        return out.toString();
    }

    /**
     * LeetCode 443 - String Compression: in place with reader / writer pointers. Returns the
     * new length.
     */
    public static int compress(char[] chars) {
        int write = 0;
        int read = 0;
        while (read < chars.length) {
            char c = chars[read];
            int start = read;
            while (read < chars.length && chars[read] == c) read++;   // consume the run
            chars[write++] = c;
            int len = read - start;
            if (len > 1) {
                for (char d : Integer.toString(len).toCharArray()) chars[write++] = d;
            }
        }
        return write;
    }
}

TIME O(n)

SPACE O(n) / O(1) for compress

In compress, convert the run length with Integer.toString and write its digits one by one (counts above 9 take several characters).

Longest Palindromic Substring and Palindromic Substrings

LongestPalindromicSubstring.java — LeetCode 5 and 647

Java 17+

/**
 * LeetCode 5 - Longest Palindromic Substring (expand around every centre) and LeetCode 647.
 */
public class LongestPalindromicSubstring {

    public static String longestPalindrome(String s) {
        int bestStart = 0;
        int bestLen = 0;
        for (int centre = 0; centre < s.length(); centre++) {
            int odd = expand(s, centre, centre);          // odd length: single centre
            // even length: centre between two chars
            int even = expand(s, centre, centre + 1);
            int len = Math.max(odd, even);
            if (len > bestLen) {
                bestLen = len;
                bestStart = centre - (len - 1) / 2;
            }
        }
        return s.substring(bestStart, bestStart + bestLen);
    }

    /** LeetCode 647 - Palindromic Substrings: every successful expansion is one palindrome. */
    public static int countSubstrings(String s) {
        int count = 0;
        for (int centre = 0; centre < s.length(); centre++) {
            count += countAround(s, centre, centre);
            count += countAround(s, centre, centre + 1);
        }
        return count;
    }

    private static int expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--;
            r++;
        }
        return r - l - 1;                                  // length of the palindrome found
    }

    private static int countAround(String s, int l, int r) {
        int count = 0;
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            count++;
            l--;
            r++;
        }
        return count;
    }
}

TIME O(n²)

SPACE O(1)

Start index of an odd/even palindrome of length len around centre is centre − (len − 1) / 2.

G. Variations of the Pattern

Is Subsequence and the follow-up with many queries

For one s the greedy scan is optimal. With millions of queries against the same t, preprocess t into, for each character, a sorted list of positions; every query then binary searches the next occurrence of each character (O(|s| log |t|)). That is a direct application of Part II.

Valid Palindrome with removals

Allow at most one deletion (680) as implemented. For at most k deletions the question becomes longest palindromic subsequence (DP), a different pattern (Part XI).

Counting palindromic substrings

Every successful expansion step is a distinct palindrome (by position), so counting needs no extra bookkeeping: add one per step. This is countSubstrings in the same class.

Reverse words, in place

When the input is a mutable char[]: reverse the whole array, then reverse every word. O(n) time, O(1) space; the same three-reversal idea as Chapter 9. The listing above builds a new string by scanning from the right, which avoids split and regex overhead.

Run-length compression

Reader / writer pointers: read consumes a run, write emits the character and, for runs longer than 1, the decimal digits of the length. The write pointer never overtakes the read pointer, so it is safe in place.

J. Interview Tips

INTERVIEW

Ask about the alphabet and case first. It decides whether int[26], int[128] or a HashMap<Character, …> is appropriate.

Mention the StringBuilder reason (immutability) when you build output; interviewers listen for it.

For palindromes, state the centre count (2n − 1) to justify why both odd and even expansions are needed.

Follow-ups: many subsequence queries (position lists + binary search), at most k deletions, longest palindromic subsequence, shortest palindrome by prepending (KMP), Unicode and surrogate pairs.
Edge cases: empty string, single character, all identical characters, leading / trailing / repeated spaces, numRows greater than the length.

CHAPTER SUMMARY

String problems are array problems plus immutability: build output with StringBuilder or char[], compare characters (not references).

Subsequence: one greedy pointer into the pattern. Palindrome check: two ends, skip junk. One deletion: try both sides at the first mismatch.

Longest / count of palindromic substrings: expand around 2n − 1 centres in O(n²) time and O(1) space.

Zigzag, reverse words, compression: simulate with a cursor, scan from the right, or use reader / writer pointers.
