Fenwick Tree (Binary Indexed Tree)

Prefix sums with updates in a dozen lines, driven by the lowest set bit of the index.

A. Pattern Overview

A Fenwick tree (binary indexed tree, BIT) supports point update and prefix sum in O(log n) using one array and two loops. Index i (1-based) stores the sum of the lowbit(i) = i & -i elements ending at i. A prefix query hops down by removing the lowest set bit; an update hops up by adding it. Counting problems become easy: store a frequency array and ask how many values are <= x.

KEY IDEA

Fenwick trees only answer prefix queries natively, so the operation must be invertible (sum, XOR, count). For min/max use a segment tree (Chapter 96).

Building in linear time

Instead of n updates (O(n log n)), copy the array, then push each cell to its parent once: j = i + lowbit(i); if (j <= n) T[j] += T[i]. O(n).

Counting with ranks

For "count of smaller numbers after self", compress values to ranks 1..m. Scan from right to left: the answer for a[i] is prefix(rank(a[i]) - 1), then add(rank(a[i]), 1). Inversions and Reverse Pairs use the same loop with different rank queries.

k-th element by binary descent

Start at pos = 0, step 2^k for k from log n down to 0. If pos + step <= n and T[pos + step] < target, move there and subtract. At the end the answer is pos + 1. This is lowerBound, O(log

n), without a binary search over prefix queries.

RANGE UPDATE, RANGE SUM

Range add and range sum need two BITs: with a difference array d, sum(0..i) = (i+1) * prefix_d(i) - prefix_{d*idx}(i). Use a segment tree with lazy tags if you can't remember that identity.

E. Java Implementation

Fenwick tree: add, prefix, range, linear build, lowerBound

Fenwick.java: binary indexed tree with k-th element descent
/** Ch 97: Fenwick (binary indexed) tree, 1-based internally; LeetCode 307. */
public class Fenwick {
    private final long[] tree;
    private final int n;

    public Fenwick(int n) {
        this.n = n;
        this.tree = new long[n + 1];
    }

    /** Builds from values in O(n). */
    public Fenwick(int[] a) {
        this(a.length);
        for (int i = 1; i <= n; i++) {
            tree[i] += a[i - 1];
            int parent = i + (i & -i);
            if (parent <= n) tree[parent] += tree[i];
        }
    }

    /** Adds delta at 0-based index i. */
    public void add(int i, long delta) {
        for (i++; i <= n; i += i & -i) tree[i] += delta;
    }

    /** Sum of positions [0, i], 0-based. */
    public long prefix(int i) {
        long s = 0;
        for (i++; i > 0; i -= i & -i) s += tree[i];
        return s;
    }

    public long range(int l, int r) {
        return prefix(r) - (l == 0 ? 0 : prefix(l - 1));
    }

    /**

Java 17+

     * Smallest 0-based index whose prefix sum is >= target (values must be >= 0).
     */
    public int lowerBound(long target) {
        int pos = 0;
        int log = Integer.highestOneBit(Math.max(1, n));
        for (int step = log; step > 0; step >>= 1) {
            int next = pos + step;
            if (next <= n && tree[next] < target) {
                pos = next;
                target -= tree[next];
            }
        }
        return pos;     // 1-based pos + 1 - 1
    }
}

FenwickApps.java: coordinate-compressed counting, NumMatrix, RangeAdd

import java.util.*;

/** Ch 97: Fenwick applications; LeetCode 315, 327, 308, 1649, 493 style. */
public class FenwickApps {
    /** Rank compression: maps each value to 1..distinct in sorted order. */
    private static int[] ranks(int[] a) {
        int[] sorted = Arrays.stream(a).distinct().sorted().toArray();
        int[] r = new int[a.length];
        for (int i = 0; i < a.length; i++) r[i] = Arrays.binarySearch(sorted, a[i]);
        return r;
    }

    /** LeetCode 315: counts[i] = number of smaller elements to the right of i. */
    public static List<Integer> countSmaller(int[] nums) {
        int n = nums.length;
        int[] rank = ranks(nums);
        Fenwick bit = new Fenwick(n + 1);
        Integer[] out = new Integer[n];
        for (int i = n - 1; i >= 0; i--) {
            out[i] = rank[i] == 0 ? 0 : (int) bit.prefix(rank[i] - 1);
            bit.add(rank[i], 1);
        }
        return Arrays.asList(out);
    }

    /** LeetCode 327: number of subarray sums in [lower, upper]. */
    public static int countRangeSum(int[] nums, int lower, int upper) {
        int n = nums.length;
        long[] pre = new long[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];
        long[] sorted = Arrays.stream(pre).distinct().sorted().toArray();
        Fenwick bit = new Fenwick(sorted.length + 1);
        int count = 0;
        for (long p : pre) {
            // earlier prefixes q with p - upper <= q <= p - lower
            int lo = lowerIdx(sorted, p - upper);
            int hi = lowerIdx(sorted, p - lower + 1) - 1;
            if (hi >= lo) count += (int) bit.range(lo, hi);
            bit.add(lowerIdx(sorted, p), 1);
        }
        return count;
    }

    private static int lowerIdx(long[] a, long x) {
        int lo = 0, hi = a.length;
        while (lo < hi) {
            int m = (lo + hi) >>> 1;
            if (a[m] < x) lo = m + 1; else hi = m;
        }
        return lo;
    }

    /** LeetCode 308: mutable 2D prefix sums. */
    public static final class NumMatrix {
        private final long[][] tree;
        private final int[][] val;
        private final int m, n;

        public NumMatrix(int[][] matrix) {
            m = matrix.length;
n = m == 0 ? 0 : matrix[0].length;
            tree = new long[m + 1][n + 1];
            val = new int[m][n];
            for (int r = 0; r < m; r++)
                for (int c = 0; c < n; c++) update(r, c, matrix[r][c]);
        }

        public void update(int r, int c, int v) {
            int delta = v - val[r][c];
            val[r][c] = v;
            for (int i = r + 1; i <= m; i += i & -i)
                for (int j = c + 1; j <= n; j += j & -j) tree[i][j] += delta;
        }

        private long prefix(int r, int c) {
            long s = 0;
            for (int i = r + 1; i > 0; i -= i & -i)
                for (int j = c + 1; j > 0; j -= j & -j) s += tree[i][j];
            return s;
        }

        public int sumRegion(int r1, int c1, int r2, int c2) {
            return (int) (prefix(r2, c2) - prefix(r1 - 1, c2)
                    - prefix(r2, c1 - 1) + prefix(r1 - 1, c1 - 1));
        }
    }

    /** Range add, point query using a Fenwick tree over differences. */
    public static final class RangeAdd {
        private final Fenwick diff;

        public RangeAdd(int n) {
            diff = new Fenwick(n + 1);
        }

        public void add(int l, int r, long v) {
            diff.add(l, v);
            diff.add(r + 1, -v);
        }

        public long get(int i) {
            return diff.prefix(i);
        }
    }

    /** Counts inversions (i < j, a[i] > a[j]) with a Fenwick tree. */
    public static long inversions(int[] a) {
        int[] rank = ranks(a);
        Fenwick bit = new Fenwick(a.length + 1);
        long inv = 0;
        for (int i = 0; i < a.length; i++) {
            // earlier elements strictly greater
            inv += i - bit.prefix(rank[i]);
            bit.add(rank[i], 1);
        }
        return inv;
    }
}

TIME O(log n) per op, O(n) build

SPACE O(n)

Every loop removes or adds the lowest set bit, so at most log2(n) + 1 iterations. Compression adds an O(n log n) sort.

F. Detailed Dry Run

countSmaller([5, 2, 6, 1]): ranks of [1, 2, 5, 6] are 1, 2, 3, 4, so the array maps to [3,

2, 4, 1]. Scan from the right: 1 (rank 1): prefix(0) = 0; add rank 1. 6 (rank 4): prefix(3) =

1; add rank 4. 2 (rank 2): prefix(1) = 1; add rank 2. 5 (rank 3): prefix(2) = 2; add rank 3. Result left to right: [2, 1, 1, 0].

countRangeSum([-2, 5, -1], -2, 2): prefix sums 0, -2, 3, 2. For each prefix p[j] count earlier p[i] in [p[j] - 2, p[j] + 2]. p1 = -2: earlier {0} in [-4, 0] gives 1. p2 = 3: earlier {0, -2} in [1, 5] gives 0. p3 = 2: earlier {0, -2, 3} in [0, 4] gives 2 (0 and 3). Total 3.

G. Variations of the Pattern

Inversions and Reverse Pairs

Inversions: for each element count earlier elements greater than it. Reverse Pairs needs nums[i] > 2 nums[j], so compress both a[i] and 2a[i] into one rank space.

Queries on a Permutation with Key

Keep positions in a BIT with extra room at the front: moving an element to the front is add(old, -1), add(newFront, +1). The answer for a query is the prefix count before its position.

2D Fenwick

Nested loops for (i; i <= m; i += i & -i) for (j; j <= n; j += j & -j). Use it for dynamic matrix region sums (LeetCode 308, premium).

Fenwick with min or max

Works for prefix max with increases only (values never decrease), which suffices for LIS with dp[v] = max over earlier queries.

Offline with sorted queries

Sort queries by right end and sweep the array while updating the BIT; useful for "number of distinct values in a range" (record the last occurrence).

CHAPTER SUMMARY

A Fenwick tree stores block sums, with cell i owning the i & -i elements that end at i.

Queries drop the lowest set bit; updates add it, both in O(log n) with a few lines of code.

Rank counting is the main pattern: compress, scan, query a prefix, then add.

The operation must be invertible (sum, count, XOR); use a segment tree for min/max.

Binary descent finds the k-th element without nested binary search.
