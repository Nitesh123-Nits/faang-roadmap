Tree DFS

One recursion per node: return a summary up, or pass a bound down.

A. Pattern Overview

A binary tree is a recursive structure: a node, a left subtree and a right subtree. Depth-first search (DFS) exploits that: solve the problem on left and right, then combine at the node. Nearly every tree-DFS problem is one of two shapes:

ShapeInformation flowsThe function returnsExamples
Bottom-up (postorder)Children → parentA summary of the subtree (height, best path, is-balanced)Max depth, diameter, balanced tree, max path sum
Top-down (preorder)Parent → childrenUsually nothing, or a boolean; the parent passes a parameter (remaining sum, bounds, path so far)Path sum, root-to-leaf paths, validate BST, good nodes
BothDown, then upPass a parameter down; return a summary upPath Sum III (prefix sums), LCA, lowest-ancestor problems
KEY IDEA

Ask two questions at every node: (1) what do I need from each child? (that is the return value), and (2) what do I tell each child? (that is the parameter). The answer to the problem is then either the root's return value, or a global that every node updates (diameter, best path).

The three classic traversal orders differ only in when the node is visited relative to its two recursive calls:

OrderVisit positionTypical use
Preorder (root, left, right)Before both callsCopy or serialize a tree; top-down parameters
Inorder (left, root, right)Between the callsSorted order of a BST (Chapter 42)
Postorder (left, right, root)After both callsBottom-up summaries; delete a tree; evaluate expression trees

B. When to Recognize This Pattern

Pattern Recognition Signals

Any question whose answer for a node depends on its two subtrees: height, size, sum, balanced, symmetric, same tree, diameter.
"Root-to-leaf path" with a sum or a property: carry the running value down (Path Sum

I/II).

"Path between any two nodes": bottom-up; the best path bends at some node, but only one arm continues upward (diameter, max path sum).
"Count / find nodes satisfying a relation with their ancestors": pass the ancestor

information down (good nodes, validate BST).

"Do it without recursion" / a very deep (skewed) tree: the same DFS with an explicit stack, or Morris traversal for O(1) space.
ONE-LINE TEST

A tree problem with no ordering by levels and no BST property is almost always DFS. Decide bottom-up (return a summary) or top-down (pass a parameter); if you need both, return a summary and pass a parameter.

Bottom-up: diameter and the "bend" idea

The diameter is the number of edges on the longest path between any two nodes. That path bends at its highest node; there it uses a downward arm into each child, so its length is leftHeight + rightHeight. But the parent can only extend one arm, so the function returns 1 + max(left, right) while a global keeps the best bend.

Failing fast: Balanced Binary Tree

Balanced means every node's subtree heights differ by at most 1. Computing height at every node separately is O(n²) on a skewed tree. Instead return the height, or the sentinel -1 as soon as any subtree is unbalanced; the parents propagate it without further work: O(n).

Every tree algorithm uses this node

TreeNode.java: the shared node, with LeetCode level-order helpers

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

/**
 * Binary tree node, plus helpers to read and write LeetCode's level-order format
 * ({@code null} = missing child).
 */
public class TreeNode {
    public int val;
    public TreeNode left, right;

    public TreeNode(int val) { this.val = val; }

    public TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }

    /**
     * Builds a tree from level-order values, e.g. {3, 9, 20, null, null, 15, 7}.
     */
    public static TreeNode fromLevelOrder(Integer... vals) {
        if (vals.length == 0 || vals[0] == null) return null;
        TreeNode root = new TreeNode(vals[0]);
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);
        int i = 1;

Java 17+

        while (!queue.isEmpty() && i < vals.length) {
            TreeNode node = queue.poll();
            if (i < vals.length && vals[i] != null) {
                node.left = new TreeNode(vals[i]);
                queue.add(node.left);
            }
            i++;
            if (i < vals.length && vals[i] != null) {
                node.right = new TreeNode(vals[i]);
                queue.add(node.right);
            }
            i++;
        }
        return root;
    }

    /**
     * Level-order values with trailing nulls removed (the inverse of {@link
     * #fromLevelOrder}).
     */
    public static List<Integer> toLevelOrder(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        // LinkedList, not ArrayDeque: the queue holds null placeholders
        Queue<TreeNode> queue = new LinkedList<>();
        queue.add(root);
        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            if (node == null) { out.add(null); continue; }
            out.add(node.val);
            queue.add(node.left);
            queue.add(node.right);
        }
        int end = out.size();
        while (end > 0 && out.get(end - 1) == null) end--;
        return new ArrayList<>(out.subList(0, end));
    }
}

Traversals: recursive, iterative, and Morris

Traversals.java: LeetCode 144, 94, 145
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Deque;
import java.util.List;

/**
 * LeetCode 144 / 94 / 145 - preorder, inorder, postorder; recursive, iterative, and
 * Morris (O(1) space) inorder.
 */
public class Traversals {
    // ---- recursive: the visit position relative to the two recursive calls names
    // the order
    public static List<Integer> preorder(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        pre(root, out);
        return out;
    }

    private static void pre(TreeNode n, List<Integer> out) {

Java 17+

        if (n == null) return;
        out.add(n.val);                 // before the children
        pre(n.left, out);
        pre(n.right, out);
    }

    public static List<Integer> inorder(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        in(root, out);
        return out;
    }

    private static void in(TreeNode n, List<Integer> out) {
        if (n == null) return;
        in(n.left, out);
        out.add(n.val);                 // between the children
        in(n.right, out);
    }

    public static List<Integer> postorder(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        post(root, out);
        return out;
    }

    private static void post(TreeNode n, List<Integer> out) {
        if (n == null) return;
        post(n.left, out);
        post(n.right, out);
        out.add(n.val);                 // after the children
    }

    // ---- iterative with an explicit stack (no recursion depth limit)
    public static List<Integer> preorderIterative(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        if (root != null) stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode n = stack.pop();
            out.add(n.val);
            // right first so that left is popped first
            if (n.right != null) stack.push(n.right);
            if (n.left != null) stack.push(n.left);
        }
        return out;
    }

    public static List<Integer> inorderIterative(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            // dive left, remembering the path
            while (cur != null) { stack.push(cur); cur = cur.left; }
            cur = stack.pop();
            out.add(cur.val);
            cur = cur.right;
        }
        return out;
    }

    /** Postorder is the reverse of "root, right, left". */
    public static List<Integer> postorderIterative(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        if (root != null) stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode n = stack.pop();
            out.add(n.val);
            if (n.left != null) stack.push(n.left);
            if (n.right != null) stack.push(n.right);
        }
        Collections.reverse(out);
        return out;
    }

    /**
     * Morris inorder: temporary threads from each predecessor back to its ancestor;
     * O(1) extra space, tree restored.
     */
    public static List<Integer> inorderMorris(TreeNode root) {
        List<Integer> out = new ArrayList<>();
        TreeNode cur = root;
        while (cur != null) {
            if (cur.left == null) {
                out.add(cur.val);
                cur = cur.right;
            } else {
                TreeNode pred = cur.left;
                while (pred.right != null && pred.right != cur) pred = pred.right;
                // first visit: thread back to cur, then go left
                if (pred.right == null) {
                    pred.right = cur;
                    cur = cur.left;
                // second visit: remove the thread, visit cur, go right
                } else {
                    pred.right = null;
                    out.add(cur.val);
                    cur = cur.right;
                }
            }
        }
        return out;
    }
}

TIME O(n)

SPACE O(h) (Morris: O(1))

h is the height: log n for a balanced tree, n for a chain. Morris temporarily threads each predecessor's right pointer to its ancestor and removes it again, so the tree is restored.

        if (root == null) return 0;

    }

    /** LeetCode 226 - Invert Binary Tree: swap the children at every node. */
    public static TreeNode invert(TreeNode root) {
        if (root == null) return null;
        TreeNode left = invert(root.left), right = invert(root.right);
        root.left = right;
        root.right = left;
        return root;
    }

    /** LeetCode 100 - Same Tree: equal shape and equal values. */
    public static boolean isSameTree(TreeNode a, TreeNode b) {
        if (a == null || b == null) return a == b;
        return a.val == b.val
                && isSameTree(a.left, b.left)
                && isSameTree(a.right, b.right);
    }

    /** LeetCode 101 - Symmetric Tree: the left subtree mirrors the right one. */
    public static boolean isSymmetric(TreeNode root) {
        return root == null || mirror(root.left, root.right);
    }

    private static boolean mirror(TreeNode a, TreeNode b) {
        if (a == null || b == null) return a == b;
        return a.val == b.val && mirror(a.left, b.right) && mirror(a.right, b.left);
    }

    /**
     * LeetCode 572 - Subtree of Another Tree: O(m * n) by trying every node as a
     * root.
     */
    public static boolean isSubtree(TreeNode root, TreeNode sub) {
        if (root == null) return sub == null;
        return isSameTree(root, sub)
                || isSubtree(root.left, sub)
                || isSubtree(root.right, sub);
    }
}

TIME O(n) (subtree: O(m·n))

SPACE O(h)

isSameTree and mirror use a == b when either side is null: both null is a match, one null is a mismatch.

Diameter of a binary tree

DiameterOfBinaryTree.java: LeetCode 543
/**
 * LeetCode 543 - Diameter of Binary Tree (edges on the longest path). Height
 * returned up, best path kept in a field-free holder.
 */
public class DiameterOfBinaryTree {
    public static int diameter(TreeNode root) {
        int[] best = {0};
        height(root, best);
        return best[0];
    }

Java 17+

    /**
     * Returns the height (in nodes) of n; updates best with the longest path that
     * bends at n.
     */
    private static int height(TreeNode n, int[] best) {
        if (n == null) return 0;
        int left = height(n.left, best);
        int right = height(n.right, best);
        // path through n uses both downward arms
        best[0] = Math.max(best[0], left + right);
        // but only one arm can continue upward
        return 1 + Math.max(left, right);
    }
}

TIME O(n)

SPACE O(h)

best is a one-element array so the recursion can update it. Heights are in nodes, so left + right is the path length in edges.

Balanced binary tree

BalancedBinaryTree.java: LeetCode 110
/**
 * LeetCode 110 - Balanced Binary Tree. A single pass returns the height, or -1 as
 * soon as any subtree is unbalanced.
 */
public class BalancedBinaryTree {
    public static boolean isBalanced(TreeNode root) {
        return height(root) != -1;
    }

    private static int height(TreeNode n) {
        if (n == null) return 0;
        int left = height(n.left);
        // propagate failure without visiting the right side
        if (left == -1) return -1;
        int right = height(n.right);
        if (right == -1 || Math.abs(left - right) > 1) return -1;
        return 1 + Math.max(left, right);
    }
}

Java 17+

TIME O(n)

SPACE O(h)

The −1 sentinel stops all further work as soon as one subtree fails.

Path sums: root-to-leaf, all paths, and any downward path

PathSum.java: LeetCode 112, 113, 437
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

/**
 * LeetCode 112 / 113 / 437 - root-to-leaf path sums and path sums that start and
 * end anywhere downward.

Java 17+

 */
public class PathSum {
    /** 112: does a root-to-leaf path sum to target? */
    public static boolean hasPathSum(TreeNode root, int target) {
        if (root == null) return false;
        if (root.left == null && root.right == null) return root.val == target;
        return hasPathSum(root.left, target - root.val)
                || hasPathSum(root.right, target - root.val);
    }

    /**
     * 113: every root-to-leaf path with the given sum (backtracking on a shared
     * list).
     */
    public static List<List<Integer>> allPaths(TreeNode root, int target) {
        List<List<Integer>> out = new ArrayList<>();
        walk(root, target, new ArrayList<>(), out);
        return out;
    }

    private static void walk(TreeNode n, int remain, List<Integer> path,
                             List<List<Integer>> out) {
        if (n == null) return;
        path.add(n.val);                                // choose
        if (n.left == null && n.right == null && remain == n.val)
            out.add(new ArrayList<>(path));
        walk(n.left, remain - n.val, path, out);
        walk(n.right, remain - n.val, path, out);
        path.remove(path.size() - 1);                   // unchoose
    }

    /**
     * 437: count downward paths (any start, any end) with the given sum, using
     * prefix sums along the current path.
     */
    public static int countPaths(TreeNode root, int target) {
        Map<Long, Integer> seen = new HashMap<>();
        seen.put(0L, 1);                                // the empty prefix
        return count(root, 0L, target, seen);
    }

    private static int count(TreeNode n, long prefix, int target,
                             Map<Long, Integer> seen) {
        if (n == null) return 0;
        prefix += n.val;
        // paths ending here that start just below an ancestor
        int total = seen.getOrDefault(prefix - target, 0);
        seen.merge(prefix, 1, Integer::sum);                  // choose
        total += count(n.left, prefix, target, seen)
                + count(n.right, prefix, target, seen);
        seen.merge(prefix, -1, Integer::sum);                 // unchoose
        return total;
    }
}

TIME O(n) (113: O(n²) worst)

SPACE O(h)

113 copies a path of length up to h at each qualifying leaf. In 437, long prefix sums avoid overflow, and the map entry is decremented on return.

G. Variations of the Pattern

Passing state down

Count Good Nodes (1448) passes the maximum so far; Sum Root to Leaf Numbers (129) passes num·10 + digit; Validate BST passes (lo, hi) bounds (Chapter 42).

Returning more than one value

House Robber III returns (rob, skip); Binary Tree Cameras returns a three-state code (Chapter 44). A record or a small int[] keeps the code clean.

Collecting paths

Backtracking on a shared list (Binary Tree Paths 257, Path Sum II 113): add on entry, record at leaves, remove on exit.

Two trees at once

Same Tree, Symmetric Tree, Merge Two Binary Trees (617), Subtree of Another Tree: recurse on a pair of nodes with the same base cases.

Iterative and Morris traversals

When the tree can be 10⁵ deep, replace recursion with a stack; when even O(h) space is too much, use Morris (O(1) extra space, O(n) time, temporarily modifies pointers: not thread-safe).

J. Interview Tips

INTERVIEW

Say the two questions aloud: "what do I need from each child, and what do I tell each child?" Then the code writes itself.

Mention the O(h) stack and what h is for a skewed tree; offer the iterative or Morris version as the follow-up.

For path problems, point out the bend: the answer may use both children, but the return value uses only one.

Follow-ups: iterative version; O(1) space (Morris); count nodes in O(log² n) for a complete tree; an n-ary tree; a tree with parent pointers.
Edge cases: empty tree, single node, skewed tree (a linked list), negative values, duplicate values, a leaf with one child missing.

CHAPTER SUMMARY

Tree DFS = solve both subtrees, combine at the node. Decide what each child returns (summary, bottom-up) and what it receives (parameter, top-down).

Preorder / inorder / postorder differ only in when the node is visited; inorder of a BST is sorted.

Path problems bend: update a global with left + right (plus the node), but return only the better arm to the parent.

Fail fast with a sentinel (−1) so a bad subtree stops all work; prefix sums + a map turn path-sum counting into O(n).

For deep trees use an explicit stack; for O(1) space use Morris threading.
