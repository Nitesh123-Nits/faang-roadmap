Matrix Traversal and Manipulation

Four shrinking boundaries, a transpose, and bits in the cells: grids without extra grids.

A. Pattern Overview

A matrix is an array with two indices, and most interview matrix problems are not about search but about systematic traversal and in-place transformation. Four ideas cover the majority of them:

KEY IDEA

Grid traversal gets easy when you pick an invariant that names a position:

top/bottom/left/right for rings, r + c for anti-diagonals, r - c for diagonals, (r /

* 3 + c / 3 for sudoku boxes, (index / cols, index % cols) to flatten. Write the invariant in a comment before the loop.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Return the elements in spiral / diagonal / zigzag order": boundary shrinking or an index invariant.
"Rotate / flip / transpose the matrix in place": combine transpose and reversal; do not

allocate a second grid if the statement forbids it.

"If a cell is 0, set its row and column to 0", or any update that must not see its own changes: separate marking from applying, using spare storage inside the matrix.
Simultaneous cell updates (cellular automata, Game of Life): encode both states in a cell.
Validate a board (Sudoku, N-Queens placement): one set or bitmask per row, column, and box.
m, n ≤ 200 and a requirement of O(1) extra space.
SQUARE VS RECTANGLE

Beware non-square inputs. Transposing in place only works for n × n (rotating a rectangular matrix needs a new n × m grid), and boundary-shrinking spirals need the "does a row/column remain?" guards.

C. Core Intuition with Illustrations

Spiral = peel the outer ring, repeat. Walk the top row left to right, the right column downward, the bottom row right to left, the left column upward, then shrink all four boundaries by one. Two guards (top <= bottom before the bottom row, left <= right before the left column) handle the last single row or column.

Figure 24. Visit order 1 → 12: the outer ring is peeled first, then the remaining inner row.

Rotate 90° clockwise = transpose, then reverse every row. The cell at (i, j) ends up at (j, n−1−i); the transpose sends it to (j, i) and the row reversal mirrors the column index.

INTUITION

Counter-clockwise rotation: transpose then reverse each column (or reverse each row first, then transpose). 180°: reverse rows, then reverse each row. Memorise the 90° case and derive the rest by composition.

Set Zeroes in O(1) space. If you zero rows immediately, later cells see fake zeros. Instead, record zeros in the first row and first column (they act as per-column and per-row flags), apply from the inside out, and use two booleans to remember whether the first row and column originally contained a zero.

D. Brute Force to Optimal Solution

Example: Set Matrix Zeroes (LeetCode 73)

Copy the matrix: read from the copy, write to the original: O(mn) space.
Two boolean arrays zeroRow[m], zeroCol[n]: O(m + n) space.
Markers inside the matrix: reuse the first row and column as those arrays: O(1) space. The first row/column need their own two booleans because they double as storage.
Apply order matters: inner cells first (using the markers), then the first row and column last.

The same ladder appears in Rotate Image: allocate a new grid (rotated[j][n−1−i] = m[i][j], O(n²) space), then rotate four cells at a time in cycles (O(1)), or transpose-then-reverse (O(1), the easiest to remember).

E. Java Implementation

Spiral Matrix I and II

SpiralMatrix.java — LeetCode 54 and 59

Java 17+

import java.util.ArrayList;
import java.util.List;

/**
 * LeetCode 54 - Spiral Matrix and LeetCode 59 - Spiral Matrix II: shrinking four boundaries.
 */
public class SpiralMatrix {

    public static List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> out = new ArrayList<>();
        int top = 0;
        int bottom = matrix.length - 1;
        int left = 0;
        int right = matrix[0].length - 1;
        while (top <= bottom && left <= right) {
            // top row  ->
            for (int c = left; c <= right; c++) out.add(matrix[top][c]);
            top++;
            // right column v
            for (int r = top; r <= bottom; r++) out.add(matrix[r][right]);
            right--;
            // a row may remain
            if (top <= bottom) {
                // bottom row <-
                for (int c = right; c >= left; c--) out.add(matrix[bottom][c]);
                bottom--;
            }
            // a column may remain
            if (left <= right) {
                // left column ^
                for (int r = bottom; r >= top; r--) out.add(matrix[r][left]);
                left++;
            }
        }
        return out;
    }

    public static int[][] generateMatrix(int n) {
        int[][] m = new int[n][n];
        int top = 0, bottom = n - 1, left = 0, right = n - 1, value = 1;
        while (top <= bottom && left <= right) {
            for (int c = left; c <= right; c++) m[top][c] = value++;
            top++;
            for (int r = top; r <= bottom; r++) m[r][right] = value++;
            right--;
            if (top <= bottom) {
                for (int c = right; c >= left; c--) m[bottom][c] = value++;
                bottom--;
            }
            if (left <= right) {
                for (int r = bottom; r >= top; r--) m[r][left] = value++;
                left++;
            }
        }
        return m;
    }
}

TIME O(m·n)

SPACE O(1) extra

The two if guards before the bottom row and left column prevent duplicates when one row or column is left.

Rotate Image

RotateImage.java — LeetCode 48

Java 17+

/**
 * LeetCode 48 - Rotate Image 90 degrees clockwise in place: transpose, then reverse every
 * row.
 */
public class RotateImage {

    public static void rotate(int[][] matrix) {
        int n = matrix.length;
        for (int i = 0; i < n; i++) {
            // transpose: swap across the diagonal
            for (int j = i + 1; j < n; j++) {
                int tmp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = tmp;
            }
        }
        for (int[] row : matrix) {                           // mirror each row left <-> right
            for (int lo = 0, hi = n - 1; lo < hi; lo++, hi--) {
                int tmp = row[lo];
                row[lo] = row[hi];
                row[hi] = tmp;
            }
        }
    }
}

TIME O(n²)

SPACE O(1)

The inner loop starts at j = i + 1 so each pair is swapped once; starting at 0 would swap everything back.

Set Matrix Zeroes

SetMatrixZeroes.java — LeetCode 73

Java 17+

/**
 * LeetCode 73 - Set Matrix Zeroes in O(1) extra space: the first row and column store the
 * flags.
 */
public class SetMatrixZeroes {

    public static void setZeroes(int[][] matrix) {
        int rows = matrix.length;
        int cols = matrix[0].length;
        boolean firstRowZero = false;
        boolean firstColZero = false;
        for (int c = 0; c < cols; c++) if (matrix[0][c] == 0) firstRowZero = true;
        for (int r = 0; r < rows; r++) if (matrix[r][0] == 0) firstColZero = true;

        // use row 0 / col 0 as marker arrays
        for (int r = 1; r < rows; r++) {
            for (int c = 1; c < cols; c++) {
                if (matrix[r][c] == 0) {
                    matrix[r][0] = 0;
                    matrix[0][c] = 0;
                }
            }
        }
        // apply the markers (inner cells only)
        for (int r = 1; r < rows; r++) {
            for (int c = 1; c < cols; c++) {
                if (matrix[r][0] == 0 || matrix[0][c] == 0) matrix[r][c] = 0;
            }
        }
        if (firstRowZero) for (int c = 0; c < cols; c++) matrix[0][c] = 0;   // markers last
        if (firstColZero) for (int r = 0; r < rows; r++) matrix[r][0] = 0;
    }
}

TIME O(m·n)

SPACE O(1)

Process the first row and column last, otherwise the markers are destroyed before they are used.

G. Variations of the Pattern

Valid Sudoku: one bitmask per row, column and box

A board is valid if no digit repeats in any row, column or 3 × 3 box. Keep nine bitmasks per group; the box index is (r / 3) * 3 + c / 3. One pass, O(81) = O(1) time.

ValidSudoku.java — LeetCode 36

Java 17+

/** LeetCode 36 - Valid Sudoku: one pass with bitmasks for every row, column and 3x3 box. */
public class ValidSudoku {

    public static boolean isValidSudoku(char[][] board) {
        int[] rows = new int[9];
        int[] cols = new int[9];
        int[] boxes = new int[9];
        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                char ch = board[r][c];
                if (ch == '.') continue;
                int bit = 1 << (ch - '1');
                int box = (r / 3) * 3 + c / 3;               // box index 0..8
                if ((rows[r] & bit) != 0 || (cols[c] & bit) != 0 || (boxes[box] & bit) != 0) {
                    return false;
                }
                rows[r] |= bit;
                cols[c] |= bit;
                boxes[box] |= bit;
            }
        }
        return true;
    }
}

TIME O(1) (fixed 9 × 9)

SPACE O(1)

Only filled cells are checked; the board need not be solvable.

Game of Life: encode two generations in one int

Each cell must be updated using the old neighbours. Store the old state in bit 0 and the new state in bit 1; read neighbours with & 1; at the end shift every cell right by one. No copy of the board is needed.

GameOfLife.java — LeetCode 289

Java 17+

/** LeetCode 289 - Game of Life in place: encode (old, new) state in two bits. */
public class GameOfLife {

    public static void gameOfLife(int[][] board) {
        int rows = board.length;
        int cols = board[0].length;
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                int live = 0;
                for (int dr = -1; dr <= 1; dr++) {
                    for (int dc = -1; dc <= 1; dc++) {
                        if (dr == 0 && dc == 0) continue;
                        int nr = r + dr;
                        int nc = c + dc;
                        if (nr >= 0 && nr < rows && nc >= 0 && nc < cols) {
                            // bit 0 = OLD state, still readable
                            live += board[nr][nc] & 1;
                        }
                    }
                }
                boolean willLive = board[r][c] == 1 ? (live == 2 || live == 3) : live == 3;
                if (willLive) board[r][c] |= 2;                // bit 1 = NEW state
            }
        }
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) board[r][c] >>= 1;   // keep only the new state
        }
    }
}

TIME O(m·n)

SPACE O(1)

On an infinite board the follow-up is to track only live cells in a set, which is O(live) per step.

Diagonal Traverse: the anti-diagonal invariant

All cells with the same r + c lie on one anti-diagonal; even-numbered diagonals go up-right, odd ones down-left. Bounce when the walk hits the first/last row or column, in the right order of checks.

DiagonalTraverse.java — LeetCode 498

Java 17+

/**
 * LeetCode 498 - Diagonal Traverse: the anti-diagonal index is r + c; direction flips per
 * diagonal.
 */
public class DiagonalTraverse {

    public static int[] findDiagonalOrder(int[][] mat) {
        int rows = mat.length;
        int cols = mat[0].length;
        int[] out = new int[rows * cols];
        int r = 0;
        int c = 0;
        for (int i = 0; i < out.length; i++) {
            out[i] = mat[r][c];
            if ((r + c) % 2 == 0) {                          // moving up-right
                if (c == cols - 1) r++;
                else if (r == 0) c++;
                else { r--; c++; }
            } else {                                         // moving down-left
                if (r == rows - 1) c++;
                else if (c == 0) r++;
                else { r++; c--; }
            }
        }
        return out;
    }
}

TIME O(m·n)

SPACE O(1) extra

Other grid idioms to know
Direction arrays: int[][] dirs = {{0,1},{1,0},{0,-1},{-1,0}} with a visited grid or a rotating direction index (the alternative spiral implementation).
Flatten: index → (index / cols, index % cols); used in Chapter 15 for 2D binary search.
Layer-by-layer rotation: four-cell cycles in rings; O(1) space, trickier indices than transpose + reverse.
Search in grids (islands, flood fill, shortest path) belongs to the Graph part (grid-based

BFS / DFS).

J. Interview Tips

INTERVIEW

Start with the easy extra-space version, then state the O(1) improvement: "I can reuse the first row and column as markers".

Draw a 3 × 3 and a 3 × 4 example. Spiral bugs appear only on rectangles with an odd leftover row or column.

Name the invariant (r + c, box index, flatten formula) before coding: it signals structure rather than trial and error.

Follow-ups: rotate counter-clockwise, rotate a non-square matrix, spiral in reverse, spiral of a linked structure, infinite Game of Life, solve Sudoku (backtracking, Part VI).
Edge cases: 1 × 1, single row, single column, all zeros, zero only in the first row /

column.

CHAPTER SUMMARY

Matrix problems are solved by naming an invariant: four boundaries, r + c, box index, or the flatten formula.

Spiral: shrink top/bottom/left/right; guard the bottom row and left column. Rotate 90° clockwise: transpose, then reverse each row.

Set Zeroes: mark with the first row and column, apply inside-out, handle row 0 and column 0 last. Game of Life: two generations in two bits.

Always test 1 × n, n × 1 and non-square inputs; keep rows and cols separate.
