State Machine DP

Name the states, draw the allowed transitions, and keep one value per state.

A. Pattern Overview

Some problems are best seen as a finite automaton: at each step you are in one of a few states (holding a stock, in cooldown, painted red), and each step moves you along an allowed transition that earns or costs something. The DP keeps one value per state and updates all of them from the previous step's values. Part I covered the basic stock problems with greedy and Kadane-style passes; this chapter gives the general framework that also handles cooldowns, fees and at most k transactions, plus colouring problems with a neighbour constraint.

KEY IDEA

Draw the automaton first. Every edge becomes one line of the update; the starting state gets the base value and the answer is the best of the final states that are legal to end in.

B. When to Recognize This Pattern

Pattern Recognition Signals

A day-by-day process with modes (holding or not, cooling down, on or off).
"At most k transactions", "cooldown", "fee per transaction".
A constraint between consecutive choices: different colours for neighbours, no two consecutive identical actions.
A small number of modes (2 to 5) so that the state per step is a vector, not a table.
Greedy fails because the best action today depends on the mode you want to be in tomorrow.
ONE-LINE TEST

Sequence + a handful of modes + allowed transitions: keep one value per mode.

At most k transactions

Let hold[t] be the best profit while holding a share during the t-th transaction, and free[t] the best profit after finishing t transactions. Update per price p: hold[t] = max(hold[t], free[t-1] - p); free[t] = max(free[t], hold[t] + p). For k = 2, prices [3,3,5,0,0,3,1,4]:

SHORTCUT

When k >= n / 2 transactions are never the limit; the answer is the sum of all positive day-to-day gains (Stock II). Check this first to avoid an O(n k) table for huge k.

Transaction fee (714)

Two states are enough: cash (no share) and hold. Pay the fee when selling: cash = max(cash, hold + p - fee); hold = max(hold, cash - p). For prices [1,3,2,8,4,9] and fee 2 the best is 8 (buy 1, sell 8 minus fee 2 gives 5; buy 4, sell 9 minus fee 2 gives 3).

Paint House (256)

Neighbouring houses must differ in colour. Keep the best cost of painting the prefix with the last house in each colour: red' = cost[red] + min(green, blue) and so on. For costs

Paint House II (265): k colours in O(nk)

Naively each house takes O(k^2). Keep only the smallest and second smallest values of the previous row: a colour can use the smallest unless it was that colour's own, in which case it uses the second smallest. That is O(n k) overall.

E. Java Implementation

Stock with k, two, cooldown, fee; paint house with 3 and k colours

StockStates.java: LeetCode 188, 123, 309, 714, 256, 265
import java.util.*;

/** Ch 89: state-machine DP; LeetCode 188, 123, 309, 714, 256, 265. */
public class StockStates {

    /**
     * LeetCode 188: at most k transactions (a buy followed by a sell).
     * States per transaction count t: hold[t] (a share in hand, t buys made) and
     * free[t] (no share, t sells made).
     */
    public static int maxProfitK(int k, int[] prices) {
        if (k <= 0 || prices.length < 2) return 0;
        int[] hold = new int[k + 1], free = new int[k + 1];
        Arrays.fill(hold, Integer.MIN_VALUE / 2);
        for (int p : prices)
            for (int t = 1; t <= k; t++) {
                hold[t] = Math.max(hold[t], free[t - 1] - p);        // buy
                free[t] = Math.max(free[t], hold[t] + p);            // sell
            }
        return free[k];
    }

    /** LeetCode 123: at most two transactions. */
    public static int maxProfitTwo(int[] prices) {
        return maxProfitK(2, prices);
    }

    /** LeetCode 309: unlimited transactions, one day of cooldown after a sell. */
    public static int maxProfitCooldown(int[] prices) {
        int hold = Integer.MIN_VALUE / 2, sold = 0, rest = 0;

Java 17+

        for (int p : prices) {
            int prevSold = sold;
            sold = hold + p;                      // sell today
            // keep, or buy from the rest state
            hold = Math.max(hold, rest - p);
            rest = Math.max(rest, prevSold);      // idle (cooldown just ended)
        }
        return Math.max(sold, rest);
    }

    /** LeetCode 714: unlimited transactions, a fee paid on every sell. */
    public static int maxProfitFee(int[] prices, int fee) {
        int hold = Integer.MIN_VALUE / 2, free = 0;
        for (int p : prices) {
            hold = Math.max(hold, free - p);
            free = Math.max(free, hold + p - fee);
        }
        return free;
    }

    /** LeetCode 256: paint houses with 3 colours, neighbours differ; min cost. */
    public static int paintHouse(int[][] costs) {
        if (costs.length == 0) return 0;
        int r = costs[0][0], g = costs[0][1], b = costs[0][2];
        for (int i = 1; i < costs.length; i++) {
            int nr = costs[i][0] + Math.min(g, b);
            int ng = costs[i][1] + Math.min(r, b);
            int nb = costs[i][2] + Math.min(r, g);
            r = nr;
            g = ng;
            b = nb;
        }
        return Math.min(r, Math.min(g, b));
    }

    /** LeetCode 265: k colours; keep the two smallest previous costs. */
    public static int paintHouseK(int[][] costs) {
        int n = costs.length;
        if (n == 0) return 0;
        int k = costs[0].length;
        int[] prev = costs[0].clone();
        for (int i = 1; i < n; i++) {
            int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE, idx = -1;
            for (int c = 0; c < k; c++) {
                if (prev[c] < min1) {
                    min2 = min1;
                    min1 = prev[c];
                    idx = c;
                } else if (prev[c] < min2) {
                    min2 = prev[c];
                }
            }
            int[] cur = new int[k];
            for (int c = 0; c < k; c++)
                cur[c] = costs[i][c] + (c == idx ? min2 : min1);
            prev = cur;
        }
        int best = Integer.MAX_VALUE;
        for (int v : prev) best = Math.min(best, v);
        return best;
    }
}

Always update sold using the previous hold, and rest using the previous sold; the code saves prevSold before overwriting to keep the order right.

G. Variations of the Pattern

Unlimited transactions (Stock II) and one transaction (Stock I)

Special cases: one state pair and k = 1, or k = infinity where the sum of positive gaps wins (Chapter 1's Kadane-style reasoning).

Cooldown of c days

Extend the automaton with a queue of c cooldown states, or look back c + 1 days when buying.

House colouring and fences

Paint Fence (276) counts colourings with at most two equal neighbours: states same and diff. Paint House III (1473) adds a target number of neighbourhoods as another dimension.

Game and toggle automata

Student Attendance Record II (552): states (absences, trailing lates); Knight Dialer (935): state = current digit; both are automaton DPs with counting and a modulus.

Stock with k and fee together

Combine the layered hold[t], free[t] with a fee on sale; the structure does not change.

J. Interview Tips

INTERVIEW

Draw the states and arrows before writing code; it communicates the model at once.

List the base values for each state (what is legal on day 0).

Mention the k >= n / 2 shortcut for Stock IV; it is a common trap.

Follow-ups: return the transactions (keep parent days); a cooldown of c days; fee on both

sides; transactions that cannot overlap.

Edge cases: one price, decreasing prices, k = 0, all equal prices, empty array.

CHAPTER SUMMARY

State machine DP: one value per mode, updated each step from the previous step's values.

Stock problems differ only in the automaton: cooldown adds rest, fee changes the sell edge, k transactions layer the pair hold, free.

Initialise holding states to -infinity and never overflow when subtracting a price.

Paint House keeps the best cost per last colour; with k colours track min and second min.

Draw the automaton first; the code is its edge list.
