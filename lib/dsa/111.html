Segment Tree

Answer range queries and point or range updates in O(log n) with a tree of intervals.

A. Pattern Overview

A segment tree stores, for every node, a summary (sum, min, max, gcd, count) of an interval of the array. The root covers everything; children cover the two halves. Any range [l, r] decomposes into at most 2 log n nodes, and changing one element recomputes only the log n ancestors. With lazy propagation, adding a value to a whole range is also O(log n).

KEY IDEA

The only requirement on the combine function is associativity (and an identity element). Sum, min, max, gcd, XOR, matrix product and "max with position" all qualify.

B. When to Recognize This Pattern

Pattern Recognition Signals

Interleaved updates and range queries on an array (Range Sum Query - Mutable).
A range query that is not a sum (min, max, gcd), so a Fenwick tree is awkward.
"Add v to every element in [l, r]" mixed with queries: lazy propagation.
Dynamic programming whose transition is a range maximum over a value window (LIS II).

Updates and range queries are interleaved, and the combine is not simply invertible: segment tree.

The bottom-up (iterative) layout

Store leaves at t[n..2n-1] and set t[i] = t[2i] + t[2i+1]. For a query [l, r] put pointers lo = l + n, hi = r + 1 + n. While lo < hi: if lo is odd it is a right child, so take it and move right; if hi is odd take t[hi - 1]; then climb with lo >>= 1, hi >>= 1. About 10 lines, no recursion.

Lazy propagation for range updates

To add v to [l, r] store at each fully covered node an unpushed tag lazy and update its aggregate right away (sum += v x length, max += v). A node's tag is pushed down to its children only when a later operation must look inside it. The invariant: a node's aggregate is correct for its own interval; its children are stale by exactly the node's tag.

E. Java Implementation

Iterative segment tree for sum/min/max

SegmentTree.java: bottom-up tree with a pluggable combine
import java.util.function.IntBinaryOperator;

/**
 * Ch 96: iterative segment tree for any associative operation; LeetCode 307, 699
 * style.
 */
public class SegmentTree {
    private final int n;
    private final int[] t;
    private final int identity;
    private final IntBinaryOperator op;

    /** Builds over a copy of values in O(n); identity is the neutral element. */
    public SegmentTree(int[] values, int identity, IntBinaryOperator op) {
        this.n = values.length;
        this.identity = identity;
        this.op = op;
        this.t = new int[2 * n];
        System.arraycopy(values, 0, t, n, n);
        for (int i = n - 1; i >= 1; i--)
            t[i] = op.applyAsInt(t[2 * i], t[2 * i + 1]);
    }

    public static SegmentTree sum(int[] v) {
        return new SegmentTree(v, 0, Integer::sum);
    }

    public static SegmentTree min(int[] v) {
        return new SegmentTree(v, Integer.MAX_VALUE, Math::min);
    }

    public static SegmentTree max(int[] v) {
        return new SegmentTree(v, Integer.MIN_VALUE, Math::max);
    }

    /** Sets position i to value, O(log n). */
    public void update(int i, int value) {
        i += n;

Java 17+

        t[i] = value;
        for (i >>= 1; i >= 1; i >>= 1) t[i] = op.applyAsInt(t[2 * i], t[2 * i + 1]);
    }

    /** Combines positions [l, r] inclusive, O(log n). */
    public int query(int l, int r) {
        int resL = identity, resR = identity;
        for (l += n, r += n + 1; l < r; l >>= 1, r >>= 1) {
            if ((l & 1) == 1) resL = op.applyAsInt(resL, t[l++]);
            if ((r & 1) == 1) resR = op.applyAsInt(t[--r], resR);   // keeps order
        }
        return op.applyAsInt(resL, resR);
    }
}

Lazy segment tree: range add, range sum and range max

LazySegmentTree.java: lazy propagation for add / sum / max
/** Ch 96: recursive segment tree with lazy range add; range sum and range max. */
public class LazySegmentTree {
    private final int n;
    private final long[] sum, max, lazy;

    public LazySegmentTree(long[] a) {
        n = a.length;
        sum = new long[4 * n];
        max = new long[4 * n];
        lazy = new long[4 * n];
        build(1, 0, n - 1, a);
    }

    private void build(int node, int l, int r, long[] a) {
        if (l == r) {
            sum[node] = max[node] = a[l];
            return;
        }
        int m = (l + r) >>> 1;
        build(2 * node, l, m, a);
        build(2 * node + 1, m + 1, r, a);
        pull(node);
    }

    private void pull(int node) {
        sum[node] = sum[2 * node] + sum[2 * node + 1];
        max[node] = Math.max(max[2 * node], max[2 * node + 1]);
    }

    private void apply(int node, int l, int r, long v) {
        sum[node] += v * (r - l + 1);
        max[node] += v;
        lazy[node] += v;
    }

    private void push(int node, int l, int r) {
        if (lazy[node] == 0) return;
        int m = (l + r) >>> 1;
        apply(2 * node, l, m, lazy[node]);
        apply(2 * node + 1, m + 1, r, lazy[node]);
        lazy[node] = 0;
    }

Java 17+

    /** Adds v to every position in [ql, qr]. */
    public void add(int ql, int qr, long v) {
        add(1, 0, n - 1, ql, qr, v);
    }

    private void add(int node, int l, int r, int ql, int qr, long v) {
        if (qr < l || r < ql) return;
        if (ql <= l && r <= qr) {
            apply(node, l, r, v);
            return;
        }
        push(node, l, r);
        int m = (l + r) >>> 1;
        add(2 * node, l, m, ql, qr, v);
        add(2 * node + 1, m + 1, r, ql, qr, v);
        pull(node);
    }

    public long sum(int ql, int qr) {
        return querySum(1, 0, n - 1, ql, qr);
    }

    private long querySum(int node, int l, int r, int ql, int qr) {
        if (qr < l || r < ql) return 0;
        if (ql <= l && r <= qr) return sum[node];
        push(node, l, r);
        int m = (l + r) >>> 1;
        return querySum(2 * node, l, m, ql, qr) + querySum(2 * node + 1, m + 1, r,
                ql, qr);
    }

    public long max(int ql, int qr) {
        return queryMax(1, 0, n - 1, ql, qr);
    }

    private long queryMax(int node, int l, int r, int ql, int qr) {
        if (qr < l || r < ql) return Long.MIN_VALUE;
        if (ql <= l && r <= qr) return max[node];
        push(node, l, r);
        int m = (l + r) >>> 1;
        return Math.max(queryMax(2 * node, l, m, ql, qr),
                queryMax(2 * node + 1, m + 1, r, ql, qr));
    }
}

    /**
     * LeetCode 732 offline: max overlap after each booking, coordinate compressed.
     */
    public static int[] myCalendarThree(int[][] bookings) {
        TreeSet<Integer> set = new TreeSet<>();
        for (int[] b : bookings) {
            set.add(b[0]);
            set.add(b[1]);
        }
        Map<Integer, Integer> idx = new HashMap<>();
        for (int x : set) idx.put(x, idx.size());
        LazySegmentTree st = new LazySegmentTree(new long[Math.max(1, idx.size())]);
        int[] out = new int[bookings.length];
        for (int i = 0; i < bookings.length; i++) {
            st.add(idx.get(bookings[i][0]), idx.get(bookings[i][1]) - 1, 1);
            out[i] = (int) st.max(0, idx.size() - 1);
        }
        return out;
    }

    /**
     * LeetCode 699: Falling Squares, heights after each drop (compressed cells).
     */
    public static List<Integer> fallingSquares(int[][] positions) {
        TreeSet<Integer> set = new TreeSet<>();
        for (int[] p : positions) {
            set.add(p[0]);
            set.add(p[0] + p[1]);
        }
        Map<Integer, Integer> idx = new HashMap<>();
        for (int x : set) idx.put(x, idx.size());
        int m = idx.size();
        int[] h = new int[m];             // simple O(n * m) height array per cell
        List<Integer> out = new ArrayList<>();
        int best = 0;
        for (int[] p : positions) {
            int l = idx.get(p[0]), r = idx.get(p[0] + p[1]);
            int base = 0;
            for (int i = l; i < r; i++) base = Math.max(base, h[i]);
            int top = base + p[1];
            for (int i = l; i < r; i++) h[i] = top;
            best = Math.max(best, top);
            out.add(best);
        }
        return out;
    }
}

F. Detailed Dry Run

myCalendarThree on [10,20), [50,60), [10,40), [5,15): the code compresses the endpoints and range-adds 1 on each booking. After booking 1 the maximum is 1; after 2 it is 1; after 3 the interval [10,20) has coverage 2, so 2; after 4 the interval [10,15) has coverage 3 (bookings 1, 3 and 4), so 3. Output 1, 1, 2, 3.

lengthOfLIS([4,2,1,4,3,4,5,8,15], k = 3): processing in order, dp[v] = longest valid subsequence ending in value v. each value is queried over the window [v-3, v-1] and then written back: 4 -> 1, 2 -> 1, 1 -> 1, 4 -> 2 (from 2 or 1), 3 -> 2, 4 -> 3 (from 3), 5 -> 4, 8 -> 5 (from 5), 15 -> 1. The answer is 5, the subsequence 2, 3, 4, 5, 8. The segment tree stores dp at index v and each step is one range-max query plus one point update.

G. Variations of the Pattern

Range max with index

Store pairs (value, index) and combine by comparing values; used for "leftmost position with value >= x" via a descent from the root in O(log n).

Descent queries (binary search on the tree)

Find the first index whose prefix sum reaches S: start at the root, go left if the left child's sum is enough, else subtract it and go right. No need for O(log^2 n) binary search with queries.

Coordinate compression

When positions go up to 10^9, sort the distinct endpoints and index the tree by rank (Chapters 74 and 76). Or use a dynamic tree that creates nodes on demand.

Merge-sort tree and persistent trees

Store a sorted list at each node to count values <= x in a range, in O(log^2 n). A persistent tree keeps every version so you can query the array "as of" an earlier time.

2D and tree-flattening

Euler-tour a tree so each subtree is a contiguous range; subtree updates and queries become range operations on a segment tree.

J. Interview Tips

INTERVIEW

Say which tree you want in one sentence: "point update, range sum: iterative tree of size 2n".

If the interviewer mentions range updates, introduce lazy tags and state the invariant before writing code.

Mention that a Fenwick tree is shorter for sums and offer it first if only sums are needed.

Follow-ups: range assign instead of add; query the first position meeting a condition; 2D; offline vs online; persistent versions.
Edge cases: n = 1, query of a single cell, l > r, repeated updates to the same index, large value ranges.

CHAPTER SUMMARY

A segment tree keeps an aggregate per interval, answering range queries in O(log

and applying point updates in O(log n).

The combine function must be associative; the iterative form additionally needs it commutative.

Lazy propagation defers range updates: apply a tag at a covering node, push it down only when you must look inside.

Index the tree by value or coordinate rank for DP and event-overlap problems.

A Fenwick tree is shorter for sums; the segment tree wins for min, max, gcd and range updates.
