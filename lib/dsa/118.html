Z Algorithm

For every position, how long is the match with the whole string's prefix? Answer in O(n).

A. Pattern Overview

The Z array of a string s has z[i] equal to the length of the longest substring starting at i that is also a prefix of s (with z[0] = n by convention). It is computed in O(n) by maintaining a Z-box [l, r): the rightmost interval that matched a prefix. Positions inside the box copy information from the matching spot near the beginning, so characters are compared at most once outside it.

KEY IDEA

Z and KMP are interchangeable for most tasks. Z is easier to reason about ("match length with the prefix"); KMP's pi is easier for borders. Know both; pick one and stay fluent.

C. Core Intuition with Illustrations

The Z array and the Z-box

For s = aabxaab, compare each suffix with s. Keep [l, r), the farthest-reaching match so far. For i inside the box, z[i] is at least min(r - i, z[i - l]) because s[i..r) equals s[i-l..r-l). Extend by direct comparison only past r.

Result with z[0] = n: [7, 1, 0, 0, 3, 1, 0]. The value 3 at index 4 says aab (the prefix) starts again at 4.

Why it is linear

r only moves right. Each loop iteration that compares characters either extends r (at most n

times in total) or stops at the first mismatch (once per i). The copy step inside the box is O(1). Total O(n).

Pattern search with a separator

Build p + '#' + t where # appears in neither string. Because the separator can never match, z[i] never exceeds |p|, and positions in the text part with z[i] == |p| are exactly the occurrences of p. Report i - |p| - 1.

Sum of scores

The score of the suffix starting at i is z[i] (with z[0] = n). The sum equals the total number of (prefix, occurrence) pairs. For babab: z = [5, 0, 3, 0, 1], sum 9. LeetCode 2223 asks exactly this.

TRAP

Remember the convention z[0] = n (or skip index 0 consistently). Different problems define the score of the whole string differently.

Z array, search, sum of scores, period, border and palindromic prefix

ZAlgorithm.java: Z-function and its applications
import java.util.*;

/** Ch 103: Z function; LeetCode 28, 1392, 2223, 214. */
public class ZAlgorithm {
    /** z[i] = length of the longest common prefix of s and s[i..]; z[0] = n. */
    public static int[] zArray(String s) {
        int n = s.length();
        int[] z = new int[n];
        if (n == 0) return z;
        z[0] = n;
        // [l, r) is the rightmost match
        for (int i = 1, l = 0, r = 0; i < n; i++) {
            if (i < r) z[i] = Math.min(r - i, z[i - l]);
            while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) z[i]++;
            if (i + z[i] > r) {
                l = i;
r = i + z[i];
            }
        }
        return z;
    }

    /** All occurrences of pattern in text via z on pattern + sentinel + text. */
    public static List<Integer> search(String text, String pattern) {
        List<Integer> hits = new ArrayList<>();
        int m = pattern.length();
        if (m == 0) {
            for (int i = 0; i <= text.length(); i++) hits.add(i);
            return hits;
        }
        String s = pattern + '\u0000' + text;
        int[] z = zArray(s);
        for (int i = m + 1; i < s.length(); i++) if (z[i] >= m) hits.add(i - m - 1);
        return hits;
    }

    /** LeetCode 2223: sum over all suffixes of their common prefix with s. */
    public static long sumScores(String s) {
        long total = 0;

Java 17+

        for (int v : zArray(s)) total += v;
        return total;
    }

    /** Smallest period of s (n if it is not a repetition). */
    public static int smallestPeriod(String s) {
        int n = s.length();
        int[] z = zArray(s);
        for (int p = 1; p < n; p++) if (n % p == 0 && z[p] == n - p) return p;
        return n;
    }

    /** LeetCode 214 via z: longest palindromic prefix of s. */
    public static int longestPalindromicPrefix(String s) {
        String t = s + '\u0000' + new StringBuilder(s).reverse();
        int[] z = zArray(t);
        int n = s.length();
        for (int i = n + 1; i < t.length(); i++)
            // suffix of t equals a prefix
            if (z[i] == t.length() - i) return z[i];
        return 0;
    }

    /** Length of the longest border (prefix that is also a suffix), proper. */
    public static int longestBorder(String s) {
        int n = s.length();
        int[] z = zArray(s);
        for (int i = 1; i < n; i++) if (i + z[i] == n) return z[i];
        return 0;
    }
}

SPACE O(n)

The pointer r never moves left, so the total number of character comparisons is at most 2n. The array of n integers is the only extra memory.

G. Variations of the Pattern

Number of distinct substrings

Incremental Z on the reversed string: each new character adds len - max(z) new substrings (O(n^2) total). Suffix automata do it in O(n).

Count of each prefix as a substring

cnt[z[i]]++, then for len from n - 1 down to 1, cnt[len] += cnt[len + 1]. The number of occurrences of the prefix of length len is cnt[len] + 1.

Compress a string

The smallest period gives the shortest string u with s = u^k (when p | n), used for "shortest repeating unit".

Z on a tree or grid

Flatten (preorder with markers), then use the usual array version.

Reverse Z for suffix matches

Run Z on the reversed string to answer "longest common suffix with the whole string" at each position.

INTERVIEW

Explain the copy step: inside the box, s[i..r) equals s[i-l..r-l), so we reuse z[i-l].

CHAPTER SUMMARY

z[i] is the length of the longest match between s[i..] and s; the Z array is built in O(n) using a Z-box [l, r).

Inside the box copy min(r - i, z[i - l]) and extend only beyond r.

Pattern search, borders, periods and palindromic prefixes are all one Z computation on a cleverly built string.

Always use a separator when concatenating, and report indices relative to the text.

Z and KMP are equivalent in power; choose by which statement matches the problem.
