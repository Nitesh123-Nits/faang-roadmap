Topological Sorting

Order a DAG so every edge points forward: reverse postorder of DFS.

A. Pattern Overview

A topological order of a directed graph lists the vertices so that for every edge u → v, u appears before v. It exists if and only if the graph is a DAG (acyclic). It answers "in what order can I do these tasks given prerequisites?".

KEY IDEA

Append a vertex to the output after all its descendants are done (postorder); the reversed list is a topological order. Proof: for an edge u → v, v finishes before u (no back edges exist in a DAG), so u appears earlier in the reversed list.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Prerequisites", "dependencies", "build order", "must happen before".
"Derive an order from comparisons": alien dictionary, sorted-by-rules, rankings.
"Longest / earliest completion with dependencies": DP along a topological order.
"Is the ordering consistent / unique?".
The answer is a sequence of all vertices, or [] / false when a cycle exists.
ONE-LINE TEST

Edges that mean "A before B" form a directed graph; the answer is a topological order, and a cycle means impossible.

C. Core Intuition with Illustrations

DFS finish order, reversed

The sample DAG has edges 5→2, 5→0, 4→0, 4→1, 2→3, 3→1. Run DFS from each unvisited

vertex; append a vertex when it finishes; reverse at the end.

Figure 90. A DAG with its topological positions.

Postorder reversed gives the order [5, 4, 2, 3, 1, 0]. Every edge points from an earlier to a later position, e.g. 5 → 2 (positions 0 → 2) and 3 → 1 (positions 3 → 4).

A cycle breaks the order

If DFS meets a gray vertex, no valid order exists; the Java returns an empty list. Do not return a partial order, because it would silently look like a legitimate answer for the vertices processed so far.

Alien Dictionary: derive the graph, then sort

Words are sorted by an unknown alphabet. For each pair of adjacent words, the first

position where they differ gives one edge a[k] → b[k]. Compare nothing else: later letters

carry no information. Then topologically sort the letters. Two pitfalls: (1) a longer word before its own prefix ("abc" before "ab") is invalid; (2) letters that appear in no edge must still be emitted.

Longest path in a DAG

With a topological order the longest (or shortest!) path in a DAG is a one-pass DP, even with

negative edges: dist[v] = min over u → v of dist[u] + w. Process vertices in order, relax

outgoing edges once: O(n + m), faster than Dijkstra and Bellman-Ford.

TopologicalSort.java: LeetCode 210, 269
import java.util.*;

/** Ch 50: DFS topological order; LeetCode 210 and 269. */
public class TopologicalSort {

    /**
     * Topological order of a directed graph, or an empty list if it has a cycle.
     */
    public static List<Integer> order(List<List<Integer>> g) {
        int n = g.size();
        int[] color = new int[n];                      // 0 new, 1 on stack, 2 done
        List<Integer> post = new ArrayList<>();
        for (int s = 0; s < n; s++)
            if (color[s] == 0 && !visit(g, s, color, post))
                return new ArrayList<>();
        Collections.reverse(post);                     // reverse postorder
        return post;
    }

    private static boolean visit(List<List<Integer>> g, int u, int[] color,
                                 List<Integer> post) {
        color[u] = 1;
        for (int v : g.get(u)) {
            if (color[v] == 1) return false;           // back edge: cycle
            if (color[v] == 0 && !visit(g, v, color, post)) return false;
        }
        color[u] = 2;
        post.add(u);                                   // after every descendant
        return true;
    }

    /** LeetCode 210: {a, b} = take b before a. Empty array if impossible. */
    public static int[] findOrder(int numCourses, int[][] prerequisites) {
        int[][] e = new int[prerequisites.length][];
        for (int i = 0; i < e.length; i++)
            e[i] = new int[] {prerequisites[i][1], prerequisites[i][0]};
        List<Integer> o = order(GraphRepresentation.adjList(numCourses, e, true));
        return o.stream().mapToInt(Integer::intValue).toArray();
    }

    /**
     * LeetCode 269: derive the letter order from a sorted alien dictionary.
     * Returns "" if inconsistent (cycle, or a longer word before its own prefix).
     */
    public static String alienOrder(String[] words) {
        boolean[] present = new boolean[26];
        for (String w : words)
            for (char c : w.toCharArray()) present[c - 'a'] = true;
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < 26; i++) g.add(new ArrayList<>());
        for (int i = 0; i + 1 < words.length; i++) {
            String a = words[i], b = words[i + 1];
            int k = 0, m = Math.min(a.length(), b.length());
            while (k < m && a.charAt(k) == b.charAt(k)) k++;
            if (k == m) {
                if (a.length() > b.length()) return "";
            } else {

Java 17+

                g.get(a.charAt(k) - 'a').add(b.charAt(k) - 'a');
            }
        }
        int[] color = new int[26];
        List<Integer> post = new ArrayList<>();
        for (int c = 0; c < 26; c++)
            if (present[c] && color[c] == 0 && !visit(g, c, color, post)) return "";
        Collections.reverse(post);
        StringBuilder sb = new StringBuilder();
        for (int c : post) sb.append((char) ('a' + c));
        return sb.toString();
    }
}

SPACE O(n + m)

order() returns an empty list on a cycle. For findOrder an edge {a, b} means b before a, so the graph edge is b → a; reversing it

by mistake gives the reverse order.

F. Detailed Dry Run

Trace the postorder table: DFS starts at 0 (no outgoing edges) and finishes it immediately; then 1 (finishes); then 2 → 3 → 1 (already done): 3 finishes, then 2; then 4: its neighbours 0 and 1 are done, so 4 finishes; finally 5. Finish order 0, 1, 3, 2, 4, 5 reversed is 5, 4, 2, 3, 1, 0. Check two edges: 4 → 0 positions 1 < 5 and 2 → 3 positions 2 < 3.

G. Variations of the Pattern

Unique or lexicographically smallest order

Kahn's algorithm with a min-heap instead of a queue gives the lexicographically smallest order. The order is unique iff the queue never holds two vertices (Sequence Reconstruction, Chapter 51).

Reachability in a DAG

Course Schedule IV (1462): compute for each vertex the set (or bitset) of ancestors in topological order: anc[v] |= anc[u] | {u}.

DP on a DAG

Largest Color Value in a Directed Graph (1857): for each colour keep count[v][colour] = most nodes of that colour on a path ending at v; propagate in topological order; a cycle returns −1.

Grouped dependencies

Sort Items by Groups (1203): two-level topological sort: order groups first, then items inside each group.

Two orders at once

Build a Matrix with Conditions (2392): independent row and column topological orders, combined into coordinates.

J. Interview Tips

INTERVIEW

State the existence condition: "a topological order exists iff the graph is acyclic"; so cycle detection comes for free.

Draw the dependency direction on the board before coding to avoid reversing edges.

For Alien Dictionary, list the three failure modes (cycle, prefix, missing letters) up front.

Follow-ups: unique order; lexicographically smallest order; count the number oftopological orders (bitmask DP, O(2ⁿ n)); parallel scheduling (levels); dynamic edges.
Edge cases: no edges (any order works), a single vertex, a self-loop, disconnected DAG, duplicate prerequisites.

CHAPTER SUMMARY

A topological order exists iff the directed graph is acyclic; usually many exist.

DFS postorder reversed is a valid order: append a vertex after all its descendants finish.

Edge direction = "before"; for [a, b] prerequisites the edge is b → a.

Alien Dictionary: edges only from the first difference of adjacent words; reject prefix violations and cycles.

A DAG supports linear-time DP in topological order: longest path, ancestor sets, colour counts.
