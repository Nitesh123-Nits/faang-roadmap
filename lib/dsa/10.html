Cyclic Sort

When values are 1..n, the array is its own hash table: send every value to its home index.

A. Pattern Overview

Cyclic sort applies when an array of length n holds values from a known contiguous range such as 1..n (or 0..n). Each value v has a natural home index (v - 1, or v). Walk the array; while the current value is not at home, swap it into its home slot. Every swap places at least one value permanently, so the whole array is sorted in O(n) swaps with O(1) extra space. After one pass, any index holding the wrong value reveals a missing or duplicate number.

KEY IDEA

The array is the hash table: index = key, value = presence. You get the effect of a boolean[] seen without allocating it.

B. When to Recognize This Pattern

Pattern Recognition Signals

The array has n elements with values in [1, n] (or [0, n]) and the statement asks for

missing, duplicate, or misplaced numbers.

The constraint demands O(1) extra space and O(n) time: a HashSet or counting array is explicitly ruled out.
"Find the smallest missing positive": the answer must lie in 1..n+1 by the pigeonhole principle.
You may modify the input (or you can clone it, and say so).
KEY ARGUMENT

Pigeonhole thinking: with n slots, the first missing positive is at most n + 1. So values outside [1, n] are irrelevant and can be ignored.

CONSTRAINT

If the array must not be modified, use Floyd's cycle detection (Chapter 1, LeetCode 287), XOR (missing number), or sums. Cyclic sort destroys the original order.

C. Core Intuition with Illustrations

Sort [3, 1, 5, 4, 2]. At index 0 the value 3 belongs at index 2, so swap; the value that arrives at index 0 (5) is checked next, and so on. The index i advances only when nums[i] is already home.

Figure 16. Each swap sends one value home permanently; the array is sorted after 3 swaps and one final scan.

INTUITION

Why O(n) with a while inside? Each swap puts at least one value in its final position and a placed value is never moved again, so there are at most n - 1 swaps. The pointer i itself advances at most n times.

D. Brute Force to Optimal Solution

Example: First Missing Positive (LeetCode 41)

Brute force: for x = 1, 2, … scan the array: O(n²).
Sorting: sort, then scan for the gap: O(n log n) time. Misses the required O(n).
HashSet: put everything in a set, try 1, 2, …: O(n) time but O(n) space. Misses the required O(1).
Observation: the answer is in [1, n + 1]. Use the array itself as the set: place each v in [1, n] at index v - 1.
Optimal: cyclic sort; the first index with nums[i] != i + 1 gives answer i + 1, else n +
1. O(n) time, O(1) space.

E. Java Implementation

The base routine

CyclicSort.java
/** Cyclic sort for a permutation of 1..n: put every value v at index v - 1. */
public class CyclicSort {

    /** Sorts in place in O(n) time, O(1) space. Requires values to be exactly 1..n. */
    public static void sort(int[] nums) {
        int i = 0;
        while (i < nums.length) {
            int correctIndex = nums[i] - 1;
            if (nums[i] != nums[correctIndex]) {
                // send nums[i] home; re-examine the new nums[i]
                swap(nums, i, correctIndex);
            } else {
                // already home (or a duplicate of what is home)
                i++;
            }
        }
    }

    static void swap(int[] a, int i, int j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
    }
}

First Missing Positive

FirstMissingPositive.java — LeetCode 41
/**
 * LeetCode 41 - First Missing Positive. O(n) time, O(1) extra space (mutates the input
 * array).
 */
public class FirstMissingPositive {

    public static int firstMissingPositive(int[] nums) {
        int n = nums.length;
        // The answer is always in [1, n+1], so only values in 1..n matter.
        for (int i = 0; i < n; i++) {
            while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                int home = nums[i] - 1;
                int t = nums[i]; nums[i] = nums[home]; nums[home] = t;
            }
        }
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
}

Missing Number (values 0..n)
MissingNumber.java — LeetCode 268 (cyclic sort and XOR)

Java 17+

/** LeetCode 268 - Missing Number. Values are 0..n with one missing (array has n slots). */
public class MissingNumber {

    /** Cyclic-sort version. Modifies a copy, so the caller's array is untouched. */
    public static int missingNumber(int[] input) {
        int[] nums = input.clone();
        int n = nums.length;
        int i = 0;
        while (i < n) {
            int home = nums[i];
            // value n has no slot: leave it where it is
            if (home < n && nums[home] != home) {
                int t = nums[i]; nums[i] = nums[home]; nums[home] = t;
            } else {
                i++;
            }
        }
        for (int idx = 0; idx < n; idx++) {
            if (nums[idx] != idx) return idx;
        }
        return n;
    }

    /** Alternative: XOR of all indices and values. Also O(n) time, O(1) space, no mutation. */
    public static int missingNumberXor(int[] nums) {
        int xor = nums.length;
        for (int i = 0; i < nums.length; i++) {
            xor ^= i ^ nums[i];
        }
        return xor;
    }
}

TIME O(n)

SPACE O(1)

Value n has no slot in an array of length n: leave it. The XOR version does not mutate and is usually preferable in production.

All missing numbers
FindDisappearedNumbers.java — LeetCode 448
import java.util.ArrayList;
import java.util.List;

/**
 * LeetCode 448 - Find All Numbers Disappeared in an Array (values in 1..n, duplicates
 * allowed).
 */
public class FindDisappearedNumbers {

    public static List<Integer> findDisappearedNumbers(int[] input) {
        int[] nums = input.clone();
        int i = 0;
        while (i < nums.length) {
            int home = nums[i] - 1;
            if (nums[i] != nums[home]) {
                int t = nums[i]; nums[i] = nums[home]; nums[home] = t;
            } else {
                i++;
            }
        }
        List<Integer> missing = new ArrayList<>();
        for (int idx = 0; idx < nums.length; idx++) {
            // slot idx never received its value
            if (nums[idx] != idx + 1) missing.add(idx + 1);
        }
        return missing;
    }
}

J. Interview Tips

INTERVIEW

Start with the HashSet solution, then say: "values are in 1..n, so the array itself can act as the set". That leap is the whole pattern.

Explain termination: each swap fixes one value, so at most n − 1 swaps.

Ask whether mutation is allowed. If not, offer Floyd (one duplicate) or XOR (one missing).

Follow-ups: return counts of each duplicate, handle values 0..n-1, handle range [a, a+n-1] (shift by a), restore the array afterwards (negation marking is an alternative that can be undone).with valid values.
Edge cases: n = 1, all values equal, values already sorted, negatives and zeros mixed

CHAPTER SUMMARY

If values live in 1..n, send each to index v - 1; the array becomes its own hash table.

Loop: swap while nums[i] != nums[nums[i] - 1], else i++. Total swaps ≤ n - 1.

After the pass, indices with nums[i] != i + 1 expose missing (i + 1) and duplicate (nums[i]) numbers.

First Missing Positive: answer ∈ [1, n + 1]; guard indices against out-of-range values.
