Palindrome Partitioning and String Splits

Cut the string: choose the next piece, recurse on the rest.

A. Pattern Overview

Partitioning problems split a string s into consecutive pieces so that every piece satisfies a rule. The decision at each step is where does the next piece end; the recursion works on the suffix that remains. A string of length n has 2^(n−1) ways to be cut, so the pieces' validity test is what prunes the tree.

KEY IDEA

Make the piece test O(1) before you recurse. A palindrome check by scanning is O(n) per candidate piece; a table pal[i][j] built once in O(n²) makes it O(1). For dictionaries, check prefix feasibility with a memo or a trie.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Partition the string such that every substring is …" (palindrome, valid word, valid number).
"Insert spaces / dots / separators" to create valid segments: Restore IP, Word Break II.
"Return all possible …" over a string of length ≤ 16–20.
"Minimum cuts" or "can it be segmented?": the same recurrence, solved by DP (Part XI).
ONE-LINE TEST

Pieces are consecutive and cover the whole string. Each choice is the end of the next piece. If you only need how many or whether, the recursion has few distinct states (start index) and should be memoised.

E. Java Implementation

Palindrome Partitioning

PalindromePartitioning.java: LeetCode 131

Java 17+

import java.util.ArrayList;
import java.util.List;

/**
 * LeetCode 131 - Palindrome Partitioning. Choose the next piece s[start..end] if it is a
 * palindrome; a DP table makes that test O(1).
 */
public class PalindromePartitioning {
    public static List<List<String>> partition(String s) {
        int n = s.length();
        // pal[i][j] = s[i..j] is a palindrome
        boolean[][] pal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--)
            for (int j = i; j < n; j++)
                pal[i][j] = s.charAt(i) == s.charAt(j) && (j - i < 2
                        || pal[i + 1][j - 1]);
        List<List<String>> out = new ArrayList<>();
        build(s, 0, pal, new ArrayList<>(), out);
        return out;
    }

    private static void build(String s, int start, boolean[][] pal,
            List<String> cur, List<List<String>> out) {
        if (start == s.length()) { out.add(new ArrayList<>(cur)); return; }
        for (int end = start; end < s.length(); end++) {
            if (!pal[start][end]) continue;
            cur.add(s.substring(start, end + 1));
            build(s, end + 1, pal, cur, out);
            cur.remove(cur.size() - 1);
        }
    }
}

TIME O(n · 2ⁿ)

SPACE O(n²)

The table costs O(n²); each partition copy costs O(n). j − i < 2 handles lengths 1 and 2, whose inside is empty.

Restore IP Addresses

RestoreIPAddresses.java: LeetCode 93

Java 17+

import java.util.ArrayList;
import java.util.List;

/**
 * LeetCode 93 - Restore IP Addresses. Choose 1 to 3 digits for each of four parts; reject
 * leading zeros and values above 255.
 */
public class RestoreIPAddresses {
    public static List<String> restoreIpAddresses(String s) {
        List<String> out = new ArrayList<>();
        build(s, 0, new ArrayList<>(), out);
        return out;
    }

    private static void build(String s, int start, List<String> parts,
            List<String> out) {
        int left = 4 - parts.size();
        int remaining = s.length() - start;
        // prune: the rest cannot be split into `left` parts
        if (remaining < left || remaining > 3 * left) return;
        if (left == 0) { out.add(String.join(".", parts)); return; }
        for (int len = 1; len <= 3 && start + len <= s.length(); len++) {
            String part = s.substring(start, start + len);
            // no leading zeros (and longer pieces would keep one)
            if (len > 1 && part.charAt(0) == '0') break;
            if (Integer.parseInt(part) > 255) break;
            parts.add(part);
            build(s, start + len, parts, out);
            parts.remove(parts.size() - 1);
        }
    }
}
TIME O(1)
SPACE O(1)

At most 3⁴ = 81 splits, so the work is constant for any input

length ≤ 12. The break after a rejected piece is valid: a longer piece keeps the leading zero or a larger value.

Word Break II with memoisation

WordBreakII.java: LeetCode 140

Java 17+

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Set;

/**
 * LeetCode 140 - Word Break II. Break at every dictionary prefix; memoise the sentences for
 * each suffix start.
 */
public class WordBreakII {
    public static List<String> wordBreak(String s, List<String> wordDict) {
        return sentences(s, 0, Set.copyOf(wordDict), new HashMap<>());
    }

    private static List<String> sentences(String s, int start, Set<String> dict,
            Map<Integer, List<String>> memo) {
        if (memo.containsKey(start)) return memo.get(start);
        List<String> result = new ArrayList<>();
        if (start == s.length()) {
            result.add("");
        } else {
            for (int end = start + 1; end <= s.length(); end++) {
                String word = s.substring(start, end);
                if (!dict.contains(word)) continue;
                for (String rest : sentences(s, end, dict, memo))
                    result.add(rest.isEmpty() ? word : word + " " + rest);
            }
        }
        memo.put(start, result);
        return result;
    }
}

TIME O(output + n²)

SPACE O(output)

Worst case exponential output ("aaaa…" with {a, aa, aaa, …}). Memoising makes the computation proportional to the number of distinct suffixes times their sentence counts.

J. Interview Tips

INTERVIEW

Name the decision: "at each step I choose where the next piece ends." Then say what makes a piece valid and how you test it in O(1).

Mention the output bound for an all-a string: it shows that exponential output is unavoidable, not a flaw in your algorithm.

When asked for a count or minimum, switch to DP and say the state is just the start index.

Follow-ups: minimum cuts (DP); only count the partitions; stream partitions lazily;

Word Break with a trie; limit the number of pieces; very long strings with few answers (memo + feasibility DP first).

Edge cases: single character, all-equal characters, no valid partition (Restore IP with 3 or 13 digits), a dictionary containing the empty string.

CHAPTER SUMMARY

Partitioning: at each start, choose the end of the next piece; keep it only if the piece is valid; recurse from end + 1.

Precompute the piece test: pal[i][j] in O(n²) (fill i downwards); then each test is O(1).

Restore IP: four parts, 1–3 digits, no leading zero, ≤ 255, prune with left ≤

remaining ≤ 3·left.

Word Break II: memoise sentences by start; use an empty-string base case.

For a count or minimum, the same recurrence over start is a DP (Part XI); all-equal strings show why listing is exponential.
