String DP

Edit distance, palindromic subsequences, distinct subsequences, interleaving and pattern matching.

A. Pattern Overview

String DP uses prefixes of one or two strings as the state and a handful of local operations as the transition. Chapter 83 covered LCS; this chapter collects the other recurring shapes. Each fits a template: dp[i][j] over two prefixes (edit distance, distinct subsequences, interleaving, regex, wildcard) or over a substring s[i..j] (palindromic subsequence).

KEY IDEA

In string DP the base row and column are not boilerplate. Matching the empty string, converting to the empty string and "zero copies" for * all live there, and most wrong answers start in them.

B. When to Recognize This Pattern

Pattern Recognition Signals

"Minimum number of operations to convert one string into another".
"Does the pattern match the whole string" with . * ?.
"Number of distinct subsequences of S equal to T".
"Can s3 be formed by interleaving s1 and s2".
Palindromic subsequence (gaps allowed) as opposed to substring (Chapter 45 expand-around-centre).
Strings up to ~1000 to a few thousand characters so O(m n) fits.
ONE-LINE TEST

Two prefixes and local edits or matches: dp over (i, j). One string and a range: dp over [i, j].

Three operations (insert, delete, replace). dp[i][j] is the minimum cost to convert the first

i characters of a into the first j of b. Row 0 is 0..n (insert everything), column 0 is 0..m

Distinct Subsequences: how many ways does t appear inside s?

Scan s once. A character c of s can extend every partial match of t[0..j) where t[j-1] == c; update j from high to low so a character is used once. For s = rabbbit, t = rabbit:

The answer 3 comes from choosing which two of the three bs of s are used.

Regular expression matching: aab against c*a*b

* applies to the previous element. For p[j-1] == '*': zero copies is dp[i][j-2]; one more copy is dp[i-1][j] if p[j-2] matches s[i-1] (. matches anything). Otherwise the characters must match one-to-one.

Figure 137. Regex table: the bottom-right cell is the answer.

Wildcard Matching and Interleaving String

Wildcard * matches any sequence: dp[i][j] = dp[i][j-1] or dp[i-1][j] (match empty, or consume one character and stay on *). ? is a diagonal match. Interleaving String uses dp[i][j] = prefix s3[0..i+j) can be built from s1[0..i) and s2[0..j): take the next character of s3 from s1 if dp[i-1][j] and s1[i-1] == s3[i+j-1], or from s2 symmetrically.

DON'T MIX THEM UP

Regex * is bound to the preceding element; wildcard * stands alone. Writing the zero-copies line first for regex keeps the recurrence honest.

import java.util.*;

/** Ch 85: string DP; LeetCode 72, 516, 1312, 115, 97, 10, 44. */
public class StringDP {

    /** LeetCode 72: dp[i][j] = edits to turn a[0..i) into b[0..j). */
    public static int editDistance(String a, String b) {
        int m = a.length(), n = b.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 0; i <= m; i++) dp[i][0] = i;              // delete all
        for (int j = 0; j <= n; j++) dp[0][j] = j;              // insert all
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= n; j++)
                dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                        ? dp[i - 1][j - 1]
                        : 1 + Math.min(dp[i - 1][j - 1],
                                Math.min(dp[i - 1][j], dp[i][j - 1]));
        return dp[m][n];
    }

    /** An optimal edit script such as "keep h", "replace e->a", "delete x". */
    public static List<String> editScript(String a, String b) {
        int m = a.length(), n = b.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 0; i <= m; i++) dp[i][0] = i;
        for (int j = 0; j <= n; j++) dp[0][j] = j;
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= n; j++)
                dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                        ? dp[i - 1][j - 1]
                        : 1 + Math.min(dp[i - 1][j - 1],
                                Math.min(dp[i - 1][j], dp[i][j - 1]));
        List<String> ops = new ArrayList<>();
        int i = m, j = n;
        while (i > 0 || j > 0) {
            if (i > 0 && j > 0 && a.charAt(i - 1) == b.charAt(j - 1)
                    && dp[i][j] == dp[i - 1][j - 1]) {
                ops.add("keep " + a.charAt(i - 1));
                i--;
                j--;
            } else if (i > 0 && j > 0 && dp[i][j] == dp[i - 1][j - 1] + 1) {
                ops.add("replace " + a.charAt(i - 1) + "->" + b.charAt(j - 1));
                i--;
                j--;
            } else if (i > 0 && dp[i][j] == dp[i - 1][j] + 1) {
                ops.add("delete " + a.charAt(i - 1));
                i--;
            } else {
                ops.add("insert " + b.charAt(j - 1));
                j--;
            }
        }
        Collections.reverse(ops);
        return ops;
    }

    /** LeetCode 516: dp[i][j] = longest palindromic subsequence of s[i..j]. */
    public static int longestPalindromeSubseq(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];
        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++)
                dp[i][j] = s.charAt(i) == s.charAt(j)
                        ? dp[i + 1][j - 1] + 2
                        : Math.max(dp[i + 1][j], dp[i][j - 1]);
        }
        return n == 0 ? 0 : dp[0][n - 1];
    }

    /** LeetCode 1312: fewest insertions to make s a palindrome. */
    public static int minInsertionsToPalindrome(String s) {
        return s.length() - longestPalindromeSubseq(s);
    }

    /** LeetCode 115: how many subsequences of s equal t? */
    public static long numDistinct(String s, String t) {
        long[] dp = new long[t.length() + 1];
        dp[0] = 1;
        for (int i = 0; i < s.length(); i++)
            for (int j = t.length(); j >= 1; j--)
                if (s.charAt(i) == t.charAt(j - 1)) dp[j] += dp[j - 1];
        return dp[t.length()];
    }

    /** LeetCode 97: is c an interleaving of a and b (each kept in order)? */
    public static boolean isInterleave(String a, String b, String c) {
        int m = a.length(), n = b.length();
        if (m + n != c.length()) return false;
        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;
        for (int i = 0; i <= m; i++)
            for (int j = 0; j <= n; j++) {
                if (i > 0 && dp[i - 1][j] && a.charAt(i - 1) == c.charAt(i + j - 1))
                    dp[i][j] = true;
                if (j > 0 && dp[i][j - 1] && b.charAt(j - 1) == c.charAt(i + j - 1))
                    dp[i][j] = true;
            }
        return dp[m][n];
    }

    /** LeetCode 10: regex with '.' and '*' (zero or more of the previous). */
    public static boolean isMatchRegex(String s, String p) {
        int m = s.length(), n = p.length();
        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;
        for (int j = 2; j <= n; j++)
            dp[0][j] = p.charAt(j - 1) == '*' && dp[0][j - 2];
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= n; j++) {
                char pc = p.charAt(j - 1);
                if (pc == '*') {
                    dp[i][j] = j >= 2 && dp[i][j - 2];                // zero copies
                    if (j >= 2 && (p.charAt(j - 2) == '.'
                            || p.charAt(j - 2) == s.charAt(i - 1)))
                        // one more copy
                        dp[i][j] |= dp[i - 1][j];
                } else {
                    dp[i][j] = dp[i - 1][j - 1]
                            && (pc == '.' || pc == s.charAt(i - 1));
                }
            }
        return dp[m][n];
    }

    /** LeetCode 44: wildcard with '?' (one char) and '*' (any sequence). */
    public static boolean isMatchWildcard(String s, String p) {
        int m = s.length(), n = p.length();
        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;
        for (int j = 1; j <= n; j++)
            dp[0][j] = p.charAt(j - 1) == '*' && dp[0][j - 1];
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= n; j++) {
                char pc = p.charAt(j - 1);
                if (pc == '*') dp[i][j] = dp[i][j - 1] || dp[i - 1][j];
                else dp[i][j] = dp[i - 1][j - 1]
                        && (pc == '?' || pc == s.charAt(i - 1));
            }
        return dp[m][n];
    }
}

TIME O(m * n)

SPACE O(m * n)

All two-string methods fill an (m+1) x (n+1) table. numDistinct uses one row (O(n)), and editDistance's time is unchanged under space reduction (Chapter 91). numDistinct returns long; its answer is bounded by LeetCode to fit in 32 bits.

F. Detailed Dry Run

editDistance("horse", "ros"): row 0 [0,1,2,3]. Row h: [1,1,2,3]. Row o: [2,2,1,2]. Row r: [3,2,2,2]. Row s: [4,3,3,2]. Row e: [5,4,4,3]. Answer 3.

isMatchRegex("aab", "c*a*b"): c* matches zero copies (dp[0][2] = true). a* can consume the two as: dp[2][4] = true by the diagonal-up transition through dp[1][4], dp[0][4]. Finally b matches b: dp[3][5] = dp[2][4] = true.

G. Variations of the Pattern

Weighted edit costs

Replace the unit costs with an arbitrary cost function (Minimum ASCII Delete Sum, DNA alignment scores). The table is unchanged.

One Edit Distance and K Edits

For "at most one edit" (161) a linear scan suffices; for "within k edits" restrict the table to a diagonal band of width 2k + 1, giving O(k n).

Palindromic problems

Min insertions to make a palindrome = n - LPS. Palindrome partitioning needs interval palindromicity tables (Chapter 86). Counting palindromic subsequences (730) adds inclusion-exclusion over equal ends.

Subsequence counting

Distinct Subsequences II (940) counts distinct subsequences of one string: total[i] = 2 * total[i-1] - total[last[c]-1] to remove duplicates.

Pattern matching

Regex and wildcard share the same table shape. For wildcard-only problems a greedy two-pointer with backtracking to the last * runs in O(m n) worst case and O(m + n) typically.

J. Interview Tips

INTERVIEW

Define the cell in words, then each of the four moves (keep, replace, delete, insert) in terms of the neighbours.

Show the base row and column on the board before filling the interior; interviewers watch for it.

For regex, explain * as "zero or more of the previous element" and write the zero-copies line first.

Follow-ups: print the edit script; reduce space; weighted costs; banded edit distance for large strings; wildcard with greedy backtracking.
Edge cases: empty strings, identical strings, pattern longer than text, only stars, repeated characters.

CHAPTER SUMMARY

Two-string DP: dp[i][j] over prefixes. Edit distance chooses among keep/replace/delete/insert; LCS drops either side.

One-string DP: dp[i][j] over a range; palindromic subsequence wraps equal ends or drops one.

Counting subsequences scans once and updates a row from high to low.

Regex * repeats the previous element; wildcard * matches any string.

Base rows and columns carry the empty-string cases; most failures live there.
