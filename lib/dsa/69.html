Strongly Connected Components

Maximal groups of vertices that can all reach each other.

A. Pattern Overview

In a directed graph, a strongly connected component (SCC) is a maximal set of vertices in which every vertex can reach every other. Contract each SCC to one node and the result, the condensation, is always a DAG. Two linear-time algorithms find the SCCs: Tarjan (one DFS with low-links and a stack) and Kosaraju (DFS on the graph, then DFS on the reversed graph in decreasing finish order).

HOW OFTEN

Honest note: SCC rarely appears in LeetCode (Critical Connections is the undirected cousin of Chapter 59). It is, however, a standard senior-level tool: dependency cycles in build systems, deadlock detection, 2-SAT, and condensing a graph before DP. Learn the idea well; do not over-invest in memorising code.

Tarjan's low-link

DFS assigns disc[u] in visit order. low[u] is the smallest disc reachable from u's subtree using tree edges plus one edge to a vertex still on the stack. When low[u] == disc[u], u is the root of an SCC: pop the stack down to u; those vertices form the component. The "still on the stack" test is what separates cross edges to finished SCCs (ignored) from back edges into the current one.

Kosaraju in two passes

Pass 1: DFS on G, push vertices in finish order. Pass 2: process vertices in reverse finish order on the transposed graph Gᵀ; each DFS tree is exactly one SCC. Why: the vertex

finishing last belongs to a source SCC of G, which is a sink SCC of Gᵀ, so its DFS in Gᵀ cannot

escape the component.

Condensation and counting sources

To make a graph strongly connected by adding the fewest edges, count SCCs with in-degree 0 (s) and out-degree 0 (t) in the condensation: the answer is max(s, t) (when there is more than one SCC).

Functional graphs: a lighter special case

When every vertex has exactly one outgoing edge (Longest Cycle in a Graph, 2360; Maximum Employees to Be Invited, 2127), each component has at most one cycle; you can find cycles with timestamps or Kahn's algorithm without full SCC machinery.

E. Java Implementation

Tarjan, Kosaraju, condensation, longest cycle

StronglyConnected.java: Tarjan, Kosaraju, condensation, LeetCode 2360

import java.util.*;

/**
 * Ch 58: strongly connected components (Tarjan and Kosaraju); LeetCode 2360, 802.
 */
public class StronglyConnected {

    /** Tarjan: comp[v] = SCC id; ids come out in reverse topological order. */
    public static int[] tarjan(List<List<Integer>> g) {
        int n = g.size();
        int[] low = new int[n], disc = new int[n], comp = new int[n];
        Arrays.fill(disc, -1);
        Arrays.fill(comp, -1);
        int[] timer = {0, 0};                          // {clock, component count}
        Deque<Integer> stack = new ArrayDeque<>();
        for (int s = 0; s < n; s++)
            if (disc[s] < 0) dfs(g, s, low, disc, comp, timer, stack);
        return comp;
    }

    private static void dfs(List<List<Integer>> g, int u, int[] low, int[] disc,
                            int[] comp, int[] timer, Deque<Integer> stack) {
        low[u] = disc[u] = timer[0]++;

Java 17+

        stack.push(u);
        for (int v : g.get(u)) {
            if (disc[v] < 0) {
                dfs(g, v, low, disc, comp, timer, stack);
                low[u] = Math.min(low[u], low[v]);
            } else if (comp[v] < 0) {                  // v is still on the stack
                low[u] = Math.min(low[u], disc[v]);
            }
        }
        if (low[u] == disc[u]) {                       // u is the root of an SCC
            int v;
            do {
                v = stack.pop();
                comp[v] = timer[1];
            } while (v != u);
            timer[1]++;
        }
    }

    /** Kosaraju: DFS order on G, then DFS on the reversed graph in that order. */
    public static int[] kosaraju(List<List<Integer>> g) {
        int n = g.size();
        boolean[] seen = new boolean[n];
        List<Integer> finish = new ArrayList<>();
        for (int s = 0; s < n; s++) if (!seen[s]) finishOrder(g, s, seen, finish);
        List<List<Integer>> rev = new ArrayList<>();
        for (int i = 0; i < n; i++) rev.add(new ArrayList<>());
        for (int u = 0; u < n; u++) for (int v : g.get(u)) rev.get(v).add(u);
        int[] comp = new int[n];
        Arrays.fill(comp, -1);
        int id = 0;
        for (int i = n - 1; i >= 0; i--) {             // decreasing finish time
            int s = finish.get(i);
            if (comp[s] >= 0) continue;
            Deque<Integer> stack = new ArrayDeque<>();
            comp[s] = id;
            stack.push(s);
            while (!stack.isEmpty()) {
                int u = stack.pop();
                for (int v : rev.get(u))
                    if (comp[v] < 0) {
                        comp[v] = id;
                        stack.push(v);
                    }
            }
            id++;
        }
        return comp;
    }

    private static void finishOrder(List<List<Integer>> g, int u, boolean[] seen,
                                    List<Integer> finish) {
        seen[u] = true;
        for (int v : g.get(u)) if (!seen[v]) finishOrder(g, v, seen, finish);
        finish.add(u);
    }

    public static int count(int[] comp) {
        int k = 0;
        for (int c : comp) k = Math.max(k, c + 1);
        return k;
    }

    /** Condensation DAG: edges between distinct SCCs, deduplicated. */
    public static List<Set<Integer>> condensation(List<List<Integer>> g,
                                                  int[] comp) {
        List<Set<Integer>> dag = new ArrayList<>();
        for (int i = 0; i < count(comp); i++) dag.add(new HashSet<>());
        for (int u = 0; u < g.size(); u++)
            for (int v : g.get(u))
                if (comp[u] != comp[v]) dag.get(comp[u]).add(comp[v]);
        return dag;
    }

    /**
     * LeetCode 2360: longest cycle in a functional graph (each node has one out-
     * edge).
     */
    public static int longestCycle(int[] edges) {
        int n = edges.length, best = -1;
        int[] when = new int[n];                       // step at which a walk saw v
        int[] walk = new int[n];                       // id of the walk that saw v
        Arrays.fill(walk, -1);
        for (int s = 0; s < n; s++) {
            int u = s, step = 0;
            while (u != -1 && walk[u] < 0) {
                walk[u] = s;
                when[u] = step++;
                u = edges[u];
            }
            if (u != -1 && walk[u] == s) best = Math.max(best, step - when[u]);
        }
        return best;
    }
}

SPACE O(V + E)

Both algorithms return a component id per vertex. The DFS is recursive; for graphs deeper than a few thousand levels, convert to an explicit stack or run on a thread with a larger stack. Tests verify Tarjan and Kosaraju agree with a mutual-reachability oracle.

F. Detailed Dry Run

From the table: DFS from 0 reaches 1, then 2; the edge 2→0 goes to a stacked vertex, so low[2]

= 0 and low[1] = 0; vertex 2 also reaches 3, 4, 5 which close 5→3 (low 3). Back at 3: low[3] =

disc[3], so {3,4,5} pops first. Returning to 0: low[0] = disc[0] pops {0,1,2}. Vertex 6 then

starts a new DFS, sees 5 (already assigned: ignored) and 7; 7→6 makes {6,7} an SCC. Three

components, and Tarjan emits them in reverse topological order of the condensation.

G. Variations of the Pattern

2-SAT

Each clause (a ∨ b) gives implications ¬a → b and ¬b → a. The formula is satisfiable iff no

variable shares an SCC with its negation; an assignment follows from the topological order of the SCCs.

DP on the condensation

Collapse SCCs, aggregate their weights, then run longest-path / max-reward DP on the DAG with Kahn or memoised DFS.

Safe states (reverse thinking)

Find Eventual Safe States (802): nodes that can reach no cycle. Reverse the graph and run Kahn from terminal nodes, or use 3-colour DFS (Chapter 49). It is SCC-adjacent but needs no components.

Strong connectivity check

Whole graph strongly connected iff DFS from vertex 0 reaches all vertices and DFS on the reversed graph from 0 also does: two traversals, no Tarjan needed.

Dominant cycles in functional graphs

Maximum Employees to Be Invited (2127): cycles of length ≥ 3 stand alone; 2-cycles can be extended by the longest chains into each endpoint.

CHAPTER SUMMARY

An SCC is a maximal set of mutually reachable vertices; contracting SCCs yields a DAG (the condensation).

Tarjan: one DFS, disc, low, stack; low == disc marks a root and pops a component. Kosaraju: DFS, transpose, DFS in reverse finish order. Both O(V + E).

Use SCC for cycle groups, 2-SAT, DP on cyclic graphs and strong-connectivity repair (max(sources, sinks)).

Only compare low against disc of vertices on the stack; loop over all start vertices; recursion depth is a real risk.

SCC is rare on LeetCode; cycle detection (Ch 49) or bridges (Ch 59) usually suffices, but know the idea for senior interviews.
