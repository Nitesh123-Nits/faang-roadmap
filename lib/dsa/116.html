KMP and the Prefix Function

Never move backwards in the text: reuse what a partial match already told you.

A. Pattern Overview

Naive substring search restarts at the next text position after every mismatch, costing O(n m). Knuth-Morris-Pratt observes that after matching k characters, the pattern itself says which shorter prefix is still a valid partial match. That information is the prefix function pi[i]: the length of the longest proper prefix of p[0..i] that is also a suffix of it (a border). With pi, search is O(n + m) and the text pointer never goes backwards.

KEY IDEA

The prefix function answers a whole family of questions: borders, periods, repetitions, the shortest palindrome, and counts of every prefix as a substring.

Overlap between a string's prefix and suffix, or repeated search for one pattern: prefix function.

C. Core Intuition with Illustrations

The prefix function

Searching: reuse the border

Treat k as the number of pattern characters currently matched. On a mismatch, drop to pi[k-1] and retry; on a full match (k == m) record the hit and also drop to pi[m-1] so overlapping matches are found. The text index only increases.

Periods and repetition

If p = pi[n-1] and n % (n - p) == 0, the string is made of repetitions of its first n - p characters. abcabcabc: pi[8] = 6, 9 - 6 = 3, 9 % 3 == 0, so period 3, three repeats. The smallest period (no divisibility needed) is simply n - pi[n-1].

Shortest palindrome by prepending

Let t = s + '#' + reverse(s). The last prefix-function value is the length of the longest palindromic prefix of s. Prepend the reverse of the remaining suffix: aacecaaa has longest palindromic prefix aacecaa (7), so prepend a to get aaacecaaa.

Counting every prefix's occurrences

Count cnt[pi[i]]++ for each i, then propagate from long to short (cnt[pi[len-1]] += cnt[len]) and add 1 for each prefix itself. Total O(n). This is the same fact as "Sum of Scores of Built Strings" (Chapter 103).

TRAP

pi stores proper borders: pi[i] < i + 1. Forgetting that the whole string is not its own border gives infinite loops or wrong periods.

E. Java Implementation

Prefix function, search, period, shortest palindrome and prefix counts

KMP.java: prefix function and its applications
import java.util.*;

/** Ch 101: Knuth-Morris-Pratt; LeetCode 28, 459, 214, 1392. */
public class KMP {
    /**
     * pi[i] = length of the longest proper prefix of s[0..i] that is also a suffix.
     */
    public static int[] prefixFunction(String s) {
        int n = s.length();
        int[] pi = new int[n];
        for (int i = 1, k = 0; i < n; i++) {
            // fall back
            while (k > 0 && s.charAt(i) != s.charAt(k)) k = pi[k - 1];
            if (s.charAt(i) == s.charAt(k)) k++;
            pi[i] = k;
        }
        return pi;
    }

Java 17+

    /** All start indices where pattern occurs in text, O(n + m). */
    public static List<Integer> search(String text, String pattern) {
        List<Integer> hits = new ArrayList<>();
        int m = pattern.length();
        if (m == 0) {
            for (int i = 0; i <= text.length(); i++) hits.add(i);
            return hits;
        }
        int[] pi = prefixFunction(pattern);
        for (int i = 0, k = 0; i < text.length(); i++) {
            while (k > 0 && (k == m || text.charAt(i) != pattern.charAt(k)))
                k = pi[k - 1];
            if (text.charAt(i) == pattern.charAt(k)) k++;
            if (k == m) hits.add(i - m + 1);
        }
        return hits;
    }

    /** LeetCode 28: first occurrence or -1. */
    public static int strStr(String haystack, String needle) {
        List<Integer> r = search(haystack, needle);
        return r.isEmpty() ? -1 : r.get(0);
    }

    /** LeetCode 459: s is a repetition of a proper substring. */
    public static boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        int p = prefixFunction(s)[n - 1];
        return p > 0 && n % (n - p) == 0;
    }

    /** LeetCode 214: shortest palindrome by prepending characters. */
    public static String shortestPalindrome(String s) {
        String t = s + "#" + new StringBuilder(s).reverse();
        // longest palindromic prefix
        int keep = prefixFunction(t)[t.length() - 1];
        return new StringBuilder(s.substring(keep)).reverse() + s;
    }

    /** LeetCode 1392: longest proper prefix that is also a suffix. */
    public static String longestPrefix(String s) {
        return s.substring(0, prefixFunction(s)[s.length() - 1]);
    }

    /** Smallest period p such that s is built from repeating s[0..p). */
    public static int smallestPeriod(String s) {
        int n = s.length();
        int p = n - prefixFunction(s)[n - 1];
        return n % p == 0 ? p : n;
    }

    /**
     * Number of times each prefix occurs as a substring (sum over all positions).
     */
    public static int[] prefixOccurrences(String s) {
        int n = s.length();
        int[] pi = prefixFunction(s);
        int[] cnt = new int[n + 1];
        for (int v : pi) cnt[v]++;
        for (int i = n - 1; i > 0; i--) cnt[pi[i - 1]] += cnt[i];
        for (int i = 0; i <= n; i++) cnt[i]++;
        // occurrences of length 1..n
        return Arrays.copyOfRange(cnt, 1, n + 1);
    }
}

TIME O(n + m)

SPACE O(m)

Each iteration either increases k or decreases it along the chain; k increases at most n times, so total fall-backs are at most n: amortised O(1) per character.

G. Variations of the Pattern

KMP automaton

Precompute next[state][char] so each text character is one array lookup; useful for streams and DFA problems (Find All Good Strings combines it with digit DP).

Matching on a tree or in a trie

Failure links over a trie generalise pi to many patterns: Aho-Corasick.

Subtree of another tree

Serialise both trees (with null markers and separators) and test substring: O(n + m) with KMP instead of O(n m).

Counting distinct substrings

Incrementally append characters and use pi of the reversed string to count new substrings (O(n^2) total); suffix automata do it in O(n).

Minimum characters to append to make a string periodic

Answer comes straight from n - pi[n-1] combined with divisibility rules.

CHAPTER SUMMARY

The prefix function pi[i] is the longest proper border of p[0..i] and is computed in O(m) with the same loop used for searching.

Search follows borders instead of re-reading text, giving O(n + m) with the text pointer moving only forward.

Periods, repetition, rotation and shortest-palindrome questions all reduce to pi of a well-chosen string.

Fall back with pi[k - 1], and fall back after a full match so overlapping hits are found.

Use a separator character when concatenating strings, otherwise borders cross the boundary.
