Failure modes to design for

Stampede (thundering herd). A hot key expires and thousands of requests hit the DB. Use single-flight locking, request coalescing, soft TTLs or jittered expiry.
Penetration. Requests for keys that do not exist bypass the cache. Cache negative results briefly or use a Bloom filter.
Avalanche. Many keys expire together. Add random jitter to TTLs.
Hot key. One key overloads one cache node. Replicate it or add a small local (L1) cache.
Stale data. Delete on write rather than update, and set a TTL as a safety net.

HARD TRUTH

Cache invalidation is hard because the cache and the database are two systems updated non-atomically. Always state the staleness you accept, in seconds, for each cache.
