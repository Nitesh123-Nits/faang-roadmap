How Apple Pay Works

THE IDEA

Your card number never reaches the merchant; a device-bound token does.

HOW IT WORKS
1

Add card Card sent to the network once

2

Network issues token (DAN) Token tied to this one device

3

Stored in Secure Element Secure Element holds the key

4

Tap: one-time cryptogram One-time code for this payment

5

Network validates Network recomputes and approves

REMEMBER
Merchants see a token, never the card number.
A cryptogram works once, for one transaction.
Pattern: swap a real secret for a scoped stand-in.
DEEP DIVE

Apple Pay is a case study in tokenization. When you add a card, the card details go to the card network (via the issuer), which returns a Device Account Number, a token that stands in for the card and is bound to that one device. Apple does not keep the real number on the phone or its servers.

What happens at the terminal

The phone talks to the reader over NFC and receives the transaction details (amount,

merchant, a nonce).

The Secure Element, an isolated tamper-resistant chip, produces a cryptogram: a one-

time code computed from the token's key and those transaction details. Biometric approval gates this step.

Only the token and the cryptogram travel onward. The merchant never sees the card

number.

The network recomputes the cryptogram with its copy of the key. A match proves the

genuine device authorised this transaction, and the issuer then approves or declines.

Why this design is strong

Replay is useless. A cryptogram is valid for one transaction only.
Breach containment. A merchant database leak exposes tokens that cannot be used anywhere else.
Device binding. A stolen token without the Secure Element's key cannot generate valid cryptograms.
Revocation is cheap. The issuer can disable one token without reissuing the card.
TA K E AWAY

The pattern generalises: replace a high-value secret with a low-value, scoped, single-use stand-in, and keep the real secret in the smallest possible trusted boundary. Payment gateways use the same idea for card-on-file tokens.
